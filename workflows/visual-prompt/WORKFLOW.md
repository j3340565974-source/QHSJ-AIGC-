# 快速生成图片或视频提示词

> 工作流 ID: `visual-prompt`

**版本**: 8.0.0

**描述**: 快速生成图片或视频提示词

## 阶段
### V0 意图提取
**输入**: 用户白话描述

**输出**: 六大维度提取（时代/地域/题材/次文化/艺术运动/情绪）

**模块**:
- `06-aesthetics-style`

### V1 质感基底选择
**输入**: 意, 图

**输出**: 质感基底（真人摄影/3D CG/混合）

**模块**:
- `07-prompt-engineering`

### V2 视觉参数编译（并行）
**输入**: 意图 + 基底

**输出**: 完整提示词

**模块**:
- `07-prompt-engineering（主体/构图/光影/色彩/材质）`
- `03-cinematography（镜头参数）`
- `06-aesthetics-style（风格叠加）`
- `08-model-adapters（平台适配）`

**并行**: True

### V2.5 空间锚点与物理锁定
**输入**: 完整提示词 + 项目空间账本

**输出**: 带绝对方位坐标系、景别-取景半径匹配、单实例铁律、重力/动量/接触面/惯性/流体/光学锁定句的提示词

**模块**:
- `04-spatial-continuity（绝对方位坐标系、单实例铁律、景别-取景半径匹配）`
- `13-vfx-motion-physics（重力/动量/接触面/惯性/流体/光学/热力学/生物力学锁定）`

### V3 输出适配
**输入**: 编译好的提示词

**输出**: 目标平台格式的完整提示词

**模块**:
- `08-model-adapters`

## 门禁
- 图片/视频提示词必须携带空间锚点（绝对方位坐标系）与物理锁定项；缺失时返回 GATE_SPATIAL_PHYSICS_MISSING。
- 不得引用尚未锁定的资产（Asset-First 硬门禁，违反时返回 BLOCKED_ASSET_NOT_LOCKED）。

## 最终产物
- 正向提示词
- 负向提示词（或正向锁定句）
- 空间锚点与物理锁定清单
- 可调参数说明
