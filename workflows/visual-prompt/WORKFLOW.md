# 快速生成图片或视频提示词

> 工作流 ID: `visual-prompt`

**版本**: 7.0.0

**描述**: 快速生成图片或视频提示词

## 阶段
### V0 意图提取
**输入**: 用户白话描述

**输出**: 六大维度提取（时代/地域/题材/次文化/艺术运动/情绪）

**模块**:
- `06-aesthetics-style`

### V1 质感基底选择
**输入**: 意, 图

**输出**: 质感基底（真人摄影/3D CG/混合）

**模块**:
- `07-prompt-engineering`

### V2 视觉参数编译（并行）
**输入**: 意图 + 基底

**输出**: 完整提示词

**模块**:
- `07-prompt-engineering（主体/构图/光影/色彩/材质）`
- `03-cinematography（镜头参数）`
- `06-aesthetics-style（风格叠加）`
- `08-model-adapters（平台适配）`

**并行**: True

### V3 输出适配
**输入**: 编译好的提示词

**输出**: 目标平台格式的完整提示词

**模块**:
- `08-model-adapters`

## 最终产物
- 正向提示词
- 负向提示词（或正向锁定句）
- 可调参数说明
