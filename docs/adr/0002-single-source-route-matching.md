# ADR-002: 路由匹配单一数据源

- 状态：已采纳
- 日期：2026-10-18

## 背景

路由匹配逻辑若分散在 SKILL.md、后端、前端多处，容易出现规则不一致、维护困难。

## 决策

路由匹配算法的唯一权威实现位于 `backend/app/services/route_matcher.py`：

- 纯 Python 标准库实现，不导入 fastapi。
- 后端 `/route` 端点直接调用此模块。
- SKILL.md 仅描述算法概要，不重复实现。
- 前端只负责调用后端 API，不内置匹配逻辑。

## 后果

- 正面：规则一致，修改一处即全局生效。
- 负面：前端无法离线匹配，需后端服务运行。但对 Skill 运行时场景可接受。
