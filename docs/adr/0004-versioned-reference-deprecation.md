# ADR-004: 版本化参考文件的清理策略

- 状态：已采纳
- 日期：2026-10-18

## 背景

历史版本文件（`v322-` 前缀、`p1-` 前缀）与当前版本内容大量重复，占用知识库条目并可能造成混淆；仅标记 `> DEPRECATED` 而不清理会长期保留重复体积与陈旧引用。

## 决策

采用**原子化去壳**，一步完成、一步校验：

1. **抢救独有内容**：逐文件内容指纹比对，别名/门户文件中存在而主文件缺失的段落（如物理锁定层）先合并回权威主文件。
2. **删除壳文件**：仅剩纯副本或无独有内容的别名、门户、重复目录直接删除。
3. **同步重写指针**：删除前将全库 SPEC / WORKFLOW / 索引 / 文档中的指针重写为真实目标，删除后无悬空引用。
4. **索引对齐**：目录索引去除 `p1-` / `v322-` 前缀残留与重复条目，计数与 `manifest.json` 一致。
5. **防复发**：`check_package.py` / `check_content.py` 在每次 `make check-all` 中验证无悬空引用、无重复条目、计数一致。

## 后果

- 正面：当前版本文件成为唯一权威；仓库不再保留重复副本体积；陈旧引用归零。
- 负面：历史版本正文不再以文件形式留存，仅在 [CHANGELOG.md](../../CHANGELOG.md) / [migration-log.md](../migration-log.md) 中留下溯源记录。
