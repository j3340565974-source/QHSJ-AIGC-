# ADR-004: 版本化参考文件的废弃策略

- 状态：已采纳
- 日期：2026-10-18

## 背景

历史版本文件（v322- 前缀、p1- 前缀）与当前版本内容大量重复，占用知识库条目并可能造成混淆。

## 决策

- 所有 `v322-` 前缀文件标记为 `> DEPRECATED`，并注明 `替代:` 指向当前版本文件。
- 所有 `p1-` 前缀文件同样标记废弃。
- 保留文件不删除，以维持历史可追溯性与链接兼容性。
- `check_content.py` C9 校验：废弃文件必须包含 `替代:` 字段。

## 后果

- 正面：消除歧义，当前版本文件成为唯一权威。
- 负面：仓库仍保留旧文件体积。通过内容去重（C4）标记重复段落供后续清理。
