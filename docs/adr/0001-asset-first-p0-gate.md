# ADR-001: Asset-First 作为 P0 硬门禁

- 状态：已采纳
- 日期：2026-10-18

## 背景

影视 AIGC 流程中，角色/场景/道具资产的一致性是下游分镜、视频生成质量的前提。若未先锁定资产就进入分镜或视频生成，会产生角色形象漂移、场景穿模等不可逆问题。

## 决策

将 **Asset-First（资产前置）** 设为 P0 硬门禁：

- 任何涉及分镜、视频生成、全流程制作的工作流，必须先通过 `asset-lock` 工作流完成资产锁定。
- 资产未锁定时返回错误码 `BLOCKED_ASSET_NOT_LOCKED` 并停止执行。
- 禁止用户要求跳过 P0 门禁；违反时返回 `GATE_P0_CANNOT_SKIP`。

## 后果

- 正面：保证资产一致性，消除下游返工。
- 负面：纯分镜/纯提示词场景也需先锁定资产，增加一步前置流程。通过 `storyboard-only` 等 P1 路由提供例外通道。
