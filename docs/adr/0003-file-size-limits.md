# ADR-003: 文件大小限制与拆分策略

- 状态：已采纳
- 日期：2026-10-18

## 背景

Agent Skill 运行时对单文件加载有上下文预算限制。过大的文件会挤占上下文窗口，降低加载效率。

## 决策

强制文件大小上限：

| 文件类型 | 行数上限 | 字节上限 |
|---|---|---|
| SKILL.md | 500 | 24 KB |
| SPEC.md | 200 | 10 KB |
| WORKFLOW.md | 150 | 8 KB |
| reference .md | 300 | 12 KB |
| index.md | 100 | 4 KB |

超过限制的文件按 `##` 二级标题拆分为子目录下的多分片，原文件改为索引指向各分片。

## 后果

- 正面：单次加载可控，符合上下文预算。
- 负面：需要维护拆分映射；`check_package.py` 持续校验上限。
