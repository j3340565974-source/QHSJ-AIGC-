# QHSJ 空间、距离、朝向、视线与动作连续性账本

## 1. 适用范围

本模块用于分镜、关键帧、图生视频、追逐戏、打斗戏、双人对白、多人调度和连续镜头。它解决的不只是“角色在画面左还是右”，还包括角色之间的实际距离、身体朝向、头部转角、注视目标、摄影机位置、动作路径、接触关系和镜头首尾状态。凡是描述“看向某人”“伸手拿东西”“从门口走到桌边”“打中对方”“从上一镜接到下一镜”，都应建立可验证的空间状态。

## 2. 坐标与锚点

每个场景使用独立坐标系，必须先选择稳定原点和方向，例如：入口门框中心为 `(0,0,0)`、室内向北为 `+Y`、向东为 `+X`、地面为 `Z=0`。如果没有实测尺寸，使用相对单位，并写明尺度假设；禁止把未经测量的相对描述伪装成真实米数。

建立固定锚点：门、窗、墙角、楼梯、柱子、桌沿、车门、床沿、主要灯源和明确地面标志。每个锚点必须有 ID、位置、尺寸/范围、是否固定、是否可移动和引用资产。视角改变不等于锚点移动。

## 3. 人物状态变量

每个镜头中，每个出场人物必须按需补齐以下字段：

- `character_id`：引用锁定角色资产，不在分镜里另造角色版本。
- `root_position`：脚底/骨盆的场景坐标或可复现的相对位置。
- `body_yaw`：身体水平朝向，说明以人物自身前方为基准还是以场景方位为基准。
- `head_yaw_pitch`：头部相对身体的转角/俯仰。
- `gaze_target_id`：注视目标的角色、道具、场景锚点或画外指定点。
- `eye_line`：注视方向是否与目标可见位置相交；目标不在画面内时，需记录屏幕外方位。
- `stance_and_balance`：双脚支撑、重心、躯干倾斜、手部任务。
- `action_phase`：准备、启动、加速、接触、受力、恢复、停稳等阶段。
- `held_prop_ids`：手持道具及其状态；左右手不可在无动作的情况下互换。
- `distance_constraints`：与其他角色、道具、边界和摄影机的必要距离。
- `screen_position`：当前构图中的左/中/右、前景/中景/背景及遮挡关系。

不必对每个静态镜头都给每个变量填精确数字，但影响动作、注视、构图或连续性的字段必须明确，不能留给生成模型随意猜测。

## 4. 人物间距离与交互可行性

根据动作需求判断距离区间，而不是机械套一个万能数值：近距离对白、伸手触碰、握手、拥抱、踢击、挥拳、兵器长度、追逐速度和摄影机安全距离需要不同判定。每次写出具体数字时，必须说明其来源：实际场景尺寸、角色身高比例、道具规格、导演给定值或明确标注的估算。若没有根据，只写“触手可及”“一臂距离”“需跨一步”等可观察关系，不捏造精确测量。

接触动作必须满足：动作发起位置、行进路径、有效距离、接触点、受力方向、目标反应、重心转移和恢复状态互相吻合。若角色手臂长度不足以到达目标，必须改变站位、动作或镜头设计；不能依靠提示词形容词掩盖几何错误。

## 5. 视线规则

每条注视都写清楚“谁看向什么”：注视主体 ID、目标 ID、目标当前坐标、头部方向、眼球方向、持续时段和情绪意义（只在对表演有用时写）。双人对话必须核对视线高度和目标方位；摄影机越到轴线另一侧时，需要重新核验屏幕方向。镜头切到被看对象时，目标的位置应与上一镜眼线相容。角色如果低头看手机，眼睛不能仍平视对手；角色如果盯着远处的车，头部和眼睛必须朝向车所在方向。

没有明确目标的“目光坚定”“看向远方”属于不可验证表述。应改为：“她的目光落在走廊尽头半掩的门缝，头部向右转约二十度，视线在门把手高度停留两秒”，只有在场景布局允许且精度有意义时才给角度/时间数字。

## 6. 摄影机状态

每个有空间连续性要求的镜头应记录摄影机所在场景、坐标/站位、镜头高度、镜头朝向、视线高度、焦段、移动路径、起点、终点、运动速度变化和轴线侧。运镜说明要可执行，如“从门外距门框约两步的位置沿走廊缓慢前移至角色胸前中景”，优于“电影感推进”。机位不可穿过墙、家具或演员身体；需要越过障碍时，必须设计绕行路径、转场或明确的剪辑省略。

摄影机移动与演员移动要分开写，再检查两者相对速度。镜头写“持续环绕一周”时，必须确认可用时长、半径、遮挡和演员动作允许；不能同时要求摄影机固定不动又全程跟随角色移动。

## 7. 镜头起态、终态与下一镜接续

每镜建立 `state_in` 和 `state_out`，至少追踪角色位置/朝向、手部、道具、门窗状态、受伤/湿润/污渍、光源变化和相机轴线。下一镜的 `state_in` 应与上一镜 `state_out` 一致；如果故意跳切，要记录“变化原因、时间间隔、剪辑动作或画外事件”。无解释的位移、道具换手、衣服干湿改变、伤口消失、灯光反向和背景结构变化都属于连续性缺陷。

## 8. 动作时间和物理检查

把复杂动作拆成能够在指定镜头时长内完成的阶段。按需估算位移、速度、加速度、关节活动范围、制动距离、惯性、碰撞顺序、受力反馈和恢复时间。摄影描述不能要求违背重力、摩擦、支撑和物体质量的动作，除非用户明确要求超自然效果；超自然效果也必须说明其规则、启动条件、作用对象、视觉反馈和结束状态。

对于飞行、爆炸、坠落、车辆运动或多人打斗，必须同时检查地形、轨迹、摄影机、碰撞物、碎片方向、尘土/液体反馈及人物反应。特效光源应照亮附近表面，烟尘应受风向和遮挡影响，布料和头发应对运动与气流作出有因果的反应。

## 9. 输出账本格式

| 字段 | 必填说明 |
|---|---|
| 场景 ID / 规范资产版本 | 镜头所引用的唯一环境资产 |
| 镜头 ID / 时间码 | 镜头顺序和时长 |
| 角色 ID / 状态 | 出场角色和可见状态 |
| 坐标 / 固定锚点 | 人物与场景之间的空间关系 |
| 身体朝向 / 头部朝向 | 身体动作和目光方向分开记录 |
| 注视目标 / 眼线 | 目标 ID、目标方位、注视时段 |
| 人物间距离 / 接触关系 | 几何与动作可行性 |
| 摄影机位置 / 轨迹 | 机位、轴线、运动范围 |
| 道具状态 / 持有者 | 所有权、手别、位置、开合/损坏状态 |
| 起态 / 终态 | 本镜开始与结束的空间快照 |
| 变更或例外 | 对连续性破坏的明确叙事理由 |

## 10. 路由触发

出现“站位、轴线、越轴、看向哪里、眼神对不上、人物距离、伸手够不到、动作接不上、相机穿墙、镜头空间不连贯、手里道具换边、走位不合理、视线方向、起态终态、位置锁定”等需求时，路由 `spatial_continuity`，按类型叠加 `cinematography`、`performance_emotion`、`action_choreography`、`vfx_physics` 和 `quality_assurance`。若用户只要文字分析，不要擅自生成图片/视频提示词；若需要分镜资产，必须引用锁定资产 ID。
