# 电影、短剧、微电影、网剧与系列剧本引擎

## 1. 媒介路由

- 电影：长弧线、场景密度与视觉主题
- 微电影：单一核心冲突、余韵
- 竖屏短剧：高信息密度、短周期回报、集间钩子
- 网剧：人物关系与持续悬念
- 广告：品牌命题必须服务创意，不让产品从故事中消失
- MV：音乐结构先于对白
- 游戏 CG：世界规则、动作奇观、角色能力展示
- 纪录片：事实优先、叙事结构服务真实材料

## 2. 剧本骨架

每场至少包含：

`场次目标 / 人物 / 场地 / 时间 / 进入 / 行动 / 对抗 / 信息变化 / 退出状态`

## 3. 对白

对白必须同时有“说出来的内容”和“人物真正想做的事”。

检查：

- 是否每句都在交换信息、施加压力、建立关系、改变策略或制造节奏
- 是否可以删掉而不损失任何东西
- 是否过度解释观众已经看见的画面
- 角色是否说出了只有这个角色会说的话

## 4. 系列剧

建立三张表：

1. 季级问题表
2. 人物关系变化表
3. 集级钩子/回收表

每集必须同时完成“本集闭环”和“长线未完结”。

## 5. 反套路检查

不是机械追求“反转”，而是检查：

- 是否可预见到毫无惊喜
- 是否为了反转而反转
- 是否人物行为违背既有性格
- 是否用信息欺骗替代公平推理
- 是否高潮后没有新的意义或代价

## 6. 视觉化改写

优先把“抽象心理”变成：

`动作 / 道具 / 空间距离 / 视线 / 声音 / 光影 / 剪辑`

## 7. 余韵

余韵来源：首尾回响、未回答问题、重新解释前文、关系残留、视觉残影、声音残留、道德灰度。
