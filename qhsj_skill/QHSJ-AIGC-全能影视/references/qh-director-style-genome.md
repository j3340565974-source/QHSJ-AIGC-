## 一、昆汀风格体系

### 1.1 观看逻辑三选（提示词先设计观看方式，再设计表面光色）

**① 空间嵌入**：不要只写"低机位仰拍广角"，必须说明摄影机被放在场景内部什么位置。
- 后备箱：摄影机贴近货厢锁扣，人物从开口外俯视
- 餐桌：摄影机贴着桌沿或夹在杯具之间，人物被物件局部切分
- 车内：摄影机位于主副驾之间、后排中央或仪表台边缘
- 商店：摄影机嵌在柜台转角、收银机与商品之间、冷柜内部边缘

写清物理位置、离地高度、朝向、与前景物距离、遮挡比例、主体可见范围。嵌入不是鱼眼畸变，也不是让黑色容器边框吞掉画面。

**② 物件凝视**：区分"语义主体"和"视觉锚点"。明确四件事：第一眼看见什么；第二眼看见谁及动作；物件/人物/环境的权重顺序；物件为什么值得持续观看。物件作为视觉锚点可占20%-40%，人物退居边缘或次级。不要同时让多个物件争夺凝视权。

**③ 镜头滞留**：图片不能真正延迟切镜，但可表现"来自一段长时间固定观察中的某一帧"。线索：摄影机长时间不动人物只做极小/重复/迟疑动作；主要动作已完成镜头仍停留物件上；物件持续占据中心人物进出边缘；视线/手指/液体/机械停留在未被叙事消耗的状态。

**强度选择**：1=只用一种观看逻辑（通常是空间嵌入）；2=用两种（空间嵌入+物件凝视 或 空间嵌入+镜头滞留）；3=三种同时成立但仍只保留一个视觉锚点。

**关键**：潜在威胁、黑色幽默、枪械、雨夜、霓虹和鲜艳色块都不是这三项逻辑的替代品。

### 1.2 默认浓色胶片响应（签名色）

**核心：复古不等于低饱和。**

22个镜头统计：平均亮度0.313，阴影49.9%，中间调41.2%，高光8.9%；平均饱和度0.536，高饱和区域43.3%。

**执行范围**：
- 阴影约40%-65%、中间调约30%-50%、高光约5%-15%（防灰防过暗的校准区间）
- 至少一个场景色/服装色形成约20%-50%的连续中高色密度区域；第二色约10%-30%；小强调色约3%-10%
- 近黑浓密但不是无色死黑，可受相邻布景轻微染成酒红/暖紫/墨绿/深蓝，同时保留头发衣料空间边界
- 白衬衫/雪地/浅色墙面/日光高光保持明亮奶油色或略带染料偏色，不压成灰白
- 肤色处于饱满中间调，保留红黄粉棕变化；环境偏色只轻微进入暗部，不把肤色统一染橙
- 高光有柔和滚降和很轻的光化扩散，彩色灯点浓而不荧光

**提示词句法**：
```
默认浓色胶片响应：复古不等于低饱和；以一个连续中高色密度主场配合清楚的第二色和小强调色，
白色与肤色处于饱满中间调，近黑浓密并接受相邻主色的轻微染料偏色，高光柔和滚降，
避免灰褐平均化和现代青橙调色。
```

**否决项**：用户没要求时用"低饱和/灰调/褪色/压暗/阴郁冷灰"做总体成像目标；最大色块是低饱和灰褐而人物服装与背景明度相近；夜景只剩青黑环境和橙色肤色；为胶片颗粒牺牲白色肤色纯色块连续性；阴影超过75%却没有剪影/极暗环境/用户硬性要求作为理由。

### 1.3 光色架构三模式（只选一种主模式，不混成平均彩色照明）

**① 图形纯色场**（适合表演性/仪式性/主观化场景）
- 一个干净主色占35%-65%，落在整面墙/窗格/地面/幕布/连续灯光区域
- 深色/中性色承托区占25%-50%，负责人物轮廓和负空间
- 强调色不超过10%，只落在人物服装/道具/一处实景光

**② 从黑位建立的方向性照明**（适合对话/等待/交易/发现中的张力）
- 先确定深色基底，再用一个明确方向的窗光/顶光/侧光/实景灯切出主体
- 指定照明覆盖区（如"只照亮手、面部与桌面中央"）+ 禁光区（如"远墙、天花板不接受补光"）
- 背景比主体低约一至两档；亮部集中在3%-10%局部区域，形成硬边窄光带

**③ 心理性光色转换**（只用于主观/表演性/情绪明显转折的画面）
- 两个有物理来源的色温区域，但只让其中一个占主导
- 静态图片写成"转换过程被截取的一帧"，不要伪装成均匀双色棚拍

### 1.4 17槽位提示词模板（写成一段自然连续的中文，不展示字段名）

1. 画幅与图像媒介 → 2. 时间与地点 → 3. 人物参考/选角/身份/服装 → 4. 人物位置 → 5. 当前动作 → 6. 目光方向 → 7. 潜在冲突 → 8. 关键道具 → 9. 摄影机位置 → 10. 焦段与景别 → 11. 构图与空间关系 → 12. 主光来源 → 13. 主光方向/覆盖区/禁光区/背景相对曝光 → 14. 浓色胶片响应+色块面积落点 → 15. 材质 → 16. 35mm负片-印片响应 → 17. 负面约束

**写法优先级**：一级约束锁（用户明确给的主体/人数/身份/地点/时间/动作/朝向/关系/视线/画幅/机位/焦段/景别/构图/颜色）> 摄影机嵌入位置+视觉锚点权重 > 表面光色。风格补充与一级约束冲突时，删除风格补充，不折中用户要求。

### 1.5 输出校准七节清单

0. **一级约束一致性**：每个新增动作/视线/冲突/道具必须通过兼容检查；会改变一级约束就删。"过渡瞬间"只能改变重心/关节/脚步/衣料/动作完成度，不能改变关系轴。
1. **主体与画面层级**：第一眼必须看见设计好的视觉锚点；第二眼发现用户语义主体及关键动作。只能有一个主导物件。
2. **曝光与颜色**：先执行浓色胶片响应；检查光色布置卡五要素（主光方向/覆盖区/禁光区/背景相对曝光/色块面积落点）缺一不可；检查是否落入"冷青环境+暖橙皮肤+湿地反光"流媒体套路。
3. **摄影机物理合理性**：写清镜头位于场景内部哪里；24mm以下超广角只在空间变形本身有叙事作用时用；人物主导低位主观优先28-35mm。
4. **类型片质感**：检查人物是否有明确关系动作；动作状态服从观看节奏（推进用过渡瞬间，滞留用微小重复迟疑）；35mm负片-印片响应（主色有印片密度/近中性浓黑保留暗部层次/中间调饱满/肤色保留红黄变化/高光柔和滚降/不规则颗粒）。
5. **观看逻辑检查**：空间嵌入是否有具体非常规但物理可行的位置；物件凝视是否明确第一眼第二眼权重；镜头滞留是否像从固定凝视中截出而非广告画面；表面标签（雨夜/湿地/霓虹/青橙/枪械/黑西装）不能代替前三项逻辑。
6. **时代与地域**：场所年代≠故事年代；老式建筑可出现在当代；未指定年代默认当代/时代中立；未指定地域不加外语标牌/国旗/地标。
7. **反馈迭代**：对比主体占比/遮挡占比/平均明度/阴影中间调比例/肤色可读性/色块关系；单次差异记录为输出缺陷，多次重复才升级为稳定负面规则。

## 二、诺兰硬色彩签名

### 2.1 四区颜色关系

| 区域 | 颜色 | 禁止 |
|------|------|------|
| 阴影与黑位 | 深青绿/墨绿青/蓝绿黑/带青绿环境反射的浓黑 | 中性黑/纯黑/棕黑/只降亮度不改色相 |
| 中间调 | 道路/墙体/灰衣/动物毛发/植被/空气透视统一带连续青灰绿或灰青绿偏色 | 只植物绿而道路天空衣物保持中性灰 |
| 高光 | 脏暖灰/灰黄/旧象牙/微暖乳白 | 高饱和橙黄/干净蓝白/银蓝白/纯白HDR边缘 |
| 强调色 | 最多一个小面积低亮度现实强调色（暗红项圈/旧橙外套/锈褐砖墙） | 扩散到整个高光区/与青绿形成商业大片式强青橙对撞 |

### 2.2 选择性饱和（不是"低饱和"）

不要写"低饱和度"（会洗成近乎黑白中性灰）。写成：**"选择性压低鲜红、鲜黄、纯蓝和无关杂色，同时保留青绿阴影与青灰绿中间调的色彩密度。"** 目标是颜色集中而不是颜色消失。

### 2.3 影调结构

- 阴天暮色外景：画面重量落在深色和浓中间调，高光只集中天空/窗面/少量反光；深色约55%-65%，高亮约15%-22%
- 夜景室内：可整体更暗，但中间调仍带青灰绿，高光仍偏旧象牙/脏暖灰
- 明亮日景雪地：可增加高亮占比，但雪云白墙水面仍用暖灰白/旧象牙高光，阴影维持青绿
- 沙漠火光暖色：沙土火焰木材皮革保留本地暖色；阴影仍向青绿/蓝绿黑收敛，高光仍为低色度暖灰

### 2.4 诊断锚点（仅检查同类阴天生成结果时用，不写入提示词）

- 中位饱和度约0.25-0.35（低于0.12=青绿密度消失）
- 阴影与中间调Lab a*约-5到-11（接近0=退回中性灰）
- 高光Lab b*约+4到+10（≤0=偏中性白或冷白）

### 2.5 失败检查

- 绿色是否只存在于树草而道路墙体衣物仍是中性灰？→ 强化连续中间调偏色
- 天空反光是否干净蓝白？→ 改为旧象牙/脏暖灰
- 黑色毛发衣物树林是否无色死黑？→ 恢复青绿环境反射和暗部层次
- 画面是否因"低饱和"接近黑白？→ 恢复青绿家族选择性色彩密度

## 三、韦斯安德森对称体系

### 3.1 构图铁律

- **默认严格正面中央对称**：正面平视、相机水平、地平线水平、建筑正立面与画面边缘平行
- **禁止荷兰角/斜拍/歪地平线/随手倾斜透视/极端广角建筑歪斜**
- **竖线切脸禁令**：严禁可见竖线（电线/柱子/墙缝/门缝/地砖缝/标牌支杆/窗框中梃）穿过人物脸/头部/脖子/躯干/双腿之间
- 两侧元素尽量成对出现：两排椅子/两排洗衣机/两排植物/两盏灯/两个窗/两摞箱子
- 柔性对称和偏中心平衡可以用，但不能牺牲水平感

### 3.2 画面骨架类型

| 骨架 | 特点 | 适用 |
|------|------|------|
| 正立面建筑 | 舞台正面摆放，主体中央，两侧窗门油泵路灯盆栽平衡 | 小旅馆/售票亭/加油站/甜品店/邮局/灯塔 |
| 室内盒子 | 浅景深舞台盒子，后墙平行画面，天花灯墙板窗帘床柜台桌椅挂画成对重复 | 卧室/餐厅/药房/柜台/候车厅 |
| 纵深通道 | 中心消失点，左右两排机器植物桌子窗格灯具整齐后退 | 洗衣房/温室/车厢/走廊 |
| 框中框背影 | 人物背对镜头居中站在门窗柜台前，外景作为完整背景 | 门/窗/阳台前 |
| 陈列墙 | 地图钟表标本时刻表药瓶行李箱按网格行列左右成组排列 | 博物馆陈列/柜台展示 |

### 3.3 复古明亮配色（1960s-70s胶片/旧印刷品/保存良好彩色明信片）

**不是发灰**：旧胶片感来自色彩组合、布景和轻微颗粒，不来自脏雾/低亮度/整体灰罩。

常用组合：
- 粉红+奶油白+天蓝+暖棕
- 薄荷绿+黄油黄+橙红+铜色
- 湖蓝+珊瑚粉+象牙白+旧木色
- 芥末黄+橄榄绿+酒红+暖金
- 蜜桃橙+焦糖棕+玫瑰粉+米白

### 3.4 人物调度

- 表情克制安静微妙冷幽默，不大笑不大哭不夸张惊恐
- 动作小而精确：站着等车/端托盘/扶门把/拿信封/对视/低头看菜单/抱包裹
- 优先"动作进行到一半"的电影瞬间，不是摆拍完成态
- 情绪像"事情不太对劲，但所有人都保持礼貌"

### 3.5 负面提示词分类

禁止：斜拍/歪地平线/荷兰角/建筑歪斜/竖线穿脸/现代霓虹/赛博朋克/恐怖片冷绿/过度高饱和塑料色/整体发灰/雾霾感/低亮度旧照片感/网红摆拍/夸张姿势/戏剧化动作。
