# 04 - 空间一致性引擎

## 一、核心原则

**永远先算空间，再写分镜。**

空间穿帮是AI视频最常见的崩坏原因之一。站位不对、轴线乱了、人物突然左右互换、手里的道具消失了——这些都是空间推演没做好。

## 二、最低空间检查清单（10项）

每个场景必须确认：

1. ☐ **场景锚点**：这个场景有哪些固定参照物？
2. ☐ **世界坐标映射**：屏幕左右 = 角色自身的哪边？
3. ☐ **初始站位**：每个角色一开始站在哪？
4. ☐ **行动路径**：角色从哪走到哪？
5. ☐ **180°轴线**：对话/对峙的轴线在哪一侧？
6. ☐ **视线关系**：谁看谁？视线方向对不对？
7. ☐ **机位可达性**：这个角度从哪拍？能拍到吗？
8. ☐ **前后状态传递**：上一镜结束时人物在哪？下一镜开始时还在那吗？
9. ☐ **终帧检查**：这一镜结束时所有东西都在哪？
10. ☐ **下一镜起帧回读**：下一镜开始时和上一镜终态对得上吗？

## 三、180°轴线规则

对话戏/对峙戏必须守住轴线：

- 两个角色对话时，想象他们之间有一条连线
- 摄影机只能在这条线的同一侧拍
- 一旦越线，角色的左右方向就反了，观众会混乱
- 如果必须越线，中间必须加一个中性镜头（正面/背面/全景）过渡

**"左/右"默认是观众屏幕视角**；角色自身左右必须标注"自身"。

## 四、站位声明格式

短剧/多角色群像场景，用一行式【站位声明】：

```
【站位声明】场景：客厅
轴线：横向（观众视角左=角色A自身右）
角色A：画面左侧，面朝右，距沙发1米
角色B：画面右侧，面朝左，距茶几0.5米
道具：茶几在两人中间偏前
位移：B向A走近0.5米
```

## 五、顶视图机位推演

复杂群戏或动作戏，先在脑中（或纸上）画顶视图：

- 场景平面图
- 所有角色和道具的位置
- 摄影机位置和朝向
- 轴线位置
- 运动路径

确认无误后，再开始写分镜。

## 六、空间语言翻译

导演层可以用坐标和专业术语，AI输出层必须翻译成模型可见的自然语言。

| 导演层语言 | AI输出层语言 |
|---|---|
| 180°轴线 | 保持人物左右方向一致 |
| 过肩镜头 | 从角色A肩膀后方拍角色B |
| 反打 | 切换到角色B的视角看角色A |
| 机位高度1.5米 | 与人眼平齐的高度拍摄 |
| 焦距50mm | 接近人眼视角的自然镜头 |

## 七、常见穿帮类型

1. **左右反转**：上一镜人物面朝左，下一镜突然面朝右（没转身）
2. **道具瞬移**：手里拿的杯子，下一镜没了，再下一镜又回来了
3. **位置跳变**：人物从房间左边突然出现在右边，没有走的过程
4. **视线错位**：两个人对话，眼睛不看对方，看向画面外
5. **比例失调**：同一个人，这一镜头很大，下一镜头很小
6. **背景跳变**：背景里的建筑/树木位置突然变了
