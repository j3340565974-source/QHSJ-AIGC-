# 参考图、参考片、参考镜头反推引擎

## 1. 七要素

`主体 / 构图 / 空间 / 摄影机 / 光影 / 材质 / 显影`

视频增加：

`动作 / 时间 / 镜头节奏 / 声音 / 转场 / 连续性`

## 2. 事实分层

- A：画面直接可见
- B：高可信推断
- C：不可从画面确认

C 类不能伪装成事实。

## 3. 图片反推

先做结构描述，再做风格描述，最后做模型 Prompt。禁止一上来堆“8K、电影感、超精细”。

## 4. 视频拉片

逐镜记录：

`镜号 / 时长 / 景别 / 构图 / 主体 / 动作 / 摄影机 / 焦点 / 光 / 声 / 剪辑功能 / 终帧`

## 5. 一比一还原

如果用户要求 1:1：

- 资产层尽可能精确
- 结构层尽可能精确
- 风格层提取可见特征
- 对不可见内部参数标“无法确认”

## 6. 风格抽取

如果用户只想要“类似感觉”，输出“风格属性”，不要复制具体对象。

## 7. 反推失败诊断

若生成结果不像参考图，判断是：

`资产不一致 / 构图不一致 / 光线不一致 / 材质不一致 / 模型不支持 / Prompt 过载 / 参考素材质量不足`
