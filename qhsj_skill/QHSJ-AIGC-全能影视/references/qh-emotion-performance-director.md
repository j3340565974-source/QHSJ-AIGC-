# QHSJ 情绪表达导演（减法微表情/转场模式/表情线索/表演连续性）

# 人物情绪表演导演

把情绪当作一段表演过程，而不是一个形容词。描述观众能够看见或听见的变化，使人物在有限时长内自然地进入、维持、泄露并完成情绪。

## 识别任务

先提取以下信息；缺失时采用默认值，不为非关键细节反复追问：

- 人物、场景和参考素材
- 初始情绪、目标情绪和隐藏情绪
- 触发情绪变化的事件、动作或台词
- 时长、景别、机位和是否允许切镜
- 台词原文、语言、语气或方言
- 表演强度：1–3 克制，4–6 自然，7–8 强烈，9–10 爆发

默认采用 5 秒、4–6 级自然影视表演、稳定近景或面部特写、单镜头、轻微自然身体反应。若上传人物图，默认保持原人物身份、五官、发型、服装、场景、构图与画面风格，只改变用户要求的表情和必要动作。

根据任务选择模式：

- **单一表情**：建立表情、产生细小活变化、自然回落或停留。
- **渐变情绪**：从 A 缓慢过渡到 B，保留明确的中间状态。
- **转折情绪**：先维持 A，经触发点与抵抗阶段转向 B。
- **混合情绪**：让两种情绪同时留在脸上，如笑中带泪、愤怒中的心软。
- **台词表演**：把面部变化、视线、呼吸和动作绑定到具体字句与停顿。
- **双轨长镜头**：保持举枪、驾驶、守卫、行走等外部任务线稳定，让内部情绪经历裂缝、压回、反弹和最终失守。

## 设计表演

按以下顺序完成复杂情绪，必要时压缩，但不得跳过过渡逻辑：

1. 建立初始状态和表情强度。
2. 设置可理解的触发点。
3. 让人物短暂维持、掩饰或抵抗原有表情。
4. 用一至两个微表情泄露真实情绪。
5. 保留 A 与 B 短暂并存的桥接状态。
6. 让目标情绪完成转折并停留片刻。

优先使用眼神、眼睑、眉间、嘴角、嘴唇、下巴、呼吸和头部的细微变化。需要细化表情时读取 [references/qh-facs-micro-expression.md](#表情动作参考)；需要选择转折结构和时长分配时读取 [references/qh-emotion-beat-curve.md](#情绪转折与时间轴)。每次生成或改写人物表情视频提示词时，读取 [references/qh-facs-micro-expression.md](#减法式微表情提示词)，用“强度控制 + 动作归因 + 时间顺序”检查并精简表演。遇到长镜头、演技派、情绪层层失守、边执行任务边发生情绪变化或参考视频式表演时，必须读取 [references/qh-acting-systems.md](#双轨长镜头与演技连续性)。

## 设计双轨表演

先锁定外部任务线，再设计内部情绪线：

- **外部任务线**：人物正在持续完成什么动作，哪些姿态、道具、方向和空间关系不得改变。
- **内部情绪线**：人物公开表现什么、真实感受什么、此前情绪还残留多少、在哪一刻出现裂缝。

除非剧情或用户明确要求，不要因为人物害怕、悲伤或流泪就擅自让其放下武器、停车、转身、低头、后退、捂脸或停止任务。优先让外部动作保持稳定，在眼神、呼吸、嘴部和面部肌肉中表现冲突。

不要把情绪写成互相替换的面具。新情绪出现时保留旧情绪的痕迹，例如“职责警觉仍在，认出对方后的惊恐渗入，随后悲痛和自责覆盖上来”。长镜头优先使用波浪式变化：

```text
维持控制 → 出现裂缝 → 短暂压回 → 情绪反弹 → 再次控制失败 → 最终失守
```

确定关系视线锚点。人物可以短暂闭眼、失焦或侧移视线，但若任务和关系要求持续注视对方，应让视线重新回到对方，不要用随机游移替代演技。

## 应用减法式微表情

坚持“少即是多，动即是稳”：不要让模型全力摆出情绪，而要让情绪成为动作、视线和呼吸自然产生的结果。

1. **控制强度**：优先使用微弱、轻微、几乎看不见、克制等程度，避免默认满格表演。
2. **动作归因**：先写人物因为什么而低头、移开视线、闭眼、换气或放松肩膀，再写表情浮现。
3. **时间顺序**：至少建立起始状态、触发或变化动作、最终微表情；复杂转折继续使用完整情绪弧线。

只选择与情绪有因果关系的一至三个物理动作。不要为了“生活感”机械加入咬唇、挽头发、挠头、揉眼睛等动作，也不要让这些动作改变人物性格或剧情。

遵守以下原则：

- 把“开心、悲伤、温柔”等抽象词转换为可见动作，但不要机械罗列所有五官。
- 每个阶段选择二至四个最有辨识度的线索，并保持因果连续。
- 先让眼神或呼吸变化，再让嘴角和泪水完成转折，避免突然变脸。
- 允许自然的不完全对称、短暂停顿、换气和轻微回落，避免表情像静止面具。
- 让身体动作服从剧情、人物关系和外部任务；除非用户要求，不加入大幅摇头、捂脸、后退或戏剧化肢体动作。
- 不擅自改变用户给出的剧情事实、人物关系、台词、情绪落点和镜头限制。

## 编排台词

原样保留用户给出的台词，不擅自续写。把台词放入具体时间段，并说明：

- 开始说话的时点和说话对象
- 音量、语速、语气、重音与停顿
- 哪个字句触发表情变化
- 说完后的呼吸、视线与余韵
- 台词口型和声音情绪与面部表演同步

台词较长而时长不足时，先指出冲突，再给出最小改动方案；不要悄悄删词。多人台词必须标清说话者和轮次。

没有明确台词时，允许设计“未完成表达”：人物像要叫出名字、解释或求证，嘴唇先轻启，声音却被呼吸、哽咽或犹豫堵住。只描写可见和可听反应，不擅自补出台词内容。

## 编写视频提示词

默认直接输出一段可复制使用的完整中文提示词，不输出分析过程。按以下顺序组织：

1. 时长、景别、机位、人物、外部任务与镜头稳定要求
2. 关系视线锚点、按事件顺序排列的语义节拍与连续表演
3. 台词、语气、声音和口型同步
4. 最终情绪落点与停留
5. 仅保留必要的负向约束

根据用途选择时间表达：

- **Seedance 生成模式（默认）**：总时长只在开头提及一次，并提醒用户在生成设置中选择相同总时长。正文使用“开场、随后、中段、短暂压回、后半段、结尾”等语义节拍，不给每个阶段标注精确秒数或小数秒。让模型按事件因果自然安排节奏。
- **通用视频模型模式**：若没有可靠的精确时间控制说明，同样使用语义节拍。
- **分镜脚本或后期剪辑表模式**：只有用户明确要求分镜表、剪辑点或逐秒规划时，才输出具体时间码；明确这些时间码用于创作规划，不代表生成模型会逐帧执行。

普通复杂转折使用 3–4 个语义节拍，8–15 秒双轨长镜头使用 4–6 个语义节拍。每一节拍只承担一个主要变化，前后动作必须连续。优先写自然语言，不写参数堆砌。

常用稳定性约束按需选择：保持人物身份与五官稳定；不突然变脸；不表情冻结；不夸张挤眉弄眼；不无故大哭或大笑；不面部扭曲；不漂移视线；不增加人物、台词、字幕或镜头切换。不要把所有约束机械追加到每次输出。

## 处理歧义

根据上下文区分“喜极而泣”“悲伤穿透笑容”“伪装的笑崩溃”等不同逻辑。若不同解释会显著改变表演结果且上下文不足，用一个简短问题确认；否则选择最合理解释，并在提示词中自然落实，不额外解释。

当用户指定 Seedance 时，使用“主体与镜头 + 外部任务不变量 + 按事件推进的动作和神态变化 + 台词与声音 + 稳定约束”的中文自然语言格式。不要把精确秒数当成 Seedance 的硬控制指令。用户指定其他模型时保留情绪逻辑，并适配其格式；模型规则不明确时输出通用中文视频提示词，不虚构专用参数。

## 自检

输出前检查：

- 是否存在清楚的初始情绪、触发点、桥接状态和最终情绪
- 是否锁定外部任务动作，并避免情绪变化擅自改写剧情动作
- 新情绪是否保留旧情绪痕迹，而非换成另一张表情面具
- 长镜头是否至少有一次“压回或恢复控制”，形成波浪式升级
- 视线是否受任务和人物关系牵引，并在短暂偏移后正确回到锚点
- 无台词时是否只设计未完成表达，而没有擅自添加人物说的话
- 表情是否通过可见线索呈现，而非只有情绪标签
- 是否控制了强度，并避免整段保持同一张满格表情
- 身体动作、视线和呼吸是否真正解释了表情为什么发生
- 转折是否连续，强度是否符合用户要求
- 台词是否原样保留并与口型、语气、表情同步
- Seedance 生成模式是否使用语义节拍，并删除不可靠的阶段秒数和小数秒
- 只有分镜或剪辑模式才使用具体时间码，并说明其规划属性
- 是否保持参考人物、场景、构图和风格稳定
- 是否没有添加多余剧情、台词、动作、字幕或切镜

# 双轨长镜头与演技连续性

## 适用场景

用于以下要求：

- AI 演员、演技派、情绪层层失守
- 人物一边完成任务，一边发生强烈内心变化
- 8–15 秒单镜头面部特写或近景
- 惊恐到悲痛、职责与亲情冲突、强忍后哭泣
- 用户提供参考视频并希望复现其表演逻辑

## 一、先锁定外部任务线

写情绪前，先回答：

1. 人物正在持续做什么？
2. 哪个姿势、方向、道具或空间关系必须保持？
3. 什么情况下任务才会被解除？

常见外部任务：

- 举枪瞄准、驾驶车辆、守住入口
- 继续行走、抱住某人、等待命令
- 面向审讯对象、读完信件、完成告别

除非用户或剧情给出解除条件，把任务动作写为全程不变量。情绪应在任务内部发生，不要自动让人物放下道具、转身离开或停止行动。

提示词句式：

```text
外部动作始终保持：他仍维持原来的举枪姿势，双手与枪口方向基本稳定；所有情绪变化主要发生在眼神、眼睑、呼吸、嘴部和下巴，不因悲伤自动放下武器。
```

根据具体任务替换动作，不机械使用“举枪”。

## 二、建立公开层与隐藏层

为人物同时定义：

- **公开层**：人物为了职责、尊严、谎言或保护他人而维持的表情。
- **隐藏层**：正在积聚、试图泄露的真实情绪。
- **残留层**：前一阶段没有消失、仍留在脸上的情绪痕迹。

例：

```text
公开层仍是警觉和职责感；隐藏层是认出战友后的惊恐与否认；当悲痛出现时，警觉、自责和不敢相信仍残留在脸上。
```

避免写成：

```text
惊恐消失，变成伤心；伤心消失，变成哭泣。
```

改写为：

```text
警觉没有完全消失，惊恐从眼神中渗入；随后悲痛覆盖上来，嘴角和下巴开始失守，但目光里仍残留不敢相信和职责压力。
```

## 三、使用波浪式失守

长镜头不要线性增加情绪强度。使用：

```text
维持控制 → 第一处裂缝 → 短暂压回 → 情绪反弹
→ 再次尝试控制 → 最终失守并停留
```

每次“压回”都要有可见依据：

- 嘴唇重新抿住
- 呼吸暂时恢复
- 眼睛短暂闭合后重新睁开
- 下颌重新绷紧
- 视线重新锁定目标
- 表情幅度短暂减小

反弹时只升级一至两个通道：

- 水光变成泪滴
- 无声换气变成破碎呼吸
- 嘴唇轻启变成想说话却发不出声音
- 下巴绷紧变成克制颤抖

不要让眉毛、眼睛、嘴巴、头部、肩膀和双手同时达到最大强度。

## 四、设置关系视线锚点

视线不是装饰，而是人物关系的连接线。

先确定锚点：战友、爱人、孩子、敌人、镜头外声音或关键物品。再判断人物是否能够移开视线。

- **职责或对峙**：多数时间锁定对方；允许短暂失焦、闭眼或侧移，然后重新锁定。
- **羞耻或逃避**：允许较长时间避开，但要写清避开的原因。
- **告别或不舍**：可能反复离开又返回，形成犹豫。
- **震惊认出**：先停住或失焦，再重新确认目标。

不要为了“自然”让所有人物随机看向旁边。视线必须服务于任务和人物关系。

## 五、设计未完成表达

没有台词不等于嘴部完全静止。可以使用：

- 嘴唇像要叫出名字般轻启，最终没有声音
- 吸气准备说话，却在第一个音节前停住
- 嘴唇张开又重新抿紧
- 喉咙吞咽，呼吸从鼻腔变成破碎的口呼吸
- 声音被哭腔堵住，只留下极轻的气声

不要擅自写出用户没有提供的台词。未完成表达只呈现“想说而没有说出”的状态。

## 六、参考式表演示例

剧情：人物保持举枪，认出枪口另一端是战友，逐渐哭泣。

表演逻辑：

1. 外部任务保持：举枪姿势、枪口方向和人物站位不自动改变。
2. 公开层保持警觉，眼眶和嘴唇先泄露不敢相信。
3. 视线短暂侧移或失焦，再回到战友脸上确认。
4. 嘴唇轻启，像要叫出名字，但没有声音。
5. 人物重新抿住嘴唇并控制呼吸，短暂收回表情。
6. 情绪再次反弹，眼泪出现，下巴和嘴角开始克制颤抖。
7. 最终哭意明显，但职责、自责和不敢相信仍同时存在；外部动作是否解除取决于剧情，不由情绪自动决定。

## 七、写作模板

```text
[时长与镜头]。外部任务始终保持：[不可改变的动作、道具、方向和站位]。

[阶段一] 人物公开维持[表层状态]，但[隐藏情绪]已经通过[极弱线索]泄露。

[阶段二] 因为[触发或认出]，[眼神或呼吸]先出现裂缝；[旧情绪]没有消失，[新情绪]开始渗入。人物的视线短暂[闭眼/失焦/侧移]，随后重新回到[关系锚点]。

[阶段三] 人物试图恢复控制：[压回动作]，表情幅度短暂减小；外部任务仍保持不变。

[阶段四] 情绪再次反弹，[泪水/声音/嘴角/下巴]升级；人物出现[未完成表达]，但不增加台词。

[最终阶段] [复合情绪]同时停留在脸上。除非剧情明确要求，人物不自动停止外部任务。
```

## 八、失败检查

- 是否因悲伤自动放下道具或停止任务？
- 是否把情绪写成一张脸替换另一张脸？
- 是否只有持续升级，没有一次压回或恢复控制？
- 是否让视线无原因地随机游移？
- 是否擅自补出人物没说过的台词？
- 是否所有面部和身体通道同时用力，导致夸张表演？
- 是否在流泪后仍保留职责、恐惧、自责或其他残留情绪？

# 表情动作参考

## 使用方法

从每种情绪中选择二至四个最有辨识度的线索，结合人物性格、景别和强度改写。不要整段照抄，也不要同时驱动所有五官。

## 笑与愉悦

### 温柔的笑

- 嘴角缓慢、轻微上扬，通常保持闭唇或微微启唇
- 双眼柔和，下眼睑出现很轻的收紧
- 视线稳定地落在对方身上，偶尔轻轻垂眼
- 呼吸平稳，头部可有极小幅度的侧倾
- 避免露齿大笑、眉毛高挑和夸张眯眼

### 开心的笑

- 笑意先从眼睛和脸颊出现，再扩展到嘴角
- 脸颊自然抬起，双眼微弯，嘴角上扬幅度中等
- 可伴随一次短促换气、轻笑或肩膀轻微起伏
- 表情出现细小变化和自然回落，不全程锁死在最大强度

### 苦笑或无奈的笑

- 嘴角勉强上扬，幅度较小且略有不对称
- 眼神不参与笑意，短暂躲闪或向下移动
- 呼气比吸气明显，下巴或嘴唇短暂绷紧
- 笑容停留很短，随后回落

## 悲伤与泪水

### 克制悲伤

- 目光变慢、失焦或暂时避开对方
- 内眉轻微抬起或眉间出现很浅的收紧
- 嘴唇抿住、下巴轻轻绷紧，呼吸短暂停顿
- 眼眶逐渐湿润，但不立刻流泪

### 强忍眼泪

- 先眨一次较慢的眼睛，试图把泪水压回去
- 下眼睑轻轻发紧，鼻翼和嘴角出现极小颤动
- 吸气变浅，喉咙像被堵住，说话尾音略微不稳
- 视线可以抬起或移开，但避免连续翻眼和用力挤眼

### 情绪失守

- 在克制阶段后出现一次呼吸断裂或声音卡住
- 嘴角失去控制，下巴出现轻微颤动
- 眼泪先积聚，再有一滴自然滑落
- 强度较高时才加入连续落泪、肩膀抽动或哭声

## 紧张、恐惧与惊讶

### 紧张

- 眨眼频率略有改变，视线短暂游移后重新锁定目标
- 嘴唇抿紧或轻轻张开，吞咽一次
- 呼吸变浅，肩颈略微绷紧
- 眉间轻蹙，不默认睁大双眼

### 恐惧

- 眼睛逐渐睁大，视线固定在威胁来源
- 眉毛抬起并向内收，下唇或呼吸出现颤动
- 身体先僵住，再出现很小的后缩或屏息
- 避免一开始就张大嘴尖叫，除非用户要求爆发强度

### 惊讶

- 眉毛快速抬起，眼睛短暂睁大
- 嘴唇轻启，呼吸停顿半拍
- 之后必须落入第二情绪，如惊喜、警觉、怀疑或恐惧

## 愤怒、失望与决心

### 克制愤怒

- 视线稳定锐利，眉间逐渐收紧
- 下颌绷紧，嘴唇压成较直的线
- 鼻息稍重，但头部和身体保持克制
- 说话音量不必提高，可通过语速变慢和重音表现压力

### 失望

- 原本紧绷的眉间和下颌慢慢松开
- 目光从对方身上移开或缓慢垂下
- 嘴角轻微下沉，呼出一口较长的气
- 愤怒转失望时，让攻击性先消失，再出现疲惫和疏离

### 决心

- 短暂垂眼或吸气后重新抬眼
- 视线稳定、下颌轻收、嘴唇恢复平静
- 表情从摇摆变得清晰，动作幅度减小
- 避免用夸张皱眉代替坚定

## 混合情绪

### 笑中带泪

- 嘴角仍保留笑意，眼神和下眼睑先泄露悲伤
- 笑声逐渐减弱，呼吸停顿，嘴角随后轻轻颤动
- 泪水出现时不要立刻抹去笑容
- 根据剧情区分喜极而泣、重逢后的释然或悲伤穿透笑容

### 哭着笑了

- 先保持湿润眼眶和不稳呼吸
- 某个触发点让视线重新聚焦，嘴角试探性抬起
- 笑意很小，泪痕仍在，呼吸逐渐恢复
- 不要让哭泣痕迹瞬间消失

### 愤怒中的心软

- 眉间和下颌仍紧绷，但视线首先失去攻击性
- 听到触发内容后出现短暂停顿，呼吸放缓
- 嘴唇仍抿紧，眼神却逐渐柔和或避开
- 最终可以保留不情愿、克制和关心同时存在

# 减法式微表情提示词

## 核心原则

```text
少即是多，动即是稳。
```

视频表演不要堆叠满格情绪。使用以下三层结构：

```text
强度控制 + 动作归因 + 时间顺序
```

- **强度控制**：限制表情幅度，避免假笑、僵脸和广告摆拍感。
- **动作归因**：让身体、视线和呼吸成为表情产生的原因。
- **时间顺序**：写出情绪从何处开始、如何变化、在哪里结束。

## 一、控制情绪强度

避免只写“开心地笑”“非常悲伤”“害羞地看镜头”。这类结论容易使模型把情绪固定在最大值。

将抽象情绪改写为：

```text
[人物状态] + [低强度情绪] + [嘴角或眉间微动] + [眼神状态]
+ [面部肌肉与呼吸状态] + [非摆拍要求]
```

中文例句：

```text
她神态放松，嘴角只带着一丝很淡的笑意，目光柔和，面部肌肉自然松弛，呼吸平稳，像被镜头偶然捕捉到，而不是主动摆出笑容。
```

英文模型需要时可使用：

```text
The character has a faint, subtle or barely visible emotion; facial muscles remain relaxed, breathing naturally, realistic and candid, not posing.
```

程度词：

- 微弱的 / faint
- 轻微的、微妙的 / subtle
- 几乎看不见的 / barely visible
- 被压住的、克制的 / suppressed
- 放松的 / relaxed
- 自然呼吸 / breathing naturally
- 抓拍感、非摆拍 / candid, not posing

不要机械地在每段提示词中加入所有词语。根据情绪强度选择一至两个即可。

## 二、给表情一个动作原因

真实表情通常是对人、事件或身体动作的反应，而不是孤立的面具。

```text
身体微动 + 视线转移 = 可读的微表情
```

改写顺序：

```text
人物感到[情绪]或受到[触发]。
人物先做出[身体微动作]，以[动作目的]。
视线[移动方式]，同时出现[嘴部、头部或手部动作]。
作为结果，[低强度微表情]自然浮现。
```

例：不要只写“她很害羞”。改为：

```text
听见对方的话后，她立刻垂下视线，轻轻收住下巴，避开对方的注视；目光向旁边短暂游移，嘴唇轻轻抿住，随后嘴角才浮现出一个几乎看不见的紧张笑意。
```

可选动作：

- 低头、收下巴、缓慢闭眼、重新抬眼
- 视线移开、向下看、短暂侧瞥、重新聚焦
- 深吸气、短暂停住呼吸、缓慢呼气
- 肩膀放松或轻微下沉
- 嘴唇抿紧、轻启、下巴轻微绷紧
- 与剧情有关时才使用挽头发、咬下唇、挠后脑勺、揉眼睛或低头看手机

不要同时加入过多动作。动作必须与人物性格、场景和情绪有因果关系。

## 三、写出时间顺序

微表情的本质是变化。至少使用：

```text
Start 起始状态 → Transition 触发与变化 → End 最终微表情
```

通用公式：

```text
视频开始时，人物处于[起始状态]，面部肌肉[松弛或克制]。
随后，因为[触发原因]，人物做出[身体微动作]，眼神[视线变化]，嘴部[细微变化]。
最后，一个[低强度程度词]的[最终情绪]慢慢浮现在脸上。
整体动作克制、真实、自然，有呼吸和轻微回落，不像摆拍。
```

适合用作起始状态：

- 平静、中性、发呆、疲惫
- 严肃、坚忍、警觉
- 心不在焉、无聊、压抑

适合用作触发动作：

- 眉毛轻轻抬起或眉间开始收紧
- 视线突然停住、移开或重新聚焦
- 缓慢闭眼、深吸气、屏住呼吸
- 肩膀轻轻下沉、头部缓慢低下
- 嘴角停顿、嘴唇抿紧或轻启

适合用作最终状态：

- 温暖或释然的淡笑
- 震惊后留下的警觉
- 一滴自然落下的眼泪
- 困惑的轻蹙眉
- 微弱担忧、失望或悲伤

## 四、对照改写

### 开心

弱写法：

```text
女人喝着咖啡，开心地笑着，享受这个早晨。
```

减法写法：

```text
她轻轻举起杯子闻到咖啡香气，双眼自然闭合一瞬，随后缓慢吹散杯口的热气，暂时没有喝下。她的面部肌肉逐渐放松，嘴角浮现很淡的舒适笑意，呼吸平稳，没有看向镜头摆姿势。
```

因果链：

```text
闻到香气 → 闭眼感受 → 吹散热气 → 身体放松 → 舒适笑意出现
```

### 害羞

弱写法：

```text
她害羞地一直看着镜头，对观众微笑。
```

减法写法：

```text
她听见对方的话后立刻垂下视线，轻轻收住下巴，不敢继续与对方对视；目光紧张地向旁边瞥了一下，嘴唇轻轻抿住，随后才出现一个克制而短暂的害羞笑意。
```

因果链：

```text
受到触发 → 低头 → 避开对视 → 侧瞥 → 紧张笑意出现
```

### 释然

弱写法：

```text
男人露出释然的笑容。
```

减法写法：

```text
开始时，他神情严肃而克制，望着远处。随后，他缓慢闭上双眼，完成一次清晰而平稳的深呼吸，肩膀随呼气轻轻下沉。当他重新睁开眼睛时，目光已经柔和下来，嘴角才慢慢浮现一个很淡的释然笑容。
```

因果链：

```text
严肃克制 → 闭眼 → 深呼吸 → 肩膀放松 → 重新睁眼 → 释然微笑
```

## 五、使用边界

- 不要把“微表情”误解为始终低强度。用户明确要求爆发、崩溃或大笑时，可以提高强度，但仍需保留发生过程和自然回落。
- 不要为了真实感强行加入与剧情无关的手部动作。
- 不要把人物限制成完全静止；细小眨眼、换气、视线和肌肉回落有助于避免表情冻结。
- 不要要求害羞人物始终直视镜头，或要求恐惧人物保持完全放松等互相冲突的动作。
- 不要把负向词堆满结尾。正向描述清楚动作逻辑后，只保留最必要的限制。

## 六、写完后的九项检查

1. 是否只写了开心、悲伤、害羞、愤怒等情绪结论？
2. 是否使用恰当的低强度程度，而非默认满格？
3. 表情是否在整段视频中存在呼吸、变化和回落？
4. 是否写出起始状态、变化动作和最终结果？
5. 表情是否有清楚的发生原因？
6. 是否由身体、视线或呼吸带出表情，而不是直接摆表情？
7. 视线是否符合情绪逻辑，而不是始终盯着镜头？
8. 物理动作是否少而准确，并与剧情相关？
9. 是否避免夸张表演、强迫式笑容、僵硬脸和摆拍感？

一句话检查：

```text
不要只写人物有什么情绪；写清为什么产生、身体先怎么动、眼神如何变化、情绪怎样慢慢出现。
```

# 情绪转折与时间轴

## Seedance 时间控制边界

Seedance 生成提示词默认使用事件顺序和语义节拍，不输出“0–1.5 秒”“2.5–4.5 秒”等阶段时间码。精确时间只作为内部规划或用户明确要求的分镜、剪辑表使用，不能表述为模型必然逐秒执行的硬控制。

用户指定总时长时，在提示词开头提及一次，并让用户在生成设置中选择对应总时长。正文使用：

```text
开场 → 随后 → 中段 → 短暂压回 → 后半段 → 结尾
```

根据镜头复杂度删减节拍；每个节拍只承担一个主要情绪变化。

## 选择原则

先确定转折为何发生，再决定表情如何变化。优先使用事件或台词作为触发点；没有触发点时，可以使用回忆涌现、看见某物或一次呼吸停顿，但不要凭空添加改变剧情的事件。

## 约五秒语义节拍

### 单一表情

- 开场：从中性状态自然建立表情
- 随后：维持表情并加入呼吸、眨眼、视线或轻微回落
- 结尾：自然停留或轻微收束

### 渐变 A → B

- 开场：明确 A
- 随后：触发与桥接，A 逐渐减弱，B 开始泄露
- 结尾：B 完成并停留

### 转折 A → 抵抗 → B

- 开场：建立 A
- 随后：触发点出现，人物短暂停顿
- 中段：人物试图维持 A，但眼神、呼吸或嘴角泄露 B
- 结尾：B 完成，保留一点 A 的痕迹形成复合情绪

## 六至十秒内部节奏规划

构思时可按以下大致比例分配，但 Seedance 成品提示词要把比例转换成语义节拍，不输出百分比：

- 初始状态：20%–30%
- 触发与抵抗：20%–25%
- 桥接与情绪泄露：25%–35%
- 最终状态与余韵：20%–30%

台词横跨多个阶段时，把关键词或停顿放在触发点。不要让人物先完成情绪变化，再机械地说出台词。

## 八至十五秒双轨长镜头内部规划

先写明外部任务或持续动作保持不变，再在内部按波浪分配。最终给 Seedance 的提示词应改写为“开场、随后、中段、短暂压回、后半段、结尾”，不输出百分比：

- 0%–20%：维持外部任务与公开表情，隐藏情绪只留下极弱线索
- 20%–40%：触发或认出，眼神、呼吸或嘴部出现第一道裂缝
- 40%–55%：人物短暂压回情绪，重新控制表情和呼吸
- 55%–75%：情绪反弹，旧情绪与新情绪同时存在，眼眶、声音或下巴开始失控
- 75%–90%：再次试图维持任务，但控制失败，泪水或哭腔出现
- 90%–100%：最终情绪停留；除非剧情要求，外部任务仍不自动解除

不要把每个阶段都写得比前一阶段更大。短暂回收、停顿和重新控制是长镜头表演的重要节奏。

## 常见转折

### 笑着笑着哭了

1. 真实笑意建立在眼睛、脸颊和嘴角。
2. 笑声或台词在触发词后逐渐减弱。
3. 嘴角继续维持笑意，视线却停顿或失焦。
4. 呼吸卡住，眼眶湿润，嘴角出现细微颤动。
5. 一滴眼泪落下，笑意没有完全消失。

### 哭着突然笑了

1. 先建立泪水、哽咽或失控后的余波。
2. 触发点让人物愣住，视线重新聚焦。
3. 嘴角先出现不确定的小幅上扬。
4. 笑意扩展但泪痕仍在，形成释然或荒诞感。

### 愤怒转为失望

1. 眉间、下颌和注视建立克制愤怒。
2. 听见或看见触发内容后停顿。
3. 视线先失去攻击性，下颌和眉间逐渐松开。
4. 目光移开、嘴角下沉、长呼气，落入疲惫与疏离。

### 强装镇定后失守

1. 表情平静，语速和姿态刻意稳定。
2. 通过吞咽、眨眼或一次浅吸气泄露压力。
3. 关键字处声音卡住，视线避开，嘴唇或下巴轻颤。
4. 眼泪积聚或呼吸断裂，最后才允许情绪释放。

### 害怕转为坚定

1. 视线游移、浅呼吸和身体轻微僵硬建立恐惧。
2. 人物停顿并完成一次较深吸气。
3. 视线重新锁定目标，下颌轻收，动作幅度减少。
4. 呼吸稳定，眼神明确，恐惧仍有余痕但不再支配人物。

## 台词绑定示例

台词：“我就知道你一定会回来。”

- “我就知道”：笑意自然，语气带着确认后的欣喜。
- “你一定会”：眼神持续落在对方身上，声音开始放慢。
- “回来”：作为转折词，尾音变轻，笑声停住，呼吸卡顿。
- 台词后：嘴角仍上扬，眼眶逐渐湿润，一滴眼泪落下。

## 防失败调整

- **突然变脸**：延长触发与桥接阶段，减少最终情绪强度。
- **表情冻结**：加入一次自然眨眼、换气、视线变化或笑容回落。
- **表演夸张**：把强度降至 3–5，删除大幅肢体动作和“崩溃、嚎啕”等词。
- **只哭不笑**：明确嘴角在泪水出现后仍保留微弱笑意。
- **只有笑没有泪**：写出眼眶积聚水光到泪滴滑落的因果过程。
- **口型与情绪脱节**：把变化绑定到具体关键词、停顿和台词结束后的余韵。
- **人物崩脸**：采用稳定近景、单镜头、小幅动作，并限制五官、身份和发型变化。
- **情绪一来就停止任务**：锁定外部任务为不变量，只允许必要的肌肉、呼吸和视线变化。
- **情绪直线上升显得机械**：在中段加入一次短暂恢复控制，再让情绪以更高强度反弹。
- **人物无故移开视线**：明确关系视线锚点，只允许短暂闭眼、失焦或侧移，并让视线重新回到目标。
