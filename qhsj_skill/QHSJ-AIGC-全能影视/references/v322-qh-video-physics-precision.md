## 一、移动状态系统（每镜必写）

AI视频模型默认生成"慢慢走"，必须强制写清移动状态。

| 移动方式 | 速度 | 身体姿态 | 步频 | 步幅 | 手臂 | 呼吸 | 环境反馈 |
|----------|------|----------|------|------|------|------|----------|
| 静立 | 0 | 直立 | 无 | 无 | 自然下垂 | 平稳 | 无 |
| 慢走 | 慢 | 直立 | 慢 | 小 | 小幅摆动 | 平稳 | 轻微尘土 |
| 快走 | 中 | 略前倾 | 中 | 中 | 中幅摆动 | 略急 | 尘土 |
| 小跑 | 中快 | 前倾15° | 快 | 中 | 大幅摆动 | 急促 | 尘土扬起 |
| 奔跑 | 快 | 前倾30° | 很快 | 大 | 剧烈摆动 | 急促 | 尘土飞扬 |
| 极速狂奔 | 极快 | 前倾45° | 极快 | 极大 | 剧烈摆动 | 极急促 | 尘土+残影+运动模糊 |
| 冲刺 | 极快 | 前倾45° | 极快 | 极大 | 剧烈摆动 | 极急促 | 尘土+残影+速度线 |
| 后退 | 中 | 后仰 | 中 | 中 | 小幅摆动 | 略急 | 尘土 |
| 蹲行 | 慢 | 蹲姿 | 慢 | 小 | 小幅摆动 | 平稳 | 轻微尘土 |
| 匍匐 | 慢 | 匍匐 | 慢 | 小 | 交替前伸 | 平稳 | 尘土 |

**铁律**：
- 追赶场景必须写"极速狂奔"或"奔跑"或"冲刺"，不能只写"追"
- 逃窜场景必须写"极速狂奔"或"奔跑"或"小跑"，不能只写"逃"
- 回头看、说话时必须仍是极速狂奔状态，不能停下来
- 极速狂奔镜头至少2秒，冲刺镜头至少2.5秒
- 镜头内移动状态全程不停，没有慢下来，没有停下来

## 二、左右手逻辑系统（每镜必写）

AI视频模型默认生成"左手受伤左手摸"的错误，必须强制写清。

| 要素 | 写法 |
|------|------|
| 受伤手 | 右腕旧疤 |
| 动作手 | 左手拇指 |
| 物体手 | 右手握枪 |
| 物体位置 | 枪口指向画面右前 |
| 动作路径 | 左手拇指→摩挲右手腕旧疤 |
| 反馈 | 右手血珠渗出 |

**铁律**：左手受伤只能用右手摸；右手拿物体左手做动作；动作路径必须写清从哪到哪。

## 五、顿帧体系

顿帧=画面在关键瞬间短暂定格，强调冲击/转折/爆点。**不是动作占用时长，是画面停住的瞬间。**

| 用顿帧 | 不用顿帧 |
|--------|----------|
| 打击接触瞬间 | 连续动作（前进/后退/摩挲/握拳） |
| 情绪爆发瞬间 | 过渡动作（转身/抬手/转头） |
| 视觉冲击瞬间 | 环境描写（雨落/云动/风吹） |
| 关键帧强调（血珠/眼神/雨滴悬停） | 运镜过程（推近/拉远/环绕） |
| 黑白闪前后 | 一般对白 |
| 对视瞬间 | |

格式：`动作，顿帧Xs`（如`血珠渗出，顿帧0.1s`）。每段最多一个顿帧，不能跨段使用。

## 六、高精密画面总公式

```
高精密画面 = 物 + 状态 + 变化 + 参数
```

- **物**：精确名词，不用类别词。人=身份+外观锚点+视觉符号+音色锚点；物=精确材质+形态+状态
- **状态**：表面状态（湿沥青/拉丝铝/锈斑/崩口）+ 物理状态（前倾15°/腕内旋/指节白/瞳孔微缩）+ 光学状态（镜面高光/次表面透光/体积光柱/湿反射）
- **变化**：动作（关节链+力线+惯性）+ 反馈（头偏/退半步/血溅/尘扬）+ 环境响应（雨珠溅落/水洼涟漪/烟雾翻涌）

**心理层外化表**：
| 不可见心理 | 外化写法 |
|------------|---------|
| 紧张 | 瞳缩/呼吸浅/指节白/上前半步 |
| 恐惧 | 瞳孔放大/后退半步/手指松开 |
| 决心 | 方向盘指节白/下颌收紧/重心前压 |
| 绝望 | 肩线塌/视线失焦/手指垂下 |
| 愤怒 | 鼻翼张/咬肌紧/拳握紧又松 |
| 回忆 | 视线失焦/呼吸一顿/拇指摩挲旧疤 |

## 七、关节链速查

| 动作 | 主导链 | 力线 | 惯性滞后 |
|------|--------|------|----------|
| 挥手 | 肩→肘→腕→指 | 肩发力→肘传导→腕加速 | 腕0.1s 指0.15s |
| 踢腿 | 髋→膝→踝→趾 | 髋扭转→膝伸展→踝发力 | 小腿0.08s 脚掌0.12s |
| 转头 | 胸椎→颈椎→头 | 胸先转→颈跟随→头稳 | 发0.2s 耳饰0.3s |
| 出拳 | 髋→肩→肘→腕→拳 | 髋旋→肩送→肘直→腕锁 | 拳套0.03s |
| 拔刀 | 肩→肘→腕→刀 | 肩后拉→肘弯→腕翻 | 刀鞘0.05s |

## 八、物理矫正八法（每镜必含物理锁定模块）

```
【物理锁定】重力9.81m/s²|动量守恒|接触面贴合|惯性传导链|流体受重力|
光学定律|热力学定律|生物力学
```

| 矫正项 | 核心规则 | 禁止 |
|--------|----------|------|
| 重力 | 自由落体t=√(2h/g)，速度随时间线性增加 | 慢动作下落、悬浮、无加速 |
| 动量守恒 | 碰撞前动量=碰撞后动量，质量大速度变化小 | 无接触变速、穿透、反弹角度异常 |
| 接触力 | 手掌完全贴合，脚掌无滑动，重量产生压痕 | 手指穿透、脚底打滑、悬浮抓取 |
| 惯性 | 力从核心传导至末端，末端延迟0.03-0.15s，重心偏移先于肢体0.1s | 末端同步启动、无回弹 |
| 流体 | 液体受重力向下，粘度决定流速，表面张力决定液滴形状 | 液体上浮、无重力流淌 |
| 光学 | 阴影方向与光源相反，反射角=入射角，镜面高光位置=光源方向 | 阴影方向错误、反射角度异常 |
| 热力学 | 热气上升冷气下降，温度梯度产生对流 | 热气下沉、冷气上升 |
| 生物力学 | 肘关节单向弯曲，重心在支撑面内 | 关节反弯、重心失衡 |

## 九、音色锁定系统

每个角色开头必须锁定8个参数：音高 / 音色 / 语速 / 口音 / 语气 / 情绪基调 / 共鸣位置 / 气息特点。

**一致性规则**：基频锁定全程不变；音色质感锁定；共鸣位置锁定。语速/语气/情绪可随剧情递进，但**基频偏移不超过半音**。

对白格式：`角色（音色+语气）："台词"`
