## 一、情绪表演导演

### 1.1 减法式微表情三层结构

不要堆叠情绪形容词。用三层结构控制强度：
- **强度控制**：不是"很悲伤"，而是"嘴角下垂0.5cm，眼眶微红但无泪，呼吸比平时慢半拍"
- **动作归因**：每个微表情必须有物理原因（为什么眨眼？因为被风吹了沙，不是因为"情绪到了"）
- **时间顺序**：情绪有时间线——先身体反应（瞳孔缩/呼吸顿），再面部变化（眉皱/嘴抿），最后行为表现（后退/握拳）

### 1.2 双轨长镜头

一个长镜头内同时跑两条轨：
- **外部任务线**（不变）：角色要走到门口/要拿起杯子/要开门
- **内部情绪线**（波浪式失守）：情绪不是直线升级，而是波浪式——压住→漏一点→再压住→大爆发

外部动作不停，内部情绪在动作的缝隙里泄漏。观众看到的是"他在做一件事，但那件事已经不重要了"。

### 1.3 情绪三层（公开层/隐藏层/残留层）

```
情绪层次 = 生理反应层 + 心理活动层 + 行为表现层
```
- **生理**：瞳孔/呼吸/心跳/汗腺/肌肉 → 瞳孔微缩，呼吸急促，指尖微颤
- **心理**：认知/判断/回忆/预期 → 眼神聚焦远处，嘴角微抽动
- **行为**：动作/姿态/距离/触碰 → 身体前倾2cm，手指握紧又松开

**心理层必须外化**：不可见心理转为可见动作。
- "世界观崩塌" → 视线失焦/呼吸停顿/后退半步/手指松开
- "回忆" → 拇指摩挲旧疤/呼吸一顿/视线下移
- "判断威胁" → 瞳孔放大/下颌收紧/重心后移

### 1.4 Seedance语义节拍

不写精确秒数（模型会机械执行），写语义节拍：
- "她倒咖啡的手停在半空，悬了一会儿，然后继续倒"
- "他张了张嘴，没说出话，转过头去"
- "听到名字的瞬间，肩膀几不可察地僵了一下"

## 二、胡金铨武侠视觉体系

### 2.1 五种色彩光线模式

| 模式 | 色彩光线 | 适用场景 |
|------|----------|----------|
| 青绿瀑布 | 青绿主调，水雾弥漫，光线穿过水汽形成体积光 | 山水打斗/轻功追逐 |
| 金色芦苇 | 金黄/琥珀色，逆光芦苇荡，长影子 | 离别/伏击/诗意战斗 |
| 钴蓝月夜文戏 | 钴蓝/深蓝，月光从窗格射入，室内暗调 | 夜谈/密谋/静戏 |
| 钴蓝月夜对峙 | 钴蓝冷调+人物局部暖色灯，剪影对峙 | 对决前/杀意 |
| 雾蓝山水 | 灰蓝/雾白，远山如黛，水墨意境 | 全景定场/独行 |

### 2.2 旧彩武侠片电视转制质感

不是现代数码高清，是老式彩色武侠片的电视录像带质感：色彩偏浓但带轻微色偏，对比度中等，暗部有彩色噪点，画面略带柔焦，不是锐利4K。

### 2.3 构图母型

- 框中框：从门框/窗格/树隙中窥视人物
- 纵深追逐：沿走廊/回廊/台阶纵深方向追逐，消失点在画面中心
- 静态对峙：两人分据画面两侧，中间大面积留白（庭院/水面/屋顶）
- 高空俯瞰：俯拍屋顶追逐，人物变成小色块在灰色瓦面移动

### 2.4 人物铸型规则

干净宽袍，无战术装备，无现代手表/拉链/塑料。长发束起或披散，衣料随风飘动。打斗时衣袂翻飞，不是紧身战斗服。

## 三、古风摄影捕获引擎

### 3.1 五种摄影捕获引擎

| 引擎 | 光线特点 | 适用 |
|------|----------|------|
| 近轴闪光暗环境 | 相机自带闪光直打，背景死黑，人物受光硬 | 夜晚闺房/烛火近景 |
| 低照度柔光高光扩散 | 弱光环境，高光扩散成柔和光斑 | 室内窗光/午后 |
| 硬质侧逆光 | 侧后方硬光，人物边缘金边，正面补弱 | 全身像/轮廓 |
| 低调仪式肖像 | 大部分画面暗，只有人物面部/手部被光打亮 | 庄重/祭祀/权威 |
| 纱帐包裹逆光 | 光线穿过薄纱形成柔光雾感，人物在纱后 | 闺房/暧昧/朦胧 |

### 3.2 四种外景适配器

根据外景类型调整光色：
- **宫城外景**：暖金主光+冷蓝阴影，高对比
- **山林外景**：青绿漫射光，低对比，雾感
- **水面外景**：反射光从下方补光，波纹光斑
- **雪天外景**：冷白主光+蓝调阴影，高亮度

### 3.4 100分评审rubric

| 维度 | 分值 | 检查点 |
|------|------|--------|
| 色彩准确性 | 20 | 是否符合目标色彩模式，无色偏 |
| 光线逻辑 | 20 | 光源方向一致，光比合理，阴影方向正确 |
| 材质真实 | 20 | 皮肤有纹理/布料有织纹/金属有反光，无塑料感 |
| 构图美感 | 15 | 主体位置/前中后景/留白合理 |
| 人物铸型 | 15 | 服装发型符合时代，无现代物品穿帮 |
| 氛围统一 | 10 | 整体调性统一，无割裂 |

### 3.5 反商业写真修正块

如果生成结果变成了"商业写真"（过度磨皮/塑料感/背景虚化过度/姿势摆拍），注入修正：
```
保留真实皮肤毛孔与细微瑕疵，拒绝磨皮硅胶假面；
服装布料有自然褶皱与织纹，拒绝塑料反光；
背景保留场景结构细节，不是纯虚化光斑；
人物动作是正在进行的行为，不是摆拍完成态。
```
