# 小说与长篇叙事引擎

## 目标

覆盖短篇、网文、中长篇、系列小说、影视 IP 原创、续写、扩写、改写、压缩、润色、章节修复。

## 1. 长篇状态机

建立四层状态：

1. 世界状态：时间、地理、制度、超自然/技术规则、社会关系
2. 人物状态：位置、身体、资源、关系、信念、秘密、已知信息
3. 剧情状态：主线、支线、伏笔、误导、债务、未解决问题
4. 文风状态：叙述视角、时态、句长、段落节奏、对白比例、禁用表达

任何新章节都必须从上一章终态进入。

## 2. 世界观

最少建立：

`空间 + 规则 + 禁忌 + 代价 + 权力结构 + 历史 + 文化 + 日常 + 技术/魔法 + 视觉符号`

规则必须有“可观察后果”，否则只是设定说明。

## 3. 人物六层

`身份/外在目标/深层欲望/恐惧或缺陷/关系网络/不可替代的行为细节`

角色必须有：

- 主动欲望
- 当前策略
- 资源
- 盲点
- 代价承受能力
- 说话方式
- 与他人的差异

## 4. 长线结构

可组合：三幕、五幕、七幕、英雄之旅、故事圈、倒叙、闭环、双线、群像、多 POV、单线推进。

层级建议：

`系列 → 卷/季 → 大弧 → 中弧 → 章节 → 场景 → beat`

每层回答：

- 主问题是什么
- 谁想要什么
- 阻力是什么
- 哪个状态被改变
- 什么信息应该暂时保留
- 下一层如何承接

## 5. 章节引擎

每章至少具有：

`进入状态 → 本章目标 → 阻力 → 选择 → 代价/变化 → 新信息或关系变化 → 章尾钩子`

钩子不一定是“突然出现怪物”；可使用：信息缺口、关系变化、倒计时、道德选择、身份揭示、错误答案、异常日常。

## 6. 场景引擎

每个场景至少具备：

`目标 + 冲突 + 策略 + 变化 + 结果`

高级场景增加：

`潜台词 + 视觉行为 + 道具功能 + 反应镜头 + 未说出口的信息`

## 7. 续写算法

### A. 状态差分

从上一章提取：

- 谁在哪里
- 身体/情绪状态
- 物品在哪
- 谁知道什么
- 哪条线正在推进
- 哪条线暂时被冻结

只写新增变化。

### B. 伏笔账本

每个伏笔记录：

`ID / 首次出现 / 当前表面意义 / 真实功能（若作者已知） / 可见线索 / 已回收 / 计划回收 / 禁止提前泄露`

### C. 角色语气锁

提取角色高频句式、句长、停顿、称谓、禁用语。续写时先过“角色声纹”检查。

### D. 大纲锁

大纲已有的未来事件不是当前章节可随便提前揭露的事实。除非用户明确要求重写大纲，否则保持“知道但不说”的作者状态与“角色不知道”的叙事状态分离。

## 8. 防 AI 味

禁止把抽象总结替代场景：

- “他很愤怒” → 具体行为、语言、呼吸、节奏
- “气氛很压抑” → 空间、声音、视线、停顿、人的选择
- “她非常漂亮” → 可见五官、姿态、服装、光线和他人反应

中文网文尤其检查：

- 过度短段落
- 一句一段的机械节奏
- 连续使用同一种句式
- 形容词堆叠
- 过量总结
- 重复姓名与动作
- 无原因的“突然”“顿时”“不由得”

## 9. 章节长度

以用户给出的字数为硬约束；若没有指定，按媒介目标自动选择合理长度，并明确长度假设。不要为“看起来完整”擅自扩写到用户未要求的数量。

## 10. 改稿模式

改稿优先级：

`逻辑漏洞 → 人物动机 → 因果节奏 → 信息控制 → 场景可视化 → 文风 → 句子润色`

不要先润色后发现剧情逻辑错了。

## 11. 文学到影视

先抽取：

`不可失去的主题/角色核心/关键事件/不可替代对白/视觉化动作/隐藏信息`

再决定哪些内心独白转化为：表演、物件、空间、声音、镜头、剪辑。
