# 高速动作、受击反馈与环境调度

用于打斗、追逐、驾驶等高速段落；紧张文戏仅采用适合原稿的剪辑节奏，不把静默、对峙或对白改成动作戏。本页是通用分镜工作流的导演执行规则，服从主 SKILL 的源事实、原台词与连续性锁定。

## 1. 原稿先行，按条件启用

先列原稿动作、击中或未中、受力对象、结果、起终点、人物可移动范围、已有破坏和特效。人物可移动范围专指原剧本允许场景内的可通行区域与边界，不指摄影机绕行幅度，也不是获准新增地点。每项绑定原文事件；主要主体沿用员工上传图片的 @ 引用。

- 可细化同一事件的速度曲线、接触点、受力方向、构图、机位和物理表现；力度来自准确呈现已有动作。原稿若仅概括打斗或追逐事件，允许在已定参与者、能力、场地及起止结果内设计完成该事件所需的攻防节奏和移动路线；这些是执行细化，不得引出新的剧情转折或后果。
- 原稿具体规定的招式、次数、命中关系和动作顺序逐项保留；不能把擦过变成命中，也不能把一次攻击拍成多次攻击。不擅自追加伤势、摔倒、逃脱、撞车、爆炸或场景转移。
- 环境破坏、超能力与特效仅在原稿已有时启用，保持原有对象、范围和后果。原稿只有击中，可描写接触瞬间的受力反应；不得因此追加骨折、流血或飞出数米。
- 不为速度删改、补写、重排台词，不取消原稿规定的停顿、犹豫或慢动作。以原稿范围内的高速爆发形成刺激感。

## 2. 分开写三种速度

**动作速度**：默认要求高速动作极快、爆发明确；写清谁从哪里沿什么允许路径，在多短的时间内完成什么已有动作，包含骤然加速、迅疾位移、接触后的惯性传递及紧接既定下一动作。用主体位移、环境相对掠过和沿实际运动方向的动态模糊共同提供速度证据，不能只有强度形容词。原稿明确限制速度、原地动作或停顿时优先保留。

**镜头与组接速度**：摄影机快速跟进、横移或转向，服务正在发生的动作；切点交接同一运动的方向、阶段和受力结果。镜头运动速度不能代替人物与车辆速度。先判断连续时空及观察路径是否适合一镜到底；多镜头 30 秒 Beat 默认 8–10 镜、至少 8 镜，可按动作密度增加。各镜时长可不同，不能用平均分配或新增事件凑镜数。

**组接节奏**：在原事件具备相应阶段时，按“短暂读清空间与动作起势 → 极速发起 → 接触或落空 → 即时反馈 → 位移与下一动作续接”安排观看顺序。准备段利用已有状态或原动作起势，不新增蓄力、对峙或停顿。各阶段可在一镜中完成，也可按信息与动作相位切分；重点是先读得懂，再迅疾推进，落点与反馈短而清楚。短镜与较长的空间交代形成快慢层次，不把出招变慢、不改变对白速度，也不每阶段必切、等长均分或无因果乱切。

分配动作时间时区分镜长与爆发动作本身的用时：正常播放中的短距离出拳、踢击和接触应短促完成，较长镜头可容纳原有连续攻防、位移及反馈，不把单次出招从起手到命中缓慢摊满镜长。跨切要紧接同一动作进度，不能让肢体悬在半程等待下一个切点。文字写了极速但实际起手、接触和反馈时间拉长时，回到同一时间轴修正；源稿规定的慢动作仍按其要求。

**播放速度**：保留原稿明确的速度与慢动作要求；未指定时默认正常时间中的高速爆发。必要时只对既有关键瞬间做短暂时间拉伸，明确进入点、结束点和恢复正常时间的位置。即使极慢呈现，仍描写爆发起势、惯性、接触传力和已有结果；不能演成主动缓慢动作。慢动作占用实际片长预算，不自动重复已发生事件，也不将对白拖慢。极慢呈现仍须保留速度与力度的视觉证据，这是表现要求，不是模型帧率或精确倍率保证。真实摄影的采集速度与播放速度须区分。[RED 慢动作原理](https://www.reddigitalcinema.com/red-101/slow-motion-video)

## 3. 接触必须交付反馈

把一个既定动作写成：**发力与路径 → 接触位置和时刻 → 受力方向 → 原稿允许的身体或物体响应 → 已有后果与下一状态**。躲闪、格挡和未命中使用其实际关系，不统一写成挨打。

反馈紧随接触，身体、衣物或持有物的响应必须符合材质和受力；位移与伤势不超出原稿。若原稿写了破坏或特效，还需说明起点、传播方向、出现时序、作用对象及结束状态。声音只使用原台词、动作声和环境声，接触声与可见接触对应；BGM 与字幕绝对禁止。

快速位移与相对掠过的环境可带沿实际运动方向的动态模糊；模糊方向随主体和摄影机的相对运动变化。关键手脚、武器轮廓、实际接触点或避让间隙、受力方向必须仍能辨认，接触时刻和反馈之间不能被全屏拖影隔断。让移动路径快、背景掠过明显、关键动作关系清楚；不把全画面持续糊成一片当成速度，也不要求高速全程毫无模糊。通过合适观察侧、主体占幅和切点保住可读性，不用持续抖动或遮挡藏掉动作过程。

RED 的快门资料说明：更短曝光可提高快速动作的单帧细节清晰度，也可能增强断续感；更长曝光产生更多拖抹。这里据此平衡动作可读性和速度质感，沿运动方向布置模糊是本工作流的画面描述，不是模型参数保证；不机械同时要求极强拖影与所有细节始终锐利。[RED 快门与运动模糊](https://www.reddigitalcinema.com/red-101/shutter-angle-tutorial)

## 4. 让动作使用空间

先确定人物在原剧本允许场景内能移动多远、经过哪些可通行区域、在哪些边界必须停下；再依据原稿或不与其冲突的已确认场景图，写出起点、途中已有地标、方向变化与终点。摄影机路径随后匹配这条人物路径，不能用相机转圈代替人物的真实位移。

概括性打斗或追逐在已定参与者、能力、地点、起止状态和结果内，主动选取较充分的移动路线：利用可用前景、中景与后景区域，横向跨越、纵深推进以及原本存在且人物能力允许使用的高差，让攻防距离、前后关系与环境经过确实变化。不是每场必须用尽全部方向或高差；选择能清楚完成原事件的范围，不能把新增剧情后果混入路线设计。原稿已精确规定动作与路线时直接保留，不因通用偏好擅自扩大。

摄影机可以跟随快速横越、纵深逼近或既有高差变化，但不能只围绕原地互打的人持续转圈。原稿明确原地、受困或空间狭小时保留限制，通过动作速度、受力反馈和视点变化强化表现；不得为扩大范围新增地点、人物能力、穿墙或未建立的通道，也不得把原本留在同一场景的动作自动移到另一场景。

## 5. 驾驶与追逐的速度参照

按镜头位置描述实际可见项目：

- **路径与相对位置**：车沿已有路线的前进方向、逼近或拉开关系、原稿已有转向；不添加漂移、急刹或超车。
- **轮胎与车身**：可见车轮高速旋转，与行进状态相符；原稿动作允许的车身俯仰、侧倾与悬挂响应，随加减速或转弯发生。
- **环境流动**：跟拍中近处已有路面纹理或路旁物快速掠过，较远背景变化较缓；迎面、侧面、车内视角分别写对流向。固定机位改写为车辆迅速穿越画幅，不把静止背景写成横移。
- **感官反馈**：已有光影、倒影随掠过环境变化，发动机、轮胎及风声随对应动作变化；烟、火花、碎片与额外交通只在来源支持时出现。

## 6. 正向词组与可填模板

按事实选用少量词组：**瞬间爆发、迅疾切入、连续极速位移、沿运动方向拉开的动态模糊、关键接触清楚可辨、接触瞬间传力、反馈紧随命中、原有地标飞速掠过、近快远缓的层次视差、轮转与车速呼应、动作中切换并接续同一运动、短暂拉伸关键瞬间后迅速恢复正常时间**。

动作模板：

```text
<时间段>，<已绑定主体>从<原稿起点>沿<原场景内允许的移动路径>以<速度变化>完成<原稿动作>；<可见位移与环境相对流动>呈现爆发速度，<动态模糊方向>沿实际运动展开，<关键手脚或武器轮廓及作用关系>清楚可辨。<实际作用位置或避让间隙>呈现<原稿命中、格挡或落空关系>；<仅在实际受力时填写受力方向与不改变结果的即时反馈，未受力时填写原有续接状态>，衔接<原稿下一位置与状态>。镜头以<景别与观察位置>采用<固定观察或与主体速度相配的跟随方式>呈现，<方向和轴线关系>连续；有实际切镜时，切点位于<本事件的信息变化或动作相位>。播放为<正常时间或限定时段慢动作>；按【声音】时间表对应本镜发声状态与声源，台词全文不在此重复。
```

追逐模板：

```text
<已绑定车辆或人物>沿<既有路线>高速<原稿动作>，与<目标>的距离按原稿<变化>。镜头位于<实际视角>，<可见轮转或步频>与前进速度呼应；<按机位选择：固定观察时主体沿既定方向迅速穿越画幅、背景稳定；跟拍时按实际视角描写既有近景快速相对掠过、既有远景较缓变化>。结束于<原稿终点与状态>。
```

## 7. 动作连续性、防穿帮与验收

每个动作先按同一真实时间轴核对，再检查跨镜连续性：

- **攻防时序与轨迹**：发起、应对、接触或落空、反馈和续接的先后或并行遵从原稿；肢体与武器从真实起点沿连续轨迹到达终点，不突然换侧、变长或穿过身体与实体。
- **接触与作用**：命中须有可辨的作用位置、方向和时刻；未接触的攻击不产生被击中反馈，避让与格挡保留各自实际关系。源稿明确存在非接触作用时，按其既定机制交代作用到达，不补造接触或能力。
- **动量、支撑与落地**：速度变化、受力响应与后续位移相连；重心、支撑点、落脚与身体姿态相容。原稿没有授权时，不凭空飞起、悬停、瞬移或新增摔倒与伤势。
- **遮挡与再出现**：遮挡前后的主体位置、轨迹、时间、手部和道具状态一致；关键接触若被挡住，调整观察侧或切点使其可读，不靠遮挡掩饰位置跳跃、穿模或漏动作。
- **武器、手部与结果**：持有物、所在手、握持关系、伤势、衣物和环境破坏逐镜继承；源稿没有变化时不换手、不恢复、不消失。已定破坏与特效保留对象、传播、结果和持续状态。
- **攻击次数与剪辑**：不同角度接续同一动作相位，不把镜头重放拍成再次出招；一次事件只完成一次。原稿已有回放要求时明确其观看性质，不能把回放计入剧情内攻击次数。

常见错误修正：

- 只有“非常快” → 补主体路径、时间变化和可见速度参照。
- 只有快切或绕拍，主体仍缓慢 → 回到动作本身的爆发速度及空间推进。
- 概括打斗只在原地、相机持续环绕 → 在允许场景内重选较充分的人物路线，保留已定起止状态和结果。
- 全屏糊或接触看不清 → 保留位移和环境速度，控制模糊范围并调整观察侧，使关键肢体、武器与作用关系可辨。
- 击中后无反应 → 补接触传力及原稿允许的即时反馈。
- 为凑镜数改动既定攻击次数或追加破坏 → 撤回越界事件，换取同一事件的不同观察信息。
- 全段慢动作显疲软 → 限定拉伸范围，恢复高速主体段，保留原稿指定慢动作。

提示词交付前逐项核对：原事件和逐字台词未变；模式判断与镜数符合要求；镜头节奏有快慢层次且动作保持爆发速度；人物移动范围属于原场景；攻防时序、轨迹、作用关系、支撑与动作次数一致；定向模糊呈现速度但关键接触可辨；遮挡和再出现衔接；武器、手部、伤势及环境结果连续；车轮、车身与环境相对速度符合机位；已有破坏和特效有清楚反馈；BGM、字幕为禁用。此时只更新计划状态；取得实际成片并验收通过后，才另行回填成片最终状态，不能用成片验收要求阻塞纯提示词交付。
