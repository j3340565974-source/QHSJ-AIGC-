# 质量门禁与进化系统

> 来源：质量门禁体系 + 进化知识库 + 自我进化机制
> 全自动质量检查 + 持续学习进化。

---

## 1. 质量门禁体系（QG0~QG8）

| 门禁 | 检查内容 | 失败处理 |
|---|---|---|
| **QG0** | 意图完整性：用户需求是否被完整理解 | 回问用户澄清 |
| **QG1** | 叙事一致性：人物/情节/世界观是否自洽 | 修正叙事逻辑 |
| **QG2** | 空间一致性：轴线/站位/机位是否正确 | 重新推演空间 |
| **QG3** | 资产一致性：角色/场景/道具是否跨镜一致 | 锚点校验修正 |
| **QG4** | 表演一致性：情绪/动作是否符合逻辑 | 调整表演设计 |
| **QG5** | 提示词可执行性：参数是否在模型能力范围内 | 降级或转写 |
| **QG6** | 段缝衔接：多段之间是否连贯 | 调整过渡设计 |
| **QG7** | 风格一致性：全片风格是否统一 | 统一风格锚点 |
| **QG8** | 原创性安全：是否有抄袭/合规风险 | 原创化处理 |

## 2. 机检项（C1~C20）

### 2.1 人物一致性检查
- C1: 面部特征是否跨镜一致
- C2: 服装是否跨镜一致
- C3: 发型是否跨镜一致
- C4: 体型是否跨镜一致

### 2.2 空间一致性检查
- C5: 左右方向是否一致
- C6: 物体位置是否跨镜一致
- C7: 光源方向是否统一
- C8: 轴线是否被打破
- C9: 人物站位是否连续

### 2.3 动作物理检查
- C10: 动作是否物理合理
- C11: 重力是否正确
- C12: 接触面是否贴合
- C13: 惯性是否合理

### 2.4 风格一致性检查
- C14: 色调是否统一
- C15: 质感是否统一
- C16: 光影方向是否统一

### 2.5 提示词质量检查
- C17: 有没有抽象形容词
- C18: 位置关系明确吗
- C19: 朝向写清楚了吗
- C20: AI能看懂吗

## 3. 失败归因树

当结果不理想时，不盲目抽卡，而是精准诊断：

```
结果不好
├─ 人物崩了？
│  ├─ 变脸 → 资产问题 → 加角色锚点
│  ├─ 动作僵 → 表演问题 → 加关节链四阶段
│  └─ 穿模 → 空间问题 → 检查站位和距离
├─ 场景跑了？
│  ├─ 场景变了 → 资产问题 → 加场景锚点
│  ├─ 光线不对 → 光影问题 → 统一光源方向
│  └─ 风格不对 → 美学问题 → 加风格锚点
├─ 提示词问题？
│  ├─ AI看不懂 → 转写问题 → 改成自然语言
│  ├─ 参数不对 → 模型问题 → 换模型适配
│  └─ 太复杂 → 拆分问题 → 拆成多段
└─ 逻辑问题？
   ├─ 剧情不连贯 → 叙事问题 → 检查因果
   ├─ 空间穿帮 → 空间问题 → 检查轴线
   └─ 情绪不对 → 表演问题 → 检查情绪三层
```

## 4. 自我进化机制

### 4.1 经验沉淀
- 每次成功案例都记录下来
- 每次失败案例也记录下来
- 形成自己的"审美直觉"库

### 4.2 版本管理
- 每次更新都记录变更日志
- 哪些方法有效，哪些方法无效
- 持续迭代优化

### 4.3 矛盾检测
- 自动检测前后矛盾的设定
- 自动检测不一致的参数
- 自动修复已知问题

### 4.4 审美涌现
- 不机械执行规则
- 如果某种"错误"创造了有趣的艺术效果，保留它
- 有自己的审美判断

## 5. 全自动质量回归

每次输出后自动跑一遍质量门禁：

```
输出 → QG0检查 → QG1检查 → QG2检查 → ... → QG8检查
   ↓
全部通过 → 交付
   ↓
有问题 → 回到对应层级修正 → 再检查
```

## 6. 短剧专项机检

短剧/漫剧额外检查：
- 前3秒有没有钩子
- 每15秒有没有一个爆点
- 人物出场是否清晰
- 每集结尾有没有钩子
- 节奏是否够快
