# 13 - 质量门禁体系

## 一、质量门禁总览

每个输出必须通过多层门禁。失败时不要随机重写，先归因到对应层，只修改对应层。

## 二、通用质量门禁 QG0~QG8

### QG0 - 输入完整性
- 用户硬约束是否正确识别？
- 引用文件/参考素材是否读取？
- 参考图是否正确理解？
- 目标平台/模型是否明确？

**失败归因**：输入层问题。重新理解用户需求。

### QG1 - 叙事质量
- 因果链是否完整？
- 目标、阻力、选择、代价、变化是否齐全？
- 伏笔是否有回收？
- 人物弧光是否完整？

**失败归因**：故事层问题。调整剧本结构。

### QG2 - 资产一致
- 角色外观是否跨镜稳定？
- 服装道具是否一致？
- 场景元素是否一致？
- 声音特征是否一致？

**失败归因**：资产层问题。检查资产锚点是否锁定。

### QG3 - 空间正确
- 锚点是否一致？
- 距离比例是否正确？
- 180°轴线是否守住？
- 视线关系是否正确？
- 物体方向是否一致？
- 机位是否可达？

**失败归因**：空间层问题。重新做空间推演。

### QG4 - 表演动作
- 动作是否有起承收？
- 情绪是否有触发与过渡？
- 动作幅度是否合理？
- 微表情是否外化可见？

**失败归因**：表演层问题。调整动作设计。

### QG5 - 物理真实
- 重力、接触、惯性是否正确？
- 碰撞反应是否合理？
- 光影方向是否一致？
- 材质反应是否正确？

**失败归因**：物理层问题。修正物理规则。

### QG6 - Prompt可执行
- 每句话是否可见（观众能看到）？
- 是否可执行（模型能理解）？
- 是否与模型语法兼容？
- 是否有模糊不清的词？

**失败归因**：编译层问题。优化提示词写法。

### QG7 - 连续性
- 上一镜终态 = 下一镜初态？
- 章节状态与大纲状态一致？
- 时间线是否连续？
- 人物状态是否连续？

**失败归因**：连续性层问题。检查段缝衔接。

### QG8 - 交付合规
- 时长是否符合要求？
- 画幅是否正确？
- 字段是否齐全？
- 平台格式是否符合？
- 语言是否正确？

**失败归因**：交付层问题。调整输出格式。

## 三、视频专项机检 C1~C20

进入视频生产时叠加以下机检：

| 编号 | 检查项 |
|---|---|
| C1 | 站位入画检查 |
| C2 | 首镜锚定检查 |
| C3 | 单主体原则（一个镜头一个主动作） |
| C4 | 禁令三改规则 |
| C5 | 语气位检查 |
| C6 | 道具光效锁定 |
| C7 | 段缝衔接校验 |
| C8 | 角色一致性检查 |
| C9 | 场景一致性检查 |
| C10 | 光线方向一致性 |
| C11 | 色彩一致性 |
| C12 | 动作幅度合理性 |
| C13 | 运镜单一性（不要一个镜头又推又摇又环绕） |
| C14 | 焦点明确性 |
| C15 | 情绪外化可见性 |
| C16 | 物理合理性 |
| C17 | 时长准确性 |
| C18 | 画幅正确性 |
| C19 | 负向约束完整性 |
| C20 | 平台兼容性 |

## 四、失败归因树

```
生成失败
├─ 画面不对？
│  ├─ 人物变脸 → 资产锚点不够强 → 加更多外观描述
│  ├─ 空间穿帮 → 空间推演不足 → 加重站位和轴线描述
│  ├─ 动作奇怪 → 动作描述太模糊 → 拆解得更细
│  └─ 风格跑偏 → 风格锚点不够 → 加更多风格关键词
├─ 文字不对？
│  ├─ 剧情不合理 → 故事层问题 → 改剧本
│  ├─ 台词不自然 → 表演层问题 → 改台词写法
│  └─ 结构不对 → 节奏问题 → 调整节奏曲线
└─ 技术不对？
   ├─ 格式不对 → 交付层问题 → 调整格式
   ├─ 长度不对 → 交付层问题 → 调整时长
   └─ 平台报错 → 模型适配问题 → 查平台最新规则
```

**核心原则**：不要全盘重写。定位问题层，只改那一层。
