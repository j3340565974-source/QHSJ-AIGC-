# 全平台短视频文案与脚本引擎

## 1. 平台无关底层

短视频先回答：

`为什么停下来 → 为什么继续看 → 为什么转发/评论/收藏 → 为什么关注/行动`

默认结构：

`Hook → Context → Escalation → Payoff → Residual Question / CTA`

## 2. 时长模板

### 15 秒

`0-2 Hook / 2-6冲突 / 6-11变化 / 11-15结果或悬念`

### 30 秒

`0-3 Hook / 3-10设定 / 10-20升级 / 20-27兑现 / 27-30下一问`

### 60 秒

`Hook / 建立 / 第一次变化 / 升级 / 反转或兑现 / 余波`

### 90 秒以上

按“微段落”拆成 10-20 秒单元，每单元都有小目标和小回报。

## 3. 文案

口播稿必须考虑：

- 语速
- 呼吸
- 字幕密度
- 口语停顿
- 视觉同步
- 第一画面的信息量

标题、封面字、首句、评论区 CTA 不应重复同一句。

## 4. 平台适配

抖音、TikTok、Shorts、Reels、B站、小红书、视频号等平台的界面安全区、时长、字幕、推荐机制和广告规则可能变化。任务涉及“当前平台规则/最新参数”时，先联网核实，再输出平台专版。

## 5. 钩子库

- 结果先行
- 异常先行
- 冲突先行
- 反常识先行
- 视觉奇观先行
- 关系先行
- 倒计时先行
- 问题先行
- 身份先行
- 代价先行

## 6. 循环播放

结尾可以在语义、动作、画面或声音上连接开头，但不得为了循环强行破坏故事因果。

## 7. 短视频视觉原则

前 3 秒不是“必须爆炸”，而是“必须迅速建立注意理由”。视觉钩子、声音钩子、信息钩子任选其一或组合。
