# 导演思维、摄影、分镜与运镜引擎

## 1. 导演九问

1. 观众此刻应该看什么？
2. 为什么此刻切？
3. 为什么摄影机现在移动？
4. 谁在主动？谁在被动？
5. 什么信息暂时隐藏？
6. 人物之间的空间关系是什么？
7. 表演是推进还是重复？
8. 声音是否提前或延迟提供信息？
9. 终帧如何把下一镜推出来？

## 2. 视觉圣经

至少锁定：

`画幅 / 画面密度 / 色彩 / 光影 / 镜头质感 / 材质 / 服化道 / 时代 / 摄影机行为 / 剪辑节奏`

## 3. 景别

`大远景 / 远景 / 全景 / 中全景 / 中景 / 中近景 / 近景 / 特写 / 大特写`

景别不是装饰，它必须承担信息距离或心理距离。

## 4. 运镜动机

推、拉、横移、跟拍、环绕、升降、摇、俯仰、手持、稳定器、静止、焦点变化、变焦、复合运动都可以调用，但必须说明“为什么”。

禁止“为了电影感而运动”。

## 5. 复合运镜

复合镜头只保留一个主导运动，其余是次运动。

例如：`侧跟拍为主 + 轻微前推为辅 + 最后停住`，而不是连续堆叠五种运镜。

## 6. 分镜模式

### 完整影视模式

`镜号 / 时长 / 场次功能 / 景别 / 构图 / 机位 / 镜头运动 / 焦点 / 主体动作 / 反应 / 空间状态 / 光影 / 声音 / 对白 / 转场 / 终帧`

### AI 生成模式

`镜号+时长 / 主体 / 动作 / 场景 / 摄影机 / 光线 / 声音 / 连续性 / 终帧`

## 7. 单镜纪律

默认：一个主动作 + 一个主运镜 + 一个主空间关系。

动作复杂度超过模型可稳定执行范围时，拆镜，不要靠更多形容词“压住”模型。

## 8. 节奏

静→动、远→近、宽→窄、慢→快、声音先行→画面兑现，都可以形成节奏，但必须服务戏剧状态变化。

## 爆款引擎（流量数学）

### 黄金三秒：开场钩库（至少命中一个）
1. 结果前置：先把最炸的1秒结果放出来，再倒叙。
2. 身份反差：同一人前后两副面孔，一秒切换。
3. 禁忌画面：不可能出现在日常场景里的东西（血、钞票、枪、跪着的大人物）。
4. 直击台词：第一句就是挑衅/判决/告白/诀别。
5. 数字压迫：倒计时、巨额数字、排名、倒计时器音效。
6. 悬念提问：画面里出现一个"为什么"的具象答案载体。
7. 危机进行中：开场即中途，不交代前因。
8. 极端情绪特写：一滴泪、一声笑、一个咬牙。
9. 视觉奇观：非常规光影/色彩/空间（红色雨、倒置房间、无脸人群）。
10. 冒犯常识：让一个本该弱小的人做一件极度冷静的事。
11. 失去的瞬间：东西落地、手松开、灯灭。
12. 声音先入：画面未到，一声枪响/哭声/破碎声先到。

### 钩子矩阵（全片埋5-8个）
| 钩子类型 | 用法 | 密度 |
|---|---|---|
| 悬念钩 | 提出问题，不给答案 | 每30秒 |
| 反转钩 | 推翻刚建立的认知 | 每90秒 |
| 危机钩 | 危险临近，明确倒计时 | 每60秒 |
| 情感钩 | 一个未完成的承诺/未说出口的话 | 每2场 |
| 信息差钩 | 观众知道，角色不知道 | 全片2-3个 |
| 站队钩 | 制造两难，让评论区吵起来 | 结尾前1个 |

铁律：每场戏的最后一个镜头，必须带一个钩子，让人想看下一场。

### 12种爆款骨架公式
1. 绝境开局 → 身份反差 → 连续打脸 → 终极反转
2. 倒计时危机
3. 信息差 / 秘密揭露
4. 错位身份
5. 复仇清算
6. 守护 / 救赎
7. 赌局 / 最后一票
8. 系统 / 规则流
9. 循环 / 重生
10. 寻人 / 寻物
11. 双强对决
12. 温情反转（催泪）

### 剧情缺口诊断清单（12项）
☐ 开局是否3秒内就有冲突/悬念/反差？
☐ 主角的困境是否具体、可感、可视化？
☐ 反派是否有"他认为自己是对的"的理由？
☐ 是否有"观众知道但角色不知道"的信息差？
☐ 每场戏是否都有"权力关系的转移"？
☐ 中段是否有"以为赢了其实输了"的假胜利？
☐ 是否有情感锚点（一个能哭/能笑的具象物件或人）？
☐ 高潮前是否有"最黑暗的时刻"？
☐ 高潮是否是主角主动选择，而不是被动得救？
☐ 是否留了续集/讨论钩子？
☐ 有没有可以删掉的整场戏？
☐ 有没有一句话能被截图当金句？
