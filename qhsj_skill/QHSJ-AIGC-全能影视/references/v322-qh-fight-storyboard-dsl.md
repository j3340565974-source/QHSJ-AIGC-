## 一、总公式

```
打斗分镜 = 基础风格 + 世界观 + 角色 + 五幕结构 + 单镜卡 + 节奏曲线 + 声音设计 + 因果闭环
```

## 二、单镜槽位公式

```
[时长] + [景别] + [角度] + [运镜] + [主体动作] + [对手反应] + [环境反馈] + [特效] + [声音] + [台词/情绪]
```

示例：
```
2S + 大角度倾斜仰拍 + 侧拍背影 + 固定/切摇 + 主角五指张开召唤武器 +
武器震颤抖动飞起 + 碎石被气流卷起 + 紫蓝雷电粒子 + 战刀拖曳紫色光轮 + 无台词/冷静
```

## 三、五幕阶段模板

```
阶段一：出场
[时长][大角度倾斜仰拍/中景]{主角}从{烟雾/阴影}中走出，{召唤/接住}{武器}，{扛肩/插兜}，说"{短台词}"，瞬间消失留残影。

阶段二：混战
[多机位快切]{主角能量}与{反派能量}化作两道流光对撞，黑白闪；连续{挥砍/碰撞}；
破坏{承重柱/墙体/楼板}；慢镜命中，{反派}倒飞。

阶段三：追击
[侧拍跟随]{反派}负伤逃窜，说"{恐慌台词}"；{主角}立于{高地}，{武器}飞回，冷笑"{嘲讽台词}"；
特写手部触发变身，{发色/形态}变化，能量爆发；瞬身刺击。

阶段四：进化
[俯拍/环绕]{反派}愤怒砸地，胸口异化，进化为{终极形态}，升空，说"{宣言}"，
释放{放射光束/大招}，轰炸{城市/战场}。

阶段五：终极
[倾斜推进]爆炸逼近，{主角}冷笑"{轻蔑台词}"，化{能量}消失；纯黑背景慢镜蓄力；
0.5S突进；0.5S斩击；黑白闪；狂风骤停；{反派}头身分离；第一视角死亡黑屏。
```

## 四、燃点公式

```
燃 = 因果闭环 ×（冲突升级 + 节奏张弛 + 冷暖对冲 + 空间破坏 + 角色反差 + 声音爆点）
```
因果为0，燃点为0。观众必须先知道"谁打谁、为什么打、打到什么程度"，特效才有意义。

## 五、强度分级词库

```
破坏层级：柱子 < 墙体 < 楼板 < 楼层 < 整楼 < 城市
能量等级：微光 < 电弧 < 爆闪 < 全屏 < 黑白闪
情绪等级：冷静 < 冷笑 < 嘲讽 < 杀意 < 狂暴 < 绝望
节奏等级：常速 < 快切 < 高速 < 极速 < 急停 < 慢镜 < 定格
```

## 六、打斗用词库（七类）

**镜头库**：景别（大全景/全景/中景/中近景/近景/特写/大特写/超远景/第一视角）、角度（平视/仰拍/超低仰拍/俯拍/倾斜/侧拍/背面/正面/过肩）、运镜（推/拉/摇/移/跟/升/降/环绕/希区柯克变焦/24mm近大远小/手持/甩镜/急停/定格）、速度（常速/慢镜头/高速/极速/0.5S/1S/2S/残影/拖曳/运动模糊）

**动作库**：出场（召唤/接刀/扛肩/插兜/走出烟雾/残影消失）、攻击（挥刀/劈砍/斩击/刺击/回旋踢/瞬身/蓄力/爆发）、受击（倒飞/贯穿/坠落/砸穿/翻滚/撞墙）、位移（冲刺/穿梭/跃起/下坠/追击/逃窜/升空/悬浮）、变身（觉醒/发色变化/能量爆发/形态异化/羽翼展开）、终结（斩首/头身分离/刺穿/踢飞/黑白闪/第一视角死亡）

**特效库**：能量（紫蓝雷电/暗红能量/红色刀光/血色裂隙/红色光束）、粒子（电弧/粒子飞溅/光轮/残影/拖尾/血雾/灾厄粒子）、光影（黑白闪/强光爆闪/热浪扭曲/色散畸变/边缘模糊/纯黑背景）、破坏（碎石/钢筋/烟尘/气浪/冲击波/火光/楼体倾覆）

**声音库**：前景（金属刀剑碰撞/建筑坍塌/爆炸轰鸣/破空锐响/雷电炸裂/妖兽怒吼/心脏搏动/踢刀柄）、背景（低频压迫/狂风呼啸/远处崩塌/环境震颤）、静默（狂风骤停/声音衰减/黑屏无声）

**情绪库**：主角（冷静/干脆/嘲讽/轻蔑/冷笑/杀意/绝对压制）、反派（惊愕/恐慌/暴怒/嘶吼/不甘/绝望/威严狂暴）、观众（紧张/窒息/期待/释放/震撼）

**台词库**：短句（开打/哼/想跑/徒劳）、嘲讽（哼，想跑！/徒劳。）、怒吼（可恶！/毁灭吧！）、宣言（找死！）、临终（不可能……）

## 七、全局节奏曲线

```
快 → 慢 → 静 → 爆
每阶段提高破坏层级和情绪强度。
```

**禁止**：无因果乱打、无目标切换、无破坏升级、无情绪曲线。
