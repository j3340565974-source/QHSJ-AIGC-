## 一、坐标系统（框外使用，框内翻译掉）

```
Y（上）
↑
│
│ +Z（画面深处 / 主角面朝方向）
│ /
│/
└────────→ X（水平右）

-Z = 镜头方向 / 来向 / 观众方向
+X = 画面右, -X = 画面左
```

**核心规则**：物体一旦定坐标全程不动，镜头可换位置物体不动。主角在O点，移动时重新标O点。

## 二、全局空间建模十步

1. 定场景（室内/室外/森林/城市/太空/水下）
2. 定地面（材质+颜色+反光）
3. 定远处物体（+Z方向有什么）
4. 定近处物体（-Z方向有什么）
5. 定左右物体（+X/-X方向有什么）
6. 定天空（颜色+光源+云层）
7. 定雾气（贴地/悬浮/浓度）
8. 定粒子（发光粒子/尘埃/雨雪）
9. 定主角（位置+朝向）
10. 定参照物（全程不动的物体）

## 四、坐标→画面语言转译表（框内禁用坐标，用此表翻译）

| 推演语言（框外） | AI画面语言（框内） |
|----------|-----------|
| 镜头在+Z侧 | 镜头在主角身后 |
| 镜头在-Z侧 | 镜头在主角前方 |
| 镜头朝+Z | 拍向画面深处 |
| 镜头朝-Z | 拍主角正脸 |
| 主角面朝+Z | 主角面朝画面深处 |
| 主角面朝-Z | 主角面朝镜头 |
| 物体在镜头后方 | 不写，省略 |
| 对手从-Z来 | 对手从镜头方向冲来 |
| 飞行物从-X来 | 飞行物从画面左侧射来 |
| 盟友在-X | 盟友在画面左侧 |

## 六、30种空间矫正方法（五分类）

**空间建模类**：空间表 / 空间图（俯视图）/ 三维坐标推演 / 沙盘推演 / 全局空间模型 / 镜头位置标记 / 深度层次法（前景/中景/背景）/ 方向箭头法 / 固定参照物法 / 背景自动补全法

**轴线与方向类**：轴线锁定 / 跳轴检查 / 视线匹配 / 运动方向一致性 / 左右位置锁定 / 朝向锁定

**衔接与连续类**：前后镜衔接 / 终帧锁死 / 起幅=上镜尾帧检查 / 人物位置连续 / 物体位置连续 / 距离连续 / 高度差连续

**角色与焦点类**：角色标注 / 焦点机位匹配 / 焦点主体在画面 / 背景与机位匹配

**AI可执行类**：AI可执行检查 / 术语替换（坐标→画面语言）/ 画面可见性检查（被挡不写）

## 七、防穿模检查清单

| 检查项 | 通过标准 |
|--------|----------|
| 手部穿透 | 手指完全贴合物体表面，包裹轮廓 |
| 脚部滑动 | 脚掌与地面接触点无滑动，脚趾贴合 |
| 肢体穿插 | 两人肢体无穿插 |
| 深度错误 | 人物有体积感，不纸片化 |
| 遮挡错误 | 遮挡边缘与物体轮廓一致 |
| 布料穿透 | 布料不穿透身体，褶皱自然下垂 |
| 道具漂浮 | 道具与手贴合，不悬浮 |

