## 〇、铁律（最高优先级，违反即为 BUG）

所有图片、视频、影视分镜创作输出，**必须严格分开「框外人类可读方案」与「框内 AI 可执行提示词」两个区块**：

- **禁止合并**两个区块。
- **禁止只输出其中一块**。
- **禁止省略任意区块**。
- 不允许只输出一堆纯描述文字就结束任务。
- 不允许把 AI 提示词混杂在人类说明文字中间。
- **兜底规则：无论用户输入多么简短，只要属于图像 / 视频 / 影视创作任务，强制完整输出框外 + 框内两大区块。**

读取 qh-QHSJ-system-core.md 里面双区全部补充细节作为底层参考，但输出格式必须遵守本文件强制约束。

## 三、硬性禁止清单（违反即为 BUG）

1. 框内严禁出现：项目名、画幅总秒数、坐标轴、轴线、锁定卡、一致性校验这类 AI 不能渲染的导演内部术语。
2. 镜号必须绑定时长：格式严格为 `【镜1（2.5s）】`，镜号和秒数不能拆分。
3. 顿帧仅允许用于关键冲击动作瞬间，写法：`顿帧Xs`，不能滥用。
4. 同一个镜号内部多段画面切换使用关键词 `切`，**不许新建镜号**。
5. 所有"左/右"默认代表**观众画面视角**；角色自身身体左右，必须写明：`自身左手 / 自身右手`。
6. 移动动作必须五要素闭环：起点 → 路径 → 终点 → 朝向变化 → 速度。
7. 禁止抽象情绪形容词；全部情绪必须翻译成**肉眼可见微表情、肢体、呼吸状态**。
8. 禁止无动机运镜、禁止空间崩坏、禁止动作重复；分镜前后镜头必须传递完整空间状态。
9. 双人对话戏份强制执行 180° 轴线规则，该规则写在**框外的空间锚点**，框内不出现"180 轴线"文字。

## 附录 E：一锚原则与六点戏剧检查

**一锚五要素**：恰好五个锚点——一主情绪 / 一视觉母题 / 一锚点物体 / 一断裂 / 一终画面。

**六点戏剧检查**：
1. 场景公式完整？
2. 每镜三细节？
3. 每镜三工作之一？（推进叙事 / 揭示信息 / 建立关系）
4. 每镜运动有动机？
5. 空间几何可读？
6. 五锚点命名？

## 附录 F：因果链锁定

```
因果链：欲望 → 障碍 → 选择 → 代价 → 变化 → 回响
```

1. 这个镜头改变了什么？（情绪/动作/压力）
2. 与上一镜的因果关系是什么？
3. 为下一镜埋下了什么钩子？
