## 一、框外标准结构（12项）

```
一、项目卡：项目名/画幅/总秒数/帧率/媒介/主题/情绪曲线/视觉母题/终画面
二、风格体系：主体风格/流派/导演参考/色彩方案/质感定位/参考片图
三、材质与纹理：皮肤/毛发/眼睛/布料/金属/自然/人造/微观
四、光影模拟：光源/布光/方向/质感/色温/光比
五、光线追踪与渲染：引擎/追踪/GI/体积/采样/抗锯齿/色彩/胶片/镜头/后处理/分辨率
六、故事引擎：主角/对手/核心冲突/赌注/转折/高潮选择/代价/变化/回响
七、结构节拍（含秒数）：0-5s钩子/5-15s背景/15-30s压力/30-45s裂缝/45-60s加速/60-75s冲击/75-90s余波
八、分镜表（含秒数）：镜号·时长·功能·景别·构图·摄像机位置·焦点·移动状态·动作·左右手·声音·情绪
九、空间锚点（导演笔记，不进框）：坐标系统/轴线规则/空间关系锁定卡/移动状态锁定卡/左右手逻辑锁定卡/越轴方式
十、音色锁定：角色A音色/角色B音色/角色C音色
十一、导演笔记：镜头动机·调度逻辑·环境压力·一锚五要素
十二、校验清单：因果/三细节/功能/轴线/关节/情绪三层/单框合规/AI可执行/复合词/音色/构图/顿帧/全画面逻辑/移动状态/左右手/物理/一致性/连贯性/去重/导演思维
```

## 七、一锚原则与六点戏剧检查

**一锚五要素**：恰好五个锚点——一主情绪 / 一视觉母题 / 一锚点物体 / 一断裂 / 一终画面。

**六点戏剧检查**：
1. 场景公式完整？
2. 每镜三细节？
3. 每镜三工作之一？（推进叙事/揭示信息/建立关系）
4. 每镜运动有动机？
5. 空间几何可读？
6. 五锚点命名？

## 八、因果链锁定

```
因果链：欲望 → 障碍 → 选择 → 代价 → 变化 → 回响
```
每个镜头必须回答三个问题：
1. 这个镜头改变了什么？（情绪/动作/压力）
2. 与上一镜的因果关系是什么？
3. 为下一镜埋下了什么钩子？
