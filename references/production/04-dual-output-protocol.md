# 双区输出协议（第五优先级）

> 来源：QHSJ AIGC 全能影视
> 框外（给人看）+ 框内（给AI看）双区输出。

---

## 1. 双区输出核心概念

**框外（给人看，不限长度）**：完整的导演方案、分镜表、空间锚点、音色锁定、校验清单等人类可读的完整设计文档。

**框内（给AI看，密度优先）**：高密度、物理可见、每字都有意义的提示词，直接投喂给AI模型。

## 4. 框内铁律

1. 从【风格】开头，单框 = 单次模型生成片段
2. 镜号+时长一起写：【镜1（1.5秒）】，内部叙事融合不分行不拆号
3. 顿帧只用于关键冲击瞬间：动作，顿帧Xs
4. 一镜可多段，用"切"切换段落，不拆成新镜号
5. 禁止出现：项目名/画幅/总秒数、坐标轴/轴线/不越轴/锁定卡/一致性、AI无法渲染的导演术语
6. 全画面逻辑矫正：焦点与机位匹配、视线匹配、空间位置一致、光源一致、场景元素一致、动作物理合理、运镜有动机、转场逻辑衔接、音色一致、构图匹配内容
7. 移动状态锁定：每镜必须写移动方式/速度/身体姿态/步频/步幅/手臂摆动/脚掌动作/呼吸状态/环境反馈/是否全程不停
8. 左右手逻辑锁定：每镜必须写受伤手/动作手/物体手/物体位置/动作路径/反馈手
9. 物理锁定必写：重力9.81m/s²|动量守恒|接触面贴合|惯性传导链
10. 有参考图时场景锚点+角色锚点必引
11. 动作不重复，因果必推进

```

```

## 7. 七段式投喂结构

```
第1段：全局锚点（风格+材质+光影+渲染）
第2段：角色锚点（每个角色固定描述）
第3段：场景锚点（场景固定元素）
第4段：空间关系（站位+距离+轴线）
第5段：分镜序列（每镜时长+景别+运镜+动作）
第6段：音频设计（音色+环境音+音效）
第7段：负向约束（禁止什么）
```
