# 导演思维、摄影、分镜与运镜引擎

## 1. 导演九问

1. 观众此刻应该看什么？
2. 为什么此刻切？
3. 为什么摄影机现在移动？
4. 谁在主动？谁在被动？
5. 什么信息暂时隐藏？
6. 人物之间的空间关系是什么？
7. 表演是推进还是重复？
8. 声音是否提前或延迟提供信息？
9. 终帧如何把下一镜推出来？

## 2. 视觉圣经

至少锁定：

`画幅 / 画面密度 / 色彩 / 光影 / 镜头质感 / 材质 / 服化道 / 时代 / 摄影机行为 / 剪辑节奏`

## 3. 景别

`大远景 / 远景 / 全景 / 中全景 / 中景 / 中近景 / 近景 / 特写 / 大特写`

景别不是装饰，它必须承担信息距离或心理距离。

## 4. 运镜动机

推、拉、横移、跟拍、环绕、升降、摇、俯仰、手持、稳定器、静止、焦点变化、变焦、复合运动都可以调用，但必须说明“为什么”。

禁止“为了电影感而运动”。

## 5. 复合运镜

复合镜头只保留一个主导运动，其余是次运动。

例如：`侧跟拍为主 + 轻微前推为辅 + 最后停住`，而不是连续堆叠五种运镜。

## 6. 分镜模式

### 完整影视模式

`镜号 / 时长 / 场次功能 / 景别 / 构图 / 机位 / 镜头运动 / 焦点 / 主体动作 / 反应 / 空间状态 / 光影 / 声音 / 对白 / 转场 / 终帧`

### AI 生成模式

`镜号+时长 / 主体 / 动作 / 场景 / 摄影机 / 光线 / 声音 / 连续性 / 终帧`

## 7. 单镜纪律

默认：一个主动作 + 一个主运镜 + 一个主空间关系。

动作复杂度超过模型可稳定执行范围时，拆镜，不要靠更多形容词“压住”模型。

## 8. 节奏

静→动、远→近、宽→窄、慢→快、声音先行→画面兑现，都可以形成节奏，但必须服务戏剧状态变化。
