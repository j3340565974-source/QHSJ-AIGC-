## 1. 景别体系

### 1.1 景别分类

| 景别 | 画面范围 | 心理作用 | 适用场景 |
|---|---|---|---|
| 大远景 | 人物极小，环境为主 | 渺小、孤独、史诗感 | 开场、收尾、环境展示 |
| 远景 | 人物全身，环境为主 | 人物与环境的关系 | 场景建立、动作展示 |
| 全景 | 人物全身，完整动作 | 完整动作、身体语言 | 动作戏、走位 |
| 中景 | 人物膝盖以上 | 日常交流、动作+表情 | 对话、日常 |
| 近景 | 人物胸部以上 | 表情、情绪 | 对话、情绪戏 |
| 特写 | 人物肩部以上/面部 | 强烈情绪、细节 | 关键情绪、反应镜头 |
| 大特写 | 局部细节（眼睛/手） | 极致细节、紧张感 | 关键道具、微表情 |

### 1.2 景别选择逻辑

- **景别越大**：信息量越大，情绪越客观
- **景别越小**：信息量越小，情绪越主观
- **景别跳跃大**：冲击力强
- **景别变化小**：节奏平缓

## 2. 运镜体系

### 2.1 基本运镜

| 运镜 | 效果 | 心理作用 |
|---|---|---|
| 推镜 | 靠近主体 | 强调、聚焦、紧张感上升 |
| 拉镜 | 远离主体 | 揭示、孤独、结束感 |
| 摇镜 | 左右转动 | 展示环境、跟随动作 |
| 移镜 | 平行移动 | 客观观察、流动感 |
| 跟镜 | 跟随主体 | 代入感、陪伴感 |
| 升降镜 | 上下移动 | 权力变化、视角转换 |
| 手持 | 晃动 | 紧张、真实、纪实感 |
| 稳定器 | 平滑 | 优雅、专业、电影感 |

### 2.2 运镜动机

**奥卡姆剃刀原则**：如无必要，切勿运镜。

每个运镜必须有动机：
- 为什么现在推？
- 为什么现在摇？
- 观众此刻该看什么？

## 3. 视角体系

### 3.1 拍摄角度

| 角度 | 效果 | 心理作用 |
|---|---|---|
| 平视 | 客观中立 | 平等、正常 |
| 仰拍 | 从下往上 | 权威、高大、压迫 |
| 俯拍 | 从上往下 | 渺小、脆弱、上帝视角 |
| 斜拍 | 倾斜构图 | 不安、失衡、紧张 |
| 主观镜头 | 角色视角 | 代入感、第一人称 |
| 客观镜头 | 旁观者视角 | 客观、观察 |

### 3.2 视点技术

- **主观镜头**：让观众代入角色
- **客观镜头**：让观众观察故事
- **反应镜头**：角色反应让信息被接收，观众参与情感

## 4. 光学体系

### 4.1 焦段选择

| 焦段 | 特点 | 适用场景 |
|---|---|---|
| 广角 24mm | 视野宽，畸变，空间感强 | 大场景、环境、夸张 |
| 标准 50mm | 接近人眼，自然 | 日常、对话、纪实 |
| 中焦 85mm | 空间压缩，人像美 | 人像、特写、对话 |
| 长焦 135mm+ | 强烈压缩，远摄 | 远距离、压缩感、偷窥感 |

### 4.2 光圈与景深

| 光圈 | 景深 | 效果 |
|---|---|---|
| 大光圈 f/1.4 | 浅景深 | 突出主体，虚化背景 |
| 小光圈 f/8+ | 深景深 | 前后都清晰，环境全展示 |

## 5. 时间节奏

### 5.1 镜头时长

- **长镜头**：沉浸式、流畅、真实感
- **短镜头**：紧张、快节奏、冲击力
- **蒙太奇**：快速剪辑，信息密集

### 5.2 节奏曲线

```
建立 → 铺垫 → 转折 → 释放 → 再铺垫 → 再转折 → 高潮 → 收尾
```

## 7. 黄金三秒：开场钩库（12种）

1. 结果前置：先把最炸的1秒结果放出来，再倒叙
2. 身份反差：同一人前后两副面孔，一秒切换
3. 禁忌画面：不可能出现在日常场景里的东西
4. 直击台词：第一句就是挑衅/判决/告白/诀别
5. 数字压迫：倒计时、巨额数字、排名
6. 悬念提问：画面里出现一个"为什么"的具象答案载体
7. 危机进行中：开场即中途，不交代前因
8. 极端情绪特写：一滴泪、一声笑、一个咬牙
9. 视觉奇观：非常规光影/色彩/空间
10. 冒犯常识：让一个本该弱小的人做一件极度冷静的事
11. 失去的瞬间：东西落地、手松开、灯灭
12. 声音先入：画面未到，一声枪响/哭声/破碎声先到

## 10. 15秒完播率黄金公式

> 来源：qh-camera-specs-15rules.md

```
完播率 = 开局无试探(20%) × 节奏呼吸(30%) × 运镜丰富度(25%) × 情绪绝杀(25%)
```

1. **开局无试探（0~1.5s必须见肉）**：第一帧必须双人同框近景/中景，1.5秒内必须爆发一次极端杀招正面硬撞，严禁远景慢热铺垫
2. **同运镜≤2秒，同景别≤3秒**：15秒内完成5~8次精准镜头切换
3. **以高潮收尾，不设收尾帧**：15秒最后一帧必须是终结技命中、气血炸裂、碎石飞溅或击飞倒地的最高潮定格，不设收腿平息画面

## 11. 镜头规格五要素（每次必写）

格式：`[景别] · [拍摄视角+角度] · [运镜方式] · [跟随目标]`

- **景别**：全景 / 中景 / 中近景 / 近景 / 特写
- **视角**：正面(0°) / 侧面(90°) / 斜角(30°-60°) / 俯拍 / 仰拍
- **角度**：平视 / 仰视(N°) / 俯视(N°)
- **运镜**：跟拍跟镜 / 急速推镜 / 急速拉镜 / 甩镜闪切 / 命中瞬间定格（Hit-Stop微停顿，1~2帧）
  - ⚠️ 慢动作跟镜、升格默认禁用，破坏节奏
- **跟随目标**：跟随角色、肢体或具体接触点

**镜行书写口径**：五要素是设计检查表，落到【时间轴分镜】镜行时只写三要素 `[镜头N] 景别 · 视角角度 · 运镜。动作描述。声音：…。台词：…。`，不写"跟随@谁"——跟随作为运镜策略在动作描述里自然体现。

## 12. 空间感两大铁律

1. **中景及全景严禁90°侧面正拍**：中景和全景必须使用30°~60°斜角拍摄，建立前后遮挡与空间纵深，彻底杜绝街机横版感；只有近景/特写允许90°侧拍
2. **景别与动作幅度绝对匹配**：大幅动作配全景/中景展示张力；小幅拳肘对招配近景/中近景放大密度

---

## 13. 宏微观景别阶梯跃迁

连续镜头的景别与机位严禁平铺重复，必须按阶梯跃迁制造视觉推进感：

```
标准阶梯 = 极微距特写（发力微观）→ 超广角/低角度中景（双人攻防位移）→ 宏观全景（环境/法阵破坏）→ 鸟瞰/过肩定格
```

### 13.1 阶梯跃迁铁律
- 严禁连续两个镜头使用相同景别 + 相同机位
- 动作高潮前插入极微距特写（指尖发力/剑身微颤/眼眸神纹），浅景深虚化背景制造张力
- 大招释放用宏观全景展示环境破坏（法阵崩碎/山峰崩塌/竹海覆灭）
- 绝杀收尾用鸟瞰或过肩定格，配合满天飞叶/烟尘扑镜实现自然遮挡转场（Occlusion Wipe）

### 13.2 Eye-Trace视线流引导
- 相邻镜头的主体高光/视觉焦点必须保持在屏幕同一象限或沿动势方向连续过渡
- 例如：镜头1右侧出鞘刀光 → 镜头2自右向左冲刺的流光核心，避免观众视线满屏搜索

### 13.3 极限景别跳跃（Macro-Micro Jump）
长段高燃战斗/大招段，在极微距特写（ECU）与极宏观大远景（EWS）之间极限跳跃，制造空间张力与视觉震撼：
- 两极对跳：ECU双眼怒睁蓄能 → EWS天幕分野异象
- 极端体量对比：EWS中下方山脉与人物如蝼蚁微尘，巨像背后神环轮转
- 适用：神魔觉醒/大招释放/灭世收尾段；普通对招不强制

## 14. 四阶动静呼吸律

长段战斗（≥15s或拆段成片）的节奏骨架：**静 → 极动 → 慢/滞 → 绝杀** 四阶段递进，缺一平淡：

1. **静（暴风雨前肃杀）**：眼眸特写、平心擦剑、蓄势凝神，节奏压到最低
2. **极动（节奏拉满）**：空斩、贯穿、地面犁地对冲、暴风骤雨多段拆招
3. **慢/滞（短蓄力·不用升格）**：万剑蓄力、神魔显现、能量凝核——用1~2个紧凑镜头快速带过，保持节奏推进
   - ⚠️ 升格慢镜破坏节奏，默认禁用，蓄力段只保留短促凝神+聚能
4. **绝杀定格**：法相举戈、贯穿灭世，最高情绪与视觉爽点释放，定格终帧

## 15. 受击镜头工具箱

受击不是"被打飞"三个字了事——按受击强度选用以下镜头手法：

- **短促径向震动**：命中瞬间镜头沿受力方向短促震一下（1~2帧），模拟冲击波击中摄影机
- **轻微轴向受力**：镜头随受击方向小幅偏转/倾斜，传递"摄影机也被波及"的重量感
- **瞬时焦点变化**：受击瞬间焦点从攻方急切到受击方面部（痛苦细节），或焦点随击飞目标快速转移

## 16. 美学构图四件套（打斗也出美）

> 差距在构图美学。先保动作清晰，再上美学。

### 16.1 开场ECU两极对冲
第一镜不用双人全景对撞，改用极微距双眼特写（左右对称构图），双眼各带一道属性光，瞳孔骤缩蓄能。作用：一帧立住"这是什么级别的对决"，制造压迫与悬念。

### 16.2 中心对称·天地立极
单人蓄力/对峙镜用中心对称构图 + 极低角度仰拍，人物立于画面正中，背景天地异象以人物为轴对称展开。
- ⚠️ 蓄力/对峙不得静止！必须边动边蓄——人物在上升中/踏步中/旋腕中完成蓄力
- ⚠️ 严禁裸写"能量光柱/光柱直插云霄"——模型理解不了抽象光柱质感
- 天地异象必须具象化：写"左右半边天被两色能量染透"，不写柱体

### 16.3 剪影/轮廓光/负空间
- ⚠️ 剪影定格=呆立。只用于动作瞬间（转身甩剑/跃起滞空/挥斩中）的轮廓光抓拍，不用于静止特写
- 正确写法：人物跃起滞空瞬间背对光源成纯黑剪影，边缘勾一圈银白/金红轮廓光，衣袂与发丝在风中狂舞

### 16.4 极端体量对比
大招/法相镜用体量对比制造奇观：渺小人物（蝼蚁微尘）vs 通天巨物（神魔巨躯/巨剑/法阵），人物置于画面一角或底部，巨物占据主画幅。不需要任何特效，体量差本身就是奇观。

### 16.5 组合法则
- **开场**：ECU双眼对峙 → 紧接中心对称天地立极（人物运动中）→ 才进入动作
- **蓄力/大招**：剪影轮廓光（动作瞬间）→ 极端体量对比
- **收尾**：命中瞬间Hit-Stop微停顿抓剪影，呼应开场——禁静止收尾
- 节奏优先：美学镜头每个≤1~2s，不拖节奏
