## 一、景别五级（Screen Size）

| 景别 | 英文缩写 | 画面内容 | 叙事功能 |
|------|----------|----------|----------|
| 大远景 | ELS/Extreme Long | 开阔自然/城市全貌，人物极小 | 建立环境、孤独、史诗感 |
| 远景/全景 | LS/Long Shot | 人物全身 + 周围环境 | 人物与环境关系 |
| 中景 | MS/Medium Shot | 人物膝盖/腰以上 | 对话、动作、关系 |
| 近景 | MCU/Medium Close | 胸部以上 | 情绪、对话反应 |
| 特写 | CU/Close Up | 面部/物体局部 | 情绪放大、细节强调 |
| 大特写 | ECU/Extreme Close | 眼睛/嘴唇/物件细节 | 心理冲击、关键道具 |

> 景别递进 = 观众注意力从环境 → 关系 → 情绪 → 内心逐层深入。

## 二、拍摄角度（Angle）

| 角度 | 视觉效果 |
|------|----------|
| 平视 Eye Level | 客观、中立、代入感强 |
| 仰视 Low Angle | 主体高大/权威/威胁/英雄 |
| 俯视 High Angle | 主体渺小/脆弱/被环境压制 |
| 顶视 Bird's Eye | 上帝视角、图案化、宿命感 |
| 倾斜 Dutch Angle/Canted | 不安、失衡、疯狂、紧张 |
| 过肩 OTS/Over-the-Shoulder | 对话关系、正反打 |
| 主观 POV | 角色视角、沉浸 |

## 三、运镜方式（Camera Movement）

| 运镜 | 英文 | 效果 |
|------|------|------|
| 推 | Dolly In / Push In | 逐渐靠近主体，情感聚焦、揭示重点 |
| 拉 | Dolly Out / Pull Out | 远离主体，揭示环境、孤立、结尾 |
| 摇 | Pan（水平）/ Tilt（垂直） | 展示场景、跟随视线 |
| 移 | Truck / Tracking | 横向跟随，与主体平行移动 |
| 跟 | Follow | 跟随主体前进，带入感 |
| 升降 | Crane / Boom | 升高或降低，视角转换 |
| 手持 | Handheld | 纪录片感、紧张、不安 |
| 斯坦尼康 | Steadicam | 流畅跟随，长镜头 |
| 变焦 | Zoom | 光学推拉，区别于物理推轨 |
| 甩 | Whip Pan | 快速水平甩动，转场/速度感 |
| 希区柯克变焦 | Dolly Zoom | 主体不动背景拉伸/压缩，眩晕感 |

> 推轨 vs 变焦：推轨改变透视（背景视差变化），变焦只放大画面不改变透视。

## 四、构图法则

1. **三分法则 Rule of Thirds**：画面横竖各三等分，主体放在线或交叉点上。
2. **引导线 Leading Lines**：用场景中的线条（路、栏杆、河流）把视线引向主体。
3. **对称构图 Symmetry**：中央对称，仪式感、控制感、韦斯·安德森式。
4. **框架式构图 Frame within Frame**：用门/窗/门洞框住主体，囚禁感/窥视感。
5. **三角形构图 Triangle**：三个视觉点形成三角，稳定。
6. **垂直构图 Vertical**：竖屏时代强化纵深感。
7. **留白 Negative Space**：主体旁大量空白，孤独/压抑/期待。

## 五、焦距与景深

| 焦距 | 特点 | 用途 |
|------|------|------|
| 广角 14-35mm | 夸张纵深、空间膨胀、边缘畸变 | 狭小空间、史诗、跟随 |
| 标准 35-50mm | 接近人眼 | 写实、对话 |
| 中长焦 85-135mm | 压缩纵深、背景虚化 | 人像、情绪特写 |
| 长焦 200mm+ | 极度压缩、窥视感 | 远处观察、动作 |

- **浅景深**：大光圈（f/1.4-f/2.8），主体清晰背景虚，聚焦情绪。
- **深景深**：小光圈（f/8-f/16），前后都清，环境叙事。

## 六、剪辑规则

### 6.1 180° 轴线规则（180-Degree Rule / Axis of Action）

两个角色之间画一条假想线，摄像机必须始终待在线的同一侧半圆内。这样角色 A 永远在画面左、角色 B 永远在画面右，观众不会混乱。一旦越轴，角色左右位置翻转，观众瞬间迷失方向。

- 足球比赛转播就是 180° 规则的典型：镜头永远在球场中线一侧。
- 越轴方式：①用中间带摄像机位置的中性镜头过渡；②让摄像机沿移动轨迹走过轴线；③用特写反应镜头缓冲。

### 6.2 30° 规则（30-Degree Rule）

同一主体的两个镜头之间，摄像机角度至少变化 30°，否则画面差异太小，产生跳切（Jump Cut）的不适感。

### 6.3 动作衔接（Match on Action）

在动作进行中切换机位，让观众感觉动作连续——比如手推开门的动作在两个镜头间无缝衔接。

### 6.4 视线匹配（Eye-Line Match）

角色看向画外，下一镜切到他看的东西，观众自动建立空间联系。

## 七、转场类型

| 转场 | 英文 | 用途 |
|------|------|------|
| 硬切 | Cut | 最常见，中性、不被注意 |
| 淡入淡出 | Fade In/Out to Black | 时间大跨越、章节结束 |
| 叠化 | Dissolve | 时间流逝、回忆、情绪连接 |
| 划像 | Wipe | 老式、卡通感、分屏 |
| 匹配剪辑 | Match Cut | 形状/动作/声音匹配，创意转场 |
| 跳切 | Jump Cut | 时间压缩、不安、现代感 |
| 蒙太奇 | Montage | 段落压缩、情绪积累 |
| 白闪 | Flash Frame | 冲击、回忆闪回 |
