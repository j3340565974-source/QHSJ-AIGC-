# 表演、微表情、动作幅度与情绪控制

## 1. 根因

只写“愤怒/悲伤/疯狂”会让模型从训练分布里抽取高强度表演。解决方式不是增加更多情绪形容词，而是把情绪编译成可见过程。

## 2. 情绪过程

`触发 → 目标 → 阻力 → 保护策略 → 微泄露 → 转折 → 收束`

例如：

`听到坏消息 → 想保持镇定 → 周围有人 → 低头整理物件 → 呼吸停半拍、眼神停住 → 抬头确认 → 恢复克制`

## 3. 表演幅度

默认 0-3：

- 0：中性
- 1：微弱可见
- 2：明显但克制
- 3：戏剧化

AI 写真人默认先使用 1-2，只有故事明确要求才到 3。

## 4. 微表情六维

`眉 / 眼 / 口 / 下颌 / 呼吸 / 视线`

每个镜头最多改变 1-3 个维度，避免脸部肌肉冲突。

## 5. FACS

可用 AU 作为辅助编码，但最终必须同时给可见证据。例如：

`眉毛轻微下压，眼睑收紧，嘴唇保持闭合，下颌短暂绷紧`

不要把 AU 数字当作模型通用标准；不同模型对数字编码的响应并不稳定。

## 6. 动作阶段

`预备 → 重心变化 → 发力 → 峰值 → 收势 → 反作用`

动作没有起始姿态和收势，最容易生成“瞬移式动作”。

## 7. 动作 Token

`Actor / Action / Constraint / Feedback`

例：

`右手 / 缓慢拿起杯子 / 肩膀基本保持不动 / 手指抓握后杯中液面轻微晃动`

## 8. 情绪与动作一致性

每个镜头写清：

- 他正在做什么
- 他正在感觉什么
- 他正在压制什么

“感觉”和“动作”可以冲突，这种冲突经常比直接表演更真实。

## 9. 克制规则

- 高速动作先改中速
- 大幅度表情先改微表情
- 同一镜头不同时执行多个高复杂动作
- 复杂动作使用更多时间或拆镜
- 没有明确戏剧理由，不使用夸张甩头、怒吼、挥臂、瞪眼、狂笑

## 10. 自检

`是否有触发？是否有过程？是否可见？是否与角色当前目标一致？是否与身体动作一致？是否与镜头时长匹配？`
