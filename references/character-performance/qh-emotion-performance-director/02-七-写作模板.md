## 七、写作模板

```text
[时长与镜头]。外部任务始终保持：[不可改变的动作、道具、方向和站位]。

[阶段一] 人物公开维持[表层状态]，但[隐藏情绪]已经通过[极弱线索]泄露。

[阶段二] 因为[触发或认出]，[眼神或呼吸]先出现裂缝；[旧情绪]没有消失，[新情绪]开始渗入。人物的视线短暂[闭眼/失焦/侧移]，随后重新回到[关系锚点]。

[阶段三] 人物试图恢复控制：[压回动作]，表情幅度短暂减小；外部任务仍保持不变。

[阶段四] 情绪再次反弹，[泪水/声音/嘴角/下巴]升级；人物出现[未完成表达]，但不增加台词。

[最终阶段] [复合情绪]同时停留在脸上。除非剧情明确要求，人物不自动停止外部任务。
```

## 八、失败检查

- 是否因悲伤自动放下道具或停止任务？
- 是否把情绪写成一张脸替换另一张脸？
- 是否只有持续升级，没有一次压回或恢复控制？
- 是否让视线无原因地随机游移？
- 是否擅自补出人物没说过的台词？
- 是否所有面部和身体通道同时用力，导致夸张表演？
- 是否在流泪后仍保留职责、恐惧、自责或其他残留情绪？

# 表情动作参考

## 使用方法

从每种情绪中选择二至四个最有辨识度的线索，结合人物性格、景别和强度改写。不要整段照抄，也不要同时驱动所有五官。

## 笑与愉悦

### 温柔的笑

- 嘴角缓慢、轻微上扬，通常保持闭唇或微微启唇
- 双眼柔和，下眼睑出现很轻的收紧
- 视线稳定地落在对方身上，偶尔轻轻垂眼
- 呼吸平稳，头部可有极小幅度的侧倾
- 避免露齿大笑、眉毛高挑和夸张眯眼

### 开心的笑

- 笑意先从眼睛和脸颊出现，再扩展到嘴角
- 脸颊自然抬起，双眼微弯，嘴角上扬幅度中等
- 可伴随一次短促换气、轻笑或肩膀轻微起伏
- 表情出现细小变化和自然回落，不全程锁死在最大强度

### 苦笑或无奈的笑

- 嘴角勉强上扬，幅度较小且略有不对称
- 眼神不参与笑意，短暂躲闪或向下移动
- 呼气比吸气明显，下巴或嘴唇短暂绷紧
- 笑容停留很短，随后回落

## 悲伤与泪水

### 克制悲伤

- 目光变慢、失焦或暂时避开对方
- 内眉轻微抬起或眉间出现很浅的收紧
- 嘴唇抿住、下巴轻轻绷紧，呼吸短暂停顿
- 眼眶逐渐湿润，但不立刻流泪

### 强忍眼泪

- 先眨一次较慢的眼睛，试图把泪水压回去
- 下眼睑轻轻发紧，鼻翼和嘴角出现极小颤动
- 吸气变浅，喉咙像被堵住，说话尾音略微不稳
- 视线可以抬起或移开，但避免连续翻眼和用力挤眼

### 情绪失守

- 在克制阶段后出现一次呼吸断裂或声音卡住
- 嘴角失去控制，下巴出现轻微颤动
- 眼泪先积聚，再有一滴自然滑落
- 强度较高时才加入连续落泪、肩膀抽动或哭声

## 紧张、恐惧与惊讶

### 紧张

- 眨眼频率略有改变，视线短暂游移后重新锁定目标
- 嘴唇抿紧或轻轻张开，吞咽一次
- 呼吸变浅，肩颈略微绷紧
- 眉间轻蹙，不默认睁大双眼

### 恐惧

- 眼睛逐渐睁大，视线固定在威胁来源
- 眉毛抬起并向内收，下唇或呼吸出现颤动
- 身体先僵住，再出现很小的后缩或屏息
- 避免一开始就张大嘴尖叫，除非用户要求爆发强度

### 惊讶

- 眉毛快速抬起，眼睛短暂睁大
- 嘴唇轻启，呼吸停顿半拍
- 之后必须落入第二情绪，如惊喜、警觉、怀疑或恐惧

## 愤怒、失望与决心

### 克制愤怒

- 视线稳定锐利，眉间逐渐收紧
- 下颌绷紧，嘴唇压成较直的线
- 鼻息稍重，但头部和身体保持克制
- 说话音量不必提高，可通过语速变慢和重音表现压力

### 失望

- 原本紧绷的眉间和下颌慢慢松开
- 目光从对方身上移开或缓慢垂下
- 嘴角轻微下沉，呼出一口较长的气
- 愤怒转失望时，让攻击性先消失，再出现疲惫和疏离

### 决心

- 短暂垂眼或吸气后重新抬眼
- 视线稳定、下颌轻收、嘴唇恢复平静
- 表情从摇摆变得清晰，动作幅度减小
- 避免用夸张皱眉代替坚定

## 混合情绪

### 笑中带泪

- 嘴角仍保留笑意，眼神和下眼睑先泄露悲伤
- 笑声逐渐减弱，呼吸停顿，嘴角随后轻轻颤动
- 泪水出现时不要立刻抹去笑容
- 根据剧情区分喜极而泣、重逢后的释然或悲伤穿透笑容

### 哭着笑了

- 先保持湿润眼眶和不稳呼吸
- 某个触发点让视线重新聚焦，嘴角试探性抬起
- 笑意很小，泪痕仍在，呼吸逐渐恢复
- 不要让哭泣痕迹瞬间消失

### 愤怒中的心软

- 眉间和下颌仍紧绷，但视线首先失去攻击性
- 听到触发内容后出现短暂停顿，呼吸放缓
- 嘴唇仍抿紧，眼神却逐渐柔和或避开
- 最终可以保留不情愿、克制和关心同时存在

# 减法式微表情提示词

## 核心原则

```text
少即是多，动即是稳。
```

视频表演不要堆叠满格情绪。使用以下三层结构：

```text
强度控制 + 动作归因 + 时间顺序
```

- **强度控制**：限制表情幅度，避免假笑、僵脸和广告摆拍感。
- **动作归因**：让身体、视线和呼吸成为表情产生的原因。
- **时间顺序**：写出情绪从何处开始、如何变化、在哪里结束。

## 一、控制情绪强度

避免只写“开心地笑”“非常悲伤”“害羞地看镜头”。这类结论容易使模型把情绪固定在最大值。

将抽象情绪改写为：

```text
[人物状态] + [低强度情绪] + [嘴角或眉间微动] + [眼神状态]
+ [面部肌肉与呼吸状态] + [非摆拍要求]
```

中文例句：

```text
她神态放松，嘴角只带着一丝很淡的笑意，目光柔和，面部肌肉自然松弛，呼吸平稳，像被镜头偶然捕捉到，而不是主动摆出笑容。
```

英文模型需要时可使用：

```text
The character has a faint, subtle or barely visible emotion; facial muscles remain relaxed, breathing naturally, realistic and candid, not posing.
```

程度词：

- 微弱的 / faint
- 轻微的、微妙的 / subtle
- 几乎看不见的 / barely visible
- 被压住的、克制的 / suppressed
- 放松的 / relaxed
- 自然呼吸 / breathing naturally
- 抓拍感、非摆拍 / candid, not posing

不要机械地在每段提示词中加入所有词语。根据情绪强度选择一至两个即可。

## 二、给表情一个动作原因

真实表情通常是对人、事件或身体动作的反应，而不是孤立的面具。

```text
身体微动 + 视线转移 = 可读的微表情
```

改写顺序：

```text
人物感到[情绪]或受到[触发]。
人物先做出[身体微动作]，以[动作目的]。
视线[移动方式]，同时出现[嘴部、头部或手部动作]。
作为结果，[低强度微表情]自然浮现。
```

例：不要只写“她很害羞”。改为：

```text
听见对方的话后，她立刻垂下视线，轻轻收住下巴，避开对方的注视；目光向旁边短暂游移，嘴唇轻轻抿住，随后嘴角才浮现出一个几乎看不见的紧张笑意。
```

可选动作：

- 低头、收下巴、缓慢闭眼、重新抬眼
- 视线移开、向下看、短暂侧瞥、重新聚焦
- 深吸气、短暂停住呼吸、缓慢呼气
- 肩膀放松或轻微下沉
- 嘴唇抿紧、轻启、下巴轻微绷紧
- 与剧情有关时才使用挽头发、咬下唇、挠后脑勺、揉眼睛或低头看手机

不要同时加入过多动作。动作必须与人物性格、场景和情绪有因果关系。

## 三、写出时间顺序

微表情的本质是变化。至少使用：

```text
Start 起始状态 → Transition 触发与变化 → End 最终微表情
```

通用公式：

```text
视频开始时，人物处于[起始状态]，面部肌肉[松弛或克制]。
随后，因为[触发原因]，人物做出[身体微动作]，眼神[视线变化]，嘴部[细微变化]。
最后，一个[低强度程度词]的[最终情绪]慢慢浮现在脸上。
整体动作克制、真实、自然，有呼吸和轻微回落，不像摆拍。
```

适合用作起始状态：

- 平静、中性、发呆、疲惫
- 严肃、坚忍、警觉
- 心不在焉、无聊、压抑

适合用作触发动作：

- 眉毛轻轻抬起或眉间开始收紧
- 视线突然停住、移开或重新聚焦
- 缓慢闭眼、深吸气、屏住呼吸
- 肩膀轻轻下沉、头部缓慢低下
- 嘴角停顿、嘴唇抿紧或轻启

适合用作最终状态：

- 温暖或释然的淡笑
- 震惊后留下的警觉
- 一滴自然落下的眼泪
- 困惑的轻蹙眉
- 微弱担忧、失望或悲伤
