# 05 - 角色表演与情绪系统

## 一、核心原则

**不用"哭得很伤心"当主指令。情绪必须外化为可见的动作证据。**

AI模型不理解抽象情绪词。你说"他很愤怒"，模型可能给你一个皱眉头的脸。但你说"他下颌线绷紧，牙关紧咬，拳头攥紧指节发白，呼吸粗重，眼睛眯起盯着对方"，模型就知道该怎么演了。

## 二、情绪编译链

```
触发 → 目标 → 阻力 → 保护策略 → 微泄露 → 转折 → 收束
```

情绪不是一瞬间的事，是一个有过程的曲线。写情绪要写全过程，不要只写一个终点状态。

## 三、动作阶段拆解

任何动作都按五阶段写：

```
准备/重心变化 → 发力 → 峰值 → 收势 → 反馈
```

**反例**：他挥拳打了出去。
**正例**：他重心下移，肩膀后拉蓄力，然后猛地向前挥出拳头，拳头停在对方面前三厘米处，手腕微颤。

## 四、FACS微表情辅助

FACS（面部动作编码系统）作为内部辅助标记，但默认不强迫模型理解数值编码。最终输出必须包含可见动作证据。

### 常见情绪的外化表现

| 情绪 | 可见表现（写这些，不要写情绪词） |
|---|---|
| 愤怒 | 眉下拉聚拢、眼睛眯起、牙关紧咬、下颌线绷紧、拳头攥紧、呼吸加重、身体前倾 |
| 悲伤 | 眉毛内角上扬、嘴角下拉、眼神下垂、肩膀塌下、动作变慢、声音发颤 |
| 恐惧 | 眼睛睁大、眉毛上扬聚拢、嘴微张、身体后缩、双手防御性抬起、呼吸急促 |
| 惊讶 | 眼睛突然睁大、眉毛上扬、嘴张开、身体僵住、停顿一拍 |
| 厌恶 | 鼻子皱起、上唇上扬、眼睛眯起、头向后仰、身体远离 |
| 快乐 | 眼角笑纹、嘴角上扬、眼睛发亮、身体放松、动作轻快 |
| 蔑视 | 一侧嘴角上扬、眼神斜睨、头微仰、身体后仰 |

## 五、表演幅度控制

对夸张模型，先降幅、减动作、加中性停顿，再增量测试。

**控制方法**：
- 先写最克制版本
- 如果不够，再加一点点
- 不要一上来就写"极度愤怒、歇斯底里、疯狂大吼"——那通常会崩

## 六、情绪曲线设计

一场戏的情绪要有张有弛：

```
平静 → 小波动 → 上升 → 小回落 → 再上升 → 高潮 → 回落 → 余韵
```

不要全程一个强度。观众会疲劳。

## 七、表演指导原则

1. **心理活动外化为动作**：不说"他很紧张"，说"他手指无意识地搓着衣角，视线飘来飘去，吞咽了一下"
2. **用细节代替形容词**：不说"她很美"，说"她睫毛很长，笑起来脸颊有两个浅酒窝，头发垂下来遮住半边脸"
3. **动作有因果**：每个动作都要有原因，不要无缘无故地动
4. **节奏有变化**：快动作之后要有慢动作，激烈之后要有停顿
5. **留白**：重要的情绪，不要演满。留一点空间给观众想象
