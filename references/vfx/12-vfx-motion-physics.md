# 12 - VFX 特效与物理系统

## 一、物理真实是底线

特效再炫，不符合物理规律也会假。任何特效都要先想：这个东西现实中会怎么动？

### 基本物理规则
- **重力**：所有东西都往下掉，抛物线轨迹
- **惯性**：动起来的东西不会突然停
- **碰撞**：有碰撞就有反弹和碎裂
- **重量感**：重的东西动得慢，轻的东西动得快
- **浮力**：水里的东西会浮起来
- **摩擦**：地面有摩擦力，不会无限滑

## 二、VFX 参数库

### 粒子类
| 效果 | 视觉特征 | 参数 |
|---|---|---|
| 火花 | 金色、向上飞溅、快速消失 | 数量、大小、速度、颜色 |
| 烟雾 | 灰白色、扩散、上升 | 浓度、速度、颜色、密度 |
| 尘土 | 棕色、扬起、慢慢落下 | 范围、浓度、速度 |
| 雪/雨 | 白色/透明、向下落 | 密度、大小、速度、方向 |
| 魔法粒子 | 发光、彩色、飘动 | 颜色、亮度、流动方向 |

### 爆炸类
| 阶段 | 视觉表现 |
|---|---|
| 闪光 | 瞬间纯白/黄色强光 |
| 火球 | 橙色火球膨胀上升 |
| 冲击波 | 环形气浪推开周围物体 |
| 碎片 | 木块/石头/金属飞溅 |
| 浓烟 | 黑色/灰色蘑菇云升起 |
| 余烬 | 红色火星慢慢落下 |

### 光线类
| 效果 | 描述 |
|---|---|
| 体积光/丁达尔 | 阳光穿过雾气形成光束 |
| 光晕/辉光 | 亮物体周围的柔和光圈 |
| 眩光 | 镜头眩光、鬼影 |
| 星芒 | 强光源发出的星形光芒 |
| 散景 | 背景虚化的圆形光斑 |

## 三、运动模糊规则

- 快速运动的物体要有运动模糊
- 模糊方向和运动方向一致
- 速度越快，模糊越明显
- 追焦拍摄时，背景有速度线，主体清晰

## 四、材质反应

不同材质在光线和物理作用下有不同表现：

| 材质 | 光线反应 | 物理反应 |
|---|---|---|
| 金属 | 高反射、锐利高光 | 硬碰撞、清脆声、变形小 |
| 玻璃 | 透明、折射、破碎 | 易碎、碎片锋利 |
| 布料 | 漫反射、柔软阴影 | 飘动、褶皱、垂坠 |
| 皮肤 | 次表面散射、柔和高光 | 有弹性、留指印 |
| 木材 | 漫反射、纹理 | 碎裂、纤维感 |
| 水面 | 反射、波纹、折射 | 波动、倒影、涟漪 |

## 五、VFX 不要过度

**铁律**：特效是为叙事服务的，不是为了炫技。

- 不要每个镜头都加特效
- 不要用特效掩盖叙事的空洞
- 特效的密度要有张有弛
- 安静的文戏就不要加花里胡哨的特效
