# VFX、物理、巨物、赛车与动态图形

## 1. 物理基础

默认地球场景使用重力约 9.81 m/s²。源文件中存在一处把 1.81 m/s² 写成“修正值”的历史错误，本 Skill 明确不继承该错误。

## 2. 接触

`手↔物体 / 脚↔地面 / 车轮↔路面 / 角色↔墙面 / 布料↔身体`

任何接触都要有接触点和反馈。

## 3. 惯性

动作停止后，衣物、头发、身体末端、灰尘、水、烟等可以存在延迟，但必须与速度和材质匹配。

## 4. 光影交互

VFX 必须照亮或遮蔽环境；强光应影响邻近材质；粒子受风向和重力控制。

## 5. 巨物

建立尺度证据：

- 人物比例
- 建筑比例
- 地平线层次
- 云雾遮挡
- 近景材质细节
- 声音低频与空间回响

## 6. 赛车

速度感不靠无理由的镜头抖动。使用：

`参照物位移 + 车身姿态 + 路面反馈 + 轮胎抓地 + 相对距离 + 镜头速度`

## 7. VFX QA

检查：

`光源一致 / 粒子方向 / 阴影 / 反射 / 遮挡 / 接触 / 尺度 / 时间顺序`
