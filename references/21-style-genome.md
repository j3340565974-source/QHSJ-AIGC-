# 全风格基因组

## 目标

不可能靠一个有限列表穷举“全世界所有风格”。本模块用可组合的风格基因生成器覆盖任意新风格，同时保证风格之间不互相打架。

## 1. 十四个风格维度

`时代 / 地域 / 媒介 / 类型 / 叙事气质 / 构图 / 镜头 / 光影 / 色彩 / 材质 / 美术 / 服化道 / 表演 / 声音剪辑`

## 2. 风格基因例

### 电影传统

黑色电影、法国诗意现实、意大利新现实主义、日本极简、香港犯罪、东方武侠、欧洲艺术电影、史诗大片、现代科幻、心理惊悚、复古恐怖、音乐电影、纪录片观察式、实验影像。

### 东方视觉

汉唐礼制、宋式雅致、明代武侠、园林美学、水墨、敦煌、民俗志、现代东方极简、都市霓虹、国潮商业摄影。

### 科幻/工业

赛博城市、硬科幻实验室、太空歌剧、后工业废土、生物机械、太阳朋克、复古未来主义、极简未来、军事科幻。

### 动画/游戏

2D 赛璐璐、手绘背景、写实 CG、游戏过场、低多边形、黏土、定格、纸片、绘本、虚拟偶像。

### 商业影像

奢侈品、汽车、科技产品、美妆、食品、运动、旅游、建筑、家居、时尚大片。

## 3. 风格组合算法

选择：

`1 主基因 + 1 次基因 + 1 时代表面 + 1 材质基因 + 1 情绪偏差`

例如：

`东方极简 + 黑色电影 + 湿夜城市 + 胶片颗粒 + 疏离`

## 4. 风格冲突检查

检测：

- 构图语法冲突
- 色彩冲突
- 镜头运动冲突
- 美术时代冲突
- 服化道时代冲突
- 表演方式冲突

必要时定义“主导风格”，其余只做局部修饰。

## 5. 风格迁移

从参考图抽取“基因”，不直接复制对象。输出：

`保留 / 替换 / 新增 / 禁止`

## 6. 视觉签名

每个项目至少确定一个：

- 色彩签名
- 构图签名
- 光影签名
- 镜头签名
- 声音签名

它们共同构成项目识别度。
