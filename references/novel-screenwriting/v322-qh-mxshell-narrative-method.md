## 一、核心原则：不是让AI做它不擅长的，而是选AI擅长的

AI视频最大短板：人脸一致性难、手部易崩、复杂动作易穿模。

**Mx-Shell的解法**（《丧尸清道夫》海外播放破2亿）：
- 主角用**机器人**（不需要人脸一致性，金属质感AI擅长）
- 女主角用**塑料模特**（不需要表情变化，静态美感AI擅长）
- 配角用**丧尸**（面部扭曲、肢体不协调反而符合设定）
- 故事背景放**废土世界**（破败杂乱环境AI生成好，不需要精致现代建筑）

### 可复用策略表

| AI短板 | 绕开方法 |
|--------|----------|
| 人脸一致性难 | 用面具/头盔/机器人/侧脸/背影 |
| 手部崩坏 | 用手套/机械臂/插兜/远景 |
| 复杂动作难 | 用慢动作/静态姿势/剪影/运动模糊 |
| 现代建筑难 | 用废土/古代/科幻/自然场景 |
| 口型同步差 | 减少对白，用旁白/画外音/字幕代替 |

## 二、视觉叙事：AI视频是"哑巴电影"

**核心原则**：用默片时代的叙事手法——靠视觉和音乐讲故事。

- 全片几乎没有对白，靠画面、动作、表情、环境叙事
- 用机器人的动作表达情感（如轻轻抚摸塑料模特的脸）
- 用环境细节交代背景（废墟中的旧海报、破损广告牌）
- 音乐和音效是叙事的一部分，不是背景装饰
- 关键情节用特写镜头强调（手部动作、眼神、道具）

## 三、五层提示词结构（从粗到细）

| 层级 | 内容 | 说明 |
|------|------|------|
| 第一层：基础设定 | 角色设定+场景设定+声音设定 | 先把"谁在哪、有什么声音"定死 |
| 第二层：氛围与画质 | 风格核心+视觉基调+色彩影调+美学参考 | 定调，这片子是什么感觉 |
| 第三层：几何关系 | 构图+主体位置+前景背景+空间坐标 | 不需要AI理解审美，只要执行坐标 |
| 第四层：时间轴 | 精确到秒的动作+运镜+入画出画 | 时间写得越细，AI出片稳定度越高 |
| 第五层：情绪落点 | 一句话定调，给场景一个情绪归宿 | 提示词最后通常有一句话 |

**核心**：从第一层到第五层越来越具体。前四层是"是什么"，第五层是"什么感觉"。

## 四、四要素法则（每个分镜必含）

| 要素 | 错误写法 | 正确写法 |
|------|----------|----------|
| 主体 | "一个机器人" | "生锈的机器人牛仔，右手持电磁枪瞄准左前方，左手微微下垂" |
| 构图 | "好看的构图" | "仰拍，对角线分割画面，主体位于左下三分之一处" |
| 环境 | "在一个废墟里" | "沙暴中的废弃教堂，荧光绿辐射云层，侧逆光从画面右后方照来" |
| 风格 | "电影感" | "赛博朋克混合西部片色调，高对比硬光，参考《爱死机》" |

**禁忌**：不写空泛词汇（高级、好看、震撼、有感觉），全部替换成具体、可见、可执行的描述。

## 五、叙事编写五技巧

1. **脑子里先有画面，然后用文字往死里写细**：机器人的手不是"一只手"，而是"生锈的金属右手，三根手指微微弯曲，手腕处有磨损的电线露出"
2. **写具体动作，不写状态和情绪**：❌"机器人很害怕" → ✅"机器人双手缓缓抬至下巴前方呈防御姿态，全身微微发抖，LED眼睛变成蓝色"
3. **给每个场景一个情绪落点**：提示词最后一句话定调，否则AI生成"正确但无聊"的画面
4. **时间轴精确到秒**：写每一秒发生什么、从哪入画、到哪出画、镜头怎么动
5. **几何关系用坐标，不用审美判断**：写"主体位于画面左三分之一处，距离画面左边缘30%"

## 六、分镜抽卡工作流

**抽卡**：同一个分镜提示词生成4-8张/段，选最好的1张/段。

| 镜头复杂度 | 生成数量 |
|-----------|----------|
| 简单镜头（静态、单人） | 4张选1 |
| 中等镜头（双人、有动作） | 6张选1 |
| 复杂镜头（多人、复杂动作、特效） | 8张选1 |
| 关键镜头（情绪高潮、剧情转折） | 8-12张选最好 |

**成本控制**：先用低分辨率/短时长生成预览，选好后再高清生成。不要每个镜头都高清抽卡，只对关键镜头高清抽卡。

## 七、极简工作流（7步）

1. 放弃传统首尾帧模式，不做逐帧手绘
2. 只用三类参考图：场景图+人物一致性图+关键道具图
3. 固定人物提示词：每个人物一段固定描述，每次生成都用同一段
4. 分镜抽卡法：按分镜逐个生成，每个分镜生成多张选最好
5. 用AI工具的"短剧模式"（而非普通视频模式）
6. 按分镜时长选秒数，不生成多余内容
7. 后期剪辑拼接：AI负责生成素材，人负责叙事和剪辑

## 八、人物一致性四步法

1. **固定人物描述词**：精确外貌+服装+特征，每次完整复制不修改
2. **参考图锁定**：生成1-2张高质量人物设定图，每次上传同一张
3. **种子值锁定**：同场景多分镜用相同种子值
4. **服装/特征关键词重复**：在提示词中重复关键特征，强化AI记忆
