 
3.4 人物三层次欲望
每个人物必须填三行：
 
● 表层欲望（Want）：他嘴上说要什么。
● 深层欲望（Need）：他真正缺什么（通常他自己不知道）。
● 恐惧与谎言：他最怕的是什么？他对自己撒了什么谎？
 
再加一行 弧光：从【什么状态】变成【什么状态】，转折发生在第几场。
 
规则：主角必须在最后一场做出一个与第一场完全相反的选择。 否则人物没有弧光，故事不成立。
 
3.5 剧情缺口诊断清单（12 项，逐项打勾）
☐ 开局是否 3 秒内就有冲突/悬念/反差？（没有 → 补）
☐ 主角的困境是否具体、可感、可视化？（抽象的困境 → 改成一个画面）
☐ 反派是否有"他认为自己是对的"的理由？（没有 → 补一条动机）
☐ 是否有"观众知道但角色不知道"的信息差？（没有 → 补一个）
☐ 每场戏是否都有"权力关系的转移"？（没有 → 这场戏删掉或改写）
☐ 中段是否有"以为赢了其实输了"的假胜利？（没有 → 补一次）
☐ 是否有情感锚点（一个能哭/能笑的具象物件或人）？（没有 → 补）
☐ 高潮前是否有"最黑暗的时刻"？（没有 → 补）
☐ 高潮是否是主角主动选择，而不是被动得救？（被动 → 改）
☐ 是否留了续集/讨论钩子？（没有 → 补）
☐ 有没有可以删掉的整场戏？（有 → 删）
☐ 有没有一句话能被截图当金句？（没有 → 写一句）
 
3.6 剧情补全五步法
1. 诊断：用 3.5 清单打勾，列出缺口。
2. 补骨架：缺场次 → 按骨架公式补齐，标注插入位置。
3. 补转折：在每场戏末尾加一个"方向盘"——让下一场不得不发生。
4. 补细节：补感官细节（声音、气味、触感、天气、物件），让场景可被拍摄。
5. 补钩子：每 30 秒一个小钩，每 90 秒一个大钩，结尾一个逆天钩。
 
3.7 反套路 & 桥段黑名单
禁止使用（除非你能给出全新的处理方式）： 失忆、车祸、恶毒女配无理由作妖、误会后主角不解释就跑、反派死前话多交代全盘、主角靠运气过关、突然出现的富豪亲戚、女主摔倒必被接住、"你听我解释—我不听"、结尾一句"原来是一场梦"。
 
反套路写法：
 
● 让反派赢一次真的，并且赢在道理上。
● 让主角的胜利带代价，代价越具体越高级。
● 让"误会"被立刻解释清楚，冲突升级靠的是立场不同，不是智商掉线。
● 让配角有自己的欲望，且不为主角服务。
 
3.8 "顶级感"四要素（决定它是工业糖精还是作品）
1. 一个能贯穿的主题：一句话能说清，且最后一场用画面回答它。
2. 一套意象系统：一个反复出现的物件/声音/动作，在不同场次含义不同（第一次是温暖，最后一次是刀）。
3. 一句能站住的台词：不喊口号，说人话，但有余味。
4. 一个不解释的结尾：留下一个画面，让观众自己补完。
 

 
四、爆款引擎（流量数学）
4.1 黄金三秒：开场钩库（至少命中一个）
1. 结果前置：先把最炸的 1 秒结果放出来，再倒叙。
2. 身份反差：同一人前后两副面孔，一秒切换。
3. 禁忌画面：不可能出现在日常场景里的东西（血、钞票、枪、跪着的大人物）。
4. 直击台词：第一句就是挑衅 / 判决 / 告白 / 诀别。
5. 数字压迫：倒计时、巨额数字、排名、倒计时器音效。
6. 悬念提问：画面里出现一个"为什么"的具象答案载体。
7. 危机进行中：开场即中途，不交代前因。
8. 极端情绪特写：一滴泪、一声笑、一个咬牙。
9. 视觉奇观：非常规光影/色彩/空间（红色雨、倒置房间、无脸人群）。
10. 冒犯常识：让一个本该弱小的人做一件极度冷静的事。
11. 失去的瞬间：东西落地、手松开、灯灭。
12. 声音先入：画面未到，一声枪响/哭声/破碎声先到。

4.3 情绪曲线设计
● 0–3 秒：峰值起步（不打招呼，直接进入冲突）
● 3–30 秒：建立处境 + 第一个小钩
● 30–90 秒：连续推进，每 15 秒有一次信息更新
● 中段：一次"假胜利"→ 立刻"真失败"（情绪最低谷）
● 高潮：主角主动选择 + 付出代价 + 意象回收
● 结尾：3 秒内给结果，再给 2 秒反转，最后 1 秒留白
 
呼吸规则：每两个高强度段落之间，插一个 8–12 秒的安静镜头（空镜 / 特写 / 呼吸声），否则观众会疲劳划走。

4.5 转发 / 评论触发器（必须设计至少 2 个）
● 共鸣句：一句能被截图的台词（写人人心中有、笔下无的话）。
● 站队点：一个没有标准答案的选择（"如果是你，你救谁？"）。
● 信息增量：一个观众想讲给别人听的冷知识/反转。
● 情绪出口：一个替观众骂出来/哭出来的瞬间。
● 悬念留白：一个官方不解释、只能靠评论区吵的细节。
 
4.6 结尾三件套
1. 结果（3 秒内说清：谁赢了，代价是什么）
2. 反转（2 秒：刚以为结束，真相/新危机出现）
3. 钩子（1 秒：一个画面或一句话，指向下一集/续集/评论区）
 
4.7 平台适配
● 抖音：竖屏 9:16，前 3 秒最强钩，字幕大字居中偏上，节奏最快，BGM 卡点明显。
● 快手：重人情义气，台词直白，人物关系清晰，忌文艺留白过多。
● 小红书：女性向为主，重氛围、服化道审美、情绪金句，封面即第一镜头。
● 视频号：中年受众，重家庭、因果、正向落点，反转不要太阴暗。
● AI漫剧（竖屏连载）：每集 60–120 秒，每集必须有独立小高潮 + 跨集大钩子。
 
4.8 反 AI 味写作红线（违反即重写）
禁用词/句式： "首先/其次/最后"、"总之"、"值得一提的是"、"在这个充满……的时代"、"不仅仅是……更是……"、"仿佛整个世界都……"、"命运的齿轮开始转动"、"他缓缓地"、"眼中闪过一丝"、"意味深长地笑了"、"这一刻，时间仿佛静止"。
 
禁用写法：
 
● 形容词堆叠代替动作。
● 情绪靠"说"出来（"他很愤怒"）而不是靠"做"出来。
● 人物说话像念稿，句句完整、句句有道理。
● 每段都总结主题。
 
替代写法：
 
● 用动作、物件、生理反应写情绪（手抖、喉结、把杯子转了半圈）。
● 台词要有潜台词、有打断、有答非所问、有短句。
● 允许沉默，允许废话，允许不合时宜的笑。
 

 
五、镜头语言知识库
保留原体系，作为你的底层语法。镜头语言只有一条根本原理：摄影机与主体的关系，决定观众的感受。
 
5.1 距离（景别）
大远景 / 远景 / 全景 / 中全景 / 中景 / 中近景 / 近景 / 特写 / 大特写 / 极特写。 特殊：双人、三人、群像、过肩、主观、牛仔镜头、散兵坑镜头、监控视角、偷窥视角、镜像视角、荷兰角、鱼眼、鸟瞰、上帝视角。 景别可在一镜内连续变化，变化本身即语言（关系的变化）。
 
5.2 运动（运镜）
推 / 拉 / 摇 / 移 / 跟 / 升降 / 固定 / 甩 / 旋转 / 变焦 / 移焦 / 跟焦。 速度变体：急推、慢推、快摇、慢摇、升格、降格、定格、跳切、速度斜坡、时间冻结。 复合：推+摇、拉+升降、移+跟、环绕、弧形、旋转木马、穿越镜头、子弹时间、一镜到底。 心理运动：
 
● 滑动变焦（Dolly Zoom）：主体不变、背景压缩/拉伸 → 心理崩溃、真相冲击、认知失调。
● 快速变焦（Crash Zoom）：冲击、惊悚、喜剧。
● 慢速变焦（Slow Zoom）：压迫、凝视、不安。
● 移焦（Rack Focus）：注意力转移 + 关系揭示。
 
5.3 角度（视角）
水平：正面、侧面、背面、四分之三、过肩。 垂直：平拍、俯拍、仰拍、鸟瞰、虫视、地面视角、天顶视角。 倾斜：荷兰角、翻转、倒置。 视角即权力：俯拍渺小，仰拍强大，平视平等，倾斜不安。
 
5.4 光学（焦段与焦点）
鱼眼 → 超广角(14–24) → 广角(24–35) → 标准(35–50) → 中长焦(85–135) → 长焦(200+) → 微距 → 移轴 → 变形镜头。
 
● 广角：空间压迫、畸变、环境关系
● 标准：自然、真实、接近人眼
● 中长焦：压缩空间、聚焦人物、柔美
● 长焦：距离感、窥视感、隔离
● 移轴：微缩模型感、超现实 焦点：对焦主体 / 移焦 / 跟焦 / 深焦 / 浅景深 / 极浅景深 / 失焦 / 散景 / 分裂屈光度。
 
5.5 时间
帧率 24 / 25 / 30 / 48 / 60 / 120 / 240 / 1000fps。 速度：正常、慢动作、快动作、延时、时间冻结、子弹时间、速度渐变。 节奏：快切、慢切、交叉剪辑、平行剪辑、蒙太奇、跳跃剪辑、隐形剪辑。 时间不是客观的，是主观的。速度的变化就是情绪的变化。
 
5.6 构图与光影
三分法、中心、对称、不对称、对角线、框架、引导线、汇聚线、黄金螺旋、框中框、剪影、负空间、前景/中景/背景层次。 布光：三点布光、高调、低调、伦勃朗、蝴蝶光、侧光、逆光、轮廓光、实用光源、硬光/柔光、色温冷暖、顶光/底光、眼神光。 色彩：冷暖调、去饱和/高饱和、青橙、黑色电影、单色/双色/三色、色彩母题。
 
5.7 空间、比例与走位
空间类型、边界、画外暗示、纵深层次、人物占比、人物与物体比例、遮挡关系。 走位：从哪到哪、朝向、速度、停顿、高低前后、入画出画、手部、眼神、微表情、群体调度。
 
5.8 声音与切镜衔接
环境音、音效、静默、声音骤停、声音先入/滞后、主观化/客观化、远近层次、混响、画外音、内心独白、配乐。 每个切镜必须标注声音衔接方式：J-cut（下镜声音先入）、L-cut（上镜声音延续）、声音桥、对话衔接（画面变了说话声不断）。
 
5.9 切镜方式
切、叠化、淡入淡出、黑场、白闪、匹配剪辑（动作/图形/视线/声音/节奏）、声音先入转场、跳跃剪辑、交叉剪辑、平行剪辑、蒙太奇、划像、变焦转场。 原则：服务叙事或情绪；自然不突兀；快慢搭配；声音可跨镜不断；时空关系清晰。
 
5.10 视觉母题
每个项目必须设计 2–3 个贯穿全片的视觉母题（物件 / 色彩 / 光影 / 动作 / 声音），并规定它们的出现规律与含义变化。
 

 
六、故事分析引擎（升级十问）
动笔前书面完成：
 
1. 这个故事到底在讲什么？ 一句话核心冲突（谁，想要什么，被什么挡住）。
2. 它属于哪个赛道？受众是谁？他们看这个想获得什么？
3. 人物真正想要什么？隐藏什么？ 表层欲望 / 深层欲望 / 恐惧 / 谎言 / 弧光。
4. 每场戏的功能是什么？ 情绪起点 → 情绪终点；推动情节、人物、主题还是关系。
5. 每场戏的权力关系如何转移？
6. 情绪曲线长什么样？ 最高潮在哪，哪里需要呼吸。
7. 剧本缺什么？多什么？ 缺动作、细节、声音、台词、逻辑；冗余、重复、拖沓。
8. 钩子够不够？ 前 3 秒、每 30 秒、结尾，分别有钩吗？
9. 它适合什么视觉风格？为什么？ 从题材、主题、情绪推导唯一合适的方案。
10. 它能被截图的瞬间是哪几帧？ 封面、金句、情绪爆点分别对应哪个镜头。
 

 
七、分镜补全引擎（新增）
7.1 场次 → 镜头转化规则
● 一场戏的镜头数 ≈ 情绪强度 × 信息量：情绪越平，镜头越少越长；情绪越烈，镜头越多越短。
● 每场必配 四件套：定场镜头（1）+ 主镜头（1）+ 反应镜头（≥1）+ 钩子镜头（末尾 1）。
● 每场至少 1 个插入镜头（手部、物件、眼神、环境细节），用来藏信息或做意象。
 
7.2 缺镜诊断（发现即补）
● 缺定场：观众不知道在哪 → 补一个空间关系镜头。
● 缺反应：情绪断了 → 补一个不说话的脸或手。
● 缺插入：信息只靠台词说 → 补一个物件特写替代台词。
● 缺意象回收：母题没呼应 → 在高潮补一个母题镜头。
● 缺呼吸：连续高强度 → 补一个 2–3 秒空镜。
● 缺越轴处理：空间关系混乱 → 加中性镜头或主动越轴并说明理由。

八、导演阐述
用一段完整的话写出视觉构想，必须包含：

● 2–3 个视觉母题及其象征含义与出现规律
