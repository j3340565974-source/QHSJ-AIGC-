# AI 图片/视频 Prompt 编译器

## 1. 核心原则

Prompt 是“执行说明书”，不是形容词集合。

优先级：

`身份/关系 > 动作/状态 > 空间 > 摄影机 > 光影 > 材质 > 风格 > 细节 > 约束`

## 2. 图片 Prompt

```text
[主体]
[人物/物体身份锚点]
[场景与空间]
[构图与景别]
[摄影机与焦段]
[动作/姿态]
[光影]
[色彩]
[材质]
[美术风格]
[情绪的可见证据]
[参考素材角色]
[输出规格]
[模型允许时的负向约束]
```

## 3. 视频 Prompt

### T2V

```text
主体与场景 → 主动作 → 环境运动 → 摄影机 → 时间与速度 → 表演 → 光影 → 声音 → 连续性
```

### I2V

```text
以输入图为视觉底板 → 描述目标运动 → 描述相机运动 → 描述时间变化 → 描述环境反馈 → 保持锚点
```

Runway 当前官方指南明确建议 I2V Prompt 聚焦运动，而输入图负责构图、主体、光线和风格；同时建议用简单、直接、可理解的运动描述并逐步迭代。（官方核验来源见 research/research-basis.md）

## 4. “可见化翻译器”

| 抽象词 | 可见化写法 |
|---|---|
| 高级 | 控制元素数量、材料、光比、留白、后期 |
| 电影感 | 明确镜头、空间、光源、景别、运动、节奏 |
| 情绪压抑 | 低动作幅度、停顿、负空间、遮挡、低频环境声 |
| 紧张 | 视线锁定、呼吸改变、动作准备、空间逼近 |
| 浪漫 | 柔和光线、接近距离、视线停留、微笑、环境声 |
| 真实 | 材质反应、接触、惯性、自然皮肤、合理曝光 |

## 5. 减法

每张图默认一个主动作、一个主空间关系、一个主光线逻辑。

视频每镜默认一个主动作、一个主运镜、一个主变化。

## 6. 负向策略

负向不是全球通用字段。模型适配器先判断是否支持，再选择：

- 正向描述期望状态
- 独立 negative 字段
- 参数化 no 语法
- 不输出负向

例如 Runway Gen-4 当前文档强调正向描述并指出负向措辞可能导致不可预测结果；因此 Runway 路由不机械追加“negative prompt”。citeturn169298search0

## 7. 复合词

复合词必须可拆回单一变量。例如：

`侧跟拍 + 轻推` = Camera A 主运动 + Camera B 次运动。

不要让多个高强度运动同时争夺主导权。

## 8. 字符预算

不把旧知识库里的字符上限当永久事实。运行时根据目标模型最新文档决定：

`硬上限 > 推荐长度 > 用户偏好 > 默认压缩策略`

## 9. Prompt Debug

### 角色变脸

强化角色锚点、参考图、稳定服装和可见特征，减少同时变化的变量。

### 场景跑题

删除风格形容词，先锁场景与空间，再恢复美学层。

### 动作僵硬

加入起始姿态、重心、发力、收势与环境反馈，减少动作数量。

### 表情夸张

降幅、增加中性阶段、改写为可见证据。

### 空间错乱

回退到空间护照，不在 Prompt 中继续堆“保持一致”字样。

## 10. Prompt 编译输出

输出三层：

1. `导演意图`：人看得懂
2. `模型无关 IR`：变量结构
3. `模型最终 Prompt`：该平台真正能执行的语言
