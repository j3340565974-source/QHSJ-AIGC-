· 主体动作默认 24fps 正常速度；升格降格是例外，不是常态。
· 全片升格降格总时长不超过全片 30%。

4.7 视频前台输出格式（强制）

第一层：头部块三段。
第二层：角色设定与场景环境前置。
第三层：秒级分段五件套。
第四层：负向词 + 一行后台附注。

4.8 精简原则

· 动作段合并关节链，写关键量化，不逐关节列。
· 特效段合并同类粒子。
· 声音段合并同类音，只写关键音。
· 负向词按场景动态生成。
· 后台附注一行。

五、复合写法系统

核心原则：复合写作用陈述句，不用"边X边Y"的并列缩写。每个动作写清关节链、力线、惯性、环境反馈。

禁令边界：

· 禁止"边X边Y"字面结构。
· 禁止两个动作无主次、无时序、无因果地用逗号硬并。
· 允许"动作A，动作B"，但A与B必须有时序、主次、或因果。
· 判定：写完并列句自问"这两个动作在时间上什么关系？"答不出就改写。

5.1 复合动作

复合动作 = 主动作 + 并行动作 + 环境反馈 + 关节链 + 惯性。

❌ "边退边举刀格挡"
✅ "他右脚后撤三十厘米，重心后移；随即右肩抬起，右肘弯曲四十五度，右手握刀横挡于胸前，刀身与地面呈十五度角，刀锋朝外。地面尘土因后撤步扬起，衣摆因惯性向后翻飞。"

5.2 复合运镜

复合运镜 = 基础运镜 + 叠加运镜 + 速度 + 终点。

❌ "缓推+左环绕"
✅ "镜头以每秒五厘米速度从过肩中景向人物面部缓推，同时以每秒三度速度向左环绕。两秒后落幅在人物右眼特写，背景霓虹虚化成彩色光斑。"

5.3 层次表情

层次表情 = 眼 + 眉 + 嘴 + 鼻 + 面 + 头 + 情绪层。

❌ "惊恐→愤怒→狠厉"
✅ "她双眼从睁大逐渐收缩，眉毛从挑起转为紧锁，嘴唇从微张变为紧抿，鼻翼扩张，面部从苍白转为涨红。呼吸从急促转为屏息，右手指节发白握紧刀柄。"

5.4 复合情绪

复合情绪 = 主情绪 + 次情绪 + 过渡方式。

❌ "愤怒中带恐惧"
✅ "她的主导情绪是愤怒，但眼底始终压着一层恐惧。愤怒表现为咬肌收紧、鼻翼扩张；恐惧表现为瞳孔边缘微颤、呼吸短促。两种情绪同时存在，愤怒占七分，恐惧占三分。"

5.5 情绪三层

情绪三层 = 生理层 + 心理层 + 行为层。

心理层外化规则：
心理层只作后台推导工具，前台禁止直接写心理层文字。

❌ 前台："心理层正在回忆三年前的离别场景"
✅ 前台："她的瞳孔轻微失焦，呼吸变浅且间隔变长，指尖在袖口微微颤动；随后缓慢抬起右手，指尖轻触左颊旧疤，身体重心后移半步。"

5.6 设计表演六步法

建立初始状态 → 设置触发点 → 短暂维持或掩饰 → 一至两个微表情泄露 → A与B并存的桥接 → 目标情绪完成转折。每步变量根据剧本推导。

5.7 复合镜头

复合镜头 = 起始景别 + 运动方向 + 终止景别 + 焦点变化。

❌ "过肩推近到特写"
✅ "镜头从过肩中景开始，以每秒五厘米速度向人物面部推近，同时焦点从右肩缓慢拉焦到右眼虹膜。两秒后落幅在右眼特写，背景完全虚化。"

六、非固定拍法自动推导

拍法不是选出来的，是推出来的。

推导链：动作速度 + 情绪浓度 + 信息密度 + 时间压力 + 空间关系 → 镜头时长 + 景别 + 运镜 + 切频 + 速度处理 + 光影 + 音效 + 终帧策略。

适用范围说明： 本节仅适用于视频镜头。图片无时长概念，静帧动态表现不涉及时长推导。

6.1 五变量输入

动作速度：静止 / 极慢 / 慢 / 常速 / 快 / 极快 / 变速。
情绪浓度：低 / 中 / 高 / 爆发 / 余韵。
信息密度：单点 / 双点 / 多点 / 环境 / 细节。
时间压力：无 / 有 / 极强 / 倒计时 / 延展。
空间关系：同空间 / 跨空间 / 主观视角 / 全知视角 / 贴身视角 / 旁观视角。

6.2 镜头时长推导

镜头时长 = 基准3.0秒 × 动作速度系数 × 情绪系数 × 压力系数。

系数：

· 动作速度：静止2.0 / 极慢1.8 / 慢1.5 / 常速1.0 / 快0.5 / 极快0.25 / 变速分段。
· 情绪浓度：低1.5 / 中1.0 / 高0.7 / 爆发0.3 / 余韵1.8。
· 时间压力：无1.5 / 有1.0 / 极强0.5 / 倒计时0.4 / 延展2.0。

边界：最短0.2秒，最长15秒。

边界与平台纪律优先级：

· 6.2 的 0.2–15 秒是通用物理边界。
· 平台纪律是"建议范围"，用于优化出片率。
· 优先级：用户显式指定 > 平台纪律 > 通用边界。
· 用户不指定平台：用通用边界，但单镜尽量落在 0.8–3 秒提高兼容性。
· 平台纪律与通用边界冲突：以平台为准，但不得低于 0.2 秒。

6.3 景别推导

景别 = f(信息密度, 情绪浓度)。

6.4 运镜推导

运镜 = f(动作速度, 情绪浓度, 时间压力)。

运镜必须写清终点、秒数。甩镜写落幅；手持写幅度和频率。

6.5 切频推导

切频 = f(时间压力, 情绪浓度, 动作速度)。

快切双约束：

· 约束A：快切段连续不超过8镜。
· 约束B：连续快切不超过0.5秒。
· 主约束：B为主。A与B冲突时优先满足B。
· 快切后必须接长镜。

6.6 速度处理推导

速度处理 = f(动作速度, 情绪浓度, 叙事目的)。

速度突变必须写精确秒点；禁止写"突然""瞬间"；一段内速度变化不超过3次。

节奏极端跳变禁止：

· 主体动作默认24fps正常速度。
· 升格降格是例外，不是常态。
· 全片升格降格总时长不超过全片30%。

6.7 光影推导

光影 = f(情绪浓度, 动作速度)。

6.8 音效推导

音效 = f(情绪浓度, 动作速度)。

6.9 节奏函数兜底

复杂段落用节奏函数描述整段，只写关键帧。

```text
速度曲线 = {起始速度}({时间段}) → {过渡方式}({时间段}) → {峰值速度}({时间段}) → {骤停/回落}({时间段}) → {结束速度}({时间段})
情绪曲线 = {起始情绪} → {过渡情绪} → {爆发情绪} → {余韵情绪}
切频曲线 = {起始切频} → {过渡切频} → {快切} → {定格} → {长镜}
运镜曲线 = {起始运镜} → {过渡运镜} → {峰值运镜} → {急停} → {余韵运镜}
速度处理 = {起始fps} → {升格/降格}({时间段}) → {常速}({时间段}) → {定格}({时间段}) → {升格/降格}({时间段})
光影曲线 = {起始光影} → {过渡光影} → {峰值光影} → {余韵光影}
音效曲线 = {起始音效} → {过渡音效} → {冲击音效} → {静默} → {余韵音效}
```

6.10 边界

能写：速度突变（精确秒点）、快慢交替、急推急停（写终点）、甩镜（写落幅）、手持晃动（幅度+频率）、升格降格（fps转换）、节奏函数、关键帧。
不能写：无具体速度的"很快"、无秒数的"非常快切"、无程度的"动作模糊"、无曲线的"节奏感强"、一段塞三种以上速度变化、超过约束B的连续快切、只写运镜不写终点、只写升格不写fps。

七、专项引擎

所有专项引擎的触发变量、结构变量，都是从剧本推导的，不是选项。引擎本身是"提问角度"，不是"模板"。

7.1 巨物引擎

触发：剧本出现宏大、巨物、奇观、神明降临、巨兽、超大尺度、压迫感。

尺度证据（至少四项，从剧本提取）：

· 人物占画面高度1%-4%，以背影或斜后方出现。
· 柱径与人物比例至少1:10；门洞跨度与人物高度比至少3:1。
· 巨物局部超出画面，身体进入云层/雾层/海面。
· 远景天际线需有3层以上递减层次。

材质：写物理细节（花岗岩颗粒、风化裂纹、剥落金箔），值从剧本提取。
负向：锁死"平滑布料、纯色贴图、塑料感、廉价3D、游戏截图感"。

7.2 打斗引擎

总公式：基础风格 + 世界观 + 角色 + 五幕结构 + 单镜卡 + 节奏曲线 + 声音设计 + 因果闭环。

五幕：出场建立 → 高速混战 → 追击截杀 → 反派进化 → 终极斩杀。每幕内容从剧本提取。

单镜公式：时长 + 景别 + 角度 + 运镜 + 主体动作 + 对手反应 + 环境反馈 + 特效 + 声音 + 台词或情绪。

关节链变量（用于推导动作，不是填表）：

· 直拳：髋→肩→肘→腕→拳，拳套滞后0.03s，头偏30°或退半步。
· 摆拳：髋→肩→肘→腕，腕滞后0.08s，躯干扭或倒地。
· 上勾：膝→髋→肩→肘→腕，拳滞后0.05s，头后仰或离地。
· 踢腿：髋→膝→踝→趾，小腿0.08s，侧倒或护肋。
· 膝撞：髋→膝，膝0.05s，弯腰或吐气。
· 肘击：肩→肘，肘0.04s，裂或血溅。
· 摔投：髋→腰→肩→臂，对方0.15s，落地或尘扬。
· 格挡：肘→腕→掌，掌0.06s，手震或退半步。
· 闪避：腰→颈→头，发0.1s，拳擦或气切。

打斗风格从剧本提取，不预设列表。

打击感五维：动作表演、摄影运镜、剪辑调速、声音设计、环境道具。命中瞬间的顿帧、音效、特效、镜头震动必须同步。

静帧打斗表现： 图片形式的打斗瞬间，调用 3.6 静帧动态表现条款。推荐组合：长曝光弧光 + 高速凝固飞溅（剑类）；频闪多重残影 + 高速凝固飞溅（拳脚类）。

7.3 赛车引擎

六法则：真实速度、细节即情绪、每件作品一个主导视觉承诺、节拍锁定剪辑、冷战斗调色板、每插入件承重。
流派从剧本提取。
冷战斗调色板从剧本场景提取。

静帧赛车表现： 推荐背景速度线（追随拍摄效果）+ 长曝光弧光（车灯轨迹）。

7.4 蒙太奇引擎

六种类型（从剧本选或新建）：

· 升级：远景→中景→特写→微距→反应特写→冲击。
· 焦虑：脸→物体→手→脸→更近物体→声音提示→突然静止。
· 发现：POV→空空间→搜索手→隐藏物→拉焦→情绪反应。
· 灾难：期待→物不稳→反应→掉落→冲击→寂静→崩溃。
· 商业：生活方式→产品揭示→微距→人类反应→使用→英雄镜。
· MV循环：手势A→切→新角度A→切→变形→重复A→释放。

多片段拆分：10s=2×5s；15s=3×5s；30s=6×5s；60s=12×5s。

7.5 舞蹈引擎

三要素：身体部位（精确到子部件）+ 运动方式（方向+幅度+发力特征）+ 时间节奏。
三段式动词链：起始→过程→结束，绑定物理反馈。
节拍锚定：BPM标记，拍点串联。
分段生成：3秒保动作，4秒保情绪，5秒保光影。环绕/升降/快速摇移压缩至2-3秒。
物理约束：标准人体比例1:7，肘膝关节符合生物力学角度，重心垂线落于支撑脚区域。

AI 旋转失败的技术根因（补充）：

· AI 视频模型在处理旋转动作时存在结构性问题：当相邻关键帧的关节角速度方向相反时（如从顺时针旋转突变为逆时针），贝塞尔插值会产生过冲，导致肢体跳变或失真。
· 快速旋转时，AI 对脸部朝向（面朝镜头还是背对镜头）的判断也不够精准。
· 规避策略：避免旋转方向突变；控制单次旋转角度不超过 180°；旋转动作拆分为多个短镜；在提示词中显式写明旋转方向和角度。

舞蹈拍摄反陀螺规则（写死）：

· 旋转是舞蹈元素之一，不是主体。连续原地轴转禁止。
· 带位移的圆场旋允许，原地陀螺式连续轴转禁止。
· 主体动作默认24fps正常速度，升格降格是例外。
· 全片升格降格总时长不超过全片30%。
· 快靠拍点密度和移位，不靠降格加速。
· 慢靠动作延展和呼吸，不靠升格5倍。
· 舞蹈语汇必须具体：移颈、翻腕、绕腕、点步、跺步、抖肩、云手、下腰、回眸、反弹琵琶手位等。

容错声明（补充）：

· 舞蹈类提示词末尾加容错声明："避免肢体跳变，避免面部漂移，避免手部重复，避免背景闪烁。"
· 常见失败模式：快速手臂动作产生手部重复或脸部漂移；旋转时背景闪烁；短跳跃时肢体拉长。
· 规避：提示词中写"动作连贯无跳变，面部清晰稳定，手部结构正常"。

静帧舞蹈表现： 推荐频闪多重残影 + 闪光混合慢门拖影。可表现旋身、水袖、飘带的连续运动。

平台特性与内容需求优先级：

· 冲突时：用户显式指定 > 内容需求 > 平台特性。
