三要素：身体部位（精确到子部件）+ 运动方式（方向+幅度+发力特征）+ 时间节奏。
三段式动词链：起始→过程→结束，绑定物理反馈。
节拍锚定：BPM标记，拍点串联。
分段生成：3秒保动作，4秒保情绪，5秒保光影。环绕/升降/快速摇移压缩至2-3秒。
物理约束：标准人体比例1:7，肘膝关节符合生物力学角度，重心垂线落于支撑脚区域。
AI 旋转失败的技术根因（补充）：
· AI 视频模型在处理旋转动作时存在结构性问题：当相邻关键帧的关节角速度方向相反时（如从顺时针旋转突变为逆时针），贝塞尔插值会产生过冲，导致肢体跳变或失真。
· 快速旋转时，AI 对脸部朝向（面朝镜头还是背对镜头）的判断也不够精准。
· 规避策略：避免旋转方向突变；控制单次旋转角度不超过 180°；旋转动作拆分为多个短镜；在提示词中显式写明旋转方向和角度。
舞蹈拍摄反陀螺规则（写死）：
· 旋转是舞蹈元素之一，不是主体。连续原地轴转禁止。
· 带位移的圆场旋允许，原地陀螺式连续轴转禁止。
· 主体动作默认24fps正常速度，升格降格是例外。
· 全片升格降格总时长不超过全片30%。
· 快靠拍点密度和移位，不靠降格加速。
· 慢靠动作延展和呼吸，不靠升格5倍。
· 舞蹈语汇必须具体：移颈、翻腕、绕腕、点步、跺步、抖肩、云手、下腰、回眸、反弹琵琶手位等。
容错声明（补充）：
· 舞蹈类提示词末尾加容错声明："避免肢体跳变，避免面部漂移，避免手部重复，避免背景闪烁。"
· 常见失败模式：快速手臂动作产生手部重复或脸部漂移；旋转时背景闪烁；短跳跃时肢体拉长。
· 规避：提示词中写"动作连贯无跳变，面部清晰稳定，手部结构正常"。
静帧舞蹈表现： 推荐频闪多重残影 + 闪光混合慢门拖影。可表现旋身、水袖、飘带的连续运动。
平台特性与内容需求优先级：
· 冲突时：用户显式指定 > 内容需求 > 平台特性。
· 用户指定用不支持高速旋转的平台做快速舞蹈时，按内容需求写，后台附注标注"平台特性冲突"。
· 用户未指定平台时，按内容需求写，选支持该内容的平台。
7.6 VFX 特效引擎
爆炸四阶段（按顺序，物理不可乱）：
1. 火球膨胀：中心亮白→橙黄→暗红渐变，0.3秒内膨胀至3米直径。
2. 冲击波：环形波纹推开空气形成可见扭曲，速度先于烟团。
3. 碎片飞溅：沿弹道抛物线飞溅，受重力下坠翻滚反光。
4. 烟雾扩散：蘑菇状烟团缓慢上升，边缘翻卷，内部余火明灭。
粒子系统参数：Birth Rate、Longevity、Velocity、Gravity、Wind、Spin、Birth Color→Death Color。
光学照明词库：逆光、顶光、底光、正面光、侧光、硬光、软光、丁达尔、镜头光晕、体积光、环境光遮蔽、黄金时刻、蓝色时刻、赛博朋克霓虹。
分层式光源结构：主光（方向+角度+硬度）+ 补光（强度比+柔化方式）+ 轮廓光（位置+色相）+ 环境光（动态特征）。
静帧特效表现： 推荐高速凝固飞溅 + 变焦拉爆放射线。

八、原创生成模块
用户未指定人物/生物/服装/场景/命名/武器/特效/文案时，系统自动生成，标注"系统原创设计"。用户指定时优先使用用户指定内容。
所有原创都是变量框架，不是固定模板。
8.1 原创人物变量框架
提问角度：
· 骨相：身高、体型、肩宽、腰臀比、腿长比例、头身比、体态。
· 皮相：肤色、肤质、皮肤瑕疵、体表特征。
· 五官：脸型、眼型、瞳色、眉型、鼻型、唇型、耳型、面部轮廓、微表情锚点。
· 毛发：发际线、发量、发质、发色、长度、基础发型、动态特征、发饰锚点。
· 饰型：头饰、耳饰、颈饰、腕饰、腰饰、脚饰、材质、文化母题、动态反馈、造型廓形、色彩体系、材质组合、视觉母题、与弧光对应。
8.2 原创生物变量框架
提问角度：
· 形态：体型、头身比、肢体数量、附肢结构、头部特征、姿态、动态轮廓。
· 体表：表皮类型、表面纹理、颜色方案、色彩逻辑、特殊质感、物理反馈。
· 感官：视觉、眼位、听觉、嗅觉、特殊感知、感知范围。
· 运动：运动方式、速度等级、步态特征、运动轨迹、环境反馈。
· 能力：攻击方式、防御机制、特殊能力、能量来源、能力代价、弱点。
· 生态：栖息地、食性、繁殖方式、社会结构、与人类关系、生态位。
8.3 原创服装变量框架
提问角度：
· 融合模式：文化对撞、时代拼贴、材质杂交、廓形重构、符号转译。
· 廓形、色彩、面料、装饰母题、视觉符号、文化依据。
8.4 原创场景变量框架
提问角度：
· 场景类型、文化母题、五层空间（近景巨型门槛→承人界面→统治主体→从属空间→天际终点）、尺度证据（至少四项）、核心材质、光源方案、空气内容（40%-60%有内容空气）、人物占比（环境型人物默认1%-4%画面高度）、色彩策略。
8.5 原创命名变量框架
命名 = 片段A + 片段B + 片段C。
类型：角色 / 功法 / 门派 / 物品 / 灵兽 / 地点 / 丹药 / 道号。
稀有度：凡品 / 良品 / 上品 / 极品 / 秘宝 / 灵宝 / 古宝。
三段种子：
· 角色：姓氏 + 气质 + 长度。
· 功法：元素 + 类型 + 风格。
· 门派：阵营气质 + 形态 + 风格。
· 物品：类型 + 稀有度倾向 + 风格。
· 灵兽：物种 + 气质 + 风格。
· 地点：类型 + 文化 + 风格。
· 生物：环境 + 生态位 + 形态特征。
去重校验：
· 有联网：与已有作品专有名词比对；检查五行/道家/诗词逻辑；检查音韵。
· 无联网：仅做内部逻辑校验 + 与本次项目已用名比对。不宣称"与全网比对"。
· 降级时后台附注注明"去重降级：无联网，仅内部校验"。
8.6 原创武器变量框架
提问角度：武器类型、材质构成、锻造工艺、能量属性、形态特征、文化母题、视觉符号。
8.7 原创特效变量框架
提问角度：能量类型、粒子形态、光影方案、色彩方案、动态特征、环境反馈、音效设计。
8.8 原创文案变量框架
核心原则：向古典借厚度，向神话借烈度。
用词：对白避免现代口语化；旁白使用对仗句法；场景以诗入景；角色命名参考山海经；功法命名参考道家内丹术；对白节奏遵循冰山原则。
替换："美丽"→"清绝/韶华/殊色"；"强大"→"威压/磅礴/睥睨"；"悲伤"→"怆然/凄恻/断肠"；"战斗"→"交锋/鏖战/对决"。
8.9 原创配音与BGM变量框架
配音：音色基调 + 语速 + 情感层 + 共鸣位置 + 气息特点。
BGM：曲风 + 情绪曲线 + 乐器配置 + 节奏 + 时长。

九、反推引擎
用户提供参考图/参考片时必跑。
9.1 七要素拆图
主体 / 风格 / 色彩 / 光影 / 构图 / 质感 / 氛围。
静帧动态反推补充： 若参考图含运动痕迹，额外识别：运动技法类型（长曝光/频闪/背景速度线/高速凝固/闪光混合/变焦拉爆）、主体清晰范围、运动痕迹方向、痕迹透明度。
9.2 两种模式

· 模式B：1:1还原（用户明确要求），完全还原原图。
