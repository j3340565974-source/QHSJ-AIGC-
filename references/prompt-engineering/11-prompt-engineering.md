# 提示词工程

> 来源：模板skill.doc + 模板工程skill.doc + 提示词精准化手册
> 五大台账 + 变量推导链 + 全平台适配。

---

## 1. 提示词工程核心原则

**核心原则**：AI需要的是"能执行的说明书"，不是"形容词堆砌"。

- AI绘画/视频模型是"看图说话"的水平
- 用它能听懂的人话描述比堆专业术语有效10倍

**五大原则**：
1. 不用专业空间术语改用自然语言
2. 描述动作不描述状态
3. 明确位置关系不用相对坐标
4. 朝向写"身体+脸"分开
5. 负面提示词写"禁止什么"比正面写"要什么"更有效

## 2. 五大台账

### 2.1 角色台账

记录每个角色的固定特征：
- 外观
- 服装
- 音色
- 性格
- 习惯动作

每次提到这个角色，自动调用台账里的固定描述，保证一致性。

### 2.2 场景台账

记录每个场景的固定元素：
- 空间结构
- 固定道具
- 光线特征
- 氛围

每次回到这个场景，自动调用台账里的固定描述。

### 2.3 道具台账

记录每个重要道具：
- 外观
- 位置
- 功能
- 象征意义

### 2.4 空间台账

记录每个场景的空间关系：
- 锚点
- 轴线
- 人物站位
- 机位位置

### 2.5 风格台账

记录全片统一的风格参数：
- 色调
- 质感
- 光影
- 导演风格

## 3. 变量推导链

```
用户需求 → 题材 → 类型 → 风格 → 导演参考 → 色彩 → 光影 → 材质 → 镜头 → 运镜 → 构图 → 提示词
```

每一步都有推导逻辑，不是随机选的。

---

## 4. 提示词结构

### 4.1 静态图提示词结构

```
【风格】+【主体】+【动作】+【场景】+【光影】+【材质】+【构图】+【镜头】+【渲染】+【负向】
```

### 4.2 动态视频提示词结构

```
【风格】+【角色】+【场景】+【空间】+【镜1（Xs）】+【镜2（Xs）】+...+【负向】
```

---

## 5. 防跑偏约束

每个提示词都要加约束：
- 人物一致性
- 场景一致性
- 动作物理合理
- 光线方向统一
- 风格统一

---

## 6. 提示词精准化手册

### 6.1 废词全清单

去掉没用的形容词：
- "beautiful"
- "amazing"
- "high quality"
- "detailed"
- "professional"

这些词AI听不懂，换成具体视觉词。

### 6.2 抽象词→具体视觉词对照表

| 抽象词 | 具体视觉词 |
|---|---|
| 高级感 | 低饱和、克制、留白 |
| 电影感 | 浅景深、自然颗粒、柔和高光 |
| 压抑 | 冷色调、低照度、高对比 |
| 浪漫 | 暖色调、柔光、浅景深 |
| 史诗感 | 大远景、低饱和、强纵深 |

### 6.3 提示词自检清单（12项）

□ 有没有抽象形容词？
□ 有没有具体视觉描述？
□ 位置关系明确吗？
□ 朝向写清楚了吗？
□ 动作具体吗？
□ 物理合理吗？
□ 光线方向统一吗？
□ 风格统一吗？
□ 人物一致吗？
□ 场景一致吗？
□ 有负向词吗？
□ AI能看懂吗？

## 7. 人物朝向三段式拆分

```
身体朝向 + 头部转向 + 视线看向
```

三段分开写，不要混在一起。

---

## 8. 反着写提示词去AI感

不要写"一个男人站在那里"，要写"他靠在门框上，一只脚抬着，手插在口袋里"。

**原则**：
- 具体 > 抽象
- 动作 > 状态
- 细节 > 概括

---

## 9. 五层提示词结构

```
第1层：基础设定（风格/题材/时代）
第2层：氛围画质（光影/质感/色彩）
第3层：几何关系（位置/朝向/空间）
第4层：时间轴（动作/变化/运镜）
第5层：情绪落点（情绪/氛围/主题）
```

---

## 10. 违禁词安全替代（强制）

- 不写直接伤害结果改用动作过程和视觉暗示
- 不写武器直接接触要害改用空间位置描述
- 不写血腥细节改用环境反应
- 不写自伤/自杀/危险模仿
- 不写未成年人暴力
- 不写真实政治/宗教/民族冲突

---

## 11. 段缝衔接规则

多段视频之间的衔接：
1. 最后一帧和下一帧第一帧要连贯
2. 光线方向要统一
3. 人物位置要连续
4. 动作要自然过渡
5. 风格要一致

---

## 12. 微表情六维拆解公式

把表情拆成六个维度：
1. 眉头
2. 眼睛
3. 鼻子
4. 嘴巴
5. 下巴
6. 脸颊

每个维度都有具体变化，不要只写"悲伤的表情"。
