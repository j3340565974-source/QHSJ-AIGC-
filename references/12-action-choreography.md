# 动作、武术、打斗、追逐与群像调度

## 1. 动作五段式

`意图 → 准备 → 发力 → 峰值 → 收势/反馈`

## 2. 关节链

人体动作优先检查：

`脚底 → 膝 → 髋 → 躯干 → 肩 → 肘 → 腕 → 手指`

发力方向、支撑面和重心必须一致。

## 3. 打斗回合

`试探 → 攻击 → 防守/闪避 → 反击 → 位置变化 → 下一回合`

每回合必须改变至少一个状态：位置、距离、资源、伤势、信息或心理策略。

## 4. 武术风格

可以调用：写实格斗、武侠、剑术、枪械战术、舞蹈化动作、夸张英雄动作、怪物动作等，但必须明确“物理层”和“风格层”哪个优先。

## 5. AI 视频动作策略

复杂动作不要堆在一镜。可拆成：

`蓄力镜 → 发力镜 → 接触/交错镜 → 反应镜 → 位置重置镜`

## 6. 多人打斗

给每个角色唯一 ID，建立：

`位置 / 目标 / 当前攻防状态 / 朝向 / 手持物 / 速度 / 下一动作`

## 7. 追逐

车辆、人、镜头都需要速度关系。不要只写“高速追逐”，而要写相对距离和道路空间变化。
