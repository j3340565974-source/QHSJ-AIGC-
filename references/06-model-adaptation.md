## 2. Seedance 专项适配

### 2.1 Seedance提示词结构

```
【风格】
【角色+音色】
【场景】
【空间】
【镜1（Xs）】...
【镜2（Xs）】...
```

### 2.2 Seedance相机参数

- 推镜/拉镜/摇镜/移镜/跟镜
- 运镜速度
- 运镜方向
- 镜头呼吸感

### 2.3 Seedance角色参数

- 角色外观锁定
- 服装锁定
- 音色锁定
- 动作一致性

### 2.4 Seedance灯光参数

- 光源方向
- 布光方式
- 色温
- 光比

### 2.5 Seedance风格参数

- 整体风格
- 调色
- 质感
- 美学定位

### 2.6 Seedance时长纪律

- 单段时长限制
- 超限拆法
- 段缝衔接规则

### 2.7 Seedance防崩坏

七大崩坏类型与根因分析：
1. 人物变脸
2. 场景跑题
3. 动作崩坏
4. 穿模
5. 道具瞬移
6. 空间跳变
7. 光影混乱

**人物一致性四步法**：
1. 角色锚点锁定
2. 参考图引用
3. 动作设计五原则
4. 段缝衔接检查

## 3. 其他模型适配

### 3.1 Midjourney

- 提示词结构：主体 + 风格 + 镜头 + 光影 + 材质 + 参数
- 参数：--ar 16:9 --v 6 --style raw
- 特点：美学感强，适合静态图

### 3.2 Stable Diffusion / ComfyUI

- 提示词结构：正向词 + 负向词 + ControlNet + LoRA
- ControlNet：空间透视、姿态、线稿
- LoRA：角色一致性、风格
- 特点：可控性强，适合工作流

### 3.3 Flux

- 提示词结构：自然语言描述
- 特点：理解能力强，适合复杂描述

### 3.4 Kling

- 提示词结构：场景 + 人物 + 动作 + 运镜
- 特点：动作自然，适合动态视频

### 3.5 Runway

- 提示词结构：场景描述 + 动作描述
- 特点：电影感强，适合短片

### 3.6 Veo

- 提示词结构：详细场景描述 + 镜头描述
- 特点：画质高，适合高质量视频

### 3.7 MiniMax H3

- 提示词结构：H3专属格式
- 特点：长文本理解强

## 4. 模型选择决策树

```
用户需求
├─ 要视频？
│  ├─ 要高画质？→ Veo / Kling
│  ├─ 要动作自然？→ Kling / Runway
│  ├─ 要运镜复杂？→ Seedance
│  └─ 要快出？→ 即梦
├─ 要图片？
│  ├─ 要美学感？→ Midjourney
│  ├─ 要可控性？→ SD / ComfyUI
│  ├─ 要自然语言理解？→ Flux
│  └─ 要角色一致性？→ SD + LoRA
└─ 要配音？
   └─ 音色匹配 → 对应TTS模型
```

## 5. 提示词转写规则

### 5.1 不同模型的语言风格

- **Midjourney**：关键词堆叠，用逗号分隔
- **SD**：权重语法，(word:1.2)
- **Flux**：自然语言句子
- **Seedance**：结构化分镜描述

### 5.2 专业术语转写

把导演术语转成模型能理解的词：
- "奥赛罗式构图" → "人物在画面中心，周围对称排列"
- "J-cut" → "声音提前两秒出现"
- "场面调度" → "人物位置和移动"

### 5.3 负面提示词转写

- 正面写"要什么" → 负面写"禁止什么"更有效
- 模糊的负面词 → 具体的负面词

---

## 6. AI可理解用词规范

AI绘画/视频模型是"看图说话"的水平，用它能听懂的人话描述比堆专业术语有效10倍。

**五大原则**：
1. 不用专业空间术语改用自然语言
2. 描述动作不描述状态
3. 明确位置关系不用相对坐标
4. 朝向写"身体+脸"分开
5. 负面提示词写"禁止什么"比正面写"要什么"更有效

---

## 7. 防跑偏约束

每个模型都有自己的跑偏倾向，需要针对性加约束：

| 模型 | 常见跑偏 | 约束方法 |
|---|---|---|
| Seedance | 人物变脸 | 加角色锚点 |
| Midjourney | 风格太浓 | 加--style raw |
| SD | 手部崩坏 | 加负面词 |
| Flux | 细节过多 | 加简化约束 |
