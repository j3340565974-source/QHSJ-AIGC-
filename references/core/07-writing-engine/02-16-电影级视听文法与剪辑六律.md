## 16. 电影级视听文法与剪辑六律

> 来源：qh-cinematic-dramaturgy-rules.md

### 16.1 视听镜头"三任务法则"

在生成任何镜头前，强制该镜头必须承担以下至少一个明确任务，三项皆无的镜头一律剔除：
1. **改变人物情绪**（Changes Emotion）：从自信到慌乱、从伪装到破防、从冷酷到动容
2. **实质推进动作**（Advances Action）：完成物理位移、攻防碰撞、破坏场景或传递道具
3. **施加戏剧压力**（Increases Pressure）：缩短距离、缩紧时间、逼入死角

### 16.2 大师级摄影机调度三大法则

1. **大卫·芬奇法则（Fincher Law）**：摄影机默认静止沉稳，只有画面主体发生状态改变时才跟随运镜，运镜速度与主体运动1:1同步
2. **斯皮尔伯格空间法则（Spielberg Law）**：无论打斗或调度多激烈，观众在任何一秒都必须清晰知道"主角在哪、威胁在哪、出口在哪"
3. **黑泽明环境压力法则（Kurosawa Law）**：全场必须由一种主导的物理环境压力贯穿（暴雨/狂风/水雾/碎石/频闪日光），增强视听沉浸感

### 16.3 默奇剪辑六律与视线落点连续性

剪辑切镜优先级矩阵：
```
情感真实(51%) > 剧情推进(23%) > 节奏节拍(10%) > 视线引导(7%) > 二维构图(5%) > 三维空间(4%)
```

**Eye-Trace视线引导**：上一镜观众视线落在画面右上角，下一镜切入瞬间的核心信息点必须精准承接在右上角或顺势滑动，严禁让观众满屏寻找焦点。

### 16.4 反形容词与去油腻提示词转化

严禁在提示词中使用空洞形容词，强制100%转译为摄影机可捕捉的物理事实：

| ❌ 空洞形容词（严禁） | ✅ 摄影机可记录的物理事实（强制执行） |
|---|---|
| "他很愤怒" | 咬紧后槽牙，咬肌剧烈隆起，下颌骨紧绷，指节捏得发白泛青 |
| "激烈的打斗" | 后脚蹬碎青砖，腰胯猛拧，拳峰重击下颚，断齿伴随血沫飞溅 |
| "极具压迫感的光线" | 左上方窗棂透入窄条冷天光，阴影深沉，半边脸颊隐入青灰暗部 |
| "速度极快" | 身形化作一道撕裂空气的蓝色残影，出招瞬间空气被击穿出细长气穴 |
| "剑法高超" | 剑尖沿极小侧弧绕开对手中线，寸劲直刺手腕，剑格碰撞爆出冷白星芒 |

**注意**：本节只约束画面段。声音层不受反形容词约束——语气位、镜行声音段、音效段可以用质地与力度词（嘶哑/低语/气音/冷笑），因为声音没有"肌肉动作"可写。但声音层同样禁空泛结果词：难过/生气/开心既非音质也非力度，是结果，一律禁。
