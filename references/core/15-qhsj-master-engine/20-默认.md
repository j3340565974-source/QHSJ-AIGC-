# 模块 A：镜头语言与运镜系统
## A1. 基础四大定场镜头
- **水平平移（Truck/Pedestal Level）**：平视高度，水平匀速横移，无倾斜抖动。适配：庭院长廊、舒缓开场、万能基础。抖音口诀："拍大景用横移"。
- **高低俯仰（Tilt Up/Down）**：垂直轻柔升降；仰拍拉高气场/权力感，俯拍压缩画面/渺小感。适配：建筑、庭院、人物沉思。抖音口诀："竖拍建筑全景用纵摇，仰拍高大全貌用降镜，神秘展示主体用升镜"。
- **渐近向前推（Dolly In / Push In）**：匀速缓慢向前贴近，从环境过渡到半身。适配：发呆、沉思、聚焦情绪、顿悟时刻。抖音口诀："突出主体细节用推镜；做推镜头手机开 0.5x 超广角，才有冲击感"。
- **远景向后拉（Dolly Out / Pull Back / Reveal）**：平稳向后匀速退行，铺开全景。适配：留白叙事、孤独氛围、意境结尾、揭晓真相。抖音口诀："展示整体全景用拉镜；拍雕塑用后拉"。
## A2. 情绪与氛围运镜（四大手法）
- **低速沉浸环绕（Orbit / Arc Shot）**：低速度圆弧匀速环绕，丝滑克制。适配：孤寂、温柔、独处、人物登场。**抖音实战细节**：广角端环绕信息多、动势平缓适合铺垫；长焦端环绕背景压缩感强、人物与背景运动关系被剧烈放大，适合情绪冲击。
- **微幅精细定点摇镜（Micro Pan / Locked Micro Move）**：机位锁死，微米级慢动。适配：捕捉发丝、眼神、神态留白。
- **视线情绪追随（Whip Pan / Look Follow）**：跟随人物视线偏移。适配：解决 AI 镜头死板无魂问题。
- **静置呼吸锁镜（Locked Off / Static Breather）**：机位静止，保留自然呼吸感、眨眼、衣袂微动。适配：情绪停顿、剧情留白、收尾。**杜琪峰《枪火》式美学**：用静止构图和简洁机位制造压迫感，真正的力量来自克制而非炫技。
## A3. 动态行走镜头（四大运镜）
- **贴身同步跟拍（Follow Tracking）**：贴合人物动线，匀速随行，人物在画框中位置稳定、背景流动。适配：庭院漫步、缓步前行。**手机实战**：脚后跟先着地小碎步；跟随拍摄时脚步转向前进方向，不要螃蟹步。
- **定点侧向横摇（Fixed Pan）**：机位固定，左右匀速扫动。适配：驻足观望、环视景色。
- **正向缓步前移（Push-in Walk）**：平稳慢速直线推进。适配：走向风景、治愈系开场。抖音口诀："拍小路用前推；拍风景斜前推"。
- **平行侧向滑移（Parallel Truck）**：与人物平行，同步侧移。适配：侧面展示身姿、剧情过渡、两人并肩。
## A4. 抖音十大万能运镜口诀（直接背诵）
1. 突出主体细节 → 推镜
2. 展示整体全景 → 拉镜
3. 横拍宽幅全景 → 横摇
4. 竖拍建筑全景 → 纵摇（升/降）
5. 平行画面展示 → 平移
6. 神秘展示主体 → 升镜（Crane Up）
7. 仰拍高大全貌 → 降镜（Crane Down）

## A5. 节奏衔接运镜（解决跳帧生硬）
- **节奏推拉衔接**：前推聚焦情绪，后拉交代场景。
- **多维度角度切换**：高低远近微调，丰富层次。
- **大环境时空过渡**：镜头慢速扫览全域，替代剪辑硬切。
- **快慢节奏控速**：慢镜沉淀，快镜推进，松紧错落。
## A6. 运镜三大铁律（抖音+电影学院共识）
1. **起幅落幅**：每个运动镜头前后多录/多生成 2 秒静止画面，给剪辑留手脚。
2. **动势唯一性**：一次运镜只做一个方向，要么推拉要么横移，禁止一次运镜中突然变向。
3. **运镜有动机**：镜头动是因为情绪/信息/人物需要，不是为了炫技；无动机的运动 = 业余感。
## A7. 景深四段叙事（不是虚化，是镜头叙事）
- **大景深（Deep Focus）**：全场清晰，远近通透。适配：开场定场、群戏关系、奥逊·威尔斯式纵深调度。
- **适中景深（Medium DOF）**：人物极清，环境微虚。90% 人像首选，万能平衡。
- **双人虚实景深（Differential Focus）**：一人极清一人虚化。适配：区分主次、疏离感、心理距离、三角关系。
- **极致浅景深（Shallow DOF）**：局部对焦，全屏虚化。适配：极致情绪特写、共情、主观视角。
## A8. 三步流畅镜头衔接逻辑
- **空间定调层**：优先展示整体场景（远景/全景），拒绝开篇直接切特写。
- **人物行为层**：标准中景承接，让人物与场景自然融合。
- **细节点睛层**：抓取眼神、手部、物件特写，打造视觉记忆点。
- **总结**：空间铺垫场景，行为推进剧情，细节留住观感。

**AI 制作要点**：70mm 胶片质感，暖调柔光，古装真人造型，人体比例正常，无畸形穿模，严格把控间距；两人之间的"安全距离"不要轻易打破——距离=心理距离。
**Two-Shot 导演原则（全球共识）**：双人镜头是传递关系、权力动态、情感连接的基本语法。构图必须写明：主体位置、相对大小、视线方向、两人之间的空间间隙。
- 对称双人镜头（如《黑暗骑士》蝙蝠侠 vs 小丑）：构图平衡、几乎对称，呈现"等量但对立"的力量。
- 前景遮挡法：A 在前景过肩，B 在中景，制造"我们在 A 背后偷听"的代入感。
- 框内框：用门框/窗框/车窗把两人同时框住，强化被困关系。

## B4. 金銮殿标准站位（大朝会）
- **礼制布局**：以中轴线分界，文官居左，武官居右，左右完全对称。
- **尺寸**：同列横向 1.1m，前后排纵向 1.3m。
- **状态**：全员站姿肃穆，视线统一望向御座。
- **AI 用法**：平视全景展示整体，俯视讲解阵型，侧拍强化纵深，帝王身后视角凸显尊卑。
## B5. 杜琪峰式战术站位（港片枪战经典）
- 5 人固定站桩不是呆板，是经过战术推演的攻防体系：**前排控场、中排护主、后排兜底**。
- 核心人物稳居前方紧盯前路（大脑）；护卫贴身守护 VIP；警戒位观察侧翼。
- 用静止构图让观众在开枪前就感到窒息危机。
- 枕形畸变（广角边缘拉伸）的全景，把两边人物分开，表明"互不侵犯的界限"。
## B6. 构图法则库（全球电影学院通用）
- **三分法（Rule of Thirds）**：3×3 九宫格，眼睛放上 1/3 线，地平线按下或上 1/3；兴趣点放四个交点。
- **对称构图（Symmetry）**：中心轴镜像。韦斯安德森式：秩序、控制、仪式感、微诡异。
- **不对称平衡（Asymmetry）**：用重量不对称的元素（人 vs 大面积留白）制造张力。
- **对角线构图（Diagonal）**：天然动感与张力，适合对立、奔跑、冲突。
- **框架构图（Frame within a Frame）**：门窗、桥洞、树枝、人群缝隙把主体框住，制造偷窥感/被困感。
- **引导线（Leading Lines）**：道路、走廊、栏杆、光带把视线引向主体；把 2D 变 3D。
- **前景遮挡（Foreground Occlusion）**：前景虚化的人影/树叶/栏杆，增加层次和窥探感。
- **留白（Negative Space）**：人物面朝方向留空，背对方向贴边；空得越多，孤独/渴望越强。
- **荷兰角（Dutch Angle / Tilted Frame）**：地平线倾斜，表现心理不安、醉酒、失衡、疯狂。
- **顶视/上帝视角（Bird's Eye）**：压扁人物、暴露布局、宿命感、棋局感。
- **过肩镜头（OTS）**：前景一人肩/头虚化，后景另一人清晰，对话戏基础。
- **中央构图（Centered）**：人物正中，仪式感、对峙、肖像、 Wes Anderson / 张艺谋式庄重。
