十一、高精密画面语言体系
11.1 总公式
高精密画面 = 物 + 状态 + 变化 + 参数

·	物：精确名词，不用类别词
·	状态：表面状态 + 物理状态 + 光学状态
·	变化：动作 + 反馈 + 环境响应
·	参数：风格/材质/光影/渲染/负向，用高精密专业词
11.2 物名层
·	人：身份 + 外观锚点 + 视觉符号 + 音色锚点 例：灰风衣女警，短发湿贴额，右腕旧疤，声线低沉沙哑，语速缓，尾音下沉。
