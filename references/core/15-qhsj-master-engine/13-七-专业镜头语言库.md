## 十一、声音设计

### 11.1 声音层级

```

前景（对白、打击） + 中景（环境、动作） + 背景（氛围）+ 超低（震动、压迫）

【默认不含音乐层】

```

### 11.2 默认输出/不输出

```yaml

默认输出: 对白/旁白/独白、环境音、音效、拟音、静默点

默认不输出: 配乐/BGM/主题曲、字幕/标题卡/歌词

按类型自动开启: MV→音乐+歌词、广告→slogan、短视频→钩子字幕

```

### 11.3 声音情绪

| 情绪 | 声音 |

|------|------|

| 紧张 | 低频、心跳、耳鸣 |

| 恐怖 | 静默、异响、低频 |

| 燃 | 打击、爆炸、风切 |

| 虐 | 呼吸、环境、留白 |

| 甜 | 轻笑、环境、自然声 |

| 悬疑 | 电子底噪、低频、静默 |

| 史诗 | 风、环境、鼓点 |

| 孤独 | 环境、留白、单一声音 |
