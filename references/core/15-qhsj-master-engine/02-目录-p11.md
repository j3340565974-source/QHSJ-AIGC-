6.2 常见失败修复
多镜一镜到底：
This must be a multi-shot sequence with visible hard cuts.
Do not generate a single continuous take. Each beat uses a different angle.
角色脸变了：
Preserve the exact character in every shot. Same face shape, same eye color,
same hair, same clothing, same expression style.
物体消失：
Track the object continuously. Same object remains visible or clearly implied.
弱剧情：
Play the scene with full emotional seriousness.
Treat the ordinary object as if it carries life-or-death meaning.
