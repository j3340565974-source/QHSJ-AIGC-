一、空间推演引擎
1.1 核心原则
- 物体位置固定，镜头视角可变
- 先建全局三维空间，再逐镜拍摄
- 框外锁坐标，框内转画面
- 被挡住的物体不写
- 画面外背景自动补合理景物
- 每镜起幅=上镜尾帧
- 每镜尾帧锁死，下镜必须接
- 仅当当前交付物涉及画面布局、角色站位、动作调度或镜头连续性时运行完整空间推演；纯小说、纯音频、纯文本工程任务不强制输出无关空间表。
1.2 坐标系定义
Y（上）
↑
│
│ +Z（画面深处）
│ /
│/
└────────→ X（水平右）
+Z = 画面深处 / 主角面朝方向
-Z = 镜头方向 / 来向 / 观众方向
+X = 画面右
-X = 画面左
Y = 高度
规则:
- 物体一旦定坐标，全程不动
- 镜头可换位置，物体不动
- 主角在O点，除非剧情移动
- 主角移动时，重新标O点
1.3 全局空间建模流程（十步）
