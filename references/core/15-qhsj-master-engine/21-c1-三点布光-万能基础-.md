## C1. 三点布光（万能基础）
- **主光（Key Light）**：最亮的灯，决定画面基调；通常在人物斜上方 45°。
- **辅光（Fill Light）**：补阴影，亮度为主光的 50%–80%（即光比约 1:2 到 1:1.25）；越柔越平。
- **轮廓光/背光（Rim/Back Light）**：从后上方打来，把主体从背景分离，尤其暗发/暗衣 + 暗背景时必须有，通常硬光。
- **顺序**：先主光定基调 → 再辅光补阴影 → 最后轮廓光分离背景。
## C2. 八种经典人像光位
| 光位 | 位置 | 视觉效果 | 适配 |
|---|---|---|---|
| 伦勃朗光（三角光） | 主光斜上方，鼻影尖落到对侧脸颊形成小三角光斑 | 五官立体、古典、戏剧性、神秘 | 《繁花》式民国/高级肖像 |
| 蝴蝶光（派拉蒙光） | 主光正前方高位，鼻影像蝴蝶落在上唇 | 颧骨高光、美妆、优雅 | 女性美妆、广告、红毯 |
| 侧光（Split Light） | 主光正侧方，脸一半亮一半暗 | 硬朗、双面性、戏剧冲突 | 硬汉、反派、悬疑 |

## C3. 古风漫射柔光四大层级
- **原生硬光**：光影分界清晰。适合：英气侠气古风。
- **轻透淡柔光**：轻微柔化棱角，保留场景细节。百搭基础。
- **全域温润漫射光**：全场铺满柔和光线，硬阴影全柔化。日常出图首选。
- **烟雨朦胧柔光**：高浓度柔光 + 雾感。古风意境大片。
## C4. 古风人像四大影调
- **冷调清冷风**：青蓝冷色，弱化暖调；冷调天光 + 月色逆光。适配：侠女、仙侠、悲剧。
- **暖调温柔风**：暖黄杏色，亲和力强；落日暖调逆光，柔光均匀铺面。适配：闺阁、甜宠、江南。
- **莫兰迪低饱和风**：降低艳度，素雅柔和，沉稳大气；均匀平铺漫射柔光。适配：文人、仕女、高级感。
- **高对比暗调电影风**：加深暗部，强化明暗对比；强轮廓逆光。适配：权谋、武侠、雨夜。
## C5. AI 真人影像质感避坑指南
- **核心原则**：真实第一，质感为王，情绪为魂。
- **避坑 1 过度磨皮**：保留真实毛孔、细纹、小瑕疵，去掉假面感。
- **避坑 2 CG 人偶感**：拒绝五官僵硬，保留自然微表情与真实情绪。
- **避坑 3 假脸反光**：追求哑光真实肤质，拒绝油光硅胶假面。
- **正确光影**：侧柔光塑形，逆光勾边 + 环境融合，统一柔和漫射光源。
- **硬性约束词（必带）**：8K 院线级真实皮肤肌理、35mm 富士柔光胶片颗粒、低饱和米棕暖调、原生毛孔/细纹/自然小瑕疵、ARRI Alexa 拍摄质感、Kodak Vision3 500T。
- **负向词**：卡通、动漫、手绘、漫画、塑料质感、硅胶脸、过度磨皮、CG 人偶、油光假面、解剖扭曲、多余肢体。
## C6. 现代都市精英女定妆光影
- **主光**：侧方柔光箱漫射，低对比柔和过渡，高光只落在骨骼自然凸起处（颧骨、鼻梁、眉骨、唇峰）。
- **背景**：极简浅灰纯色棚拍，无繁杂布景。
- **约束**：8K 院线真人商业人像，35mm 富士浅胶片颗粒，强制保留皮肤肌理与细微自然瑕疵；杜绝重度磨皮、硅胶塑料假面、CG 人偶感。

# 模块 D：导演思维与分镜系统
## D1. 单场戏五分镜拆解公式（万能）
> 远景环境铺垫 → 全景人物入场 → 中景核心动作（肢体潜台词）→ 近景情绪神态 → 特写细节收尾
五场范例：
1. **楼道黄昏告别**：远景楼道纵深 → 全景两人对立 → 中景克制伸手 → 近景半明半暗脸 → 特写悬空的双手（咫尺天涯）。
2. **古风胭脂美妆广告**：远景极简雅致 → 全景柔光逆光入场 → 中景轻柔涂抹产品 → 近景温婉神态 → 特写膏体质地。
3. **月光敦煌飞天独舞**：远景戈壁石窟满月 → 全景月华披身 → 中景回旋起舞 → 近景眉眼含月 → 特写纱逐月光。
4. **红衣花旦戏台独舞**：远景空台灯火 → 全景一袭红衣 → 中景水袖翻飞 → 近景眼神落寞 → 特写水袖翻跃。
5. **民国雨巷爱恨对峙**：远景狭小巷道雨幕 → 全景两人入场 → 中景克制爆发 → 近景面部细节 → 特写滴落的雨/攥紧的伞。
## D2. 正反打与 180° 轴线规则
- **关系轴线**：两个对话者之间连一条无形线。机位必须始终在这条线的同一侧（180° 半圆内）。
- **跨轴后果**：A 突然从画面左边跳到右边，观众立刻晕、方向感崩塌。
- **视线匹配（Eyeline Match）**：A 看画面右边 → 下一个镜头 B 必须出现在画面左边（因为 A 在看 B）；A 看画左，B 在画右。
- **外反拍（过肩 OTS）**：机位在 A 肩后拍 B，画面里有 A 的后脑/肩——最经典。
- **内反拍（单人特写）**：机位越过轴线拍 A 单人，不带对方肩膀。
- **顶角机位**：在两人连线中点正前方，拍双人全景。
- **三角形原理**：两个对话者连线一侧，机位可以摆出三个点（顶角 + 两个反拍），构成底边与轴线平行的三角形。
## D3. 30° 规则（避免跳切感）
- 两个连续剪辑的同景别镜头，机位角度必须相差至少 30°；否则画面"跳"一下，观众出戏。
- 如果不想动 30°，就必须改景别（中景→近景），否则就硬切。
## D4. 四类经典对话戏机位图
- **古风酒楼当众决裂**：大全景交代环境压力 → 中景 → 近景放大愤怒 → 细节特写；180° 轴线，视线匹配，机位同侧。
- **江湖渡口雨夜离别**：空间物理隔离，用距离放大离别；跨空间视线匹配，机位同侧不越轴。
- **民国雨巷爱恨对峙**：近距离站立，情绪压在面部；狭窄空间机位更不能越轴。
- **唐风夜宴舞姬群戏**：群戏先铺环境，焦点收回双人；群戏锁定双人轴线，机位同侧。
## D5. 镜头拼接五大误区
1. 开篇直切特写，毫无场景代入感。
2. 前后镜头人物姿态、站位落差大，动作衔接断层。
3. 一味堆砌精美画面，无剧情无情绪推进。
4. 特写滥用过多，造成视觉审美疲劳。
5. 场景光影色调乱切换，整体风格割裂。
- **金句**："流畅成片不靠镜头数量，只靠清晰切换逻辑。"

## F2. AI 视频八层结构（Runway/Kling/Veo/Seedance 通用）

# 模块 H：短剧节奏与钩子（新增）
## H1. 黄金 3 秒定律
- 前 3 秒决定生死，后 10 秒决定转化。
- 开场必须用强画面或强反差把人按住：扇巴掌、下跪、反转打脸、爆炸、神秘出场、裂缝里渗血的文物。
- **三个零**：零铺垫、零人物介绍、零背景交代。
- 不要从剧情开头慢慢剪，直接把最炸的一帧甩到最前面。
## H2. 单集五段式黄金结构（以 100 秒为例）
| 时间 | 段落 | 任务 |
|---|---|---|
| 0–5s | 热开场（钩子） | 圈定用户，奠定情绪原点，冲突/反常画面 |
| 5–30s | 承接 | 推进行动，展开矛盾，主角打算干什么 |
| 30–60s | 递进激化 | 矛盾升级，障碍加码，情绪拉紧 |
| 60–85s | 反转/爽点 | 中段反转或打脸，情绪释放 |
| 85–100s | 情绪落点 + 集尾钩子 | 留悬念，"观众凭什么点下一集" |
## H3. 集内钩子 vs 集间钩子
- **集内钩子**：开场 5 秒，用冲突或反常画面把人摁住。
- **集间钩子**：每集结尾 5–10 秒，在情绪最高或最意外的地方切断，抛新悬念。
- **爽点与钩子必须错开**：刚给完一个爽点，立刻抛更大的麻烦，不要让观众喘。
- **节奏密度**：一段素材超过 3 秒没有情绪冲突就剪掉。
## H4. 系列短剧长线结构
- **主线 + 支线**：主角终极目标是主线；感情/反派/配角是支线。
- **3 集一小反转，10 集一大反转，季终大高潮**。
- 每集结尾必须有"未完成动作"：手伸到一半、电话刚接通、门刚推开。

# 模块 I：转场与剪辑衔接（新增）
## I1. 硬切（Cut）
- 最常见、最透明；动作进行中切最自然。
- 遵循 30° 规则和 180° 规则。
## I2. 匹配转场（Match Cut）
- **动作匹配**：上一个镜头抬手，下一个镜头另一个人接抬手。
- **视线匹配**：A 看画外 → 下一镜切到 A 看到的东西。
- **图形匹配**：相似形状/轮廓/颜色对接——《辛德勒的名单》蜡烛烟→火车头烟。
- **声音匹配（J Cut / L Cut）**：下一个镜头的声音先出来，画面再到（J 剪）；画面切了声音还留（L 剪）。
- **甩镜头转场（Whip Pan）**：快速横摇虚化，切到下一个方向接摇。抖音手机实操：0.5x 广角，3-2-1 走。
- **遮挡转场**：手遮住镜头/人走过镜头，换场景再拉开。
## I3. 淡入淡出与叠化
- **Fade to Black**：时间大跨越、章节结束。
- **Dissolve 叠化**：回忆、梦境、时空连接、情绪流动。
- **不要滥用特效转场**：AI 生成时优先硬切和匹配，避免花里胡哨的划像。
## I4. 跳切（Jump Cut）
- 同机位同景别硬跳一段时间，制造时间压缩、焦躁、断裂感。
- 戈达尔、王家卫常用；不要在严肃对话里随便用。
## I5. 蒙太奇
- **叙事蒙太奇**：交代时间流逝、训练过程、行程。
- **对比蒙太奇**：富/穷、战争/和平并置。
- **隐喻蒙太奇**：两个不相关镜头并置产生新含义（爱森斯坦）。
- **节奏蒙太奇**：镜头越来越短，制造紧张加速。

# 模块 J：声音设计（新增）
## J1. 三层声音结构
1. **环境音（Ambience）**：房间/街道/森林的底噪，建立空间和时间（蝉鸣=夏夜、鸟鸣=清晨、雪=一切闷掉）。
2. **音效（SFX）**：动作声——脚步、衣料、剑刃、雨打伞、心跳。
3. **配乐（Score）**：情绪线；主题旋律（Leitmotif）绑定角色/关系，如《星球大战》帝国进行曲。
## J2. 声音叙事技巧
- **静响对比（Dynamic Range）**：最响和最静的差距越大，jump scare 越吓人；全程大声=疲劳。
- **Stinger（刺音）**：突然一声尖锐音效，jump scare 标配。
- **次声（Infrasound <20Hz）**：身体感到但听不到，制造"有人在场"的不安，恐怖片常用。
- **预知性音乐**：危险还没出现，音乐先告诉观众——制造悬念。
- **Diegetic vs Non-diegetic**：故事内音乐（收音机/钢琴）vs 上帝视角配乐。
- **声音先于画面**：下一个场景的雷声/哭声先出来，画面再切——高级转场。
## J3. AI 视频 Prompt 中的声音写法
- 默认无音乐无字幕，除非用户要。
- 框内可写：`环境音：雨夜瓦片滴水 + 远处更夫梆子；脚步踩积水；衣料摩擦；无配乐；无字幕`。

# 模块 K：焦段与镜头选择（新增）
## K1. 焦段情绪表（全画幅等效）
| 焦段 | 名称 | 视觉特征 | 情绪/用途 |
|---|---|---|---|
| 14–24mm | 超广角 | 拉伸空间、边缘畸变、近大远小夸张 | 史诗、孤独、建筑、紧张、《寄生虫》横移 |
| 24–35mm | 广角 | 容纳环境、轻微拉伸、手持自然 | 定场、纪录片、狭小空间扩张、《撕裂的末日》穿行 |
| 35mm | 人文眼 | 接近人眼、可进可退 | 街拍、对话、日常、万能叙事 |
| 50mm | 标准 | 最接近人眼、无透视变形 | 写实、自然、生活流 |
| 85mm | 人像中长焦 | 背景压缩、脸不变形、浅景深 | 人像特写、浪漫、隔离感 |
| 135–200mm | 长焦 | 强烈空间压缩、前后景叠在一起 | 偷窥、远距观察、孤独、人群中找一个人、背景虚化 |
| 200mm+ | 超长焦 | 极强压缩、空气感 | 野生动物、战场、监视、宿命 |
## K2. 焦段×运镜组合
- **广角 + Dolly In**：冲击感最强，环境被快速"吸走"。
- **长焦 + 环绕**：背景剧烈流动，人物相对静止——情绪冲击。
- **广角 + 跟拍**：手持穿梭感，适合奔跑、追逐、狭小空间。
- **长焦 + 静帧**：偷窥感、观察感、《情人》《色戒》式远距离凝视。
## K3. 景深与焦段关系
- 焦段越长 → 背景越虚；光圈越大 → 背景越虚；离主体越近 → 背景越虚。
- 浅景深不是"高级感开关"，是叙事工具——用它把观众注意力钉在谁脸上。

# 模块 L：导演风格参考库（新增）
## L1. 韦斯·安德森（Wes Anderson）
- 中心对称构图、人物正面朝向镜头、建筑拍正面、完美几何。
- 马卡龙低饱和配色（粉、薄荷、姜黄、砖红、奶白）。
- 镜头运动几何化：完美水平横移、垂直升降、90° 正拍。
- 舞台/模型感布景、人物像剪纸、旁白式疏离感、戏服统一。
- Prompt 拼接：`perfectly centered symmetrical composition, flat perpendicular camera angle, pastel color palette, dollhouse set, stylized theatrical acting, deadpan narration`。
## L2. 克里斯托弗·诺兰（Christopher Nolan）
- IMAX 70mm / 35mm 大画幅、实拍、实景、交叉剪辑多时间线。
- 纪录片式自然光、手持、 elliptical editing（省略时间）。
- 声音设计实验：低频轰鸣、音画错位。
- Prompt 拼接：`IMAX 70mm film grain, practical locations, naturalistic lighting, cross-time-line editing, thunderous low-frequency score`。
## L3. 王家卫
- 手持慢门拖影、抽帧、高饱和黄绿/暧昧红蓝。
- 框中框（门框/车窗/镜子）、狭长走廊、雨、夜。
- 旁白、碎片化时间、"在 X 年 X 月 X 日 X 时"。
- 情绪：暧昧、错过、孤独、记忆。
- Prompt 拼接：`Wong Kar-wai style, step-printing slow motion, neon green and red, handheld, frame-within-a-frame, rainy night, voiceover, fragmented time`。
## L4. 杜琪峰 / 银河映像
- 静止长镜头、简洁构图、人物站位像战术阵型。
- 高饱和、硬光、暗调、港片街头。
- 《枪火》式：一群人不动，张力在沉默里。
- Prompt 拼接：`Johnnie To style, static wide shot, tactical group blocking, hard rim light, Hong Kong neon, tense silence before gunfire`。
## L5. 其他可拼接风格词
- **库布里克**：一点透视走廊、单点消失、对称、冷冷机械感。
- **罗杰·迪金斯（摄影指导）**：唯美柔光窗光、极简、蓝橙对比。
- **是枝裕和**：自然光、低饱和暖米、固定机位、日常即戏剧。
- **张艺谋**：单色冲击、群体仪式、浓烈色彩、构图如油画。
- **雷德利·斯科特**：烟雾、体积光、工业废墟、史诗感。
