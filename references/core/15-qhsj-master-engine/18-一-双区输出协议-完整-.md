### 1.2 视频框内标准结构
**核心原则**：
```
镜号带时长，内部叙事融合，不分行，不拆号，一气呵成。
顿帧只用于关键冲击瞬间，不用于连续动作。
一镜可多段：同一镜号内用"切"切换镜头段落，不拆成新镜号。
全画面逻辑矫正：焦点与机位匹配、视线匹配、空间位置一致、光源一致、
场景元素一致、动作物理合理、运镜有动机、转场逻辑衔接、音色一致、
构图匹配内容、轴线不越。
移动状态锁定：每个镜号必须明确移动方式、速度、身体姿态、步频、步幅、
手臂摆动、脚掌动作、呼吸状态、环境反馈、是否全程不停。
左右手逻辑锁定：每个镜号必须明确哪只手做什么，物体在哪只手上，
动作路径必须清晰。
物理锁定：每个镜号必须包含物理锁定模块。
场景锚点：有参考图时，每个镜号必须引用场景锚点图。
角色锚点：有参考图时，每个镜号必须引用角色锚点图。
```
**核心模板**：
```
【风格】{主体风格}|{流派}|{导演}|{色彩}|{质感}|{情绪基调}
【材质】肤:{...}|发:{...}|眼:{...}|布:{...}|金:{...}|微:{...}
【光影】{光源}|{布光}|{方向}|{质感}|{色温K}|{光比}
【渲染】{引擎}|{追踪}|{GI}|{体积}|{降噪}|{抗锯齿}|{色彩空间}|{胶片}|{镜头}|{后处理}|{分辨率}

【物理锁定】重力9.81m/s²|动量守恒|接触面贴合|惯性传导链|流体受重力|光学定律|热力学定律|生物力学
```

## 二、叙事流格式
### 2.1 定位
```
槽位卡 = 给AI的精简指令
叙事流 = 给人看的分镜脚本 / 可喂长上下文模型
```
### 2.2 叙事流结构
```
【段落标题】（景别/调度/节奏总述）
· 开局状态：{谁在哪，什么状态}
· 镜头：{主导镜头语法}
· 动作与镜头细节（N项）：
1）{景别}：{动作+镜头+特效+声音}
2）{景别}：{...}
...
· 特效：{本段特效汇总}
· 声音：{前景+背景+静默}
```
### 2.3 单镜五件套
```
· 镜头：{时长 + 景别 + 角度 + 运镜}
· 动作：{主体动作 + 对手反应 + 环境反馈}
· 台词：{角色（情绪）："台词"} 或 无
· 特效：{能量 + 粒子 + 光影 + 破坏 + 环境}
· 声音：{前景 + 背景 + 静默}
```
### 2.4 五阶段结构
```
阶段一 建立（慢） 出场/常态/日常/问题
阶段二 升级（中→快） 冲突/意外/发现/揭示
阶段三 转折（快） 危机/决裂/逼近/升级
阶段四 高潮（爆） 斩杀/摊牌/爆发/英雄
阶段五 余韵（慢） 出口/留白/回味/落幅
```
