## 十三、音色与表演系统
### 13.1 音色锁定系统
每个角色在开头必须锁定音色。根据人物性格、外观、参考图、故事背景，分析适合的音色。
**音色分析维度**：音高（低沉/中低/中高/高亢）、音色（沙哑/清亮/浑厚/尖细/磁性/金属感/气声）、语速（缓慢/中速/快速/急促）、口音（标准/方言/异域/机械音）、语气（冷静/激动/颤抖/不屑/威严/温柔/疯狂）、情绪基调（压抑/爆发/隐忍/张扬）、共鸣位置（胸腔/喉腔/鼻腔/头腔）、气息特点（沉稳/急促/虚弱/有力）
**音色锁定模板**：
```
【角色A音色】
姓名：女警
音高：中低
音色：沙哑磁性
语速：缓慢
口音：标准
语气：冷静中带疲惫
情绪基调：压抑
共鸣位置：胸腔
气息特点：沉稳但偶有停顿
对白示例（沙哑磁性，冷静中带疲惫）："你跑不了。"
```
**对白写法**：格式：角色（音色+语气）："台词"
**音色一致性规则**：
```
基频锁定：角色音色基频全程不变
音色质感锁定：沙哑/清亮/金属感等质感全程不变
共鸣位置锁定：胸腔/喉腔/鼻腔/头腔全程不变
语速可递进：随情绪从慢到快或从快到慢
语气可递进：随情绪从冷静到激动或从激动到冷静
情绪基调可递进：随剧情从压抑到爆发或从爆发到压抑
基频偏移不超过半音
```

### 13.3 表演与情绪
**微表情库**：
眼（睁大/眯/翻/垂/瞟/瞪/湿润/回避）｜眉（皱/挑/锁/松/颤）｜嘴（抿/咬/张/抖/笑/撇嘴/吞）｜鼻（张/抽/皱）｜面（僵/红/白/汗/抖）｜头（点/摇/低/仰/偏/转）｜手（握/松/抖/插兜/抱臂/指）｜身（前倾/后仰/缩/挺/退/进）
**情绪曲线**：
```
平静 → 不安 → 紧张 → 恐惧 → 绝望 → 释放 → 余韵
冷静 → 好奇 → 期待 → 兴奋 → 爆发 → 满足 → 回味
```
**情绪三层（核心）**：
```
情绪层次 = 生理反应层 + 心理活动层 + 行为表现层
```
- 生理：瞳孔/呼吸/心跳/汗腺/肌肉 → 瞳孔微缩，呼吸急促，指尖微颤
- 心理：认知/判断/回忆/预期/恐惧 → 眼神聚焦远处，嘴角微抽动
- 行为：动作/姿态/距离/触碰 → 身体前倾2cm，手指握紧又松开
**心理层必须外化**：不可见心理转为可见动作。
- "世界观崩塌" → 视线失焦/呼吸停顿/后退半步/手指松开
- "回忆" → 拇指摩挲旧疤/呼吸一顿/视线下移
- "判断威胁" → 瞳孔放大/下颌收紧/重心后移
### 13.4 关节动态系统
核心：放弃抽象动词，用物理状态。
错误："她正在挥手"
正确："右臂抬起45度，肘关节弯曲30度，腕关节轻微外旋，手指张开带动空气流动"
**关节链速查**：
| 动作 | 主导链 | 力线 | 惯性 |
|------|--------|------|------|
| 挥手 | 肩→肘→腕→指 | 肩发力→肘传导→腕加速 | 腕0.1s 指0.15s |
| 踢腿 | 髋→膝→踝→趾 | 髋扭转→膝伸展→踝发力 | 小腿0.08s 脚掌0.12s |
| 转头 | 胸椎→颈椎→头 | 胸先转→颈跟随→头稳 | 发0.2s 耳饰0.3s |
| 拔刀 | 肩→肘→腕→刀 | 肩后拉→肘弯→腕翻 | 刀鞘0.05s |
| 出拳 | 髋→肩→肘→腕→拳 | 髋旋→肩送→肘直→腕锁 | 拳套0.03s |
**关节提示词模板**：
```
{动作}：
主导关节链：{关1}→{关3D→{关3}→{关4}
关节角度：{关1} {度}°, {关2} {度}°
力线传递：{发力点}→{传导路径}
惯性滞后：{末端}延迟{时间}
重力反馈：{重心偏移}
环境交互：{气流/水花/尘埃/碎片}
```

## 十四、物理定律矫正系统
### 14.1 重力矫正
核心问题：视频生成模型产生"慢动作下落"效果，物体下落有效重力加速度约为1.81 m/s²，仅为地球重力的18%。
```
【物理-重力】重力加速度9.81m/s²，自由落体时间t=√(2h/g)，
物体下落速度随时间线性增加，落地冲击力与质量成正比；
禁止：慢动作下落、悬浮、无加速下落
```
负向词：slow-motion fall, floating objects, no gravity, sub-earth gravity, moon gravity
### 14.2 动量守恒矫正
```
【物理-碰撞】碰撞前动量=碰撞后动量，质量大的物体速度变化小，
碰撞后运动方向符合牛顿第三定律；禁止：无接触变速、穿透、反弹角度异常
```
### 14.3 接触力矫正
```
【物理-接触】手掌与物体表面完全贴合，手指包裹物体轮廓，
脚掌与地面接触点无滑动，物体重量产生手指压痕/布料凹陷；
禁止：手指穿透物体、脚底打滑、悬浮抓取
```
### 14.4 惯性矫正
```
【物理-惯性】力从核心传导至末端：髋→肩→肘→腕→指，末端延迟0.03-0.15s；
重心偏移先于肢体移动0.1s；停止时末端继续运动0.05-0.1s再回弹
```
### 14.5 流体物理矫正
```
【物理-流体】液体受重力向下流动，粘度决定流速，表面张力决定液滴形状，
溅落角度与撞击角度相关；雨滴从右上斜落，水花向撞击反方向溅射
```
### 14.6 光学物理矫正
```
【物理-光学】光线沿直线传播，阴影方向与光源方向相反，反射角=入射角，
折射率符合介质属性，镜面高光位置与光源一致；
禁止：阴影方向错误、反射角度异常、光源与高光不匹配
```
### 14.7 热力学矫正
```
【物理-热力】热气上升，冷气下降，温度梯度产生对流，
热源周围空气扰动，烟雾上升扩散；禁止：热气下沉、冷气上升、无对流
```
### 14.8 生物力学矫正
```
【物理-生物】人体关节有活动范围限制，肘关节只能单向弯曲，膝关节只能单向弯曲，
重心在支撑面内，肌肉发力有方向；禁止：关节反弯、重心失衡、肌肉发力方向错误
```
### 14.9 物理矫正一体化模板
```
【物理锁定】重力9.81m/s²|动量守恒|接触面贴合|惯性传导链|流体受重力|
光学定律|热力学定律|生物力学|禁止慢动作/悬浮/穿透/无接触变速/阴影错误/关节反弯
```

## 十五、人物一致性保障系统
### 15.1 三层锁定策略
**第一层：文本锚点**
关键词：same character as reference, consistent clothing, stable face features
**第二层：角色设定图**
使用四角度角色设定图（正面、四分之三侧面、侧面、背面）作为锚点。先锁定四角度转身图，让两个角色在视觉上完全不同——不同身高、不同调色板、不同体型、不同服装轮廓。
**第三层：每镜重复**
将角色描述完整复制到每一个包含该角色的提示词中。在各镜头中重复3-5个核心特征词。

## 十七、提示词去重系统
### 17.1 去重策略
1. **每镜分配不同动作**：为每个脚本节拍分配不同的具体动作——不同的手势、不同的身体语言、不同的运动
2. **镜头角度变化**：刻意在不同片段间改变构图——特写、中景、远景交替
3. **微观手势**：给每个镜头至少一个具体的微观手势，而非提示"静止"或"平静"
4. **结构复用而非文本复用**：锁定角色锚点图，在每个镜头的提示词中引用锚点图，但改变动作和角度描述
5. **骨架冻结+单条款变化**：冻结提示词骨架，每次只改变一个子句

```
因果链：欲望 → 障碍 → 选择 → 代价 → 变化 → 回响
```

1. 这个镜头改变了什么？（情绪/动作/压力）
