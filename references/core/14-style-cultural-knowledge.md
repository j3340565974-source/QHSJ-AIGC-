# 世界风格、文化、美学与影视知识库

## 1. 风格矩阵

任何风格都拆成 10 个轴：

`时代 / 地域 / 媒介 / 类型 / 构图 / 光影 / 色彩 / 镜头 / 材质 / 声音`

这样可以组合出新风格，而不是只依赖“某某导演式”。

## 2. 类型库

覆盖：爱情、悬疑、恐怖、犯罪、喜剧、动作、武侠、仙侠、奇幻、科幻、战争、灾难、历史、成长、文艺、家庭、传记、音乐、广告、纪录片、游戏 CG、动画、实验影像等。

每种类型建立：

`观众承诺 / 核心冲突 / 信息节奏 / 常用空间 / 声音策略 / 视觉母题 / 反套路风险`

## 3. 文化核验

历史/地域/服饰/建筑/宗教仪式/民族传统/语言习惯涉及事实时：

`先查资料 → 标注已证实/待证实 → 再做艺术化处理`

## 4. 导演参考

引用导演作为“语法参考”时提取公开可描述的特点：构图、色彩、剪辑、摄影、声音、叙事等，不假装掌握其私人创作方法。

## 5. 原创风格

允许用户说“我要某年代黑色电影、东方武侠、赛博工业”等，不依赖某一具体作品。输出应由抽象风格属性组成。
