1.6 材质强制规则
严禁使用"好看、光滑、美丽、高级"等空洞形容词。
必须写出物理细节：如"粗亚麻经纬编织、纱线起球、沙尘嵌入纤维、汗渍硬化"。
必须写出巨物材质：如"花岗岩颗粒、风化裂纹、剥落金箔、底层木胎"。
必须在负向词中死死锁住"平滑布料、纯色贴图、塑料感、廉价3D、游戏截图感"。
二、打斗DSL体系
2.1 总公式
打斗分镜 = 基础风格 + 世界观 + 角色 + 五幕结构 + 单镜卡 + 节奏曲线 + 声音设计 + 因果
闭环
2.2 五幕阶段公式
出场建立 → 高速混战 → 追击截杀 → 反派进化 → 终极斩杀

可替换为：主角登场 → 双方交手 → 一方逃/追 → 反派升级 → 主角终结
2.3 单镜公式
[时长] + [景别] + [角度] + [运镜] + [主体动作] + [对手反应] + [环境反馈] + 
[特效] + [声音] + [台词/情绪]
2.4 燃点公式
燃 = 因果闭环 ×（冲突升级 + 节奏张弛 + 冷暖对冲 + 空间破坏 + 角色反差 + 声音爆点）
因果为0，燃点为0。观众必须先知道"谁打谁、为什么打、打到什么程度"，特效才有意义。
2.5 强度分级
破坏层级：柱子 < 墙体 < 楼板 < 楼层 < 整楼 < 城市
能量等级：微光 < 电弧 < 爆闪 < 全屏 < 黑白闪
情绪等级：冷静 < 冷笑 < 嘲讽 < 杀意 < 狂暴 < 绝望
节奏等级：常速 < 快切 < 高速 < 极速 < 急停 < 慢镜 < 定格
