## 一、空间推演引擎
### 1.1 核心原则
```
- 物体位置固定，镜头视角可变
- 先建全局三维空间，再逐镜拍摄
- 框外锁坐标，框内转画面
- 被挡住的物体不写
- 画面外背景自动补合理景物
- 每镜起幅=上镜尾帧
- 每镜尾帧锁死，下镜必须接

- 每次输出前必跑，无论图片/视频/小说/剧本/风景```
### 1.2 坐标系定义
```
Y（上）
↑
│
│ +Z（画面深处）
│ /
│/
└────────→ X（水平右）
+Z = 画面深处 / 主角面朝方向
-Z = 镜头方向 / 来向 / 观众方向
+X = 画面右
-X = 画面左
Y = 高度
规则:
- 物体一旦定坐标，全程不动

- 镜头可换位置，物体不动
- 主角在O点，除非剧情移动
- 主角移动时，重新标O点
```
### 1.3 全局空间建模流程（十步）
```
Step 1 定场景：室内/室外/森林/城市/太空/水下
Step 2 定地面：材质+颜色+反光
Step 3 定远处物体：+Z方向有什么
Step 4 定近处物体：-Z方向有什么
Step 5 定左右物体：+X/-X方向有什么
Step 6 定天空：颜色+光源+云层
Step 7 定雾气：贴地/悬浮/浓度
Step 8 定粒子：发光粒子/尘埃/雨雪
Step 9 定主角：位置+朝向
Step 10 定参照物：全程不动的物体
```

## 二、空间关系与防穿模系统
### 2.1 3D空间锁定策略
坐标系统一：世界坐标系 X=水平右，Y=上，Z=深（向内为Z-）
**空间关系锁定卡（每镜强制）**：
```yaml
空间锁定:

场景: {场景名}
人物A: 画面左1/3, 站立, 面朝右, 视线右前
人物B: 画面右1/3, 站立, 面朝左, 视线左前
距离: 3m
高度差: 无
前后关系: A前景, B中景
轴线: A左-B右, 不越轴
遮挡关系: A遮挡B的左肩
接触点: A右手与B左臂接触
```
### 2.2 防穿模规则
- **抓握**：手掌与物体表面完全贴合，手指包裹物体轮廓，不能穿透- **接触**：两个人物接触时，接触点必须是物理上可达的，不能有肢体穿
透
- **遮挡**：前景物体遮挡后景物体时，遮挡边缘必须与物体轮廓一致
- **深度**：人物与背景之间必须有正确的深度关系，不能出现"纸片人"效
果

- **脚部**：脚掌与地面接触点无滑动，脚趾与地面贴合
- **布料**：布料与身体贴合，不穿透身体，褶皱自然下垂
### 2.3 穿模检查清单
| 检查项 | 检查内容 | 通过标准 |
|--------|----------|----------|
| 手部穿透 | 手指是否穿透物体 | 完全贴合 |
| 脚部滑动 | 脚掌与地面接触 | 无滑动 |
| 肢体穿插 | 两人肢体是否穿插 | 无穿插 |
| 深度错误 | 人物是否像纸片 | 有体积感 |
| 遮挡错误 | 遮挡边缘是否正确 | 与轮廓一致 |
| 布料穿透 | 布料是否穿透身体 | 不穿透 |
| 道具漂浮 | 道具是否悬浮 | 与手贴合 |
