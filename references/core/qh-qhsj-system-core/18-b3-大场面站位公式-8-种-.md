## B6. 构图法则库（全球电影学院通用）
- **三分法（Rule of Thirds）**：3×3 九宫格，眼睛放上 1/3 线，地平线
按下或上 1/3；兴趣点放四个交点。
- **对称构图（Symmetry）**：中心轴镜像。韦斯安德森式：秩序、控制、仪
式感、微诡异。
- **不对称平衡（Asymmetry）**：用重量不对称的元素（人 vs 大面积留
白）制造张力。
- **对角线构图（Diagonal）**：天然动感与张力，适合对立、奔跑、冲突。
- **框架构图（Frame within a Frame）**：门窗、桥洞、树枝、人群缝隙

把主体框住，制造偷窥感/被困感。
- **引导线（Leading Lines）**：道路、走廊、栏杆、光带把视线引向主体；
把 2D 变 3D。
- **前景遮挡（Foreground Occlusion）**：前景虚化的人影/树叶/栏杆，
增加层次和窥探感。
- **留白（Negative Space）**：人物面朝方向留空，背对方向贴边；空得
越多，孤独/渴望越强。
- **荷兰角（Dutch Angle / Tilted Frame）**：地平线倾斜，表现心理不
安、醉酒、失衡、疯狂。
- **顶视/上帝视角（Bird's Eye）**：压扁人物、暴露布局、宿命感、棋局感。
- **过肩镜头（OTS）**：前景一人肩/头虚化，后景另一人清晰，对话戏基
础。
- **中央构图（Centered）**：人物正中，仪式感、对峙、肖像、 Wes 
Anderson / 张艺谋式庄重。

# 模块 D：导演思维与分镜系统
## D1. 单场戏五分镜拆解公式（万能）
> 远景环境铺垫 → 全景人物入场 → 中景核心动作（肢体潜台词）→ 近景情绪神态 → 特写细节收尾
五场范例：
1. **楼道黄昏告别**：远景楼道纵深 → 全景两人对立 → 中景克制伸手 
→ 近景半明半暗脸 → 特写悬空的双手（咫尺天涯）。
2. **古风胭脂美妆广告**：远景极简雅致 → 全景柔光逆光入场 → 中景轻
柔涂抹产品 → 近景温婉神态 → 特写膏体质地。
3. **月光敦煌飞天独舞**：远景戈壁石窟满月 → 全景月华披身 → 中景回
旋起舞 → 近景眉眼含月 → 特写纱逐月光。
4. **红衣花旦戏台独舞**：远景空台灯火 → 全景一袭红衣 → 中景水袖翻
飞 → 近景眼神落寞 → 特写水袖翻跃。
5. **民国雨巷爱恨对峙**：远景狭小巷道雨幕 → 全景两人入场 → 中景克
制爆发 → 近景面部细节 → 特写滴落的雨/攥紧的伞。## D2. 正反打与 180° 轴线规则

- **关系轴线**：两个对话者之间连一条无形线。机位必须始终在这条线的
同一侧（180° 半圆内）。
- **跨轴后果**：A 突然从画面左边跳到右边，观众立刻晕、方向感崩塌。
- **视线匹配（Eyeline Match）**：A 看画面右边 → 下一个镜头 B 必须
出现在画面左边（因为 A 在看 B）；A 看画左，B 在画右。
- **外反拍（过肩 OTS）**：机位在 A 肩后拍 B，画面里有 A 的后脑/肩——
最经典。
- **内反拍（单人特写）**：机位越过轴线拍 A 单人，不带对方肩膀。
- **顶角机位**：在两人连线中点正前方，拍双人全景。
- **三角形原理**：两个对话者连线一侧，机位可以摆出三个点（顶角 + 两个反拍），构成底边与轴线平行的三角形。
## D3. 30° 规则（避免跳切感）
- 两个连续剪辑的同景别镜头，机位角度必须相差至少 30°；否则画面"跳"一下，观众出戏。
- 如果不想动 30°，就必须改景别（中景→近景），否则就硬切。
## D4. 四类经典对话戏机位图
- **古风酒楼当众决裂**：大全景交代环境压力 → 中景 → 近景放大愤怒 → 细节特写；180° 轴线，视线匹配，机位同侧。

- **江湖渡口雨夜离别**：空间物理隔离，用距离放大离别；跨空间视线匹配，机位同侧不越轴。
- **民国雨巷爱恨对峙**：近距离站立，情绪压在面部；狭窄空间机位更不
能越轴。
- **唐风夜宴舞姬群戏**：群戏先铺环境，焦点收回双人；群戏锁定双人轴线，机位同侧。
## D5. 镜头拼接五大误区
1. 开篇直切特写，毫无场景代入感。
2. 前后镜头人物姿态、站位落差大，动作衔接断层。3. 一味堆砌精美画面，无剧情无情绪推进。
4. 特写滥用过多，造成视觉审美疲劳。
5. 场景光影色调乱切换，整体风格割裂。
- **金句**："流畅成片不靠镜头数量，只靠清晰切换逻辑。"

# 模块 G：色彩心理学与调色（新增）
## G1. 色温与情绪
- **暖色调（红/橙/黄，2700K–4300K）**：亲密、激情、能量、危险、怀旧、肉体温度；暖光让空间显得小而私人。暖色向观众"推过来"，有视觉侵略性。
- **冷色调（蓝/绿/紫，5500K–8000K）**：冷静、悲伤、疏离、神秘、未来、临床；冷色让空间显得大而空旷。
- **高饱和**：情绪强、戏剧化、卡通感/海报感。
- **低饱和（莫兰迪）**：高级、沉稳、克制、悲伤、文艺。

- **高对比（暗调电影）**：紧张、悬疑、黑色电影、权力。
- **低对比（柔雾）**：温柔、回忆、梦境、治愈。

# 模块 H：短剧节奏与钩子（新增）
## H1. 黄金 3 秒定律
- 前 3 秒决定生死，后 10 秒决定转化。
- 开场必须用强画面或强反差把人按住：扇巴掌、下跪、反转打脸、爆炸、神秘出场、裂缝里渗血的文物。
- **三个零**：零铺垫、零人物介绍、零背景交代。
- 不要从剧情开头慢慢剪，直接把最炸的一帧甩到最前面。## H2. 单集五段式黄金结构（以 100 秒为例）
| 时间 | 段落 | 任务 |
|---|---|---|
| 0–5s | 热开场（钩子） | 圈定用户，奠定情绪原点，冲突/反常画面 |

| 5–30s | 承接 | 推进行动，展开矛盾，主角打算干什么 |
| 30–60s | 递进激化 | 矛盾升级，障碍加码，情绪拉紧 |
| 60–85s | 反转/爽点 | 中段反转或打脸，情绪释放 |
| 85–100s | 情绪落点 + 集尾钩子 | 留悬念，"观众凭什么点下一集" |
## H3. 集内钩子 vs 集间钩子
- **集内钩子**：开场 5 秒，用冲突或反常画面把人摁住。
- **集间钩子**：每集结尾 5–10 秒，在情绪最高或最意外的地方切断，抛
新悬念。
- **爽点与钩子必须错开**：刚给完一个爽点，立刻抛更大的麻烦，不要让
观众喘。
- **节奏密度**：一段素材超过 3 秒没有情绪冲突就剪掉。
## H4. 系列短剧长线结构
- **主线 + 支线**：主角终极目标是主线；感情/反派/配角是支线。
- **3 集一小反转，10 集一大反转，季终大高潮**。
- 每集结尾必须有"未完成动作"：手伸到一半、电话刚接通、门刚推开。
