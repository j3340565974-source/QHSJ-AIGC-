### 10.4 镜头内动作量与时长匹配
| 时长 | 可容纳 |
|------|--------|
| 0.5s | 1个微动作（眨眼、瞳孔缩） |
| 1s | 1个简单动作（握拳、转头） |
| 1.5s | 1个动作+1个反应（握拳+呼吸顿） |
| 2s | 1个动作+1个反应+1个环境（握拳+呼吸顿+雨落） |
| 3s | 1个动作+1个反应+1个环境+1个运镜 |
| 4s | 2个动作+1个反应+1个环境+1个运镜 |
| 5s | 2个动作+1个反应+1个环境+1个运镜+1个对白 |
| 6s | 3个动作+1个反应+1个环境+1个运镜+1个对白 |
### 10.5 时长匹配原则
```
1. 每个动作有物理时长，不能压缩
2. 每个镜头的时长必须匹配内部动作量
3. 1秒内只能做1个简单动作
4. 1.5秒内只能做1个动作+1个反应

5. 2秒内只能做1个动作+1个反应+1个环境
6. 3秒内可做1个动作+1个反应+1个环境+1个运镜
7. 对白每句需要1-3秒
8. 运镜需要2-4秒
9. 建立镜需要3-5秒
10. 收束镜需要2-4秒
11. 镜头时长不够时，拆成多个镜号
12. 镜头时长过多时，合并或加内容
13. 顿帧不占时长，是瞬间定格
14. 总时长 = 各镜时长之和
15. 镜头时长必须物理合理，不能压缩动作
16. 极速狂奔镜头至少2秒
17. 冲刺镜头至少2.5秒
```

## 十一、高精密画面语言体系
### 11.1 总公式

```
高精密画面 = 物 + 状态 + 变化 + 参数
```
- **物**：精确名词，不用类别词
- **状态**：表面状态 + 物理状态 + 光学状态
- **变化**：动作 + 反馈 + 环境响应
- **参数**：风格/材质/光影/渲染/负向，用高精密专业词### 11.2 物名层
- **人**：身份 + 外观锚点 + 视觉符号 + 音色锚点
例：灰风衣女警，短发湿贴额，右腕旧疤，声线低沉沙哑，语速缓，尾音下沉- **物**：精确材质 + 形态 + 状态
例：雷纹长刀，刃口崩口，柄缠湿麻绳，刀身血槽残留暗红。- **场景**：精确空间 + 结构 + 材质
例：湿沥青反射品红霓虹，全息招牌剪影，义体臂液压管外露，地面积水倒映断楼群。
- **光**：光源类型 + 方向 + 色温
例：钠灯侧逆，3200K，体积光柱，8:1光比，湿反射高光。

- **介质**：雨/雾/尘/烟/雪/粒子
例：雨丝右上斜落，水洼镜面反射霓虹，雨珠溅落，雾气贴地流动。### 11.3 状态层

## 十三、音色与表演系统
### 13.1 音色锁定系统
每个角色在开头必须锁定音色。根据人物性格、外观、参考图、故事背景，分
析适合的音色。
**音色分析维度**：音高（低沉/中低/中高/高亢）、音色（沙哑/清亮/浑厚/尖
细/磁性/金属感/气声）、语速（缓慢/中速/快速/急促）、口音（标准/方言/异
域/机械音）、语气（冷静/激动/颤抖/不屑/威严/温柔/疯狂）、情绪基调（压抑
/爆发/隐忍/张扬）、共鸣位置（胸腔/喉腔/鼻腔/头腔）、气息特点（沉稳/急促
/虚弱/有力）
**音色锁定模板**：
```
【角色A音色】
姓名：女警
音高：中低
音色：沙哑磁性
语速：缓慢

口音：标准
语气：冷静中带疲惫
情绪基调：压抑
共鸣位置：胸腔
气息特点：沉稳但偶有停顿
对白示例（沙哑磁性，冷静中带疲惫）："你跑不了。"
```
**对白写法**：格式：角色（音色+语气）："台词"
**音色一致性规则**：
```
基频锁定：角色音色基频全程不变

共鸣位置锁定：胸腔/喉腔/鼻腔/头腔全程不变
语速可递进：随情绪从慢到快或从快到慢
语气可递进：随情绪从冷静到激动或从激动到冷静
情绪基调可递进：随剧情从压抑到爆发或从爆发到压抑
基频偏移不超过半音

```

### 13.3 表演与情绪
**微表情库**：

眼（睁大/眯/翻/垂/瞟/瞪/湿润/回避）｜眉（皱/挑/锁/松/颤）｜嘴（抿/咬/张/抖/笑/撇嘴/吞）｜鼻（张/抽/皱）｜面（僵/红/白/汗/抖）｜头（点/摇/低/仰/偏/转）｜手（握/松/抖/插兜/抱臂/指）｜身（前倾/后仰/缩/挺/退/进）**情绪曲线**：
```
平静 → 不安 → 紧张 → 恐惧 → 绝望 → 释放 → 余韵冷静 → 好奇 → 期待 → 兴奋 → 爆发 → 满足 → 回味```
**情绪三层（核心）**：
```
情绪层次 = 生理反应层 + 心理活动层 + 行为表现层```
- 生理：瞳孔/呼吸/心跳/汗腺/肌肉 → 瞳孔微缩，呼吸急促，指尖微颤- 心理：认知/判断/回忆/预期/恐惧 → 眼神聚焦远处，嘴角微抽动- 行为：动作/姿态/距离/触碰 → 身体前倾2cm，手指握紧又松开
**心理层必须外化**：不可见心理转为可见动作。
- "世界观崩塌" → 视线失焦/呼吸停顿/后退半步/手指松开
- "回忆" → 拇指摩挲旧疤/呼吸一顿/视线下移

- "判断威胁" → 瞳孔放大/下颌收紧/重心后移
### 13.4 关节动态系统
核心：放弃抽象动词，用物理状态。
错误："她正在挥手"
正确："右臂抬起45度，肘关节弯曲30度，腕关节轻微外旋，手指张开带动空气流动"
**关节链速查**：
| 动作 | 主导链 | 力线 | 惯性 |
|------|--------|------|------|
| 挥手 | 肩→肘→腕→指 | 肩发力→肘传导→腕加速 | 腕0.1s 指0.15s |
| 踢腿 | 髋→膝→踝→趾 | 髋扭转→膝伸展→踝发力 | 小腿0.08s 脚掌
0.12s |
| 转头 | 胸椎→颈椎→头 | 胸先转→颈跟随→头稳 | 发0.2s 耳饰0.3s |
| 拔刀 | 肩→肘→腕→刀 | 肩后拉→肘弯→腕翻 | 刀鞘0.05s |
| 出拳 | 髋→肩→肘→腕→拳 | 髋旋→肩送→肘直→腕锁 | 拳套0.03s |
