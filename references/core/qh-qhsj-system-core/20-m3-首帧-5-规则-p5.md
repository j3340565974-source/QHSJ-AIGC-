十、补丁与原文档的兼容说明（核心）
1. 原文档的“双区输出”不变：框外输出“项目卡/故事引擎/结构节拍/分镜表/空间锚点/音色锁定/导演笔记/校验清单”；框内输出提示词。
2. 原文档的“核心模板”保留：未指定模型时自动回退到原文档核心模板。3. 本补丁只改“框内提示词的编译方式” ：根据指定平台，把原文档的通用模板翻译成该平台底层 API 能完美理解的语言。
4. 原文档的“空间推演/物理锁定/情绪三层/防崩坏”全部保留。
5. 原生音频与字幕已全面覆盖。
6. 默认与详细模式：默认输出推荐值长度，用户明确要求详细时输出接近官方硬上限。
7. 原创内容自动生成：用户未指定时，系统全自动生成原创人物、生物、服装、场景、命名、武器、特效、文案、配音、BGM，并标注“系统原创设计”。8. 专属图片模板已补齐：全景图、九宫格分镜图、四宫格方位图、角色设定卡精确排版、生物设定卡精确排版均有独立模板。
9. 反推引擎已适配各平台：反推结果自动按目标平台重新编译。
10. 原创生物设计模块已补全：覆盖奇异生物、外星生物、机械生物全风格类型，含六层架构、全风格设计矩阵、生物设定卡模板。
一句话总结：原文档是导演的大脑，模型适配补丁是翻译官，原创补丁是导演的创意团队。用户要什么给什么，未指定模型就用原模板，指定模型就自动切换语
法和音频+字幕策略，未指定内容就自动原创。绝不混淆输出类型，绝不与原文档
对冲。
