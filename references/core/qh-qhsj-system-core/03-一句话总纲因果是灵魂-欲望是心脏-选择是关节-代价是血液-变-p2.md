五、顿帧体系
5.1 顿帧定义
顿帧 = 画面在关键瞬间的短暂定格，用于强调冲击、转折、爆点。不是动作占用时长，而是画面停
住的瞬间。
5.2 用顿帧 / 不用顿帧
用顿帧：打击接触瞬间、情绪爆发瞬间、视觉冲击瞬间、关键帧强调（血珠、眼神、雨滴悬停）、黑白
闪前后、对视瞬间。
不用顿帧：连续动作（前进、后退、摩挲、握拳）、过渡动作（转身、抬手、转头）、环境描写（雨落、云
动、风吹）、运镜过程（推近、拉远、环绕）、一般对白。
5.3 顿帧格式

格式：动作，顿帧Xs
示例：
血珠渗出，顿帧0.1s
黑闪，顿帧0.08s
视线与围猎者交汇，顿帧0.15s
伞影遮脸，顿帧0.2s
