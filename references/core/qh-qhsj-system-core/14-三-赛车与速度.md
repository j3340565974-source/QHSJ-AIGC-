## 三、赛车与速度
### 3.1 六法则
```
1. 真实速度，不是CGI/后期加速
2. 细节即情绪
3. 每件作品一个主导视觉承诺
4. 节拍锁定剪辑
5. 冷战斗调色板
6. 每插入件承重
```
### 3.2 四流派
动能蒙太奇 / 赛车真实 / 承重构图 / 规则式广告
### 3.3 赛车12仪式
水箱入水/烧胎/倒车就位/预stage灯/Stage灯/琥珀倒计时/绿发射/轮胎

Hostess-tray侧面/保险杠低前POV/硬装驾驶舱抖动/跟拍并行+对决/远

景证明
### 3.5 冷战斗调色板
硬白/脏水银白/青色/电青/钢蓝/品红/冷紫/红(仅强调)/绿(仅强调)/毒琥珀(≤15%)。温暖即毒素是唯一允许的。

```
动作不要高上帝角度

无道路纹理速度面板不画

仪式不乱序/跳
无温暖舒适

## 五、动态分镜关键帧
### 5.1 核心
面板是单位，不是镜头。每面板做4件：
1. 一个可读故事节拍
2. 一个功能标签
3. 一个情绪（不命名，通过物/光/解剖传递）
4. 一个暗示的运动（冻结物理残留）
### 5.2 关键帧卡片
```
面板ID / 时间码 / 功能标签 / 节拍 / 景别+焦段 / 主体锚点 /
深度层 / 暗示镜头 / 光线+调色板 / 物传情绪 / 静中有动 /字幕标签 / 声音 / 制作备注
```
### 5.3 密度阶梯
| 节拍 | 密度 | 面板数 |

|------|------|--------|
| 仪式/调度 | 1英雄面板 | 1个活1.5-2.5s |
| 压力爬升 | 升级单数 | 3个时长塌缩 |
| 发射/冲击 | 微爆发 | 6-9个8帧→4帧 |
| 竞赛 | 交替 | 碎片簇↔保持细节 |
| 余波/出口 | 1英雄面板 | 1-2个约2s |
### 5.4 静中有动6线索
| 线索 | 是什么 |
|------|--------|
| 方向运动模糊 | 背景拖尾主体锐 |
| 冻结部分虚化 | 一元素虚锚点清晰 |
| 条纹帧 | 整面板运动条纹 |
| 姿态/轨迹矢量 | 锁在只能向前解决的姿态 |
| 锐主体/虚场 | 浅景深微距 |
| 定格静止 | 零模糊硬边屏息 |
### 5.5 无脸的情绪替换

## 六、常见问题修复
### 6.1 连续性检查
```
镜头间同一角色/服装、一致地点、物体进展合理、无多余角色/文字/Logo、
一致年龄/体型/脸、无不可能手-物体、无模糊镜头/光线指导、无堆叠导演参考、
无矛盾、调色板用具体颜色、终画面明确
```
### 6.2 常见失败修复

**多镜一镜到底**：
``` 
This must be a multi-shot sequence with visible hard cuts. Do not generate a single continuous take. Each beat uses a different angle.
```
**角色脸变了**：
``` 
Preserve the exact character in every shot. Same face shape, same eye color, 
same hair, same clothing, same expression style. 
```
**物体消失**：
``` 
Track the object continuously. Same object remains visible or clearly implied.
```
**弱剧情**：
``` 
Play the scene with full emotional seriousness. 
Treat the ordinary object as if it carries life-or-death meaning. ```
**其他**：
- 融化手：Kling加负面；Seedance/Veo正面表述

- 光线漂移：命名主导光源方向，重复
- 忽略镜头：把镜头移最前
- 奇怪AI脸：用制作语言（Shot on 50mm, natural skin texture）
- 多脸融合：逐主体绑定+差异化
- 随机字幕：Pure video, no subtitles, no background music.
