3.1 六法则
1. 真实速度，不是CGI/后期加速
2. 细节即情绪
3. 每件作品一个主导视觉承诺
4. 节拍锁定剪辑
5. 冷战斗调色板
6. 每插入件承重

3.5 冷战斗调色板
硬白/脏水银白/青色/电青/钢蓝/品红/冷紫/红(仅强调)/绿(仅强调)/毒琥珀(≤15%)。温暖即毒素
