```
P1 结构化命名

- 坏："无模糊脸" → 好："模糊脸"
- 有效负面：低分辨率、模糊、扭曲手、多手指、融化脸、水印、字幕、Logo、抖动

Focus（焦点）→ Outcome（结果）→ Realism（写实）→ Motion（运动）
→ Setting（场景）
### 5.8 API限制注意
multi_prompt storyboard每镜上限512字符，storyboard上限6镜。
Turbo模式无negative_prompt字段。

## 一、世界电影风格流派全景图
### 1.1 欧洲电影流派与运动
**法国体系**：法国先锋派和印象派以抽象主义作品表现逃避战争痛苦，
演变成超现实主义。法国新浪潮强调作者论，反传统叙事，代表戈达尔、特
吕弗。法国"新巴洛克"风格（Cinéma du look）以《Diva》《Betty Blue》
为代表，注重视觉风格化与色彩表现力。法国新极端影片（New French 
Extremity）以极端暴力与身体恐怖探索边界。
**德国体系**：德国表现主义发源于1920年，演员、物体与布景设计都用
来传达情绪与心理状态。低调照明和硬光阴影被黑色电影全盘继承，希区
柯克与奥森·威尔斯亦受影响。德国新电影运动具有政治批判性，聚焦战争
创伤。
**意大利体系**：意大利新现实主义聚焦战后艰苦生活，实景拍摄、非职业
演员。意大利铅黄电影（Giallo）以色彩浓烈、暴力美学著称。意大利西部片

（Spaghetti Western）以莱昂内为代表，重新定义西部片视觉语言。
**英国体系**：英国新浪潮反传统，布莱顿学派是电影史上最早电影流派
之一。英国自由电影运动关注工人阶级生活。
**苏联/俄罗斯体系**：苏联电影学派包含诗电影与散文电影两大方向，电
影眼睛派反对故事片一切虚构，主张摄入生活即景。
**北欧体系**：瑞典电影以伯格曼为代表，探索存在主义与信仰问题。丹麦
Dogme 95运动提出"贞洁誓言"，反对人工布景与特效，强调手持摄影与
自然光。芬兰电影以考里斯马基为代表，极简主义与冷幽默。
**东欧体系**：波兰新浪潮聚焦战争创伤，捷克新浪潮以黑色幽默与超现
实主义著称，南斯拉夫黑浪潮具有政治批判性。
### 1.2 好莱坞与北美体系
经典好莱坞大制片厂时代（1928-1959）：类型电影体系成熟。代表类型：
西部片、歌舞片、黑色电影、传记电影等。
黑色电影（Film Noir）：源于德国表现主义传统，低调照明、百叶窗阴影、道
德模糊主角。新黑色电影（Neo-Noir）将黑色电影美学与现代题材结合。
美国独立电影：美国地下电影、新好莱坞电影（斯科塞斯、科波拉、斯皮尔伯
格等）、当代独立电影浪潮。

加拿大体系：大卫·柯南伯格"身体恐怖"流派，魁北克电影运动。
### 1.3 亚洲电影体系
**日本体系**：黑泽明武士电影将角色神情和动作表现得十分传神。小津安二郎极简主义固定机位。沟口健二长镜头美学。日本新浪潮（大岛渚、吉田喜重）反传统叙事。当代日本电影包括是枝裕和家庭剧、北野武暴力美学
**中国体系**：第一代到第五代导演演变。第五代（张艺谋、陈凯歌）历史寓言和浓烈色彩图腾，第六代个人化叙事与灰色写实。香港电影包括港式英雄片、王家卫视觉诗学、杜琪峰银河映像风格。台湾电影包括侯孝贤长镜头美学、杨德昌都市叙事、蔡明亮极简主义。
**韩国体系**：韩国新浪潮（林权泽、朴光洙），当代韩国电影（奉俊昊、朴赞郁、李沧东）类型融合与作者表达。
**印度体系**：宝莱坞歌舞片体系，印度平行电影（Parallel Cinema）现实主义传统。
**东南亚体系**：泰国阿彼察邦缓慢电影，菲律宾电影社会现实主义，越南陈英雄诗意影像。
### 1.4 其他地域体系
拉丁美洲：巴西新电影（Cinema Novo）、阿根廷新电影、墨西哥黄金时代电影、古巴电影。

中东与北非：伊朗新浪潮（阿巴斯、帕纳西）、以色列电影、阿拉伯电影。
非洲：非洲电影先驱（塞姆班、苏莱曼·西塞），非洲电影新浪潮。
大洋洲：澳大利亚新浪潮、新西兰电影（彼得·杰克逊早期作品）。
### 1.5 实验与先锋流派
布莱顿学派（20世纪初，英国布莱顿地区）、欧洲先锋派、构成主义电影、卡里加里主义电影、超现实主义电影、实验电影、结构主义电影（以固定机位和重复结构探索电影本质）。
