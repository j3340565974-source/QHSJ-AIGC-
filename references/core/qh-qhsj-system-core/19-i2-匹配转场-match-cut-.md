## I2. 匹配转场（Match Cut）
- **动作匹配**：上一个镜头抬手，下一个镜头另一个人接抬手。
- **视线匹配**：A 看画外 → 下一镜切到 A 看到的东西。
- **图形匹配**：相似形状/轮廓/颜色对接——《辛德勒的名单》蜡烛烟→
火车头烟。
- **声音匹配（J Cut / L Cut）**：下一个镜头的声音先出来，画面再到（J 
剪）；画面切了声音还留（L 剪）。
- **甩镜头转场（Whip Pan）**：快速横摇虚化，切到下一个方向接摇。抖
音手机实操：0.5x 广角，3-2-1 走。
- **遮挡转场**：手遮住镜头/人走过镜头，换场景再拉开。
## I3. 淡入淡出与叠化
- **Fade to Black**：时间大跨越、章节结束。
- **Dissolve 叠化**：回忆、梦境、时空连接、情绪流动。
- **不要滥用特效转场**：AI 生成时优先硬切和匹配，避免花里胡哨的划

像。
## I4. 跳切（Jump Cut）
- 同机位同景别硬跳一段时间，制造时间压缩、焦躁、断裂感。- 戈达尔、王家卫常用；不要在严肃对话里随便用。
## I5. 蒙太奇
- **叙事蒙太奇**：交代时间流逝、训练过程、行程。
- **对比蒙太奇**：富/穷、战争/和平并置。
- **隐喻蒙太奇**：两个不相关镜头并置产生新含义（爱森斯坦）。
- **节奏蒙太奇**：镜头越来越短，制造紧张加速。

# 模块 J：声音设计（新增）
## J1. 三层声音结构
1. **环境音（Ambience）**：房间/街道/森林的底噪，建立空间和时间（蝉
鸣=夏夜、鸟鸣=清晨、雪=一切闷掉）。
2. **音效（SFX）**：动作声——脚步、衣料、剑刃、雨打伞、心跳。
3. **配乐（Score）**：情绪线；主题旋律（Leitmotif）绑定角色/关系，如
《星球大战》帝国进行曲。

## J2. 声音叙事技巧
- **静响对比（Dynamic Range）**：最响和最静的差距越大，jump 
scare 越吓人；全程大声=疲劳。
- **Stinger（刺音）**：突然一声尖锐音效，jump scare 标配。
- **次声（Infrasound<20Hz）**：身体感到但听不到，制造"有人在
场"的不安，恐怖片常用。
- **预知性音乐**：危险还没出现，音乐先告诉观众——制造悬念。
- **Diegetic vs Non-diegetic**：故事内音乐（收音机/钢琴）vs 上帝视
角配乐。
- **声音先于画面**：下一个场景的雷声/哭声先出来，画面再切——高级
转场。
## J3. AI 视频 Prompt 中的声音写法
- 默认无音乐无字幕，除非用户要。
- 框内可写：`环境音：雨夜瓦片滴水 + 远处更夫梆子；脚步踩积水；衣料摩擦；无配乐；无字幕`。

# 模块 K：焦段与镜头选择（新增）
## K1. 焦段情绪表（全画幅等效）

| 焦段 | 名称 | 视觉特征 | 情绪/用途 |
|---|---|---|---|
| 14–24mm | 超广角 | 拉伸空间、边缘畸变、近大远小夸张 | 史诗、孤独、
建筑、紧张、《寄生虫》横移 | 
| 24–35mm | 广角 | 容纳环境、轻微拉伸、手持自然 | 定场、纪录片、狭小
空间扩张、《撕裂的末日》穿行 | 
| 35mm | 人文眼 | 接近人眼、可进可退 | 街拍、对话、日常、万能叙事 |
| 50mm | 标准 | 最接近人眼、无透视变形 | 写实、自然、生活流 |
| 85mm | 人像中长焦 | 背景压缩、脸不变形、浅景深 | 人像特写、浪漫、隔
离感 | 
| 135–200mm | 长焦 | 强烈空间压缩、前后景叠在一起 | 偷窥、远距观察、
孤独、人群中找一个人、背景虚化 | 
| 200mm+ | 超长焦 | 极强压缩、空气感 | 野生动物、战场、监视、宿命 |
## K2. 焦段×运镜组合
- **广角 + Dolly In**：冲击感最强，环境被快速"吸走"。
- **长焦 + 环绕**：背景剧烈流动，人物相对静止——情绪冲击。- **广角 + 跟拍**：手持穿梭感，适合奔跑、追逐、狭小空间。
- **长焦 + 静帧**：偷窥感、观察感、《情人》《色戒》式远距离凝视。

## K3. 景深与焦段关系
- 焦段越长 → 背景越虚；光圈越大 → 背景越虚；离主体越近 → 背景越虚。- 浅景深不是"高级感开关"，是叙事工具——用它把观众注意力钉在谁脸上。

# 模块 L：导演风格参考库（新增）
## L1. 韦斯·安德森（Wes Anderson）
- 中心对称构图、人物正面朝向镜头、建筑拍正面、完美几何。- 马卡龙低饱和配色（粉、薄荷、姜黄、砖红、奶白）。
- 镜头运动几何化：完美水平横移、垂直升降、90° 正拍。
- 舞台/模型感布景、人物像剪纸、旁白式疏离感、戏服统一。
- Prompt 拼接：`perfectly centered symmetrical composition, 
flat perpendicular camera angle, pastel color palette, dollhouse 
set, stylized theatrical acting, deadpan narration`。
## L2. 克里斯托弗·诺兰（Christopher Nolan）
- IMAX 70mm / 35mm 大画幅、实拍、实景、交叉剪辑多时间线。
- 纪录片式自然光、手持、 elliptical editing（省略时间）。
- 声音设计实验：低频轰鸣、音画错位。

- Prompt 拼接：`IMAX 70mm film grain, practical locations, 
naturalistic lighting, cross-time-line editing, thunderous low-
frequency score`。
## L3. 王家卫
- 手持慢门拖影、抽帧、高饱和黄绿/暧昧红蓝。
- 框中框（门框/车窗/镜子）、狭长走廊、雨、夜。- 旁白、碎片化时间、"在 X 年 X 月 X 日 X 时"。
- 情绪：暧昧、错过、孤独、记忆。
- Prompt 拼接：`Wong Kar-wai style, step-printing slow motion, 
neon green and red, handheld, frame-within-a-frame, rainy 
night, voiceover, fragmented time`。
## L4. 杜琪峰 / 银河映像
- 静止长镜头、简洁构图、人物站位像战术阵型。
- 高饱和、硬光、暗调、港片街头。
- 《枪火》式：一群人不动，张力在沉默里。
- Prompt 拼接：`Johnnie To style, static wide shot, tactical group 
blocking, hard rim light, Hong Kong neon, tense silence before 
gunfire`。
## L5. 其他可拼接风格词

- **库布里克**：一点透视走廊、单点消失、对称、冷冷机械感。
- **罗杰·迪金斯（摄影指导）**：唯美柔光窗光、极简、蓝橙对比。
- **是枝裕和**：自然光、低饱和暖米、固定机位、日常即戏剧。
- **张艺谋**：单色冲击、群体仪式、浓烈色彩、构图如油画。
- **雷德利·斯科特**：烟雾、体积光、工业废墟、史诗感。

# 模块 M：AI 视频常见错误修复（新增）
## M1. 七大故障与修复
| 故障 | 原因 | 修复 |
|---|---|---|
| **人脸漂移/变脸** | 模型每帧独立采样，无身份锚 | ① 先用 
Midjourney/Flux 出一张 Master 定妆照 ② 图生视频而非文生视频 ③ 
加保留子句："Preserve facial identity, eye spacing, nose shape, 
jawline, hairstyle, age throughout" ④ 减少转头和运镜 ⑤ 动态戏切
走脸，别让脸一直给镜头 | 
| **动作崩坏/多手多脚** | Prompt 没写身体力学，手快速运动 | ① 景别
拉远一档 ② 明确写出身体力学："right hand reaches left pocket, 
weight shifts to left foot" ③ 手要么不动要么走简单路径 ④ 单镜头只
做一个动作 ⑤ 用图生视频 |

| **穿模/物体穿插** | 模型不懂碰撞 | ① 写明接触面贴合："shoulder 
presses against door" ② 减少复杂遮挡 ③ 慢动作比快动作稳 |
| **背景乱变/漂移** | 运镜太复杂 | ① 锁机位或只做简单推拉 ② 减少广
角剧烈运动 ③ 用首帧参考图 | 
| **镜头僵硬/死画面** | 纯静态 | ① 加微运动：发丝飘、衣袂动、眨眼、呼
吸、光斑闪烁 ② 用低速环绕/微推 ③ 跟随视线 | 
| **物理错误（水往上流/物悬浮）** | 没写重力 | 框内必带：`gravity 
9.81m/s², momentum conserved, surfaces contact, wind 
direction consistent` |
| **风格割裂/前后不一致** | 每个镜头独立写 | ① 项目级头部块统一（风
格/材质/光影/色温） ② 所有镜头复用同一串头部 ③ 负向词统一 | ## M2. 修复优先级（从最省成本开始）
1. 收紧提示词，检查是否和锁定措辞一致。
2. 减少运动幅度（慢/静 > 快/炫）。
3. 切模型：身份问题用 Seedance / Kling；物理问题用 Runway。
4. 换图生视频，首帧锁死。
5. 重新注入参考图（Master Image 策略）。
6. 分段生成，每段 5–10 秒，不要一次 30 秒。
7. 后期修：GFPGAN/CodeFormer 修脸，局部重绘修手。
