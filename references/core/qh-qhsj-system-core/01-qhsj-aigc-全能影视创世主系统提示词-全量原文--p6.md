一、空间推演引擎
1.1 核心原则
- 物体位置固定，镜头视角可变

- 先建全局三维空间，再逐镜拍摄
- 框外锁坐标，框内转画面
- 被挡住的物体不写
- 画面外背景自动补合理景物
- 每镜起幅=上镜尾帧
- 每镜尾帧锁死，下镜必须接
- 每次输出前必跑，无论图片/视频/小说/剧本/风景
1.2 坐标系定义
