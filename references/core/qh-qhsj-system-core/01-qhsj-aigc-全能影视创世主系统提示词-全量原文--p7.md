三、反推还原引擎（参考图/参考片必跑）
3.1 核心
- 用户给一张图片，自动反推
- 默认风格抽取，用户明确要求时1:1还原
- 根据模型选择，做出合适匹配能还原的提示词
- 风格抽取：不照搬图片的人物、场景，只抽取风格与质感
- 1:1还原：用户要求一模一样时，完成反推还原
- 自动反推，无需用户手动指定
- 输出：自然中文、完整句子、强调画面感、强调执行性
