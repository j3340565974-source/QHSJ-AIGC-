## 二、左右手逻辑系统
每个镜号必须明确哪只手做什么，物体在哪只手上，动作的物理路径必须清晰。
AI视频模型默认容易生成"左手受伤左手摸"或"右手受伤左手摸错"的错误，必须在提示词里强制写清左右手逻辑。
### 2.1 左右手逻辑要素
| 要素 | 写法 | 说明 |
|------|------|------|
| 受伤手 | 右腕旧疤 | 哪只手受伤 |
| 动作手 | 左手拇指 | 哪只手做动作 |
| 物体手 | 右手握枪 | 哪只手拿物体 |
| 物体位置 | 枪口指向画面右前 | 物体在哪 | 
| 动作路径 | 左手拇指→摩挲右手腕旧疤 | 动作从哪到哪 | | 反馈 | 右手血珠渗出 | 哪只手反馈 |

### 2.2 左右手逻辑规则
```
- 每镜必须写受伤手（如果有）、动作手、物体手（如果有物体）、物体位置、动作路径、反馈手
- 左手受伤，只能用右手去摸；右手受伤，只能用左手去摸
- 右手拿物体，左手做动作；左手拿物体，右手做动作
- 动作路径必须写清从哪到哪
- 反馈必须写清哪只手反馈
```
### 2.3 左右手逻辑速查
| 场景 | 正确写法 |
|------|----------|
| 右手受伤 | 左手拇指摩挲右手腕旧疤，右手血珠渗出 | | 左手受伤 | 右手拇指摩挲左手腕旧疤，左手血珠渗出 | | 右手拿枪 | 右手握枪，枪口指向X，左手自然下垂 |
| 左手拿刀 | 左手握刀，刀尖指向X，右手自然下垂 |
| 右手拿电锯 | 右手握电锯，锯刃朝前，左手剧烈摆动 |
| 双手拿武器 | 双手握刀，右手在前，左手在后 |

| 右手挥拳 | 右拳击出，左拳护胸 |
| 左手格挡 | 左臂抬起格挡，右拳蓄力 |
| 右手拔刀 | 右手拔刀，左手扶刀鞘 |
| 右手摆动左手扶腰 | 右手剧烈摆动，左手扶腰 |---
## 三、全画面逻辑矫正系统
### 3.1 焦点与机位匹配逻辑
核心规则：焦点主体必须在摄像机拍到的画面里，背景必须是摄像机后方或主体身后的场景。
| 镜头角度 | 摄像机位置 | 焦点主体 | 背景是谁 | 对面的人在哪 | |----------|------------|----------|----------|--------------|
| A正面 | A前方 | A面部 | A身后场景 | 镜头后方，不在画面 | | A过肩 | A身后 | A后脑/肩 | B（画面深处） | 画面深处 |
| B正面 | B前方 | B面部 | B身后场景 | 镜头后方，不在画面 | | B过肩 | B身后 | B后脑/肩 | A（画面深处） | 画面深处 |
| 双人侧面 | 两人侧面 | A或B | 两人身后场景，另一人虚化但仍在画面 | 
画面另一侧 |

| 双人中景 | 两人侧面 | 两人都清晰或选一 | 两人都在画面，背景是两人身后场景 | 两人都在画面 |
### 3.2 视线匹配逻辑
核心规则：A看右，B看左，两人对视。A看左，B看左，两人看同一方向。| 关系 | A视线 | B视线 | 效果 |
|------|-------|-------|------|
| 对视 | 看右 | 看左 | 视线交汇 |
| 同向 | 看右 | 看右 | 看同一方向 |
| 错开 | 看右 | 看前 | 不交汇 |
| 回避 | 看下 | 看右 | 不交汇 |
### 3.3 空间位置逻辑
核心规则：人物位置、距离、高度差、前后关系、朝向、运动方向必须前后镜号保持一致。
| 要素 | 规则 |
|------|------|
| 画面位置 | A左、B右，全程不变 |
| 距离 | 前镜3m，后镜不能突然变1m |

| 高度差 | 前镜站立，后镜不能突然半蹲 | 
| 前后关系 | 前镜A前景，后镜不能突然B前景 | | 朝向 | 前镜A面朝右，后镜不能突然面朝左 |
| 运动方向 | 前镜A向前，后镜不能突然向后 |
| 轴线 | A左-B右，全程不越轴 |
### 3.4 光源方向逻辑
核心规则：同一场景内主光方向、色温、光比保持一致，只允许微调。| 要素 | 规则 |
|------|------|
| 主光方向 | 钠灯侧逆，全程不变 |
| 色温 | 3200K，全程不变 |
| 光比 | 8:1，全程不变 |
| 辅光 | 霓虹，可微调 |
| 特殊光 | 只在特定镜号加，如镜4暗红主调 |
### 3.5 场景元素逻辑
核心规则：场景元素以"场景锁定卡"为准，锁定卡里有什么，每镜就必须保持一致。

### 3.6 其他逻辑
- **动作物理逻辑**：每个动作有物理时长，不能压缩，镜头时长匹配动作量
- **运镜逻辑**：运镜必须有动机，起幅落幅必须写清，速度匹配内容
- **转场逻辑**：转场必须与前后镜头逻辑衔接，不跳变- **音色逻辑**：音色锁定后全程保持一致，不跳变
- **构图逻辑**：构图类型与内容匹配，主体位置前后一致- **移动状态逻辑**：每个镜号必须明确移动方式等全部要素
- **左右手逻辑**：每个镜号必须明确哪只手做什么---
## 四、视频秒数融合叙事写法
### 4.1 核心原则
```
镜号带时长，内部叙事融合，不分行，不拆号，一气呵成。顿帧只用于关键冲击瞬间，不用于连续动作。
一镜可多段：同一镜号内用"切"切换镜头段落，不拆成新镜号。
```
### 4.2 标准格式

```
【镜1（1.5秒）】景别+运镜+构图+摄像机位置+焦点，主体位置/朝向/视线，
移动状态，动作，左右手，反应，关节链，情绪三层，环境物理，光，色，台词/音色，环境音/音效，转场/终帧；切镜头，景别+运镜+构图+摄像机位置+焦点，
主体位置/朝向/视线，移动状态，动作，左右手，反应，关节链，情绪三层，环境物理，光，色，台词/音色，环境音/音效，转场/终帧。
【镜2（1.5s）】...
【负向】...
```
### 4.3 格式规则
| 规则 | 说明 |
|------|------|
| 镜号+时长 | 【镜1（1.5秒）】一起写，不单独列总秒数 | 
| 秒数单位 | 可写秒 或 s，统一即可 | 
| 内部叙事 | 景别/运镜/构图/摄像机位置/焦点/移动状态/动作/左右手/反应/情绪/光/色/音效/转场全部融合 |

| 顿帧 | 只用于关键冲击瞬间，格式 动作，顿帧Xs | | 一镜多段 | 一个镜号内可用"切"切换镜头段落 | | 不分行 | 一个镜号内连续写，不拆行 | 
| 不拆镜号 | 同一镜号内多段连续写，不拆成新镜号 | | 总时长 | 各镜时长之和 = 全片总时长 |

## 五、顿帧体系
### 5.1 顿帧定义
顿帧 = 画面在关键瞬间的短暂定格，用于强调冲击、转折、爆点。不是动作占用时长，而是画面停住的瞬间。
### 5.2 用顿帧 / 不用顿帧
**用顿帧**：打击接触瞬间、情绪爆发瞬间、视觉冲击瞬间、关键帧强调（血珠、眼神、雨滴悬停）、黑白闪前后、对视瞬间。
**不用顿帧**：连续动作（前进、后退、摩挲、握拳）、过渡动作（转身、抬手、
转头）、环境描写（雨落、云动、风吹）、运镜过程（推近、拉远、环绕）、一般对白。
### 5.3 顿帧格式
```

格式：动作，顿帧Xs
示例：
血珠渗出，顿帧0.1s
黑闪，顿帧0.08s
视线与围猎者交汇，顿帧0.15s
伞影遮脸，顿帧0.2s
```
### 5.4 顿帧错误 vs 正确
| 错误 | 正确 |
|------|------|
| 肩前倾→肘屈→腕锁→指节白（顿帧0.1s） | 肩前倾→肘屈→腕锁→指
节白（连续动作，无顿帧） | 
| 腕内旋→指腹压疤（顿帧0.08s） | 腕内旋→指腹压疤（连续动作，无顿
帧） | 
| 后退（顿帧0.5s） | 后退一步（连续动作，无顿帧） |
| 血珠渗出 | 血珠渗出，顿帧0.1s ✅ |
| 视线交汇 | 视线交汇，顿帧0.15s ✅ |


| 黑闪 | 黑闪，顿帧0.08s ✅ |
### 5.5 顿帧在一镜多段中的规则
```
顿帧只能出现在所在段落的终帧或冲击瞬间
顿帧不能跨段使用
每段最多一个顿帧
顿帧前后必须有连续动作铺垫
```

## 六、焦点系统
每个镜号必须明确焦点主体，AI才知道对焦到哪。| 要素 | 写法 | 说明 |
|------|------|------|
| 焦点主体 | 对焦A右腕旧疤 | 焦点在哪 |
| 焦点变化 | 从A面部拉焦至B | 焦点移动 |
| 景深 | 浅景深/深焦 | 虚化程度 |
| 焦点位置 | 画面左1/3 | 焦点在画面哪里 |
**焦点规则**：

- 每个镜号必须写焦点主体
- 焦点变化必须写清从谁到谁
- 浅景深只留焦点主体清晰，其余虚化
- 深焦全画面清晰，用于建立镜和收束镜
- 焦点不能跳跃，必须连续
- 焦点必须与摄像机位置匹配
**焦点示例**：
```
焦点女警右手腕旧疤，浅景深，背景虚化
焦点女警面部，浅景深，背景女警身后断楼群虚化，围猎者不在画面焦点从女警面部拉焦至背景围猎者，焦点转移
焦点女警剪影，深焦全清
```

## 七、构图系统
每个镜号必须明确构图类型、主体位置、前中后景。### 7.1 构图类型

| 构图 | 写法 | 适用 |

| 三角构图 | 三人三角站位，镜头俯拍或平视 | 群像、关系 | | 框架构图 | 从门框/窗框/树枝间隙穿过，前景虚化 | 窥视、揭示 | | 引导线构图 | 沿道路/走廊/光束引导线跟拍 | 追逐、探索 | 
| 中心构图 | 主体居中，对称 | 仪式、权力 |
| 黄金分割 | 主体在黄金分割点 | 美学 |
| 负空间 | 主体极小，环境极大 | 孤独、压迫 |
| 密集构图 | 画面充满元素 | 混乱、繁华 |
| 重复构图 | 重复元素排列 | 节奏、秩序 |
| 打破构图 | 打破常规，倾斜 | 不安、冲击 |

|------|------|

| 膝高 | 低视角，力量感 |
| 腰高 | 中性视角 |
| 胸高 | 标准视角 |
| 眼高 | 平视，平等 |
| 头高 | 略高，审视 |
| 高台 | 俯视，支配 |
| 无人机 | 上帝视角，全貌 |
| 卫星 | 极远，渺小 |
### 7.3 构图规则
```
- 每个镜号必须写构图类型
- 主体位置必须明确，前后镜号保持一致
- 前中后景必须写清，避免空间错乱
- 留白方向跟随视线，不挡主体
- 摄像机位置逻辑递进，不跳跃
- 构图类型与内容匹配
```

## 八、运镜系统
每个镜号必须明确运镜方式、速度、起幅落幅、运镜动机。### 8.1 运镜要素
| 要素 | 写法 | 说明 |
|------|------|------|
| 运镜方式 | 缓推/缓拉/环绕/跟拍 | 怎么动 |
| 速度 | 缓/中/快/急停 | 多快 |
| 起幅 | 从过肩中景 | 从哪开始 |
| 落幅 | 到面部特写 | 到哪结束 |
| 运镜动机 | 跟随A视线 | 为什么动 |
### 8.2 运镜速度量化表
| 运镜方式 | 速度范围 | 适用场景 |
|----------|----------|----------|
| 缓推 | 2-4s | 情绪增强、揭示 |
| 缓拉 | 2-4s | 情绪释放、空间展开 |
| 中推 | 1-2s | 跟随视线、引导 |

| 快推 | 0.5-1s | 冲击、紧张 |
| 环绕 | 3-5s | 仪式感、沉浸 |
| 手持跟拍 | 2-4s | 沉浸、紧张 |
| 无人机下降 | 3-5s | 空间展开、压迫 |
| 摇臂升起 | 3-5s | 揭示、空间展开 |
| 急停 | 0.3-0.5s | 冲击、急停 |
| 甩镜 | 0.3-0.5s | 冲击、转场 |
| 希区柯克变焦 | 1-2s | 眩晕、心理冲击 |
### 8.3 运镜动机库
| 动机 | 运镜 |
|------|------|
| 跟随视线 | 缓推/跟拍 |
| 情绪增强 | 缓推 |
| 情绪释放 | 缓拉 |
| 空间展开 | 拉远/升降 |
| 仪式感 | 环绕 |
| 冲击 | 甩镜/急停 |

| 沉浸 | 长镜/稳定器 |
| 揭示 | 摇臂/升降 |
| 压迫 | 俯拍/下降 |
### 8.4 运镜规则
```
- 每个镜号必须写运镜方式
- 运镜必须有动机，不无意义移动
- 起幅落幅必须写清
- 速度匹配内容，缓推2-4s，急停0.3-0.5s
- 同一场景内运镜方向不冲突
```
