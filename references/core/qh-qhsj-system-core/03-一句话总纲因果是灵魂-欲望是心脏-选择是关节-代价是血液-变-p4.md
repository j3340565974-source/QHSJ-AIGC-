10.5 时长匹配原则
1. 每个动作有物理时长，不能压缩
2. 每个镜头的时长必须匹配内部动作量
3. 1秒内只能做1个简单动作
4. 1.5秒内只能做1个动作+1个反应
5. 2秒内只能做1个动作+1个反应+1个环境

6. 3秒内可做1个动作+1个反应+1个环境+1个运镜
7. 对白每句需要1-3秒
8. 运镜需要2-4秒
9. 建立镜需要3-5秒
10. 收束镜需要2-4秒
11. 镜头时长不够时，拆成多个镜号
12. 镜头时长过多时，合并或加内容
13. 顿帧不占时长，是瞬间定格
14. 总时长 = 各镜时长之和
15. 镜头时长必须物理合理，不能压缩动作
16. 极速狂奔镜头至少2秒
17. 冲刺镜头至少2.5秒
