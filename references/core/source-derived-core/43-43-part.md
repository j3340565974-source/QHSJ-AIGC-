四、风格抽取：逆向解析与四操作符理论

4.1 逆向解析三方法

工具辅助：使用 CLIP Interrogator 的 style-only 模式或专用反推工具自动提取风格标签。

类比迁移：无图时使用 “In the style of [艺术家/文化符号]” 或 “Create an image in the same visual style as [参考图描述]” 引导 AI 锚定风格。

JSON 结构化提取：通过多模态大模型输出包含画风、色彩方案、光影表现、情绪词的 JSON 数据，实现风格的量化描述。

4.2 学术前沿：四操作符理论（上海交大研究）

复杂的风格与元素抽取本质上由四个原子操作符组合而成：

锚定 (Anchor)：从参考图中精准定位实体并保留身份特征。

解耦 (Disentangle)：从实体中单独抽取特定属性（如花纹），剥离无关信息（如穿着者体型）。

应用 (Apply)：将解耦出的属性绑定到新目标上。

组合 (Compose)：将多个处理后的元素按空间关系合理共存于同一场景。

失败诊断法则：单纯”抄风格”常失败的原因，往往是未能成功”解耦”风格与内容的绑定关系。反推时先做 Anchor→Disentangle，再做 Apply→Compose，逐步验证。

5.1 手动拆解框架三套

一、特效分类与核心术语体系

1.1 SFX / VFX / CGI 三大分类

特技效果 (SFX / Special Effects / 物理特效)：前期拍摄过程中在片场通过物理手段实现的实拍特效——特效化妆、特殊道具、机械仿生、微缩模型、爆破、天气效果（烟雾、风雨）、易碎道具及场景破坏。具有可触摸、真实存在的物理体量感与真实光影交互。行业黑话：“炸点”“硬特效”。

视觉特效 (VFX / Visual Effects / 视效)：后期制作阶段通过计算机软件创造或增强的数字效果，核心是将实景镜头与计算机生成图像（CGI）结合，用于构建现实中不存在的环境、消除高危风险或场景增强。行业黑话：“视效”“后期特效”。

计算机生成图像 (CGI)：VFX 核心子集，利用计算机技术生成图像，创造现实中难以拍摄或不存在的内容。行业黑话：“CG”“三维”。

AI-VFX：运用人工智能进行视觉特效生成与处理的技术，辅助生成视觉化表达，提升制作自动化水平。

1.2 关键技术术语（描写特效镜头时的”可信度词库”）

绿屏/蓝幕 (Green/Blue Screen)：与前景肤色区别明显的纯色背景拍摄，便于后期分离前景与背景合成。

动作捕捉 (Motion Capture)：通过标记点记录演员运动或表情数据，驱动数字角色。

抠像 (Keying)：去除实拍素材中多余部分（如背景）。

流体 (Fluid)：基于动力学计算模拟雾、火、云、烟、水等自然现象。

粒子 (Particle)：制作水花、火焰、沙尘、烟雾及群集动画。

刚体 (Rigid Bodies)：模拟碎块掉落、碰撞等复杂物理运动。

柔体 (Soft Bodies)：使物体产生柔软运动——衣服、发丝、肌肉、旗帜。

电子动画学 (Animatronics)：电气、电子控制制作的实体机械演员（动物、怪物、机器人）。

虚拟制作 (Virtual Production)：XR、LED 屏幕、体积视频采集创造的虚实结合拍摄环境。

影像合成 (Compositing)：实拍素材、CG 元素、实体特效结果分层合成并调整光照。行业黑话：“合成”“抠合”。

数字绘景 (Matte Painting)：数字或传统绘画/照片作为背景板。

遮罩绘制 (Rotoscoping)：逐帧描边分离元素。

Previs（预演）：前期规划机位、节奏与剪辑点的动态预览。

1.3 粒子系统原理与描写参数

粒子系统是模拟烟雾、火焰、爆炸、流体等模糊现象的核心技术：

基本构成：发射器 (Emitter，控制位置、频率、形状) + 运动模型 (Motion，控制速度、加速度) + 外观演变 (Appearance，控制颜色、大小、透明度)。

粒子属性：位置、速度、颜色、生命周期；每帧执行生成、更新、销毁流程。

关键参数（写特效提示词可引用的量化维度）：Birth Rate（每秒生成粒子数）、Longevity（寿命秒数）、Velocity（初速度）、Gravity（重力影响，负值上升）、Wind（水平力）、Spin（旋转）、Birth Color→Death Color（颜色渐变）、粒子类型（线条/星形/球体/气泡/透镜）。

发射器类型：Point（点）、Box（盒）、Line（线）、Grid（网格）、Sphere（球）、OBJ Model（3D模型表面发射）。

适用现象：火、爆炸、烟、水流、火花、落叶、云、雾、雪、尘、魔法能量流、数据流、能量场。

二、爆炸效果：物理四阶段与描写模板

2.1 真实爆炸四阶段（分别描写再合成，物理顺序不可乱）

火球膨胀：高温气体扩张，中心亮白→橙黄→暗红渐变，体积快速膨胀。
