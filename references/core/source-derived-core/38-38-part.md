4.2 Stable Diffusion 系（含 Flux / SDXL）

4.3 GPT Image / Nano Banana / Seedream 系（与原文参数表融合）

五、通用避坑与最佳实践（六原则 · 全流程自动执行）

正向表述原则：描述你想要看到的，而非想避免的。“No camera shake” 可能触发 shake，应改为 “Smooth, stable camera movement”。（与原文负向词纪律融合：负向词仅用于模型明确支持负向字段的场景。）

单动作原则：每个提示词/镜头块仅包含一个核心动作+一种运镜。多动作叠加是导致畸变、闪屏、割裂的首要原因。

迭代优于一次性：先用简短提示词+标清模式生成小样，满意后再用高清+长时长生成最终版；每次仅微调 5% 关键词进行迭代优化（与原文”首帧5%规则”融合）。

具象化替代抽象词：将”高级感”替换为”侧逆光+轮廓光+低饱和暖调”；将”悲伤”替换为 “Wide eyes, raised eyebrows, lips trembling”。

信息密度控制：核心信息不超过 5 个，动态元素不超过 3 组，修饰词不超过 10 个。过度规格化反而导致模型挣扎产生不自然结果。

语言适配：PixVerse、MiniMax H3、Runway、Veo、Luma 优先使用英文提示词；可灵、即梦对中文理解优秀，中国风内容使用”东方意境/宋代美学”等中文词更稳定。

六、中英文双语写法规范（全模型通用）

通用公式：[主体描述] + [动作/行为] + [场景描述] + [镜头类型] + [运镜方式] + [光线/时间] + [氛围/风格] + [画质/分辨率]。

中英对照示例：

中文：“一名穿深灰色西装的年轻女性设计师，缓慢低头看向地面，右手逐渐握紧蓝色文件夹”

英文：“A young female designer in a dark grey suit, slowly looking down, gradually gripping a blue folder with her right hand”

镜头术语中英对照：特写(close-up)、中景(medium shot)、全景(wide shot)、跟拍(tracking shot)、手持(handheld camera)、航拍(drone shot/aerial view)、推镜头(dolly in/zoom in)、拉镜头(dolly out/zoom out)。

光线术语中英对照：黄金时刻光线(golden hour lighting)、戏剧性光线(dramatic lighting)、霓虹灯光(neon lighting)、轮廓光(rim lighting)、体积光(volumetric lighting)。

双语纪律：具体、结构清晰比简单翻译更重要；使用英文模型时采用 “Subject + Action + Scene + Camera + Lighting + Style + Quality” 语序拼接；禁用”酷炫”“好看”等模糊形容词，转化为”阳光穿过森林树叶缝隙的光束 (sunbeams piercing through forest canopy)“等具体描述。

一、基础运镜七大技法详解（功能+情绪双维）

1.1 推镜头 (Push In / Dolly In)

定义：摄像机沿光轴方向向被摄主体靠近，或通过变焦模拟靠近效果，画面范围由大变小，景别从大景别向小景别过渡。

功能：突出主体细节、刻画人物心理、强调情绪重点、制造悬念或引导观众视线聚焦。

情绪差异：缓慢推进强调内心细腻变化、建立亲密感或营造沉思氛围；快速推进制造紧张严肃情绪、压迫感或心理入侵感。

1.2 拉镜头 (Pull Out / Dolly Out)

定义：摄像机沿光轴方向远离主体，画面范围由小变大，景别从小景别向大景别过渡。

功能：展现主体与环境的关系、交代环境全貌、产生宽广舒展感，常作为场景结束或情绪释放的手段。

情绪表达：传递疏离感、孤独感、释然感或留白感；急速拉远可瞬间展露人物与环境关系，制造孤独或震撼的视觉反差。

1.3 摇镜头 (Pan / Tilt)

定义：摄像机位置固定，机身依托三脚架作水平（左右）或垂直（上下）旋转运动。

功能：介绍环境、巡视场景、展示规模、跟随运动对象或表现浩大场面及高大建筑。

特殊形式：甩镜头（Whip Pan） 是摇镜头的极端形式，快速摇动产生动态模糊，用于节奏干脆的转场、表现事物急剧变化或制造心理紧迫感。

1.4 移镜头 (Truck / Track / Dolly)

定义：摄像机沿水平面作各方向（横向、纵向、曲线）移动拍摄，焦距不变。

功能：把行动着的人物和景位交织在一起，产生强烈的动态感和节奏感，展现空间层次及人物与环境的关系。

意境：横移镜头模拟侧身漫步视角，自带电影质感，传递无声陪伴或叙事流动感。

1.5 跟镜头 (Follow / Tracking Shot)

定义：摄像机跟随运动中的被摄对象拍摄，保持主体在画面中位置相对不变，分为前跟、背跟、侧跟。

功能：连续表现角色动作表情、交代运动方向速度及环境关系、保持运动连贯性、创造沉浸式体验。

情绪：赋予画面呼吸感，增强现场沉浸感与真实感，带领观众进入场景内部与角色同频。

1.6 升降镜头 (Crane / Pedestal)

定义：摄像机在垂直方向上下运动。

功能：改变画面空间、展现事件规模气势、提供独特视角或加强戏剧效果。

情绪对立：升镜头从局部扩展至开阔空间，传递崇高、希望、释然力量或仪式感；降镜头从全局收拢至细节，传递压抑、失落、窒息沉重感或俯冲压迫感。

1.7 其他重要运镜

环绕镜头 (Orbit)：围绕被摄主体做圆弧或 360° 移动，全方位展示主体立体感，强化核心人物存在感，营造视觉冲击。

手持镜头 (Handheld)：模拟手持拍摄的不规则晃动，传递临场感、紧张感、真实感或表现慌乱、混乱、不安的心理状态。

希区柯克变焦 (Dolly Zoom)：机位移动与镜头变焦反向同步（如推轨+拉焦），主体大小不变但背景透视剧烈变化，用于制造眩晕、压抑、惊悚感或表现人物内心巨大变化。
