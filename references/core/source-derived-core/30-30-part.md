模块 A：镜头语言与运镜系统

A1. 基础四大定场镜头

水平平移（Truck/Pedestal Level）：平视高度，水平匀速横移，无倾斜抖动。适配：庭院长廊、舒缓开场、万能基础。抖音口诀：“拍大景用横移”。

高低俯仰（Tilt Up/Down）：垂直轻柔升降；仰拍拉高气场/权力感，俯拍压缩画面/渺小感。适配：建筑、庭院、人物沉思。抖音口诀：“竖拍建筑全景用纵摇，仰拍高大全貌用降镜，神秘展示主体用升镜”。

渐近向前推（Dolly In / Push In）：匀速缓慢向前贴近，从环境过渡到半身。适配：发呆、沉思、聚焦情绪、顿悟时刻。抖音口诀：“突出主体细节用推镜；做推镜头手机开 0.5x 超广角，才有冲击感”。

远景向后拉（Dolly Out / Pull Back / Reveal）：平稳向后匀速退行，铺开全景。适配：留白叙事、孤独氛围、意境结尾、揭晓真相。抖音口诀：“展示整体全景用拉镜；拍雕塑用后拉”。

A2. 情绪与氛围运镜（四大手法）

低速沉浸环绕（Orbit / Arc Shot）：低速度圆弧匀速环绕，丝滑克制。适配：孤寂、温柔、独处、人物登场。抖音实战细节：广角端环绕信息多、动势平缓适合铺垫；长焦端环绕背景压缩感强、人物与背景运动关系被剧烈放大，适合情绪冲击。

微幅精细定点摇镜（Micro Pan / Locked Micro Move）：机位锁死，微米级慢动。适配：捕捉发丝、眼神、神态留白。

视线情绪追随（Whip Pan / Look Follow）：跟随人物视线偏移。适配：解决 AI 镜头死板无魂问题。

静置呼吸锁镜（Locked Off / Static Breather）：机位静止，保留自然呼吸感、眨眼、衣袂微动。适配：情绪停顿、剧情留白、收尾。杜琪峰《枪火》式美学：用静止构图和简洁机位制造压迫感，真正的力量来自克制而非炫技。

A3. 动态行走镜头（四大运镜）

贴身同步跟拍（Follow Tracking）：贴合人物动线，匀速随行，人物在画框中位置稳定、背景流动。适配：庭院漫步、缓步前行。手机实战：脚后跟先着地小碎步；跟随拍摄时脚步转向前进方向，不要螃蟹步。

定点侧向横摇（Fixed Pan）：机位固定，左右匀速扫动。适配：驻足观望、环视景色。

正向缓步前移（Push-in Walk）：平稳慢速直线推进。适配：走向风景、治愈系开场。抖音口诀：“拍小路用前推；拍风景斜前推”。

平行侧向滑移（Parallel Truck）：与人物平行，同步侧移。适配：侧面展示身姿、剧情过渡、两人并肩。

A5. 节奏衔接运镜（解决跳帧生硬）

节奏推拉衔接：前推聚焦情绪，后拉交代场景。

多维度角度切换：高低远近微调，丰富层次。

大环境时空过渡：镜头慢速扫览全域，替代剪辑硬切。

快慢节奏控速：慢镜沉淀，快镜推进，松紧错落。

A6. 运镜三大铁律（抖音+电影学院共识）

起幅落幅：每个运动镜头前后多录/多生成 2 秒静止画面，给剪辑留手脚。

动势唯一性：一次运镜只做一个方向，要么推拉要么横移，禁止一次运镜中突然变向。
