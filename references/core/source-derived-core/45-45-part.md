一、空间引用语法（各模型空间表达规范）

1.1 画面坐标描述法（框内标准，全模型通用）

以观众视角的画面平面为基准（禁用世界坐标系术语）：

垂直位置：画面上部/中部/下部/顶部边缘/底部边缘。

深度层次：前景（距镜头最近，常虚化或作遮挡）/中景（主体区）/背景（环境层）/远景（天际线层）。

相对方位：A在B的左侧/右后方/正对面/斜后方45度/身前一步距离。

1.2 叙述内嵌机位法（Veo 风格）

把机位写进叙述而非单独标注：“(the camera is behind the bar counter, shooting through the glasses)” —— 用空间介词短语内嵌摄影机位置，模型自动解析。

1.3 锚点参照法（复杂场景防漂移）

二、空间关系词汇库（前中后景三层填充法）

每个镜头的空间字段按三层填充：

深度增强技巧：

三、方位介词与运动方向语法（防方向跳变）

3.1 静态方位介词库

中文：位于/站在/坐在/靠在/悬于/嵌入/穿过/环绕/介于…之间/正对/背对/侧对。

英文：positioned at / standing on / leaning against / suspended above / embedded in /穿过 through / surrounded by / between / facing / with back to。

3.2 运动方向锁定语法

出入画规则：主体”从画面左侧入画，向右移动，从右侧出画”——下一镜必须保持同向（“从左入画向右”），除非显式转场（与原文运动轴线融合）。

朝向锁定：每镜显式声明面部朝向与视线目标——“A面朝画面右方，视线落在画面右侧的B脸上”。

相对运动：相向而行（迎面靠近）/同向而行（一前一后）/背向而行（相互远离）/交叉而过——四种关系写明后，全程不可无因由翻转。

速度参照：快速主体在画面中位移大（每秒横跨画面1/3），慢速主体位移小；同速并行的两主体相对位置恒定。

3.3 多主体空间编排（三人以上场景）

三角站位：三主体构成三角形，主戏人物占三角顶点，镜头从第四面（开放边）拍摄。

纵深排布：前中后景各置一主体，用焦点转移（rack focus）轮换叙事重心。

包围/对峙构图：对立双方分居画面两侧，中间留白即”张力区”；权力压制场用高位/低位垂直落差表达。

人群层次：人群写为”三层”——前排清晰个体（有表情动作）、中排半清晰剪影、后排模糊色块，避免模型渲染出整齐复制人。

四、防穿模空间语法（框内专用表达）

接触声明：手与物体接触必须写接触面——“右手五指环握杯身中段，指腹贴合杯壁”。

间隙声明：不接触的物体写明间隙——“刀尖距喉结10厘米悬停，未接触皮肤”。

穿透禁止声明（负向）：no clipping, no intersecting limbs, no objects passing through body。

遮挡优先级：前景遮挡物始终遮挡后景主体，运动过程中遮挡关系连续变化不跳变。
