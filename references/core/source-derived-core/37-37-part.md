一、通用提示词结构与核心公式（2025-2026 全网验证版）

尽管各模型存在”方言差异”，AI 视频提示词已形成一套被广泛验证的通用底层逻辑：

1.1 三级公式体系

基础公式：主体 + 场景 + 运动。适用于灵感启发，仅描述核心对象、环境及动态。

进阶通用公式：主体(描述) + 场景(描述) + 核心动作 + 动作过程 + 景别与构图 + 运镜 + 光线氛围 + 视觉风格 + 速度节奏 + 限制条件。强调将创意转化为可执行的画面变化，是专业创作标准范式。

六段式描述法：主体描述 + 动作及行为 + 镜头语言 + 光影色调 + 材质质感 + 情绪氛围。按画面呈现逻辑依次描述，先定内容再定形式。

1.2 核心要素撰写规范

主体：采用”特征+状态+环境”复合描述，明确外貌、服饰、材质等客观特征，避免”美女”“好看”等模糊形容词。人物主体需在每段分镜中重复保留核心特征词以确保一致性。

动作：使用”动词+量化词”结构（如”每秒3步”“旋转180度”），描述可观察的动作过程、幅度、速度及方向。单镜头仅安排 1 个核心动作，避免动作过多导致畸变。

镜头语言：明确景别（特写/中景/全景）、运镜方式（推/拉/摇/移/环绕）及拍摄角度。单镜头只使用一种主要运镜，避免指令冲突。

时间节奏：单镜头时长建议 4-8 秒，手部动作等复杂细节控制在 3-5 秒以内。长视频拆分为多个短镜头生成后剪辑。

负面提示词：添加”无穿模、无肢体畸变、解剖学正确、无多余肢体、无画面闪烁”等约束，置于提示词末尾，数量不宜过多。

二、九大视频模型专属提示词工程详解（public-release-marker 最新版）

2.1 Seedance / 即梦（含 2.0 / 2.5 全系）

核心语法：支持 @语法 精准调用素材（图片/视频/音频），如 @图片1作为首帧 固定人脸/形体。

SACSC 五步提问法：Subject(锚定主体) → Action(定义动作) → Camera(规范运镜) → Style(设定风格) → Constraints(添加约束)。关键动作建议标注英文动词，约束使用”无XX”句式。

切片粒度黄金法则（与原文”单镜秒数规范”融合使用）：

3秒：动作完整性最小闭环（战斗/运动/舞蹈），保证”起势-发力-收束”完整。

4秒：情绪递进最小单元（表情+光影+镜头三重语义上限）。

5秒：固定镜头/极缓慢推拉的安全区间，利于光影材质收敛。

多镜头/首尾帧：支持时间节点定义（如”0-2秒：…；2-5秒：…“）；首尾帧模式自动补全中间过渡；智能多帧模式支持 2-10 张关键帧图像生成一镜到底效果。

避坑规则：单条提示词只写 1 种运镜；禁止跳跃/快速转身/复杂舞蹈；权重顺序为 参考图 > 主体 > 动作 > 光影 > 镜头 > 画质 > 稳定约束 > 负面词。

2.2 可灵 Kling（3.0 / Omni）

提示词公式：(镜头语言 + 光影) + 主体(描述) + 主体运动 + 场景(描述) + (氛围)。镜头语言建议开场，风格词置于句末。

Multi-Shot 多镜头：支持 Automatic 与 Custom 两种模式。Custom 模式可在单条提示词中定义最多 6 个镜头切换，逐镜头指定内容、时长、景别、运镜。

Native Audio 原生音频：支持对话、环境音、音效同步生成，无需后期配音。

运镜控制：6 种基础运镜（水平/垂直/推进/拉远/旋转摇镜/水平摇镜）+ 4 种大师运镜（左旋推进/右旋推进/推进上移/下移拉远）。Web 端专业面板支持方位角(-180°+180°)、俯仰角(-90°+90°)数值输入及运镜强度滑块（建议 30%-70%）。

图生视频：公式为 主体+运动，背景+运动。开启”首帧锁定”保证第一帧与原图一致；人物画面只写局部微动，避免大幅度奔跑跳跃。

Elements 3.0：支持多图/视频参考保持角色一致性，文字渲染能力支持产品标签/招牌清晰生成。

2.3 Veo（Google DeepMind Veo 3 / 3.1）

提示词结构：[Cinematic Style] + [Subject & Character Details] + [Action/Movement] + [Environment/Lighting] + [Audio Cues] + [Technical Parameters]。偏好完整句子与因果描述，而非逗号分隔的标签列表。

对话与唇形同步：必须使用冒号+引号语法触发，格式为 Character Name [Visual Description] looks at camera and says: "Spoken line here."。缺少冒号或引号可能导致角色不说话或文字显示为字幕。

Sonic Landscaping（声景驱动）：支持音画同步描述，如 “A crystal wine glass shatters on marble floor, the sound reverberating…”，声音描述可直接驱动视觉元素生成。

空间引用语法：支持 “(that’s where the camera is)” 类空间锚定表达，用叙述内嵌机位。

多镜头与时间控制：支持单提示词内多镜头分段叙事；Extend 功能从上一片段末帧接力生成，实现链式长视频（单次生成上限 30 秒）。

Image-to-Video：支持 Ingredients 工作流（上传参考图作为视觉原料）和 Frames 工作流（首帧+尾帧+过渡描述）。

2.4 Sora（OpenAI Sora 2）

六部分结构：摄像机取景 + 景深 + 动作节拍 + 灯光调色 + 主体锚定 + 单一合理动作。偏好散文式自然语言描述，像给摄影师做简报。

API 参数分离：model(sora-2/sora-2-pro)、size(分辨率)、seconds(4/8/12) 不可通过提示词控制，必须在 API 调用中显式设置。提示词仅控制内容、运动、光照、风格。

多镜头叙事：可在单个提示词中描述多个镜头，但每个镜头块必须独立（一次一个机位+一个动作+一种光效）。也可使用 Storyboard Mode 分块描述。

对话处理：对话需简短自然，4 秒片段最多 1-2 句；明确标注说话人与台词内容。

Remix 与迭代：支持强/中/弱三档修改力度微调；短提示词给创作自由，长提示词给控制力；建议先低分辨率测试满意后再升高清。

2.5 Runway（Gen-4 / Gen-4.5）

四部分公式：[Camera Movement] + [Scene] + [Action] + [Details]。以镜头类型开场，使用正向表述，单动作控制在 10 秒内。

T2V vs I2V：文生视频需完整描述画面+运动；图生视频提示词仅聚焦运动描述，不重复画面已有内容，省略组件可赋予模型创作自由。

Sequential Prompting：支持自然语言或时间戳 [00:01] 格式描述时序变化；长视频通过提取末帧作为下一段输入实现接力。

Motion Brush 3.0 & Director Mode 2.0：Motion Brush 支持多主体独立动作控制，不同关键帧同区域笔刷需保持颜色/方向一致；Director Mode 支持精确运镜参数定义（推/拉/摇/移/景别/机位轨迹）。

Camera Control 面板：Horizontal、Vertical、Pan、Tilt、Zoom、Roll 六轴滑块（数值范围 [-10, 10]），支持鼠标拖拽或数值输入。

稳定性约束：推荐提示词末尾添加 no translation; no zoom; no tilt 三重否定收尾以防抖动。

2.6 海螺 MiniMax（Hailuo H3 / V3.2）

结构化两段式：Instruction(任务指令) + Body(核心字段)。英文提示词效果优于中文。

对齐指令语法：

I2VA（首帧）：For the target video, at 0.00 seconds into the target video, <image> (from [Shot 1]) is fully referenced.

FL2VA（首尾帧）：Picture 1 aligns with 0.00-second mark; Picture 2 aligns with S.SS-second mark.（S.SS 保留两位小数）。

核心字段三要素：integrated_multimodal_description(画面描述) + overall_soundscape(环境音效) + non_diegetic_music(背景音乐)。首个镜头不加时间戳，后续按 00:SS.SSS 递增。

多镜头语法：[Shot 1]…At 00:05.000, [Shot 2]…（首镜头无时间戳，后续递增）。

运镜嵌入规则：摄像机运动描述需包含类型、幅度、速度三要素，自然嵌入句子而非堆砌标签；视角微调优先写摄像机运动避免硬切。

否定约束：V3.2 模型需在提示词最末尾用英文逗号连接负向描述（如 ,no text,no watermark），必须紧贴结尾、中间不空格不换行。

2.7 Vidu

基础架构：主体/场景 + 场景描述 + 环境描述 + 艺术风格/媒介。调整句式和语序，避免主体物过多/分散。

语言风格：使用流畅准确的口语化措辞，避免过度文学化叙述；丰富、准确和完整的描述才能生成特定艺术风格视频。

联想扩充：通过具体位置描述/环境描述构建构图，通过艺术家风格/流派提升氛围；在不同位置重复强化关键风格描述可提高一致性。

核心优势：动漫风格表现突出，角色可控性强，镜头/文字/动作理解精准，30 秒极速推理。

2.8 PixVerse

万能公式：[主体描述] + [动作/动态细节] + [场景/背景环境] + [光影/色调] + [镜头语言/画质关键词]。

语言偏好：英文优先，对英文理解最精准；中文写好后可翻译为英文使用。

高频画质词：8k resolution, highly detailed, masterpiece, photorealistic, unreal engine 5, cinematic lighting, volumetric fog, golden hour。

Negative Prompt：支持 blur, distorted, low quality, deformed limbs 等负向提示词排除干扰。

Canvas 功能：支持连接参考图、提示词、运动、输出于可编辑图谱中，便于规划复杂 AI 视频制作。

2.9 Luma Dream Machine（Ray 架构）

关键帧控制 (Keyframes)：上传起始帧+结束帧图片+文本指令，AI 补全中间过渡。是控制 AI 视频动作最精准的方式之一，确保角色从 A 点平滑移动到 B 点。

Strength 滑块：Adhere 档位保留原构图，Reimagine 档位优先响应文本；stylize 值建议 600-800。

物理级相机控制：具备 3D 场景理解，输入 “Dolly”“Orbit”“Pan” 等术语即可实现符合真实透视变形的运镜，远超对形容词的理解。

Modify & Extend：Modify 支持局部重构（换装/换光/换背景），保持原始运动与几何一致性；Extend 延长时长（最多 +5 秒），支持插入中间关键帧实现多段转场。

提示词结构：主体 + 环境 + 镜头运动 + 风格质感。禁用模糊动词，使用具象动词（rotate/lift/drift）；支持 --motion 8、--consistency 9 等参数调节。

对齐检查：Preview Alignment 热力图检查首尾帧对齐；Refine Loop 30-50 弥合接缝。
