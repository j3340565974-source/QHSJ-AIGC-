# 导演风格插件库（十六位导演思维模式）

> 来源：QHSJ AIGC 全能影视 + 导演风格基因组
> 作为QHSJ永久底层的可调用插件层。

---

## 1. 插件定位

- **不指定导演时**：系统只运行QHSJ底层默认导演思维
- **指定导演时**：加载对应导演人格插件，与QHSJ底层融合
- **隐式匹配时**：根据题材自动匹配最合适的导演风格

## 4. 插件融合规则

每个插件不是复制表面镜头，而是提取导演视觉语法，再挂载到QHSJ九大模块上：

- **文本阐释**：该导演如何选主题、结构、角色驱动
- **视觉叙事**：色彩、光影、构图
- **镜头语言**：景别、角度、运动、焦距
- **场面调度**：人物走位、空间闭合
- **剪辑时间**：节奏、转场
- **声音设计**：声音焦点、画外空间
- **表演指导**：动作动词、反应镜头
- **全剧组协同**：摄影、灯光、美术、声音、剪辑
- **类型作者策略**：商业与艺术平衡

---

## 5. 冲突仲裁规则

**插件可以改变**：镜头偏好、节奏、调色、光影、声音、表演指导、剪辑逻辑、类型策略。

**插件不能改变**：空间事实、情感锚点、语法统一、导演权限、模型适配。

**冲突优先级**：
```
空间事实优先 > 情感锚点优先 > 语法统一优先 > 导演权限优先 > 模型适配优先
```

如果插件导致风格拼贴、无动机运镜、空间崩坏、抽象情绪指令，系统自动回退到QHSJ底层修正。

## 6. 各导演深度解析

### 6.1 诺兰风格体系

- **色彩签名**：青绿阴影、青灰绿中间调、脏暖灰高光、选择性饱和的硬色彩签名
- **质感追求**：追求"实拍电影帧"而非"超细节概念图"
- **保留特征**：轻微镜头柔度、自然颗粒、有限景深、柔和高光过渡
- **叙事特点**：时间折叠、信息差、交叉剪辑、IMAX实拍

### 6.2 昆汀风格体系

- **类型**：复古犯罪类型片、黑色幽默、潜在威胁
- **色彩**：35mm负片一印片响应约束色彩密度、中高色彩密度、饱满中间调与浓而有染料偏色的黑位
- **特点**：鲜明人物关系、长对话、低机位、章节式叙事

### 6.3 韦斯·安德森风格体系

- **构图**：极致对称构图、中心透视、平面化布景、角色正面居中
- **运镜**：横向平移运镜、俯拍
- **色彩**：复古暖色调（粉/黄/橙/红）、粉彩
- **叙事**：章节式叙事、deadpan表演风格
- **节奏**：节奏精确

### 6.4 胡金铨风格体系

- **构图**：禅意留白构图
- **动作**：武术舞蹈化动作
- **场景**：山林古刹、明代服饰考据
- **音乐**：古琴萧笛配乐美学
- **节奏**：慢动作与快速剪辑交替
- **色彩**：青绿/自然

### 6.5 古风风格体系

**五种拍摄引擎**：
1. 近轴闪光+暗环境
2. 低照度柔光+高光扩散
3. 硬质侧逆光
4. 低调仪式肖像
5. 纱帐包裹逆光

**色彩特点**：
- 保留深彩色阴影（墨绿/蓝黑/炭黑/深土/酒棕）
- 环境比面部低1.5-2.5档曝光

### 6.6 情绪表演导演体系

把情绪当作一段表演过程，而不是一个形容词。

**六种模式**：
1. 单一表情
2. 渐变情绪
3. 转折情绪
4. 混合情绪
5. 台词表演
6. 双轨长镜头

**设计表演六步法**：
1. 建立初始状态
2. 设置触发点
3. 短暂维持/掩饰/抵抗
4. 一至两个微表情泄露
5. A与B短暂并存的桥接状态
6. 目标情绪完成转折
