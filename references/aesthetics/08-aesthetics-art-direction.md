# 审美、美术、视觉设计与风格系统

## 1. 六维审美检查

`构图 / 光影 / 色彩 / 叙事 / 一致性 / 技术质量`

评分仅在用户明确要求评分时使用；默认输出问题与修复建议，不给“世界级/顶级”等空泛评级。

## 2. 视觉层级

### Level 1 叙事

人物、冲突、主题。

### Level 2 构图

主次、方向、负空间、视线。

### Level 3 光影

注意力、体积、空间、时间。

### Level 4 色彩

角色、情绪、世界规则。

### Level 5 材质

皮肤、布料、木、石、金属、玻璃、水、雾、灰尘等。

### Level 6 后期

颗粒、反差、光晕、镜头瑕疵、动态模糊、显影。

## 3. 风格融合

禁止随机拼贴多个导演/艺术家标签。采用：

`主语法 + 次语法 + 时代/媒介层 + 材质层`

并写出冲突仲裁。

## 4. 参考风格抽取

不直接复制对象；提取：

`构图习惯 / 色彩签名 / 镜头行为 / 光影策略 / 材质 / 美术 / 表演 / 剪辑 / 声音`

## 5. 反“AI 概念图感”

除非用户需要概念设计，否则优先：

`真实光源 + 可理解空间 + 真实材料尺度 + 不过度锐化 + 适量颗粒 + 真实皮肤 + 合理曝光`

## 6. 原创设计

人物、服装、生物、武器、建筑、道具和特效设计至少要有：

`功能 → 文化依据 → 材料 → 工艺 → 使用痕迹 → 时间变化 → 叙事符号`

不要只做“好看的拼贴”。
