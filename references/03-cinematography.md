# 03 - 摄影与运镜系统

## 一、镜头语言五维度

摄影机与主体的关系，决定了观众的感受。五个维度：距离、运动、角度、光学、时间。

## 二、景别光谱

```
大远景 → 远景 → 全景 → 中全景 → 中景 → 中近景 → 近景 → 特写 → 大特写 → 极特写
```

| 景别 | 心理距离 | 用途 |
|---|---|---|
| 大远景 | 极远 | 建立环境、宏大叙事、人物渺小 |
| 远景 | 远 | 场景全貌、人物与环境关系 |
| 全景 | 较远 | 人物全身、动作全貌 |
| 中全景 | 中等 | 人物膝盖以上、兼顾环境和动作 |
| 中景 | 中等 | 人物腰部以上、对话戏常用 |
| 中近景 | 较近 | 人物胸部以上、表情和动作兼顾 |
| 近景 | 近 | 人物肩部以上、强调表情 |
| 特写 | 很近 | 面部/物体局部、情绪放大 |
| 大特写 | 极近 | 眼睛/嘴唇/细节、极端情绪 |

## 三、运镜方式

### 基础运动
推、拉、摇、移、跟、升降、固定、甩、旋转、变焦、移焦、跟焦。

### 速度变体
急推、急拉、慢推、慢拉、快摇、慢摇、快速甩镜、慢速甩镜、升格、降格、定格、跳切、速度斜坡、时间冻结。

### 心理运动
- **滑动变焦（Dolly Zoom）**：主体大小不变，背景压缩/拉伸。用于心理崩溃、认知失调、真相冲击。
- **快速变焦（Crash Zoom）**：极快推近/拉远，冲击、喜剧、惊悚。
- **移焦（Rack Focus）**：焦点从A移到B，引导注意力，揭示关系。

## 四、焦段选择

| 焦段 | 视觉效果 | 心理暗示 |
|---|---|---|
| 超广角(14-24mm) | 畸变、空间拉伸 | 压迫、宏大、不安 |
| 广角(24-35mm) | 空间延伸 | 开放、信息量大 |
| 标准(35-50mm) | 接近人眼 | 真实、中立 |
| 中长焦(85-135mm) | 空间压缩、聚焦人物 | 亲密、柔美 |
| 长焦(200mm+) | 深度压缩 | 窥视、距离感 |
| 微距 | 极小物体纹理 | 细节、陌生化 |

## 五、布光体系

### 三点布光
- **主光**：主要光源，决定整体照明方向和强度
- **辅光**：补亮暗部，降低对比度
- **轮廓光/逆光**：勾勒主体边缘，分离背景

### 光线质感
- **硬光**：阴影边缘清晰，强烈对比，硬朗、严肃
- **软光**：阴影边缘柔和，低对比，温柔、自然

### 常见布光风格
- 伦勃朗光：面部三角形光斑，肖像经典
- 蝴蝶光：鼻下蝴蝶影，美女光
-  split light：半明半暗，悬疑、分裂
- 逆光剪影：轮廓光，神秘、诗意

## 六、构图法则

- 三分法：主体放在三分线交点
- 中心构图：主体居中，对称、稳定
- 对角线：动态、动感、张力
- 框架构图：用前景物体框住主体
- 引导线：线条引导视线到主体
- 留白：负空间，呼吸感、孤独感

## 七、常见转场

- 硬切：最常用，直接切换
- 叠化：时间流逝、回忆
- 淡入淡出：开场/结尾
- 划像：动态转场
- 匹配剪辑：动作/形状匹配
- 视线匹配：顺着人物视线切到看到的东西
