- **定位**：音色锁 = **"这个人的声音长什么样"**（角色恒定）；语气 = **"这一句怎么说"**（逐句变化）。两层分开，与角色 4 View 资产板"锁长相"的分工完全对称；
- **落法（一句话）**：已有 2.5 音频素材的，在【核心人物】行尾写 `@CHR-角色名（音色以 reference_audio 锁定：干燥近讲 / 温润中音…）`；`reference_audio` 素材用途**必须标注"锁定音色"**（官方红线 3：素材必须标注用途）；
- **不做的事（防膨胀）**：**不新建 `AUD-` 音色资产表、不改台账结构、不强制每角色配音频素材、不设前置门禁**；
- **判据**：**有素材就锁，没有就写文字音色描述**（与 2.0 写法一致）——音色锁是增强项，缺它不是缺陷。
#### 5.2.7 语气位禁写项
| # | 禁写项 | 正确做法 |
|---|---|---|
| 1 | 把语气词写进画面段（"嘶哑地抬头""冷笑地看着"） | 移入语气位；画面段只留肌肉可见动作 |
| 2 | 语气位写空泛情绪词（开心/难过/生气） | 按四维改写（情绪色/力度/音质/节奏） |
| 3 | 单句堆 4 个以上语气词 | ≤3 个，留最强的三个 |
| 4 | 给 `台词：无。` 的镜配语气位 | 无台词就没有语气位 |
| 5 | 把语气位写成独立字段或独立段 | 它是 `台词：` 字段内的限定语，不加段数 |
| 6 | 在语气位写 FACS 内部标注（AU12/〔显〕/English kernel） | 语气位用中文质地词；内部标注只进 QC 表（见 §5.1 禁写项 #8） |
#### 5.2.8 机检对照（C16 · `scripts/validate_prompt.py`）
| 检查 | 级别 | 判定 |
|---|---|---|
| 画面段出现声音词（`声音：`/`台词：` 之前出现 嘶哑/沙哑/低语/气音/嘶吼/冷笑 等） | WARN | 语气错位——声音词应移入语气位 |
| 有台词的镜行未带语气位（缺失率 >50%） | WARN | 语气缺失——按四维补写（纯过场应答可豁免） |
| 语气位含空泛情绪词 | WARN | 改四维写法 |

### 6. 官方 API 契约（创建任务请求体）
```json
{
  "model": "doubao-seedance-2-5-260628",
  "content": [
    { "type": "text", "text": "……草莓味参考@图像1……" }
  ],
  "generate_audio": true,
  "ratio": "16:9",
  "duration": 15,
  "output_format": "mov"
}
```
| 参数 | 取值与说明 |
|---|---|
| `model` | 固定 `doubao-seedance-2-5-260628` |
| `ratio` | `16:9` / `9:16` / `1:1` / `21:9`；编辑/首尾帧模式用 `adaptive` 自适应 |
| `duration` | **4~30 秒** |
| `generate_audio` | 布尔值，是否生成原生音频 |
| `content` | 数组，可混合 `text` / `image_url` / `video_url` / `audio_url` 多模态素材 |
| 素材 `role` | `reference_image` / `reference_video` / `reference_audio`；首帧 `first_frame`、尾帧 `last_frame`（**仅 2.5 模式②；首/尾帧与参考图互斥**；2.0 不适用） |
