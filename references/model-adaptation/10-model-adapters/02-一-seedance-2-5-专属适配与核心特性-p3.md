- **改法一 · 换词（被禁词根零出现）**：高关联视觉概念（发光/透光/笑/空镜）的字面词**不许出现在提示词任何位置**（含【强制禁止项】），改写为不含该词根的正向描述：
  - 道具光效 →「玉体呈深青色实心石质、哑光质感，玉面呈青玉原色」（替代"不发光不透光"；**零光效描写**——光斑/受光/照射类从句一律不写，见下 C20d 条）；
  - 冷硬表情 →「双唇抿紧、嘴角向下压、下颌绷紧、眉梢下压，说话时每个字都咬得极重」（替代"面无笑意"）；
  - 首帧锚定 →「画面主体：林清月蜷卧土炕、病容苍白。她的一只手搭在破被外」（替代"禁空镜开场"）——**写在镜1 镜行内**，不得写进【强制禁止项】（见下栏目纪律条）；⚠️ **旧示范句「首帧即这只手与林清月病容的脸同框」已废止（V6.9.7）**——该句是**并列主体句式**，实测让模型渲染出**两张脸**（见 §5.0.2 单主体铁律 / C20a）；
- **改法二 · 主体优先句式**：每段镜1第一个分句即画面主体——人名开头或「画面主体：<人名>…」；环境前置词开头（"土炕上…""房梁下…"）会诱导模型渲染空场景开场（实测两轮出空房间）；
- **改法三 · 触发器移除**：诱发被禁效果的动作/构图本身换掉——「举向油灯冲光」是透光自发光的构图触发器（道具正对光源）；⚠️ **旧建议「举到油灯旁，火光从侧面照在玉面上」已废止（V6.9.7）**——侧受光实测仍出片玉佩点火。现行正解：**道具与灯火彻底解耦**——动作只「把玩/随身佩戴」，不靠近任何光源，镜行只留材质本色（机检 C20d 两个子判据都会拦）；
- **具象光源映射污染（C19d）**：反光道具镜行**禁写「映出/倒映火苗」**——模型不理解「反射」，会把「映出+光源名词」读成光源出现在道具上（玉面画出小火苗/整体泛光）。⚠️ **旧建议"改写为光斑语言"已废止（V6.9.7）**——光斑语言实测同样点火（见 C20d）。现行正解：**零光效描写**，只写材质本色（「玉面呈青玉原色」）；
- **镜行少形容词（正向描写的密度纪律）**：正向描写**每镜只留必要项**——主体、动作、材质/光各写一处即可，修饰词堆叠（「深青色实心哑光石质原色＋暖黄反光＋冷硬下颌」连排）会稀释关键信息、拉低模型对每条指令的服从率；写完扫一遍，与镜头主体无关的形容词一律删掉；
- **抽象形态/程度副词一律删（V6.9.7 续增 · 用户逐条点出）**：「成线 / 成串 / 成股 / 如注 / 轻蜷 / 微蜷」这类词描述的是**模型无法命名的过程形态**——AI 只会渲染**可命名的具象形态**，抽象副词不被理解，写了也白写（用户：「像呈现这种东西，AI 是不能够理解的，这种形容词少一些」）。实测两处：「漏雨**成线**砸在手背上」→ 写「**雨滴**砸在手背上溅开」就够；「手指**轻蜷**」→ AI 理解不了，直接删。**判据一句话：这句里每个词都能画出来吗？画不出来的就是形容词——删掉，或换成具象动作**（机检 C20c）；
- **边界**：水印/变形/字幕/现代元素等**低关联瑕疵**仍走【强制禁止项】否定式兜底（模型本就不倾向生成它们，否定式够用）；**高关联倾向项**中，表情/开场镜头走镜行内正向描写，**道具光效走零光效描写**（正向写光反而点火，见 §5.0.3 道具光效条），两类不冲突；
- **栏目纪律 · 正向指令禁入【强制禁止项】（V6.9.6 新增）**：**禁止项只装负面清单**，正向执行指令一律回落【时间轴分镜】镜行 /【画幅风格】/【站位声明】。原因：模型把该栏当"规避清单"读——正向要求写进去**既不被当禁令、也不被当执行指令**，两头不生效（实测段1 该栏里的「全片首帧即镜1的人物近景画面」「道具保持日常石质与金属质感」两条等同废纸，模型照旧加空镜、照旧把玉画成灯泡）。同理，**否定式禁令也不得写在该栏**（被禁词根＝画面词，见改法一）——「玉佩/银镯不发光、不透光」写进禁止项同样是废纸。该栏合法内容只有三类：**画面**（角色变形/手部异常/服装变化/现代元素/字幕/Logo/水印）、**文字**（文字/UI/水印/Logo/角标）、**音频**（无背景音乐，仅环境音与人声）；
- **机检**：`validate_prompt.py` **C19**（WARN，五判据）——C19a 镜行裸禁令词（不发光/不透光/不悬浮/面无笑意等）；C19b 光路触发器（反光道具被举向/对着/冲向灯或光）；C19c 首镜第一个分句非人物名/身体局部/「画面主体」/人称开头；C19d 具象光源映射污染（反光道具镜行「映出/倒映火苗」）；**C19e 禁止项栏目纪律**（e-a 正向执行指令混入禁止项 / e-b 禁止项内裸禁令词）；**C20 单主体锚定与具象化**（a 并列主体/同框句式 → 出片两张脸；b 悬空指示代词 → 模型自补一个头；c 抽象形态形容 → 模型无法命名；**d 道具光效描写/道具贴近光源 → 出片玉佩点火**）。
#### 5.0.5 示范句验证纪律（V6.9.7 根因复盘新增 · ★权威）
> **根因复盘（「重生70」EP01 连续四轮废镜的共同源头，用户令查"skill 为什么会这么写"）**：历轮翻车的示范句——「面无笑意、唇线平直」（V6.9.4）→「首帧即这只手与林清月病容的脸同框」（V6.9.5）→「举到油灯旁，火光从侧面照在玉面上」（V6.9.5）→「受油灯照射处只有指甲盖大的一片暖黄光斑」（V6.9.5/6 光斑语言）——**全部是当轮凭对模型行为的理解新造、从未实拍验证**，就被写成 ✅ 正例、甚至嵌进机检修复建议文案；产物照抄规则，**解药成了下一轮的毒药**。这不是某一句写坏了，而是"正例的生产方式"错了。四条铁律：
- **正例只准实证回收**：示范句必须从**实拍通过**的产物或用户实测确认的原句回收（标注【实证】+ 出处，如「女帝战巨兽」聚合版）；**禁止凭理解新造正例**——写规则时对模型行为的想象不是证据。
- **新造句必须标【待验证】**：确需先写参考句时，必须显式标 **【待验证·未实拍】**，不得用 ✅/推荐箭头格式包装；**一律不得写进 `validate_prompt.py` 的修复建议文案**——机检文案是最高危传染源（产物端按建议逐字照抄，V6.9.5 的同框句、光斑句都是这么扩散的）。
- **修复建议只写判据、不造句**：告警文案只描述"改成什么结构/含什么要素"（如「改为『画面主体：』单主体开头」），具体句子由实拍通过的稿子回填。
- **上层判据升级必须同轮清扫下游**：某句式被判废止时，同轮清扫全部规则文档 + 机检文案 + 自测基线的活体残留，不得留到下一轮（本次复盘实证：checklist 旧铁律 13、C19d 修复建议各晚清了一轮，期间持续污染产物）。
- **机检兜底**：`check_package.py` **⑰ 规则自洽门**——扫描规则文档，被废止句式的关键词只允许出现在警示语境（已废止/禁写/替代/病根复盘等），裸出现即 FAIL——**规则层自己也要过自己的禁令**。
**七段式完整顺序**（2.0 版示例骨架）：
```text
【画幅风格】16:9 横屏, <风格/光影/色调/质感一句话>（2.0 版在句尾写 `model=seedance-2.0`）
【场景资产】@SCN-xxx（外观以场景参考图锁定，不另写文字描述）
【核心人物】@CHR-xxx（外观以人物参考图锁定）× N 人
【站位声明】（一行式四要素+轴线+位移，见上文）
【时间轴分镜】
00:00-00:05 [镜头1] 景别 · 视角角度 · 运镜。动作与受力。声音：音效描述。台词：无（或【谁（语气）："…"】——**语气位必写**，见 §5.2）
00:05-00:10 [镜头2] …
【接续状态】：女主立于窗下侧身45°朝左，信件半展于右手，指尖停顿在纸缘；母亲在门口背身垂手——下段自该画面起手（终段按档位写终帧定格，如：全段终帧定格最高潮画面，无平缓收势帧·R3 档强制）
【音效】环境音列举（默认由模型生成；仅用户明确指定"不出台词/走后期"时才注明后期配音层）
【强制禁止项】画面：…；文字：…；音频：…
```
> ⚠️ **末尾参数行已废止（2026-09-15 用户裁定）**：不再在提示词末尾加【参数契约】行——模型版本写在【画幅风格】句尾 `model=`，画幅/时长由项目头 A/B 锁与各镜时间轴承载，无需重复。
- 镜行格式沿用本包原生写法：`00:00-00:05 [镜头N] 景别 · 视角角度 · 运镜。动作描述。声音：…。台词：…。`——**每镜行尾必须带行内 `声音：` 与 `台词：`**（无台词写"台词：无。"），2.5 可用官方声音字符（台词 `{}`/音效 `<>`），2.0 写**由模型生成**的音效与台词描述（默认视频内出，不默认降级后期；仅用户明确指定"不出台词"才写后期配音说明）；**镜行不写"跟随@谁"**（跟随目标属运镜策略，需要时自然融进动作描述，如"镜头随其位移横移"）；**有台词的镜行台词字段必带语气位 `【谁（语气）："…"】`（2.0 / 2.5 同规格，见 §5.2，禁"只有谁和说什么"）**；不采用外部示范的"括号五要素连写 + 本镜唯一开口者"变体；
- **台词字段归属（V6.9）**：`台词：`字段**只装画内开口对白**（锁口型走 `{}`）；**画外声（OS 内心独白 / VO 旁白）一律写进 `声音：`段并标注画外身份**（`画外·内心独白（OS·音色）："…"` / `画外·旁白（VO·音色）："…"`），画面段必须写闭口证据——写法、配额与禁令见 `../../audio/qh-vo-os-weaving.md`（V6.9 ★权威），机检 C14 兜底；
- **【接续状态】**：时间轴分镜末镜后必带——**V6.9 起写具体末帧画面**（谁+在哪+姿态+关键道具/互动状态，一句话画得出画面，下段自该画面起手）；纯套话"角色动作与空间位置严格继承"已废止（模型每段零记忆，套话不承载画面信息，机检 C11 告警）；跨段接续另配段缝分镜参考图（工作流层，见 `../../spatial/qh-segment-splicing.md` §二）；终段按档位写终帧（R3 档强制"终帧定格最高潮画面，无平缓收势帧"）；
- 与本包规则的关系：**格式用七段式 + 一行式站位声明；打斗/去水/Hit-Stop/在场声明等规则仍按本包各权威文件执行**；
- 空间连续性铁律（`../../spatial/qh-asset-spatial-ledger.md` §三）继续有效：180°轴线、上一镜被击退到哪下一镜从哪继续、真实场景位置≠画面位置（运镜可改变观察，不可改变真实空间）。
### 5.1 格式禁写清单（2026-09-15 用户裁定集 · 防回归）
