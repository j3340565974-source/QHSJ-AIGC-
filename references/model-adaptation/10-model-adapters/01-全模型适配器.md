# 全模型适配器

## 0. 总原则

模型版本随时间变化。运行时先核验当前版本，再使用历史模板。没有官方资料时，把参数标记为“待验证”，不写成事实。


## 2. 当前已核验的通用观察

### Veo 3.1

Google 当前资料显示支持参考图、角色一致性、音频、镜头控制与延长片段；因此复杂角色/场景项目优先使用参考资产而非纯文字重复。citeturn538276search3

### Runway Gen-4 / Gen-4.5

Runway 当前提示指南强调：I2V 文本主要描述运动，输入图承担起始视觉；推荐简单直接、逐步增加变量，并避免不受支持的负面措辞。（官方核验来源见 research/research-basis.md）

### Midjourney Style Reference

官方文档说明 Style Reference 用于传递颜色、媒介、纹理、光线等整体视觉感觉，而不是复制人物或对象；文本应描述要生成的新内容。（官方核验来源见 research/research-basis.md）

### Seedance 2.5

Dreamina 当前公开指南给出“格式→主体→动作→环境→摄影机→视觉→时间→音频/约束”的八部分生产结构，并强调参考素材角色、动作时序与一致性。实际版本、长度与语法仍以运行时官方资料为准。（官方核验来源见 research/research-basis.md）

## 3. 适配策略

### 图像模型

优先编译：主体、构图、光影、材质、风格、参考图角色。

### 视频 T2V

优先编译：场景、主体、动作、相机、时序、声音。

### 视频 I2V

优先编译：动作、环境变化、相机、时序、保持不变项。

### 多镜头模型

先给全局保持项，再逐镜给局部变化，不让每镜重新定义一个全新世界。

## 4. 负向适配

先判断模型是否有独立负向能力：

- 支持：使用简短、稳定的结构错误词
- 不支持：用正向期望替代
- 不确定：不猜，联网核验

## 5. 模型迁移

从模型 A → B 时生成“迁移警告”：

`可直接迁移 / 需改写 / 可能丢失 / 需要参考素材 / 不支持`

## 6. 自动检索

当用户说“用最新的 X 模型”或模型名称不熟悉时：

1. 搜索官方文档
2. 找版本号和发布日期
3. 抽取输入模式、时长、参考、音频、相机、提示词、限制
4. 与现有注册表比较
5. 只把可验证信息写入本次适配器
6. 可持久化时更新 research-log 和 model registry

## 7. 不做的事情

- 不把社区传闻当官方限制
- 不把一年前的参数复制到今天
- 不用“这个模型底层就是扩散模型”作为唯一依据推断 Prompt 语法
- 不因为模型擅长某类镜头就宣称其“绝对不会崩”

## 〇、 任务前置强制锁定：A·模型版本 / B·画幅 / C·交付形态（最高优先级 · 与 SKILL.md 〇节联动）

> **每个任务动笔前必须完成 A（Seedance 2.5 / 2.0 强制二选一，或 MiniMax H3 格式支线）与 B（画幅三选一）两道创作锁。任一项用户未指定 = 任务不开始，禁止默认跳过。C·交付形态未指定时默认 ③（两者都交付），不阻塞创作。**

### A · 模型版本强制二选一（＋ MiniMax H3 格式支线 · 第三选项）
- **三选项并列：Seedance 2.5 / Seedance 2.0 / MiniMax H3**。选 Seedance = 下方强制二选一与全部契约；**选 MiniMax H3 = 进格式转换支线**（上游全流程照旧，只在 P4 转壳），见 `../qh-h3-adapter.md`（★权威）。
- 用户未指定模型版本 = 任务不开始，禁止默认跳版本；锁定后按下方对照表分语法执行。

### B · 画幅强制三选一
- 用户必须明确选择：**16:9 横屏 / 9:16 竖屏 / 21:9 宽幕**（官方另支持 1:1，仅明确指定时采用）；未指定 = 停下询问，禁止默认 9:16；
- 每条提示词 / 每个时间轴分镜 / 每个 API 载荷的 `aspect_ratio` 都回填锁定值；画幅构图细则路由见 `../../platform/qh-aspect-ratio-adaptation.md`（★权威）。

### C · 交付形态三选一（未指定默认 ③，不阻塞创作）
- **① 只要离线看板**：项目 md 照常创作（唯一编译源），最终只交付看板 HTML；**② 只要 markdown 文档**：不编译看板；**③ 两者都交付（默认）**：md + 单文件离线看板；
- 依赖关系：md 是唯一真相、看板由 md 编译生成，**看板离不开 md，不存在"跳过 md 直接写看板"**；C 只决定交付哪份文件，几乎不影响出稿速度——与 A、B 同一句话问清即可，未答不追问。

### 1. 2.5 vs 2.0 投喂法则对照表

| 语法项 | Seedance 2.5 | Seedance 2.0 |
|---|---|---|
| 音效标记 | 官方声音字符（音效 `<>`、台词 `{}`、音乐 `()`、字幕 `【】`）；社区兼容 `[SFX: ...]` 亦可 | 无官方声音字符标记，音效以文字描述写入 `声音：` 栏、由模型生成 |
| Hit-Stop 顿挫 | 允许 Hit-Stop 三件套（微停顿+火花+震颤声） | **禁顿挫词**（顿挫/阻尼/弹开），打击感靠接触瞬间画面本身 |
| 运镜 | 单段可写复杂连续运镜与转场 | 每镜一条简单运镜，禁一镜多转折 |
| 单段时长 | 15s 单段高动态直出 | 单段直出，上限 15s（按剧情分配时长，不锁 10s） |
| 蓄力 | 可写压缩逆向收束蓄力 | 必须边打边蓄，禁静止蓄力段 |
| 参考图 | 双图首尾帧（Start/End Frame）+ 角色 4 View 资产板 | 单参考图绑定锁定形象，**无首尾帧** |
| 文戏 | 微表情生理递进 + 金句发酵可用 | 简化表演指令，逐拍分解须极简 |
| 参数行 | **不使用**（2026-09-15 废止末尾参数行：模型并入【画幅风格】行 `model=`，画幅/时长由 A/B 锁与镜行时长承载） | 同左 |
| 台词 | 台词走声音层 `{}` 字符，不写进口型 |
| **对白语气**<br>（官方对白三要素之三） | **必写**：`台词：【角色（语气）："…"】`——语气写在 `{}` 外的括号内（紧贴角色名）；**另可选投 `reference_audio` 素材做音色锁**（用途须标注"锁定音色"） | **同为必写**：`台词：【角色（语气）："…"】`（文字描述写进台词栏、由模型生成对白）；**2.0 无音频参考通道，只做语气、不做音色锁** | 台词文本写入台词栏锁口型节奏，由模型生成对白（默认视频内出）；仅用户明确指定"不出台词"才走后期配音 |
