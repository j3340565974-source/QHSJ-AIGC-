## 三、 投喂前自检清单 (Pre-Flight Checklist)

1. **时长与组数核对**：单组提示词必须标注目标时长（Seedance 2.5 推荐 12~15s、官方上限 30s；Seedance 2.0 上限 15s；即梦推荐 5~10s）；
2. **资产短锚点检验**：必须使用 `@CHR_name` 或 `[CHR-xxx]` 明确对应资产图，严禁无主代词（如“他/她/神秘人”）；同时按官方要求为每份参考素材标注用途（外貌/动作/音色/运镜）；
3. **字数门禁**：中文提示词 ≤500 字、英文 ≤1000 词（官方约束，超字模型丢细节）；
4. **真人脸红线（边界：禁的是真人照片素材，不是写实画风）**：角色/场景参考图严禁含**现实真人照片 / 真人脸图**（官方限制）；资产图一律由 AI/CG 生成（动漫、3D、写实渲染均可），**写实 / 仿真人风格不受影响**；
5. **任务互斥核对**：多模态参考生视频 / 首帧生视频 / 视频编辑三选一，不可混用；
6. **安全合规转译**：血腥、断肢等动作必须按 `../../quality-safety/qh-platform-safety-compliance-guide.md` 转译为“气浪震碎/光效消散/重创定格”，避免平台审核封禁。
7. **对白语气核对（官方三要素之三 · 2.0/2.5 同规格）**：有台词的镜行，`台词：` 字段必须写成 `【角色（语气）："…"】`——**不写语气会让声音与表情一并变扁平**（官方原文点名 `tone_qualifiers`）。**语气词只进语气位，禁写进画面段**（写进画面段会被当视觉信息渲染）；音色锁**仅 2.5 且为可选增强**，2.0 只做语气。见 §5.2、机检 C16。
8. **A 锁选 MiniMax H3 时另加**：模式路由与字段集、参考素材上限（图 ≤9 / 视频 ≤3 / 音频 ≤3 / 总 ≤12）、9 张取材策略、**语气位必须继承**（语气/音色写在 `<d>` 外）、**摆位必入画必须继承**（H3 无站位栏，摆了位的人每段至少给一个镜头或写明出画/退场）、**首镜锚定与单主体继承**（`[Shot 1]` 带一个具名主体、禁并列主体句式）、**禁令改法继承**（正文只写"有什么"）、H1~H12 机检——见 `../qh-h3-adapter.md` §三~§六。
