# 质量回归与失败诊断

## QG0 输入

- [ ] 用户硬约束完整
- [ ] 参考文件已读取
- [ ] 目标平台/媒介已确定或默认已声明

## QG1 叙事

- [ ] 每场有目标
- [ ] 有阻力
- [ ] 有变化
- [ ] 每章/每镜都推进至少一个状态
- [ ] 关键伏笔没有被无意提前泄露

## QG2 资产

- [ ] 角色身份稳定
- [ ] 服装稳定
- [ ] 发型稳定
- [ ] 道具稳定
- [ ] 场景稳定
- [ ] 音色稳定

## QG3 空间

- [ ] 锚点存在
- [ ] 轴线正确
- [ ] 视线匹配
- [ ] 距离连续
- [ ] 物体连续
- [ ] 摄像机可达
- [ ] 终帧可作为下一镜起帧

## QG4 表演/动作

- [ ] 情绪有触发
- [ ] 动作有阶段
- [ ] 幅度合理
- [ ] 没有无动机高强度动作

## QG5 物理

- [ ] 重力
- [ ] 接触
- [ ] 惯性
- [ ] 反作用
- [ ] 光影方向
- [ ] 材质反馈

## QG6 Prompt

- [ ] 主体明确
- [ ] 动词具体
- [ ] 空间可见
- [ ] 相机可执行
- [ ] 时间匹配
- [ ] 模型语法兼容
- [ ] 没有无意义形容词堆积

## QG7 连续性

比较上一状态与下一状态，只允许明确的因果变化。

## QG8 交付

- [ ] 字数/时长
- [ ] 画幅
- [ ] 分辨率
- [ ] 平台
- [ ] 字幕/音频
- [ ] 输出格式

## 失败归因

```text
故事失败 → 回故事层
人物失败 → 回资产/角色层
空间失败 → 回空间护照
表演失败 → 回情绪/动作层
物理失败 → 回物理约束
Prompt 失败 → 回 IR 编译层
平台失败 → 回模型适配层
工具失败 → 回权限/接口层
```

## 最小修复原则

修复时只改造成问题的变量，保留已经通过 QA 的内容。
