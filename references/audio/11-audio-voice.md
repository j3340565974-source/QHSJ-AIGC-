# 配音、音效、声音设计与后期声音引擎

## 1. 声音三层

1. 环境声：空间存在
2. 动作声：物理动作
3. 人声/对白：叙事焦点

配乐作为第四层，除非用户要求，否则在分镜阶段不抢占动作与对白的核心信息。

## 3. 人声表演

对白提示写：

`人物 / 语速 / 停顿 / 重音 / 呼吸 / 语气 / 情绪目标 / 当前正在压制什么`

## 4. 音效

音效写成：

`声源 + 位置 + 材质 + 距离 + 是否画内 + 动态 + 尾响`

例：

`画内近距离皮鞋踩过湿瓷砖，脚步清晰，水花短促，走廊尾端有轻微混响。`

## 5. 声音先行

J-cut/L-cut、画外声、声音遮挡、静默都可作为叙事工具。

## 6. 混音

最终混音时根据目标平台/交付标准核验响度、峰值、动态和声道，而不是机械写一个永久 LUFS 数字。

## 7. 原生音频模型

模型具备原生音频时，分别编译：

`对白 / 环境 / SFX / 音乐`

并检查声音是否与画面内动作发生时间一致。
