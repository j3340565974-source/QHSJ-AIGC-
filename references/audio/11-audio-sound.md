# 11 - 声音与音频系统

## 一、声音设计原则

任何声音都必须标记：
```
声源位置 → 是否画内 → 距离 → 声学环境 → 焦点 → 动态 → 混音层
```

不要只写"有背景音乐"。要写清楚：音乐从哪来？音量多大？什么情绪？什么节奏？

## 二、声音分层

| 层级 | 内容 | 特点 |
|---|---|---|
| **环境音** | 风声、雨声、车流、人群嘈杂、底噪 | 持续、低音量、建立空间感 |
| **动效音** | 脚步声、开门声、物体碰撞、衣服摩擦 | 配合画面动作，精准同步 |
| **音效** | 爆炸、魔法、科幻、夸张效果 | 强化戏剧效果，可夸张 |
| **配音/对白** | 角色说话、旁白、内心独白 | 核心叙事载体 |
| **配乐** | 背景音乐、主题旋律 | 情绪引导，烘托氛围 |

## 三、音色锁定

角色配音需要锁定音色特征：
- 性别、年龄
- 音色特质（低沉/清亮/沙哑/温润/尖锐）
- 语速快慢
- 口音/方言
- 情绪基调
- 说话习惯

## 四、VO/OS 编织

- **VO（画外音/旁白）**：声音在画外，人不在画面里。用来讲述、回忆、内心独白。
- **OS（画内音）**：人在画面里，只是声音从 off-screen 来。比如人走出画面但还在说话。

区分清楚，观众才不会混乱。

## 五、声音与画面同步

关键动作必须有对应音效：
- 挥拳 → 风声/命中声
- 走路 → 脚步声（配合地面材质）
- 关门 → 关门声
- 下雨 → 雨声（配合雨的大小）

**口型同步**：对白必须和人物口型对得上。

## 六、静音也是声音

重要的时刻，突然安静下来——这比任何音效都有力量。

```
爆炸 → 一切声音消失 → 慢动作 → 慢慢恢复声音
```

这种"声音的骤停"是非常高级的导演手法。
