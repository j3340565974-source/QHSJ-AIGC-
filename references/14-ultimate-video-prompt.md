# 14 - 终极视频提示词标准

## 一、什么是终极视频提示词

终极视频提示词是从分镜表 + 资产图 + 空间推演 + 表演设计 + 风格锚点全部整合后，输出给AI视频模型的**完整、可直接投喂、不跑偏**的最终版本。

不是零散的关键词堆砌，而是经过系统编译、锁定、质检的专业级投喂包。

## 二、必含要素清单

一个合格的终极视频提示词，必须包含以下全部要素：

### 🔒 锚点层（全局锁定）
- ✅ **角色锚点**：每个角色的外观、服装、标志性特征的完整锁定描述
- ✅ **资产锚点**：场景、道具、关键视觉元素的引用和状态
- ✅ **风格锚点**：整体风格、色调、画质、参考导演/影片
- ✅ **音色锁定**：配音角色的音色、语速、情绪基调（如有声音输出）

### ⏱️ 时间层
- ✅ **秒数轴**：精确到秒的时间轴，标注每一段发生什么
- ✅ **总时长**：明确视频总时长

### 🎥 镜头层
- ✅ **分镜景别**：每个时间点的景别（大远景/全景/中景/近景/特写等）
- ✅ **摄影机机位**：高度、角度、与主体距离
- ✅ **运镜轨迹**：推/拉/摇/移/跟/环绕的具体路线和速度
- ✅ **景别变化**：一镜内景别如何变化

### 👤 人物层
- ✅ **人物距离站位**：角色间相对位置、朝向、前后景关系
- ✅ **人物动作**：主动作 + 并行动作 + 动作起承收
- ✅ **人物行动轨迹**：从A点到B点的路径、速度、节奏
- ✅ **人物表情情绪**：微表情、情绪外化可见证据

### 🌍 环境层
- ✅ **空间锚点**：场景关键元素的位置和状态
- ✅ **环境变化**：天气、光线、人群、物体状态的时间变化
- ✅ **场景环境锚点**：固定参照物，确保空间一致性

### 🎬 技术层
- ✅ **画幅比例**：16:9 / 9:16 / 21:9 等
- ✅ **帧率/速度**：正常/慢动作/升格/降格
- ✅ **光线色彩**：主光方向、色温、整体色调
- ✅ **负向约束**：防跑偏、防崩坏的锁定句

## 三、七段式投喂结构（标准格式）

```
【第一段：全局锁定】
[画幅] + [总时长] + [整体风格] + [画质基底] + [色彩基调]

【第二段：角色锚点前置】
角色A：[外观完整描述+服装+标志特征]
角色B：[外观完整描述+服装+标志特征]
...

【第三段：场景资产前置】
场景：[场景完整描述+关键道具+空间结构]

【第四段：秒数轴逐镜描述】
0-2s：[景别]+[机位]+[运镜]+[人物动作]+[环境]+[光线]
2-5s：[景别]+[机位]+[运镜]+[人物动作]+[环境]+[光线]
5-8s：...
...

【第五段：空间与站位声明】
轴线方向：[左右轴线]
角色站位：A在X位置，B在Y位置，间距Z
移动路径：...

【第六段：声音设计（如支持）】
配音：[音色+情绪+台词]
音效：[关键音效+声源位置]
配乐：[风格+情绪+节奏]

【第七段：负向约束/防跑偏】
[正向锁定句形式的约束，如"镜头必须保持...""人物面部特征保持..."]
```

## 四、段缝衔接规则

跨段（不同镜头片段）衔接时必须注意：

1. **终帧=起帧**：上一段最后一帧的状态 = 下一段第一帧的状态
2. **位置连续**：人物站位不能突然跳变
3. **方向连续**：人物朝向、视线方向不能180度反转（除非有明确转身动作）
4. **光线连续**：光源方向不能突然变
5. **服装道具连续**：手里拿的东西不能突然消失/出现

## 五、质量自检清单

投喂前逐项检查：

- ☐ 每个镜头是否只有一个主动作？（太多会乱）
- ☐ 人物位置是否符合空间推演？
- ☐ 运镜是否单一明确？（不要一个镜头里又推又摇又环绕）
- ☐ 动作是否有起承收？（不要只有动作没有开始和结束）
- ☐ 是否有明确的焦点主体？（不要让AI猜谁是主角）
- ☐ 环境描述是否足够具体？（不要只写"室内"）
- ☐ 光线方向是否明确？（左/右/前/后/顶）
- ☐ 情绪是否外化为可见动作？（不要只写"他很伤心"）
- ☐ 段缝是否衔接？
- ☐ 是否有防跑偏锁定？

## 六、不同模型适配要点

| 模型 | 特别注意 |
|---|---|
| **Seedance 2.5** | 七段式结构，A锁（模型版本）+B锁（画幅）前置，首尾帧差异描述 |
| **即梦** | 中文描述优先，自然语言句式，少用英文关键词堆砌 |
| **MiniMax H3** | 特定格式要求，按H3适配器规则调整 |
| **Runway** | I2V优先描述运动，T2V按官方推荐顺序 |
| **Sora** | 长描述优先，强调物理一致性和时间连续性 |
| **Kling** | 中文友好，强调主体一致性 |

> 具体模型参数必须联网核实最新版本，不凭旧记忆写死。
