## 一、三条铁律

1. **无沙盘不输出**：任何涉及空间/人物运动/多镜头的任务，必须先完成沙盘推演
2. **每秒快照**：人物行动、镜头运动、道具位置按秒（或更细粒度）模拟快照
3. **漏洞零容忍**：推演中发现的空间矛盾必须在推演阶段修复，不能留给用户试错

## 二、维度1：场景空间沙盘构建

每个场景必须明确：

| 要素 | 说明 | 示例 |
|------|------|------|
| 场景尺寸 | 长×宽×高，估算实际物理尺寸 | 宿舍：4m×3m×2.8m |
| 固定物体坐标 | 墙/门/窗/家具位置 | 门在画面左侧(X=0)，床在右侧(X=3m) |
| 空间锚点 | 1-2个固定参考点 | 主锚点=床左上角，副锚点=门中心 |
| 四层纵深 | 前景/中景/背景/远景 | 前景=床沿，中景=床铺过道，背景=门窗，远景=窗外 |
| 可行走区域 | 人物可移动范围 | 过道区域，床上不可行走 |

## 三、维度2：人物行动轨迹模拟（每秒快照法）

为每个人物建立完整行动轨迹，按秒模拟位置快照。

**必须模拟**：起始坐标 / 移动路径 / 终点坐标 / 朝向变化 / 速度变化 / 手持道具 / 与他人相对位置 / 取景范围校验。

### 追逃场景特殊校验

```
追者：起始=画面后方(远处)，面朝画面前方，从后向前追
逃者：起始=画面前方(近处)，面朝画面前方，背离追者逃跑
✅ 追者在逃者后方
✅ 逃者面朝画面前方（背离追者方向）
✅ 逃者露出背部/后脑勺（不是正面）
✅ 两人距离逐渐缩小
❌ 禁止：逃者面朝画面后方（朝追者跑）
❌ 禁止：逃者露出正脸（朝追者跑）
```

## 四、维度3：道具位置追踪表

每个关键道具建立位置追踪表，确保跨分镜不丢失、不瞬移。

**跨场景隔离铁则**：
- 每个道具必须明确标注"所属场景"
- 不属于该场景的道具，在该场景提示词中**完全不提及**
- 在负面提示词中明确排除："校园场景禁止出现古镜、罗盘、蜡烛、符咒本"
- 最安全做法：不同场景拆分成独立的视频生成请求

## 五、维度4：镜头运动模拟

为每个镜头建立机位运动轨迹，模拟取景范围变化。

**必须模拟**：机位起始坐标 / 运动路径 / 机位终点坐标 / 焦距/景别变化 / 俯仰角度变化 / 运动速度 / 取景范围校验 / 与人物相对关系。

## 六、维度5：光影连续性推演

为每个分镜建立光源状态，确保跨分镜光影方向/色温/强度一致。

每个镜头记录：
- 主光源：光源类型+方向+色温+强度
- 补光：有无+方向+强度
- 阴影：方向+软硬
- 校验：与上一镜头是否跳变

## 七、七维度总览

| 维度 | 模拟什么 | 输出什么 |
|------|----------|----------|
| 1 场景空间 | 三维空间模型 | 场景沙盘坐标图 |
| 2 人物轨迹 | 每秒位置快照 | 人物行动轨迹表 |
| 3 道具追踪 | 跨镜头道具位置 | 道具位置追踪表 |
| 4 镜头运动 | 机位轨迹模拟 | 镜头运动快照表 |
| 5 光影连续 | 光源状态推演 | 光影连续性表 |
| 6 轴线方向 | 180°轴线锁定 | 越轴检查表 |
| 7 取景范围 | 每秒人物是否在画内 | 出画校验表 |
