# 空间推演引擎（第二优先级）

> 来源：QHSJ AIGC 全能影视 + 空间一致性系统
> 每次输出前必跑，图片/视频/小说/剧本全覆盖。
> 空间铁律：无沙盘不输出。

---

## 1. 空间铁律

1. 所有"左／右"默认指画面视角（观众看到的左／右），人物自身左右必须标注"自身"
2. 每个场景必须先设定空间锚点，所有位置相对锚点描述
3. 移动动作必须五要素闭环：起点 → 路径 → 终点 → 朝向变化 → 速度
4. 分镜间必须传递空间状态
5. 对话场景必须执行180度轴线

---

## 2. 十六步空间推演工作流

```
第1步：接收输入（白话/剧本/参考片/参考图/参数）
第2步：解析补全（题材/类型/风格/媒介/时长/画幅/受众/主题/禁忌，缺失用默认补）
第3步：导演思维（QHSJ永久底层 + QHSJ导演插件按需调用）
第4步：全局空间模型
第5步：物体布局图
第6步：距离表
第7步：角色锚点表
第8步：三维坐标推演
第9步：空间表
第10步：空间图
第11步：沙盘推演
第12步：轴线锁定
第13步：前后镜衔接
第14步：终帧锁死
第15步：转译成AI画面语言（禁用坐标术语，改用画面可见语言）
第16步：模型适配 → 双区输出 → 自动校验 → 自动修正矛盾 → 质量回归
```

## 3. 空间沙盘模拟推演

### 3.1 沙盘构建

- **场景空间沙盘构建**：先搭整体空间结构
- **人物行动轨迹每秒快照**：逐秒推演人物位置
- **道具位置追踪表**：所有道具位置精确记录
- **镜头运动模拟**：预演每个镜头的运动轨迹
- **光影连续性推演**：确保光线方向一致
- **分镜衔接推演**：检查相邻镜头的空间连续性
- **生成可行性预判**：预判哪些空间关系AI可能无法生成

### 3.2 站位锚点图体系

**双锚点体系**：
- 人物连续性靠角色参考图
- 空间连续性靠俯视站位锚点图

每个场景生成一张俯视站位锚点图：
- 给每个人物绑定字母编号A/B/C/D
- 每个分镜提示词开头重复"字母-角色对应表"+"空间锚点位置描述"

## 4. 空间构建器

### 4.1 九宫格+四层纵深

**九宫格定位**：把画面分成3×3网格，每个元素都有明确位置

**四层纵深**：
1. 前景层
2. 中景层
3. 远景层
4. 背景层

### 4.2 空间锚点

- **主锚点**：场景中最核心的参照物
- **副锚点**：辅助定位的参照物
- **光源锚点**：光线方向和位置

### 4.3 人物站位模式

**双人站位（8种）**：
- 面对面
- 并排
- 一前一后
- 左右对峙
- 对角站位
- 靠近/远离
- 高低位
- 环绕

**三人站位（5种）**：
- 三角对峙
- 中心包围
- 一排站开
- 前后层次
- 主次分明

**群像站位（5种）**：
- 对称排列
- 中心聚焦
- 散点分布
- 分层排列
- 动态组合

## 5. 180度轴线系统

### 5.1 基本规则

- 对话场景必须建立并遵守180度轴线
- 轴线一旦确定，所有机位都在轴线同一侧
- 越轴会导致观众空间认知混乱

### 5.2 轴线建立方法

1. 确定对话的两个人物
2. 画一条连接两人的虚拟线
3. 所有机位都在这条线的同一侧
4. 反打镜头保持在同一侧

### 5.3 越轴处理

- 用中性镜头过渡
- 用运动镜头越过轴线
- 用插入镜头打断
- 明确告知观众空间变化

## 10. 空间错误专项排查（12项）

1. 人物左右方向是否一致
2. 物体位置是否跨镜一致
3. 光源方向是否统一
4. 轴线是否被打破
5. 人物站位是否连续
6. 道具位置是否瞬移
7. 视线方向是否匹配
8. 景深是否合理
9. 透视是否正确
10. 人物比例是否一致
11. 场景元素是否遗漏
12. 运动方向是否连贯

## 11. Asset-First资产前置管线

### 11.1 为什么资产先行

AI生成最容易出问题的就是角色变脸、场景不一致、道具瞬移。解决方案：先做资产，再做分镜，最后做提示词。

### 11.2 六阶段流水线

```
第1阶段：剧本确认
第2阶段：资产提取（角色/场景/道具）
第3阶段：分镜设计
第4阶段：沙盘推演
第5阶段：提示词生成
第6阶段：质量检查
```

### 11.3 角色资产标准

**四视图角色设定**：
- 正面大头特写
- 全身正面
- 全身侧面
- 全身背面

**角色一致性五要素锁定**：
1. 面部特征
2. 发型发色
3. 服装
4. 体型
5. 标志性配饰

## 12. 质量门禁（QG0~QG8）

| 门禁 | 检查内容 | 失败处理 |
|---|---|---|
| QG0 | 意图完整性：用户需求是否被完整理解 | 回问用户澄清 |
| QG1 | 叙事一致性：人物/情节/世界观是否自洽 | 修正叙事逻辑 |
| QG2 | 空间一致性：轴线/站位/机位是否正确 | 重新推演空间 |
| QG3 | 资产一致性：角色/场景/道具是否跨镜一致 | 锚点校验修正 |
| QG4 | 表演一致性：情绪/动作是否符合逻辑 | 调整表演设计 |
| QG5 | 提示词可执行性：参数是否在模型能力范围内 | 降级或转写 |
| QG6 | 段缝衔接：多段之间是否连贯 | 调整过渡设计 |
| QG7 | 风格一致性：全片风格是否统一 | 统一风格锚点 |
| QG8 | 原创性安全：是否有抄袭/合规风险 | 原创化处理 |
