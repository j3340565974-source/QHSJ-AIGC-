三、打斗提示词生成方法论
3.1 打斗逻辑五回合模型
每个打斗场景必须遵循以下逻辑循环，禁止无逻辑的单方面碾压：
    1. 试探回合（real time）：双方走位、观察、假动作，建立空间关系
    2. 交锋回合（fast motion）：首次正式交手，攻击 - 格挡 - 反击的完整链条
    3. 升级回合（fast→slow）：节奏加快，组合技增多，关键打击用 slow motion
    4. 高潮回合（slow motion）：决定性一击 / 武器碎裂 / 特殊能力爆发
    5. 收势回合（real time）：胜负已分，双方状态变化，余韵
3.2 武器攻击距离逻辑
    • 长兵器（枪 / 矛 / 戟）：攻击距离 2-3 米，必须有突刺 / 横扫 / 挑击的轨迹
    • 中兵器（刀 / 剑 / 棍）：攻击距离 1-1.5 米，必须有劈 / 砍 / 刺 / 格挡
    • 短兵器（匕首 / 短刀 / 指虎）：攻击距离 0.5 米以内，必须有近身 / 缠斗 / 快速刺击
    • 软兵器（鞭 / 链 / 绳）：攻击距离 1-3 米可变，必须有缠绕 / 甩击 / 回收动作
    • 远程武器（弓 / 弩 / 枪）：攻击距离 5 米以上，必须有瞄准 / 发射 / 弹道 / 命中
3.3 多人打斗空间逻辑
    • 2 人：180 度轴线，攻击方 - 防守方在轴线两侧
    • 3 人：三角站位，一人主攻，两人侧翼
    • 4-6 人：扇形包围，主角在中心，敌人从多方向攻击
    • 7 人以上：群战，主角移动路线必须清晰，敌人分批攻击，禁止所有人同时出招
3.4 打斗防崩坏检查清单
生成打斗提示词后必须逐项检查：
    •  节奏切换：是否包含 slow/fast/real 三种节奏？
    •  动作逻辑：每个攻击是否有对应的防守 / 反应？
    •  武器距离：武器攻击距离是否合理？
    •  空间一致：人物位置 / 朝向在动作中是否连续？
    •  物理合理：动作是否符合重力 / 惯性 / 碰撞规律？
    •  表情层次：打斗中是否有微表情变化（咬牙 / 皱眉 / 眼神锐利）？
    •  环境互动：打斗是否与场景元素互动（撞墙 / 碎物 / 利用地形）？
    •  违禁词：是否已通过安全替代检查？
    •  单镜单动作：每个 AI 视频请求是否只包含一个连续场景？
    •  时长控制：单片段是否在 5-15 秒范围内？

    • ✅ AI 可直接生成：在提示词中描述即可，AI 视频模型能理解并生成
