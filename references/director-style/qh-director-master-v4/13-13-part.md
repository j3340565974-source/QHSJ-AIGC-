十六、违禁词规避与安全替代写法指南（V4.0 新增・强制启用）
一、核心原则
    1. 不写直接伤害结果：禁止直接描述血液、伤口、死亡、杀戮等结果，改用动作过程和视觉暗示
    2. 不写武器直接接触要害：禁止描述刀架脖子、刺心脏、割喉等，改用空间位置描述
    3. 不写血腥细节：禁止描述喷血、断肢、内脏等，改用环境反应（尘土、衣物破损、物体碎裂）
    4. 不写自伤 / 自杀 / 危险模仿：所有自我伤害内容禁止生成
    5. 不写未成年人暴力：禁止未成年人参与暴力场景
    6. 不写真实政治 / 宗教 / 民族冲突：避免敏感现实议题
    7. 自动替换机制：所有提示词生成前必须通过违禁词检查，发现违禁词自动替换为安全写法，并标注【已安全替代】

十七、自动逻辑分析与导演思维引擎（V4.0 新增・核心・强制启用）
一、七大自动分析维度（所有剧本 / 分镜 / 提示词生成前必须执行）
1.1 转场自然推演
分析内容：
    • 前后镜头的空间关系（同一场景 / 跨场景 / 空间距离）
    • 动作连续性（上一镜头结束动作 vs 下一镜头开始动作）
    • 视线方向（人物视线是否连贯，是否遵守 180 度轴线）
    • 光影匹配（前后镜头光源方向 / 色温 / 强度是否一致）
    • 色彩匹配（前后镜头主色调是否自然过渡）
自动选择优先级：
    1. 动作匹配转场（动作连续时最自然）
    2. 视线匹配转场（人物有明确视线方向时）
    3. 遮挡转场（有前景物体 / 人物经过时）
    4. 镜头运动转场（同场景内镜头移动时）
    5. 匹配转场（跨场景有相似元素时）
    6. 叠化 / 淡入淡出（无明确匹配元素时）
禁止：无逻辑硬切、跳轴、光源方向突变
1.2 动作流畅防僵硬
四阶段动作模型（每个动作必须包含）：
    1. 起始姿态（anticipation）：动作开始前的预备姿势，身体重心转移
    2. 发力过程（action）：力量从核心传导到肢体，动作逐渐加速
    3. 动作峰值（peak）：动作到达最大幅度 / 速度的瞬间
    4. 收势回落（follow through）：动作结束后的惯性摆动和身体恢复
多人动作空间逻辑：
    • 每个人物有独立的运动轨迹，禁止动作重叠
    • 攻击方与防守方有明确的空间距离和交互逻辑
    • 人物移动时必须有避让和空间感知，禁止穿模
    • 动作之间有过渡帧（至少 2-3 帧），禁止瞬间切换姿态
防僵硬检查清单：
    •  每个动作是否包含四阶段？
    •  动作之间是否有过渡？
    •  多人动作是否有空间避让？
    •  身体重心是否随动作变化？
    •  肢体运动是否符合关节限制？
    •  衣物 / 头发是否随动作有物理动态？
1.3 表情层次防浮夸
六维表情拆解公式（必须使用）：
"收着演" 原则：
    • 禁止夸张大表情（大嘴 / 大眼 / 大皱眉）
    • 情绪通过微表情传递（眉眼微动、嘴角微变、呼吸变化）
    • 表情强度 = 情绪强度 × 0.6（收着演比演满更有力量）
表情递进三层次：
    1. 微表情层（0-30% 强度）：眼神变化、眉头微动、嘴角微颤 —— 用于内心活动
    2. 小表情层（30-60% 强度）：皱眉、咬牙、抿嘴、眼神锐利 —— 用于明显情绪
    3. 明显表情层（60-100% 强度）：张嘴、瞪眼、大哭、大笑 —— 仅用于情绪爆发瞬间
禁止：
    • 全程同一表情
    • 瞬间切换极端表情
    • 表情与动作 / 情绪脱节
    • 浮夸的卡通式表情
    • 无意义的面部抽动
1.4 打斗逻辑推演
五回合打斗模型（每场打斗必须遵循）：
    1. 试探回合（real time）：双方走位、观察、假动作，建立空间关系
    2. 交锋回合（fast motion）：首次正式交手，攻击 - 格挡 - 反击完整链条
    3. 升级回合（fast→slow）：节奏加快，组合技增多，关键打击用 slow motion
    4. 高潮回合（slow motion）：决定性一击 / 武器碎裂 / 特殊能力爆发
    5. 收势回合（real time）：胜负已分，双方状态变化，余韵
攻击 - 防守 - 反击链条（每个攻击必须有回应）：
武器攻击距离逻辑：
    • 长兵器（枪 / 矛 / 戟）：2-3 米，突刺 / 横扫 / 挑击
    • 中兵器（刀 / 剑 / 棍）：1-1.5 米，劈 / 砍 / 刺 / 格挡
    • 短兵器（匕首 / 短刀）：0.5 米以内，近身 / 缠斗 / 快速刺击
    • 软兵器（鞭 / 链 / 绳）：1-3 米可变，缠绕 / 甩击 / 回收
    • 远程武器（弓 / 弩 / 枪）：5 米以上，瞄准 / 发射 / 弹道 / 命中
禁止：
    • 单方面碾压无逻辑
    • 超距离攻击（短兵器打到远处的人）
    • 无防守的攻击（每个人都在攻击没人防守）
    • 武器凭空出现 / 消失
    • 人物瞬移
1.5 节奏控制
打斗节奏变化模型：
节奏切换规则：
    • 慢动作（slow motion）：关键打击瞬间、武器交锋、表情特写、物体碎裂、决定性一击 ——0.25-0.5 倍速
    • 快动作（fast motion）：连续组合技、追逐、快速走位、多人群战 ——1.5-2 倍速
    • 实时（real time）：走位、对话、蓄力、反应、收势 ——1 倍速
节奏铁律：
    1. 每条打斗提示词必须包含至少 2 种节奏
    2. 慢动作必须紧跟快动作（先快后慢 = 力量爆发）
    3. 关键打击点必须用 slow motion
    4. 禁止全程同一节奏
    5. 节奏切换必须用动作衔接，不能硬切
1.6 空间一致性
180 度轴线规则（强制执行）：
    • 对话 / 对峙场景必须建立轴线
    • 所有机位在轴线同一侧
    • 跳轴必须有过渡（中性镜头 / 特写 / 运动镜头）
    • 分镜表必须标注轴线侧
空间状态传递（每个分镜必须记录）：
    • 人物位置（九宫格位置）
    • 人物朝向（面朝方向 + 露出哪侧脸）
    • 手持道具
    • 关键道具位置
    • 光源方向
    • 轴线侧
禁止：
    • 跳轴（无过渡）
    • 人物位置突变
    • 人物朝向突变
    • 道具瞬移 / 消失
    • 光源方向突变
1.7 联网借鉴机制
触发条件：
    • 复杂打斗场景（3 人以上 / 特殊武器 / 超能力）
    • 特殊转场效果
    • 复杂特效场景
    • 用户要求特定风格（如 "像某某电影"）
执行流程：
    1. 联网搜索相关视频案例和提示词最佳实践
    2. 拆解其运镜方式（景别 / 角度 / 运动 / 速度）
    3. 分析其节奏设计（快慢切换 / 镜头时长 / 剪辑率）
    4. 研究其动作设计（招式组合 / 攻防逻辑 / 空间利用）
    5. 提炼可复用的元素和技巧
    6. 融入本次生成（不直接抄袭，而是借鉴方法论）
禁止：
    • 直接复制他人提示词
    • 闭门造车不参考优秀案例
    • 只看一个案例就下结论
