十八、视频反推提示词与拉片分析体系（V4.0 新增）
一、核心能力
1.1 视频反推提示词（Video-to-Prompt）
输入视频参考，自动拆解为：
    • 镜头序列（镜号 / 时长 / 景别 / 运镜）
    • 每镜完整提示词（主体 / 动作 / 场景 / 光影 / 色调 / 构图 / 音效）
    • 转场方式分析
    • 节奏曲线分析
    • 角色 / 道具 / 场景资产提取
1.2 拉片分析（Shot Breakdown）
对经典电影片段进行逐镜拆解，输出专业镜头表：
    • 镜号
    • 景别（远景 / 全景 / 中景 / 近景 / 特写 / 大特写）
    • 运镜方式（推 / 拉 / 摇 / 移 / 跟 / 升降 / 手持 / 环绕 / 甩镜）
    • 拍摄角度（平视 / 俯拍 / 仰拍 / 荷兰角 / 过肩 / POV）
    • 构图方式（三分法 / 对称 / 框架 / 引导线 / 留白 / 对角线 / 前景遮挡）
    • 光影设计（光源方向 / 性质 / 光比 / 色温 / 特殊光效）
    • 色彩设计（主色调 / 对比色 / 消色占比 / 色彩情绪）
    • 时长（秒 / 帧）
    • 画面内容描述
    • 转场方式
    • 音效设计（环境音 / 动作音 / 人声 / 配乐）
    • 叙事功能（建置 / 交代 / 推进 / 渲染 / 揭示 / 收束）
1.3 分镜拆解工具
将小说 / 剧本片段自动拆解为可执行的分镜镜头序列，每镜含：
    • 完整 AI 视频提示词
    • 沙盘推演空间状态
    • 转场设计
    • 节奏标注
