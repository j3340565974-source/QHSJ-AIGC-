### 如果画面太现代

```text
避免现代极简公寓、现代办公楼、LED 屏幕、智能手机、现代汽车、现代运动鞋、玻璃幕墙、冷白商业灯
```

### 如果画面太阴暗或恐怖

```text
避免恐怖片打光、血腥、惊悚、阴森废墟、脏污破败、强烈暗角、冷绿病态光、怪物化人物
```

### 如果画面有 AI 塑料感

```text
避免蜡像皮肤、塑料表面、过度锐化、HDR 过强、虚假胶片颗粒、质感糊成一团、手部错误、面部不自然、背景文字乱码
```

# Prompt Formula

## 固定输出格式

每次输出必须使用：

```markdown
画面标题：

色彩方案：
人物与动作：
场景与道具：

反向限制：

```

## 生成公式

把用户短句扩展为：

```text
[主体] + [半进行中的小动作/情绪] + [有变化的静止电影镜头] + [结构化构图方式] + [中轴可由布景暗示但不画实体线] + [舞台式布景] + [具体时代质感] + [道具排列] + [明亮不发灰的复古配色] + [胶片与光线] + [反向限制]
```

默认公式优先写成：

```text
[主体] + 正面平视静止电影镜头 + 严格中央对称/左右平衡 + 相机水平 + 地平线水平 + 垂直结构保持垂直 + 中轴由左右布景暗示、不画实体中线 + 舞台式布景 + 成对/成排/网格化道具 + 明亮不发灰的复古配色 + 真实摄影质感 + 不要斜拍/荷兰角/歪地平线
```
