# 08 - 多模型适配层

## 一、运行时优先级

```
用户指定模型和版本 > 当前官方文档 > 可信实测/社区资料 > 旧知识库
```

**重要**：当前模型能力、平台额度、语法、参数、接口经常变化，凡是"最新/当前/官方/底层参数/平台限制"必须联网核实，不得把旧参数当永久真理。

动态数据项必须附：日期、来源、置信度。旧知识只能作为候选，不得覆盖新官方资料。

## 二、Seedance 深度适配

### 前置锁
进入短剧视频生产前，必须先完成：
- **A·模型版本**：Seedance 2.5 / Seedance 2.0 二选一
- **B·画幅**：16:9 / 9:16 / 21:9 三选一

用户未指定 = 任务不开始，停下询问，禁止默认跳版本或默认画幅。

### 投喂顺序（官方推荐）
格式 → 主体 → 动作 → 环境 → 摄影机 → 视觉 → 时间 → 音频/约束

### 七段式投喂结构
详见 `14-ultimate-video-prompt.md`

## 三、即梦适配

- 中文描述优先
- 自然语言句式，少用英文关键词堆砌
- 强调画面感和可执行性
- 负向词尽量转写成正向锁定句

## 四、Midjourney 适配

- Style Reference 用于传递整体视觉感觉，不是复制对象
- 提示词描述新内容本身，避免与参考风格冲突
- 用 `--ar` 指定画幅，`--style` 指定风格强度

## 五、Stable Diffusion / Flux 适配

- 支持负向提示词
- 支持详细的质量标签（masterpiece, best quality, ultra-detailed等）
- 支持ControlNet等控制工具
- 提示词结构：质量标签 → 主体 → 场景 → 风格 → 画质参数

## 六、Veo 适配

- 优先把角色/场景参考与连续性状态写进输入角色
- 支持音频、镜头控制、延长片段
- 强调物理一致性和时间连续性

## 七、Runway 适配

- I2V 优先描述"要发生的运动"，输入图已经承担构图和外观信息
- T2V 按官方推荐顺序组织
- 注意时长限制和运动强度控制

## 八、Kling（可灵）适配

- 中文友好
- 强调主体一致性
- 注意动作幅度和物理合理性

## 九、负向词转写规则

如果平台不支持负向提示词，把负向约束改写成正向锁定句：

| 负向写法 | 正向锁定句写法 |
|---|---|
| 不要换角度 | 镜头必须保持正面偏右15度、胸口高度、2.5米距离、中景构图 |
| 不要变脸 | 人物面部特征保持一致，五官比例不变 |
| 不要多余的手 | 人物双手自然放在身体两侧，五指清晰正常 |
| 不要文字 | 画面中不出现任何文字、字母、符号、水印 |
| 不要模糊 | 焦点清晰落在主体面部，细节锐利 |
