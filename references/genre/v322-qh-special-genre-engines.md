## 一、巨物专项引擎

### 触发条件
输入包含：宏大/巨物/巨型/庞然大物/奇观/史诗/神明降临/巨兽/巨构/超大尺度/压迫感。必须同时命中巨物词+尺度反差词。

### 逻辑矛盾自动修正

| 矛盾类型 | 冲突表现 | 自动修正 |
|----------|----------|----------|
| 画幅冲突 | 9:16竖屏+巨物全貌 | 改"极致仰拍+局部特写"，以局部压迫感替代全貌 |
| 比例冲突 | 要2.35:1但模型只支持16:9 | 输出16:9，标注"建议后期裁切为2.35:1" |
| 尺度冲突 | 巨物远超镜头视野 | 增加"大气透视、体积雾、地平线遮挡"暗示尺度 |
| 质感冲突 | 画面发灰、塑料感 | 强制注入"PBR微表面、粗糙度贴图、经纬编织、SSS"，负向锁"平滑布料、纯色贴图" |
| 光影冲突 | 巨物自带能量+自然光 | 切换为"巨物能量为主光，环境光辅助"，极高反差8:1 |

### 打斗强度分级
```
破坏层级：柱子 < 墙体 < 楼板 < 楼层 < 整楼 < 城市
能量等级：微光 < 电弧 < 爆闪 < 全屏 < 黑白闪
情绪等级：冷静 < 冷笑 < 嘲讽 < 杀意 < 狂暴 < 绝望
节奏等级：常速 < 快切 < 高速 < 极速 < 急停 < 慢镜 < 定格
```

### 燃点公式
```
燃 = 因果闭环 ×（冲突升级 + 节奏张弛 + 冷暖对冲 + 空间破坏 + 角色反差 + 声音爆点）
```
因果为0，燃点为0。观众必须先知道"谁打谁、为什么打、打到什么程度"。

## 三、赛车与速度

### 六法则
1. 真实速度，不是CGI/后期加速
2. 细节即情绪
3. 每件作品一个主导视觉承诺
4. 节拍锁定剪辑
5. 冷战斗调色板
6. 每插入件承重

### 赛车12仪式
水箱入水 / 烧胎 / 倒车就位 / 预stage灯 / Stage灯 / 琥珀倒计时 / 绿发射 / 轮胎褶皱 / 换挡排气火焰 / 超车 / 终点 / 降落伞

### 5镜头家族
Hostess-tray侧面 / 保险杠低前POV / 硬装驾驶舱抖动 / 跟拍并行+对决 / 远景证明

### 冷战斗调色板
硬白 / 脏水银白 / 青色 / 电青 / 钢蓝 / 品红 / 冷紫 / 红(仅强调) / 绿(仅强调) / 毒琥珀(≤15%)。温暖即毒素是唯一允许的暖色。

### 防伪守卫
动作不要高上帝角度 / 不要完美稳定驾驶舱 / 无道路纹理速度面板不画 / 无"加速后好看"面板 / 速度不留空气 / 车轮不要锐利轮圈 / 无闪亮车身美容 / 仪式不乱序跳 / 无温暖舒适。

## 四、六种蒙太奇

| 类型 | 结构 |
|------|------|
| 升级 | 远景→中景→特写→微距→反应特写→冲击 |
| 焦虑 | 脸→物体→手→脸→更近物体→声音提示→突然静止 |
| 发现 | POV→空空间→搜索手→隐藏物→拉焦→情绪反应 |
| 灾难 | 期待→物不稳→反应→掉落→冲击→寂静→崩溃 |

**多片段拆分规则**：10s=2×5s / 15s=3×5s / 30s=6×5s / 60s=12×5s。每段必须重复：角色/服装/地点/视觉风格/镜头语言/光线逻辑/连续性/调色板。跨片段连续性：N+1首个节拍匹配N最后节拍。

## 五、动态分镜关键帧

### 面板四件事
1. 一个可读故事节拍
2. 一个功能标签
3. 一个情绪（不命名，通过物/光/解剖传递）
4. 一个暗示的运动（冻结物理残留）

### 密度阶梯

| 节拍 | 密度 | 面板数 |
|------|------|--------|
| 仪式/调度 | 1英雄面板 | 1个活1.5-2.5s |
| 压力爬升 | 升级单数 | 3个时长塌缩 |
| 发射/冲击 | 微爆发 | 6-9个8帧→4帧 |
| 竞赛 | 交替 | 碎片簇↔保持细节 |
| 余波/出口 | 1英雄面板 | 1-2个约2s |

### 静中有动6线索
方向运动模糊（背景拖尾主体锐）/ 冻结部分虚化（一元素虚锚点清晰）/ 条纹帧 / 姿态轨迹矢量（锁在只能向前解决的姿态）/ 锐主体虚场（浅景深微距）/ 定格静止（零模糊硬边屏息）
