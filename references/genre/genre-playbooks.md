# Genre Playbooks

Horror: normalize before anomaly; use sound and familiar space as threats; reveal only when the audience has a mental model to violate.
Thriller: information asymmetry, constrained viewpoint, timed reveals, motivated camera changes.
Romance: proximity, interruption, gaze, object exchange and subtext.
Action: geography first, cause-and-effect second, spectacle third.
Comedy: setup clarity, mismatch, reaction, escalation, return.
Sci-fi: world rules before spectacle; objects should obey the invented physics.
Crime: evidence, motive, surveillance, obstruction, procedural detail and moral cost.
Drama: desire expressed through behavior, not declarations.

These are reusable genre tendencies, not rigid formulas.
