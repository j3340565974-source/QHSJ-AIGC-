# Asset Package Engineering Specification

## ASSET-01 character

Required fields:
- stable_id
- human_label
- source_reference
- geometry_or_visual_identity
- material_profile
- scale_reference
- state_variants
- approved_views
- prohibited_drift
- generation_model
- prompt_template
- negative_constraints_if_supported
- checksum
- parent_asset_ids
- dependent_scene_ids
- approval_state
- last_verified

Dependency rule: child assets inherit immutable identity anchors from parents and may add variants only through explicit patches.

Character-specific: head shape, facial landmarks, hair mass, eye design, skin response, body proportion, silhouette, wardrobe signature, accessories, voice anchor and expression range.
Environment-specific: architectural topology, fixed landmarks, material zones, practical light sources, ambient field, sky/weather state, recurring dressing.
Prop-specific: silhouette, dimensions, material, wear, unique marks, hand affordances, interaction states.

Version rule: never overwrite an approved identity asset in place; create a new version and a migration map.
