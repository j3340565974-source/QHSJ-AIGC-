# QHSJ 资产前置、版本锁定与分镜资产引用协议

## 1. 本模块解决什么问题

本模块用于把“人物看起来像同一个人、场景始终是同一个空间、同一道具不会在镜头之间无故变形”从风格愿望改成可审计的生产约束。凡涉及角色设定图、场景设定图、道具设定图、四视图、关键帧、分镜资产、多镜头视频提示词、角色一致性和空间连续性，必须按本协议建立资产台账，再进入下游生成。不能先生成一堆互不关联的分镜图，之后才尝试把角色和场景拼成统一项目。

## 2. 核心术语和状态

- **资产规格（Asset Spec）**：生成前锁定的文字事实，包括身份、外形、材质、比例、结构、色彩、状态、空间关系和禁止变化项。
- **资产图像（Asset Image）**：根据规格生成或由用户提供的角色/场景/道具参考图像。
- **规范资产（Canonical Asset）**：经核验后指定为后续引用基准的唯一版本。
- **资产锁（Asset Lock）**：标记哪些字段不可自行改变，并记录批准来源、版本号、检查结果和引用位置。
- **分镜资产（Shot Asset）**：以规范角色资产与规范场景资产为输入构建的单镜或多镜图像，不是重新随机创造角色和场景。

统一资产生命周期状态只允许使用：`draft`（草稿）、`review`（待核验）、`locked`（已锁定）、`locked_provisional`（自动核验通过但未获用户确认的暂定锁）、`superseded`（被新版本替代）、`blocked`（缺少必要输入）、`needs_recheck`（依赖变更后必须重新核验）。`locked_provisional` 不是用户批准的同义词；`needs_recheck` 表示原验证已失效，不得继续当作当前有效锁。`locked` 不能因下游生成方便而被悄悄改写；改动时必须建立新版本并记录差异。

## 3. 生产顺序与硬门禁

### A0：需求与 Canon 盘点

提取用户要求的成品类型、角色人数、场景数量、画幅、时长、平台/模型、参考素材、硬约束和排除项。将用户已经明确的角色事实、时代、服装、色彩、世界规则和既有资产保存为 Canon。不得把推测当成已确认事实。

### A1：资产清单与唯一 ID

先生成资产清单，不立刻生成分镜图。为每项资产分配稳定 ID，例如 `CHAR-001`、`SCENE-001`、`PROP-001`、`SHOT-S01-001`。同一角色跨场景必须沿用相同角色 ID；换装属于有版本号的服装状态，不另造一个“新角色”；同一物理场景的不同机位是同一场景资产的视角引用，不是新空间。

### A2：锁定资产规格

人物规格至少包含：姓名/ID、年龄区间、身高、体型比例、脸部轮廓、眉眼鼻唇、肤色与皮肤细节、眼睛颜色、发型发色、识别标记、基础服装、服装材质、配饰、鞋履、体态、惯用手、声音锚点（若需要）、可变字段和禁止变化字段。

场景规格至少包含：场景 ID、室内/室外、时代和地域、空间长宽高或相对尺度、入口出口、墙体/窗/门/楼梯/桌椅等固定锚点、地面材质、主次光源位置、光照方向、色彩基调、可移动物体、不可穿越边界、人物可行走路径。

道具规格至少包含：道具 ID、外轮廓、尺寸级别、材质、颜色、磨损状态、开合/握持方式、初始位置、持有者、损伤/状态变化规则。

### A3：生成角色资产图与场景资产图

在可用图像生成工具存在时，分别生成角色资产图和场景资产图；没有工具时，只交付可以实际投喂的完整提示词、参考图规格和待生成清单，不得声称图像已经生成。角色资产图优先使用统一中性背景、多视图和足够清晰的身份锚点；场景资产图优先使用可读的整体布局图、关键视角和稳定空间标志。道具资产可与不依赖其他资产的项目并行准备。

角色资产生成提示必须强调“同一角色的多视图，不是多个相似角色”，不得让正面、侧面、背面视图各自重新设计脸型、年龄、身材、发型或衣服。场景资产生成提示必须强调“同一场景的不同观察角度”，固定建筑结构、开口位置和关键锚点不得因视角变化而改变。

### A4：资产核验与锁定

先检查身份锚点是否一致，再检查结构与材质，然后核查时代、道具、比例、服装、光源和画幅。所有 P0/P1 缺陷修复前不得锁定。若用户没有明确表达审批流程，可以把通过自动核验的结果标记为 `locked_provisional`（暂定锁），并明确它尚未得到用户人工确认；不得伪装成用户已批准。

每次锁定必须记录：资产 ID、版本、状态、规范文件路径或参考图 ID、SHA-256（可用时）、锁定字段、可变字段、核验人/来源、核验时间、质量结果、依赖资产和回滚版本。

### A5：建立场景空间账本

场景图核验后，建立固定空间坐标系。坐标原点必须有可见参照物，例如房间内角、门框中心或地面标记。人物位置使用空间坐标或明确定义的相对位置；仅写“左边、旁边、附近”不足以支持复杂多镜头连续性。

每个角色状态至少记录：角色 ID、世界坐标/场景坐标、身体朝向、头部朝向、眼睛注视目标、重心落点、动作阶段、双手状态、持有道具、与其他角色的距离、与墙/门/家具的距离。每个镜头还要记录摄影机位置、高度、朝向、焦段、画面轴线、人物屏幕位置、视线关系和镜头进出状态。

### A6：只用锁定资产生成分镜资产

当用户需要分镜图、关键帧或逐镜图像时，逐镜资产必须显式引用锁定的角色资产 ID/图像引用和场景资产 ID/图像引用，并注明该镜头允许改变的字段（姿势、表情、相机视角、景别、局部光线或剧情允许的服装状态）。禁止把整套角色外观和场景结构重新自由描述成另一套互不兼容版本；提示词要写明“身份、服装基准、场景结构继承引用资产，仅执行本镜头动作与机位变化”。

### A7：分镜资产门禁

每镜检查：人物身份是否匹配、衣服/发型/配饰是否匹配、场景结构是否匹配、摄影机是否位于可行位置、人物看向的目标是否存在、视线是否相交、动作能否在时长内完成、人与人距离是否支持动作、手与道具是否接触正确、重心与受力是否合理、进出画方向是否衔接、镜头结束状态是否能成为下一镜起始状态。任一关键错误都应返回对应的资产规格、空间账本或分镜阶段修复，不能只在最终提示词里加一句“保持一致”了事。

## 4. 版本和变更影响

规范资产采用语义版本或递增版本，如 `CHAR-001@1.0.0`。面部、体型比例、识别标记、场景墙体/门窗布局等变更属于重大变更，必须升级主版本；服装状态或可移动道具变化要按 Canon 建立明确子状态。任何规范资产变更都要查询依赖它的场景、分镜、提示词和已生成图像，标记受影响产物为 `needs_recheck`，并运行相关回归检查。

不能因为新生成图更漂亮就自动替换规范资产。视觉质量优化先作为候选版本，只有通过身份/空间/风格检查后才晋级。若不同参考图存在冲突，优先级为用户最新明确指令 > 用户指定的规范参考图 > 已锁定资产 > 文本推断 > 生成模型的随机细节。

## 5. 禁止的错误流程

1. 先做所有分镜图，最后才建立人物与场景设定。
2. 让每个分镜提示词重新随机决定角色脸型、身高、衣服、发型和配饰。
3. 用“场景气氛一致”代替门窗、墙体、楼梯、家具等固定空间结构一致。
4. 没有坐标基准，却声称计算出绝对距离或摄影机精确位置。
5. 没有生成工具返回结果，却将提示词输出描述为资产图已生成。
6. 修改锁定资产却不升级版本、不检查下游引用。
7. 把不同镜头角度误当成不同场景，并在镜头间改变空间布局。

## 6. 输出合同

资产前置任务至少交付：资产目录、唯一 ID、角色规格卡、场景规格卡、道具规格卡、生成提示词或图像引用、锁定状态、质量检查表和尚未解决的风险。需要分镜资产时，额外交付“分镜 → 角色资产 ID → 场景资产 ID → 道具资产 ID → 空间起态/终态 → 可变字段”的引用矩阵。

## 7. 路由和引用方式

出现“先定人物和场景”“角色资产锁定”“资产不要漂移”“先出角色设定图和场景设定图”“用同一角色参考图做每镜”“分镜资产引用角色图/场景图”“锁定脸型服装”“固定空间布局”等意图时，触发 `asset_locking`，并叠加 `asset_first`、`character_design`、`spatial_continuity` 与 `quality_assurance`。完整剧本制作通过资产锁定门禁之后才能进入 `storyboard`、`video_prompt` 和模型适配阶段。
