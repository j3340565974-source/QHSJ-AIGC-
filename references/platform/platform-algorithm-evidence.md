# Platform Optimization Evidence Framework

Internal ranking models are generally not public in full. This module therefore provides a falsifiable optimization layer rather than inventing proprietary weights.

## 抖音

### Observable signals
Primary experiment vector: stop-scroll rate, first-window retention, average watch time, completion, rewatches, meaningful interactions, shares/saves, profile actions, follower conversion, content-topic relevance and negative feedback.

### Experiment design
A/B test only one major variable per batch: opening frame, hook wording, cut timing, proof density, caption density or CTA. Hold core asset identity constant. Minimum sample size is determined by available traffic; report uncertainty rather than declaring a universal threshold.

### 30-second normalized structure
0–3s: visual/verbal premise; 3–8s: proof or escalation; 8–15s: complication; 15–22s: reveal or second payoff; 22–30s: resolution plus next curiosity or CTA. The engine rescales this structure to other runtimes instead of claiming the timings are platform rules.

### Metrics record
```yaml
platform: "抖音"
experiment_id: "EXP-001"
variables: ["hook_A", "hook_B"]
control: "same_assets"
metrics: ["chosen_to_view", "watch_time", "completion", "share", "comment", "follow"]
confidence_interval: "recorded_from_observed_data"
status: heuristic
```

### Claim filter
Any statement like “the algorithm weights X exactly Y%” is rejected unless an authoritative source exposes that exact rule. Public guidance is used as evidence of direction, not proof of a proprietary score.
