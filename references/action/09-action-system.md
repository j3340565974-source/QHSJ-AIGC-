## 1. 总公式

```
打斗分镜 = 基础风格 + 世界观 + 角色 + 五幕结构 + 单镜卡 + 节奏曲线 + 声音设计 + 因果闭环
```

---

## 2. 单镜公式

```
[时长] + [景别] + [角度] + [运镜] + [主体动作] + [对手反应] + [环境反馈] + [特效] + [声音] + [台词/情绪]
```

---

## 3. 燃点公式

```
燃 = 因果闭环 ×（冲突升级 + 节奏张弛 + 冷暖对冲 + 空间破坏 + 角色反差 + 声音爆点）
```

**因果为0，燃点为0。**

## 4. 五幕阶段公式

```
出场建立 → 高速混战 → 追击截杀 → 反派进化 → 终极斩杀
```

### 4.1 第一幕：出场建立

- 展示主角实力
- 展示反派实力
- 建立世界观和规则
- 第一次试探性交手

### 4.2 第二幕：高速混战

- 快速攻防转换
- 节奏加快
- 展示更多招式
- 环境开始被破坏

### 4.3 第三幕：追击截杀

- 一方占上风
- 另一方逃跑/被追击
- 空间转移
- 危机升级

### 4.4 第四幕：反派进化

- 反派爆种/升级
- 主角陷入绝境
- 最黑暗时刻
- 主角觉醒/突破

### 4.5 第五幕：终极斩杀

- 最终对决
- 全力一击
- 高潮爆点
- 收尾

## 6. 动作因果闭环

每一个动作必须有因果：

```
攻击 → 防守 → 反击 → 位置变化 → 下一回合
```

**铁律**：
- 动作不重复
- 因果必推进
- 每一招都有目的
- 每一次碰撞都有反馈

---

## 7. 关节链速查

每个动作都要有关节链：

```
起势 → 发力 → 峰值 → 收势
```

四阶段完整，不能跳。

## 13. 巨物专项引擎

### 13.1 逻辑矛盾自动修正

| 矛盾类型 | 冲突表现 | 自动修正 |
|----------|----------|----------|
| 画幅冲突 | 9:16竖屏+巨物全貌 | 改"极致仰拍+局部特写"，以局部压迫感替代全貌 |
| 比例冲突 | 要2.35:1但模型只支持16:9 | 输出16:9，标注"建议后期裁切为2.35:1" |
| 尺度冲突 | 巨物远超镜头视野 | 增加"大气透视、体积雾、地平线遮挡"暗示尺度 |
| 质感冲突 | 画面发灰、塑料感 | 强制注入"PBR微表面、粗糙度贴图、经纬编织、SSS"，负向锁"平滑布料、纯色贴图" |
| 光影冲突 | 巨物自带能量+自然光 | 切换为"巨物能量为主光，环境光辅助"，极高反差8:1 |
