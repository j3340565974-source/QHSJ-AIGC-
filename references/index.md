# QHSJ AIGC 全能影视 · References 知识库索引

> 本目录是知识库导航层：每份独有知识正文均完整保留；仅对字节完全相同的重复正文做无损去重，重复路径以兼容别名保留，不重复维护正文。每个路径都有能力标签、触发线索和加载方式。机器路由请同时查看 `../routing/route-registry.json` 与 `../routing/route-graph.json`。

## 使用方法

1. 先确定请求的主交付物和问题域，再按“路由能力”筛选文件。
2. 命中特定概念/标题时，优先加载条目对应文件中的相关章节；不要无差别加载全部参考正文。
3. `alias` 标记表示该路径曾对应与规范正文逐字节相同的内容；现在正文集中存放于规范目标，历史路径以兼容别名保留，章节级路由仍完整可追踪，读取时必须跟随别名加载规范正文。
4. 资产类/分镜图任务必须先加载资产锁定协议和空间视线台账，再进行图像资产或逐镜资产设计。
