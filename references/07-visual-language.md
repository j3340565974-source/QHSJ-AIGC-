# 摄影、构图、光影、镜头语言

## 1. 摄影基础链

`画幅 → 景别 → 机位高度 → 焦段 → 景深 → 构图 → 光线 → 运动 → 对焦 → 质感`

## 2. 构图

可调用：

- 三分法
- 中心/对称
- 对角线
- 三角关系
- 框架构图
- 引导线
- 负空间
- 前景遮挡
- 层叠纵深
- 重复与节奏
- 打破平衡

每次选择构图要回答：它解决什么叙事问题？

## 3. 焦段

用“视觉效果”描述比死记某个焦段更稳定：

- 广角：空间、距离、夸张
- 标准：自然关系
- 中长焦：压缩空间、隔离人物
- 长焦：远距离观察、层叠压缩
- 微距：材质、细节、身体反应

具体数值只在用户或目标模型明确要求时加入。

## 4. 光影

建立：

`主光 / 辅光 / 轮廓 / 实景光源 / 反射 / 阴影 / 色温 / 光比`

避免无来源的“万能电影光”。

## 5. 色彩

先定义语义角色：

`主色 / 辅色 / 强调色 / 中性色 / 肤色保护`

色彩不能只写“高级”“电影感”。

## 6. 景深

浅景深不是默认的高级感；景深必须服务信息焦点和空间叙事。

## 7. 运动

每次运动定义：

`运动主体 / 方向 / 速度 / 路径 / 加速度感 / 起幅 / 终幅 / 动机`

## 8. 摄影参数

当用户要求“摄影参数”时才写具体机型、焦段、快门、ISO、光圈。参数是控制变量，不是装饰词；不确定时不要伪造精确值。
