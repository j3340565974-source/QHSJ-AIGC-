## 1. 场景解剖三层结构（好莱坞置景标准）

### 1.1 部门分工
| 部门 | 职责 |
|---|---|
| Production Designer 美术指导 | 整体视觉世界 |
| Art Director 艺术指导 | 执行落地 |
| Set Decorator 置景师 | 陈设摆放 |
| Prop Master 道具师 | 演员手持道具 |
| Construction 置景施工 | 搭建墙体平台 |
| Greens 绿植组 | 植物 |
| Graphics 平面组 | 招牌/标签/文件 |

### 1.2 场景三层解剖
1. **Set（硬景）**：建筑、墙、地板、天花板、窗、固定装置。
2. **Set Dressing（陈设）**：家具、装饰、背景物件——演员不碰的。
3. **Props（手持道具）**：演员拿起/使用/交互的一切——手机、武器、书、食物、工具。

### 1.3 陈设三层叠法（base → mid → hero）
- **Base 底层**：基础环境（墙色、地板、大件家具位置）。
- **Mid 中层**：装饰层（窗帘、挂画、书架、灯具）。
- **Hero 英雄层**：特写/剧情 beat 中出现的重点道具，要有额外细节、可功能化、备替换版。

> **AI 场景 prompt 应用**：写场景时按 base→mid→hero 三层写，不要只写"一个房间"。

## 2. 中国题材美术参考体系（封神范式）

《封神第一部》确立的东方美学方法论，可复用于一切上古/仙侠/历史题材：

### 2.1 视觉基因来源
- **元明道教水陆画**：神仙族谱形象、神祇排位构图。
- **永乐宫壁画**：人物造型、衣纹线条、壁画矿物色。
- **北宋山水画**：超然气韵、空间留白、青绿山水。
- **商周青铜器**：巫元素、饕餮纹、青铜礼器造型。

### 2.2 三界空间体系
- **人界**：人间王城、战场、市井。
- **妖界**：轩辕坟、九尾狐巢穴、幽暗诡谲。
- **仙界**：玉虚宫、昆仑、云海仙山。
- 三界独立又相互关联，色彩与材质各成体系。

### 2.3 陈设隐喻（摘星阁案例）
- 商王卧榻由数根钢绳悬空吊起，像超大秋千——暗示王权的飘摇。
- 床柱手工雕刻蟠龙，顶端雕首尾相织的狐狸（妲己）与饕餮（殷商图腾）——暗示殷寿与妲己的命运纠缠。
- 卧榻整体金红配色——奢华、欲望、权力。

> **AI 应用**：重要场景的核心道具要带"叙事隐喻"，不要只是好看。

## 3. 道具做旧与时代还原（古董局中局 / 我不是药神）

### 3.1 古董道具做旧流程
1. 历史考证：查大量资料，数易其稿。
2. 反复打样：先做外观造型。
3. **做旧**：让新道具变成"用过几百年的古董"——包浆、磨损、划痕、氧化、土沁。
4. 戏用道具（佛头、子母镜、汉代金印）要额外精度，因为会给特写。

### 3.2 时代还原（我不是药神，2000 年代上海）
- 按设计稿重新搭建实景，不依赖现成街景。
- 道具事无巨细：旧广告牌、搪瓷杯、旧电话、90 年代服装、斑驳墙面。
- 风格化美术手法还原"现实而残酷的时代印象"。

### 3.3 地域特色场景（闽南古厝案例）
- 外景选闽南民居，因为周围巷道丰富——主角偷偷回家时可以穿胡同躲避。
- **场景周边环境和场景本身一样重要**：不是只拍一间屋，而是拍"人在这片街区里怎么移动"。
- 内景保留古厝木构、红砖、神龛、老式家具。

## 4. AI 场景生成 Prompt 模板

### 4.1 三层场景模板
```
[Base 底层]：[空间类型]，[墙色/地板/大件家具]，[时代/地域]
[Mid 中层]：[窗帘/挂画/书架/灯具/装饰]
[Hero 英雄道具]：[特写道具，带叙事隐喻]
[光影]：[时间/光源/色温]
[氛围]：[情绪关键词]
```

### 4.2 实战范例：古风仙侠洞府
```
Base：天然溶洞石室，粗粝岩壁，地面潮湿青石板，一张石案居中；
Mid：壁上插满火把，火光摇曳，石案上散落竹简与青铜灯台，
     角落堆着干枯药草，蛛网垂落；
Hero：石案中央一尊青铜香炉，炉身饕餮纹，香烟袅袅升起，
      炉下压着半卷泛黄的羊皮地图；
光影：火把暖橙光，岩壁阴影深黑，体积光穿过烟雾；
氛围：神秘、古朴、暗藏机关。
```

### 4.3 实战范例：2000 年代中国小饭馆
```
Base：90 年代国营饭馆，白灰墙皮斑驳，水泥地面，折叠方桌；
Mid：墙上褪色菜单黑板，搪瓷杯，吊扇缓慢转动，墙角旧冰柜；
Hero：桌上一瓶塑料瓶装可乐，标签泛黄，旁边是搪瓷碗和竹筷；
光影：头顶日光灯惨白，窗外透进黄昏暖光；
氛围：粗粝、纪实、时代感。
```

## 5. 场景布置检查清单（写 prompt 前过一遍）

- [ ] **时代**：哪个年代？有没有时代错误的物件？
- [ ] **地域**：南方/北方/西域/闽南？建筑形态对不对？
- [ ] **阶层**：穷人/富人/宫廷/市井？家具档次匹配吗？
- [ ] **Base 层**：墙、地、顶、大件家具写了吗？
- [ ] **Mid 层**：装饰、灯具、窗帘、挂画写了吗？
- [ ] **Hero 道具**：特写道具是什么？有没有叙事隐喻？
- [ ] **做旧**：新/旧/破旧/古董？磨损程度？
- [ ] **周边环境**：角色在场景外怎么移动？巷道/街道/邻居？
- [ ] **光影**：时间、光源方向、色温？
- [ ] **空气**：烟/尘/雨/雾/花粉？
